## 🎯 목표

1. 성능 문제를 **직접 겪고** 오브젝트 풀링으로 해결한다
2. 밸런싱을 마친다
3. **PC 빌드를 산출하고 전원 백업한다**

## 🗓 회차 배분

| 회차 | 내용 |
|---|---|
| 101 | **일부러 렉 만들기** — 몬스터 200마리 소환, 프로파일러로 원인 확인 |
| 102–103 | 오브젝트 풀링 구현 (몬스터 → 총알) |
| 104 | 밸런싱 + 교차 플레이 피드백 / 빌드 설정 |
| 105 | **PC 빌드 산출 → 서로 다운받아 플레이 → 전원 백업 확인** |

> ⚠️ **순서 엄수.** 풀링을 먼저 설명하면 "왜 이걸 하는지" 모른 채 코드만 베낀다. 반드시 렉을 먼저 겪게 한다.

## ✅ 종료 조건 — 전원 통과 필수

- [ ] 몬스터가 많아져도 프레임이 유지된다
- [ ] 타이틀부터 클리어/게임오버까지 완주된다
- [ ] **빌드한 실행 파일이 다른 사람 PC에서 실행된다**
- [ ] **프로젝트 압축본 + 빌드 파일이 백업됐다**

> ⚠️ **한 명이라도 빌드가 안 나오면 Phase 9로 넘어가지 않는다.** 버퍼를 여기 쓴다.
