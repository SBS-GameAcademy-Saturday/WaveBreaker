## 🎯 목표

1. 해상도가 달라도 **안 깨지는 UI**를 만든다
2. HUD로 게임 상태가 **한눈에 읽히게** 한다
3. 타이틀 → 게임 → 결과를 연결한다
4. 타격감과 사운드로 **"게임처럼" 느껴지게** 한다

> 🔑 **Phase 6까지 재미는 있지만 못생겼다.** 학생이 남에게 보여줄 수 있는 물건이 되는 게 Phase 7이다.
> 여기서 만든 화면이 26주차 발표 자료가 된다.

## 🗓 회차 배분

### 19주차 (091–095) — UI 기초와 HUD ✅

| 회차 | 주제 | 골드메탈 |
|---|---|---|
| 091 | **Canvas와 Canvas Scaler** — 해상도 대응 | 10 |
| 092 | **RectTransform · Anchor · Pivot** | 10 |
| 093 | **TextMeshPro** + 한글 폰트 적용 | 10 |
| 094 | HUD ① — 체력바 · 경험치바 | 10 |
| 095 | HUD ② — 레벨 · 생존 시간 · 처치 수 | 10 |

> 🚨 **091~092가 Phase 7의 최대 난관이다.** Anchor는 노베이스가 가장 많이 틀리는 개념이다.
> 💬 **"Anchor는 '이 UI가 화면의 어디에 붙어 있을지'를 정하는 겁니다."**
> 창 크기를 실제로 늘였다 줄이며 **어긋나는 걸 눈으로 보여준 뒤** 고친다.
>
> ⚠️ **한글 폰트 TMP 애셋은 강사가 미리 만들어 배포한다.** 학생이 각자 생성하면
> 폰트 라이선스·생성 시간·설정 차이로 회차가 통째로 날아간다.

### 20주차 (096–100) — 화면 연결과 연출 ✅

| 회차 | 주제 | 골드메탈 |
|---|---|---|
| 096 | **레벨업 선택창** UI 제작 | 11 |
| 097 | **타이틀 · 결과 화면** + 씬 전환·데이터 유지 | 13 |

| 100 | **사운드** (`AudioSource`) + 전체 연결 점검 | 15 |

> 🔑 **097회차에 "씬을 넘기면 점수가 사라지는" 사고를 일부러 겪게 한다.**
> 결과 화면으로 넘어갔더니 처치 수가 0이다. 그 뒤에 데이터 유지 방법을 준다.
> 원칙 4번(불편을 먼저)의 마지막 적용 지점이다.
>
> ✅ **완료 (095).** `CameraFollow` 가 `List<Transform> targets` 의 중심을 따라간다.
> 지금은 원소가 1개라 068과 동작이 같다 — 카메라·플레이어 거리 `0.00` 실측.
>
> 📌 **카메라는 094~095 사이에 정리한다.** Phase 5에서 만든 추적 카메라를
> **"플레이어 하나를 따라간다" → "플레이어 목록의 중심을 따라간다"** 로 바꿀 수 있게 구조만 잡아둔다.
> 목록의 원소가 1개면 동작이 완전히 같다. **Phase 9에서 이 한 곳만 고치면 협동 카메라가 된다.**
> ([기획서 6절](../00_기획/확정-게임기획서.md))

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **UI가 화면 밖으로 나감** | Anchor 설정 | **Phase 7 최다.** 창 크기를 바꿔가며 눈으로 확인시킨다 |
| **한글이 네모(□)로 나옴** | TMP 폰트 애셋 없음 | **강사 배포본을 쓴다.** 학생이 만들게 하지 않는다 |
| UI를 Scene에서 못 찾음 | Canvas가 아주 큼 | Hierarchy에서 클릭 후 `F` |
| 버튼이 안 눌림 | 다른 UI가 위를 덮음 / `Raycast Target` | 겹친 요소를 끈다 |
| 씬 넘기니 점수가 0 | **의도된 사고 (097)** | 그 뒤에 데이터 유지를 가르친다 |
| 일시정지 후 재개 안 됨 | `timeScale` 복구 누락 | 084회차와 같은 문제. 연결해 설명 |
| 셰이크가 너무 심해 어지러움 | 수치 과다 | 인스펙터로 줄인다. **"연출은 과하면 독"** |
| 효과음이 겹쳐 시끄러움 | 동시 재생 수 제한 없음 | 최소 간격을 둔다 |
| 파티클에 시간을 다 씀 | 재밌어서 빠진다 | 099회차는 **1시간만**. 나머지는 도전 과제 |
| 진도가 밀림 | 10회차는 빠듯하다 | **사운드부터 축소** (기획서 16절 4순위) |
