# Phase 3 · 유니티 2D 핵심

| | |
|---|---|
| **회차 / 주차** | 041–055 (15회) / 9~11주차 |
| **선행** | Phase 2 |
| **산출물** | 총알이 몬스터를 맞히면 체력이 깎이고 죽는 씬 + 미니게임 ① 착수 |

## 🎯 목표

1. 2D 물리와 충돌을 처리한다
2. 프리팹으로 오브젝트를 동적 생성한다
3. 다른 오브젝트의 컴포넌트를 제어한다
4. 코루틴으로 시간차 스폰을 만든다

## 📚 다루는 내용

| 주차 | 내용 |
|---|---|
| 9주 (041–045) | Rigidbody2D / 물리 기반 이동 / Collider2D·isTrigger / OnTriggerEnter2D / Tag / Layer Collision Matrix |
| 10주 (046–050) | **Prefab** / Instantiate 총알 발사 / 몬스터 동적 생성 / Destroy / **GetComponent** / 체력·피격 |
| 11주 (051–055) | **코루틴**(IEnumerator·yield·WaitForSeconds) / 일정 간격 스폰 / Sprite·Animator 기초 / 미니게임 ① 착수 |

## ✅ 종료 조건

- [ ] 총알이 몬스터에 닿으면 이벤트가 발생한다
- [ ] Tag로 "몬스터만" 골라 반응한다
- [ ] 프리팹 원본을 고치면 전부 반영된다
- [ ] `GetComponent`로 다른 오브젝트 체력을 깎는다
- [ ] 코루틴으로 2초마다 몬스터를 생성한다
- [ ] 체력이 0이면 몬스터가 사라진다

## 📦 스냅샷 — `Snapshot_P3`

플레이어 + 몬스터 프리팹 + 총알 + 코루틴 스폰 + 체력 시스템.

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **충돌이 아예 안 일어남** | 이 Phase 질문의 70% | 체크리스트 고정: 둘 다 Collider 있나 / 하나는 Rigidbody2D 있나 / isTrigger 맞나 / Layer Matrix |
| 프리팹 원본과 씬 인스턴스 혼동 | 정상 | "씬에 있는 건 복사본, Project에 있는 게 원본" 반복 |
| `GetComponent` null 에러 | Null을 처음 만남 | "없는 걸 만졌다"로 설명. Phase 0의 디버깅으로 연결 |
| **코루틴에서 무너짐** | 정상. 이 Phase 최대 난관 | `yield`를 문법으로 설명하지 말 것. "여기서 잠깐 쉬었다 이어서" |
| Animator에 시간을 너무 씀 | 함정 | 걷기 1개면 충분. 파고들면 2주 날아간다 |

## ⏭ 연결

코루틴 스폰이 Phase 5 웨이브 매니저의 원형, 체력 처리가 `IDamageable`의 실전 적용이 된다.
