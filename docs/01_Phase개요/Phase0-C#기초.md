## 🎯 목표

1. C# 프로그램의 실행 흐름을 안다
2. 변수 · 연산자 · 조건문 · 반복문 · 배열 · 메서드를 쓴다
3. 에러 메시지를 읽고 스스로 고친다
4. 디버거로 변수값을 확인한다

## ✅ 종료 조건

- [ ] 콘솔 프로그램을 만들어 실행한다
- [ ] 자료형을 구분해 쓰고 형 변환을 한다
- [ ] 조건문·반복문으로 흐름을 제어한다
- [ ] 배열/List에 값을 담고 꺼낸다
- [ ] 메서드를 정의하고 호출한다
- [ ] 컴파일 에러에서 **파일명·줄 번호**를 찾아 고친다
- [ ] 중단점을 걸고 변수값을 확인한다

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **4주 내내 콘솔만 봐서 이탈** | 🔴 **이 Phase 최대 리스크** | 001회차 완성작 시연 필수 · 매주 마지막 회차 결과물 발표 · 실습 예제를 **게임 문맥**(체력·데미지·몬스터 스탯)으로 구성 |
| "이거 게임이랑 무슨 상관이에요" | 정상적 의문 | 그 문법이 게임 어디에 쓰이는지 **한 줄로** 예고. "이 반복문이 나중에 몬스터를 줄 세웁니다" |
| 세미콜론·중괄호 오타 지옥 | 1~2주차 질문의 대부분 | 2주차에 "자주 나는 에러 유형표"를 배포하고 벽에 붙이게 한다 |
| 반복문에서 급격히 막힘 | 정상. 3주차 최대 난관 | 3주차를 서두르지 않는다. 필요하면 버퍼 투입 |
| 배열 인덱스 혼동 | 정상 | "0부터 센다"를 손으로 여러 번 |
| 진도 빠른 학생이 지루해함 | 흔함 | 콘솔 과제 난이도를 열어준다(⭐도전). **유니티를 미리 알려주지 않는다** |
