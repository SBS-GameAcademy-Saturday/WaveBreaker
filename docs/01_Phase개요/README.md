# Phase 개요

전체 130회를 11개 Phase(0~10)로 나눈 각각의 설계 문서. **회차별 강의안(`02_수업계획서/`)을 쓰기 전에 해당 Phase 문서를 먼저 확정한다.**

> **현재 구성: C# 선행.** 1~4주차 C# 문법 전용(콘솔) → 5~6주차 객체지향 → 7주차부터 C# + 유니티 병행.
> 게임 제작을 1주차부터 시작하던 옛 구성의 문서는 [`_구버전_게임우선/`](./_구버전_게임우선/README.md)에 보관돼 있다. **회차 번호가 다르므로 섞어 쓰지 않는다.**

## 문서 구조 (전 Phase 공통)

| 섹션 | 용도 |
|---|---|
| 상단 표 | 회차 범위 / 기간 / 선행 / 산출물 |
| 🎯 목표 | 이 구간이 끝났을 때 학생이 할 수 있어야 하는 것 |
| 📚 다루는 내용 | 주제 목록과 다루는 깊이 |
| 🗓 회차 배분 | 회차 범위 → 주제. 강의안 작성의 뼈대 |
| ✅ 종료 조건 | 통과 못 하면 다음 Phase로 못 간다 |
| 📦 스냅샷 | 이 Phase 끝에 배포할 프로젝트 상태 |
| 🚨 위험 신호 | **강사용.** 이 구간에서 반에 무슨 일이 벌어지는가 |
| ⏭ 연결 | 다음 Phase로 무엇이 이어지는가 |
