# Phase 6 · UI · 연출 · 사운드

| | |
|---|---|
| **회차** | 086–097 (12회) |
| **기간** | 2.5주 |
| **선행** | Phase 5 |
| **산출물** | 타이틀 → 인게임 → 결과까지 완결된 게임 |

## 🎯 목표

1. Canvas / RectTransform으로 해상도에 대응하는 UI를 만든다
2. 게임의 모든 화면을 연결한다
3. 타격감을 만든다 (파티클 · 셰이크 · 사운드)

> 💡 **연출 1회차가 밸런싱 5회차보다 학생 만족도를 올린다.** 7개월 중반 권태기를 넘기는 회복 지점으로 의도 배치된 구간이다. 시간을 아끼지 말 것.

## 📚 다루는 내용

| 주제 | 깊이 |
|---|---|
| Canvas / Canvas Scaler | 해상도 대응. **Scale With Screen Size 고정** |
| RectTransform / Anchor / Pivot | **이 Phase의 핵심.** 여기서 막히면 전부 막힌다 |
| TMP 텍스트 | 한글 폰트 애셋 (**강사가 미리 생성해 배포**) |
| HUD | 체력바, 웨이브, 남은 적 수, 보유 무기 |
| 업그레이드 선택창 | 카드 3장 + 아이콘 |
| 씬 전환 | 타이틀 → 인게임 → 결과 |
| 일시정지 | `Time.timeScale` |
| 파티클 | 피격·폭발·머즐 플래시 |
| 카메라 셰이크 / 히트스톱 | 타격감 |
| 사운드 | AudioSource, SFX, (BGM 정책은 에셋 문서 참고) |

## ✅ 종료 조건

- [ ] 창 크기를 바꿔도 UI가 깨지지 않는다
- [ ] 체력·웨이브·적 수가 실시간으로 보인다
- [ ] 타이틀에서 시작해 결과 화면까지 끊기지 않는다
- [ ] ESC로 일시정지되고 다시 풀린다
- [ ] 적을 맞히면 이펙트와 소리가 난다
- [ ] 업그레이드 카드 3장이 아이콘과 함께 뜬다

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **UI가 해상도 바꾸면 다 깨짐** | Anchor 미이해. 이 Phase 질문의 대부분 | 086–088을 절대 서두르지 않는다. **필요하면 1회 추가** |
| TMP 한글 폰트 애셋 생성에 하루 소모 | 🔴 예방 가능한 사고 | **강사가 미리 만들어 배포.** 학생이 각자 하면 회차 하나가 통째로 날아간다 |
| 연출에 빠져 진도 안 나감 | 흔하고, 어느 정도는 좋다 | 필수/⭐도전으로 선을 긋되 너무 조이지 말 것 |
| 씬 전환 후 데이터가 사라짐 | 정상적 난관 | "씬이 바뀌면 다 없어진다"를 먼저 겪게 한 뒤 해결 |
| 여기서 만족도가 확 오름 | 의도한 것 | ✅ 권태기 회복 확인 |
