# Phase 1 · C# 기초 (게임 안에서)

| | |
|---|---|
| **회차** | 009–028 (20회) |
| **기간** | 4주 |
| **선행** | Phase 0 |
| **산출물** | 키보드로 움직이고 총알을 쏘는 캐릭터 |

## 🎯 목표

1. 변수 · 조건문 · 반복문 · 함수 · List를 **게임 안에서** 쓴다
2. 키보드 입력으로 캐릭터를 조종한다
3. `Instantiate`로 총알을 만든다
4. 위 전부를 **혼자 처음부터** 만들 수 있다

## 📚 다루는 내용

| 문법 | 게임에서 배우는 형태 | 회차 |
|---|---|---|
| 변수 / 자료형 / `[SerializeField]` | 속도·체력·이름을 Inspector에서 조절 | 009–012 |
| 입력 | WASD 이동, `Input.GetAxis` | 013–015 |
| 조건문 | 화면 밖이면 제거, 체력 0이면 사라짐 | 016–018 |
| `Time.deltaTime` | 프레임과 무관한 속도 | 019 |
| 반복문 / 배열 | 적 10마리 한 줄 생성 | 020–022 |
| 함수 | `Move()`, `Fire()`로 쪼개기 | 023–024 |
| `Instantiate` / 프리팹 맛보기 | 총알 발사 | 025–026 |
| `List` | 총알·적 여러 개 관리 | 027 |
| 종합 실습 | 움직이고 쏘는 캐릭터 혼자 만들기 | 028 |

> ❌ **여기서 안 하는 것**: 클래스 설계, 상속, 인터페이스, `static`, 접근제한자 깊이. 전부 Phase 4.
> 💡 `public` vs `[SerializeField]` 질문이 반드시 나온다 → "둘 다 되지만 `[SerializeField]`가 더 안전, 이유는 4단계에서."

## ✅ 종료 조건

- [ ] 변수를 만들고 Inspector에서 조절할 수 있다
- [ ] `float`/`int`/`bool`/`string`을 구분해 쓴다
- [ ] WASD로 캐릭터를 움직인다
- [ ] 조건문으로 "화면 밖이면 제거"를 구현한다
- [ ] 반복문으로 여러 개를 한 번에 만든다
- [ ] 함수를 만들어 호출한다
- [ ] 스페이스로 총알을 발사한다
- [ ] **위 전부를 빈 프로젝트에서 혼자 재현한다** ← 진짜 기준

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **복붙만 하고 이해 못 함** | 이 Phase 최대 위험 | 회차 끝 "빈 화면에서 다시 쳐보기" 5분 고정 |
| 019회차 `Time.deltaTime`에서 급격히 막힘 | 정상. 추상도가 처음 올라감 | 수식 설명 금지. "프레임마다 다른 시간을 곱한다" + 눈으로 비교 |
| 진도 편차가 처음 벌어짐 | 정상 | ⭐도전 미션으로 흡수. **필수 미션 난이도는 절대 올리지 않는다** |
| 020회차 이후 제출 급감 | 반복문에서 무너짐 | 반복문을 2회 더 쓰고 다음으로 (버퍼 사용) |

> 📌 **이 Phase가 20회로 가장 길다.** 여기서 밀리면 전체가 밀린다. 019·020회차를 진도 점검 지점으로 삼는다.
