# Phase 0 · 적응 & 첫 성취

| | |
|---|---|
| **회차** | 001–008 (8회) |
| **기간** | 1.5주 |
| **선행** | 없음 |
| **산출물** | Unity 설치 완료 + 코드 한 줄로 움직이는 물체 |

## 🎯 목표

1. 7개월 뒤 만들 게임을 **눈으로 봤다**
2. Unity 6 LTS 개발 환경이 **전원 동일하게** 세팅됐다
3. GameObject / Component 구조를 손으로 안다
4. 스크립트를 붙여 물체를 움직여 봤다

> ⚠️ **이 Phase의 진짜 목표는 "재밌겠다"이지 지식이 아니다.** 비대면 수업은 1주차가 이탈률을 결정한다.

## 📚 다루는 내용

| 주제 | 깊이 |
|---|---|
| 완성작 시연 · 로드맵 | 동기부여용. 코드는 안 보여준다 |
| 설치 (Hub / 에디터 / VS Code) | **끝까지.** 한 명도 남기지 않는다 |
| 에디터 6개 창, 씬 조작 | 손에 익히기. `F` 키 훈련 필수 |
| GameObject & Component | Rigidbody 붙여서 물리로 놀기 (**코드 0줄**) |
| Play 모드 함정 | Play 중 변경은 저장 안 됨 |
| 첫 스크립트 | `Debug.Log`, `Start`/`Update`, `transform.position` |
| 에러 읽는 법 · 질문하는 법 | 파일명 + 줄 번호 찾기 |

> ❌ **여기서 안 하는 것**: 변수, 자료형, 클래스 설명. 학생이 `public class`가 뭐냐고 물으면 **"다음 주에 배웁니다"** 로 미루고 적어두게 한다.

## ✅ 종료 조건

- [ ] Unity 6 LTS가 설치되고 프로젝트가 열린다
- [ ] 에디터 6개 창의 역할을 말할 수 있다
- [ ] GameObject에 Component를 추가·제거할 수 있다
- [ ] 스크립트를 만들어 붙이고 `Debug.Log`를 띄울 수 있다
- [ ] `Start`와 `Update`의 차이를 한 문장으로 말할 수 있다
- [ ] Console 에러에서 **파일명과 줄 번호**를 찾을 수 있다
- [ ] Play 중 변경은 저장되지 않음을 안다
