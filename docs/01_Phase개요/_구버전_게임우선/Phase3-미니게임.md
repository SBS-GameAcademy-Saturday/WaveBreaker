# Phase 3 · 미니게임 3개 완주

| | |
|---|---|
| **회차** | 044–055 (12회, 각 4회) |
| **기간** | 2.5주 |
| **선행** | Phase 2 |
| **산출물** | 처음부터 끝까지 만든 작은 게임 3개 |

## 🎯 목표

**"끝까지 만들어봤다"를 본 프로젝트 전에 3번 경험한다.**

완주 경험 없이 대형 프로젝트에 들어가면 길을 잃는다. 이 Phase는 새 기술을 배우는 구간이 아니라 **Phase 1~2를 조립해 완결시키는 구간**이다.

## 📚 미니게임 3종

### ① 피하기 게임 (044–047)

| | |
|---|---|
| 내용 | 위에서 떨어지는 장애물을 피하고 생존 시간 점수화 |
| 복습 | 입력·이동·조건문·`Instantiate`·코루틴 |
| 신규 | 점수 표시(간단 UI), 게임오버 |

### ② 벽돌깨기 (048–051)

| | |
|---|---|
| 내용 | 공이 튕기며 블록을 부수고, 전부 부수면 클리어 |
| 복습 | 반복문·배열(블록 배치), 충돌 |
| 신규 | 반사 처리, 클리어 판정 |

### ③ 웨이브 슈팅 (052–055) ★

| | |
|---|---|
| 내용 | 웨이브로 적이 오고, 다 잡으면 다음 웨이브. 체력 소진 시 게임오버 |
| 복습 | 전부 |
| 신규 | **웨이브 개념** |

> 🔑 ③번은 **본 프로젝트의 축소판**이다. 여기서 웨이브 구조를 손에 익히면 Phase 4 진입이 훨씬 부드럽다. 3개 중 하나만 남긴다면 ③번.

## 🗓 회차 배분 (각 게임 4회 공통 패턴)

| 회차 | 내용 |
|---|---|
| 1–3 | 강사와 같이 구현 |
| 4 | **개인 개조 + 시연** — 자유롭게 바꾸고 발표 |

> 4회차의 "개조"가 이 Phase의 핵심이다. 여기서 학생이 처음으로 **"내 게임"** 감각을 갖는다.

## ✅ 종료 조건

- [ ] 게임 3개가 시작부터 게임오버/클리어까지 돈다
- [ ] 각 게임을 자기 방식으로 하나 이상 개조했다
- [ ] 3개 모두 `#자랑` 채널에 시연 영상을 올렸다

## 📦 스냅샷 — `Snapshot_P3_1` / `_P3_2` / `_P3_3`

미니게임 3종의 완성본. 각각 독립 프로젝트로 배포.

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| 개조 시간에 아무것도 안 함 | 자유도가 오히려 부담 | **개조 예시 5개를 미리 제시.** "속도 2배", "장애물 색 랜덤" 수준으로 낮게 |
| 3개 다 미완성인 학생 | Phase 1~2가 안 쌓임 | **스냅샷으로 ③번만 완주시킨다.** 3개 다 시키려다 0개가 되는 게 최악 |
| 너무 잘해서 지루해함 | 좋은 신호 | 개조 자유도를 크게 열어준다. 본 프로젝트에 쓸 아이디어 저장 |
| 여기서 "이제 좀 알겠다" 발언 | 이 Phase의 목적 달성 | ✅ |

## ⏭ 연결

③ 웨이브 슈팅이 그대로 Phase 4 본 프로젝트의 출발점이 된다. Phase 4 첫 회차에서 "③번 기억나죠? 그걸 제대로 만들 겁니다"로 연결한다.
