# Phase 8 · 네트워크 협동

| | |
|---|---|
| **회차** | 106–123 (18회) |
| **기간** | 3.5주 |
| **선행** | **Phase 7 완료 + 전원 백업 확인** |
| **산출물** | 친구와 접속해서 같이 하는 게임 (+ 싱글 모드 유지) |
| **사양서** | [확정-게임기획서.md](../../00_기획/확정-게임기획서.md) 2장·12장 |

## 🎯 목표

1. 호스트/클라이언트 구조를 감각으로 이해한다
2. 두 플레이어가 서로의 화면에서 움직인다
3. 적을 호스트만 만들고 모두에게 보이게 한다
4. **싱글 모드를 "호스트 1인"으로 통합한다**

## 🔧 기술 스택

| 항목 | 선택 | 이유 |
|---|---|---|
| 네트워크 | **Netcode for GameObjects (NGO)** | Unity 공식, 패키지 매니저 설치, 개념 수가 적다 |
| 접속 | **Relay** | 포트포워딩·공유기 설정 불필요. 학생 집 네트워크가 제각각인 비대면에 필수 |
| 로컬 테스트 | **Multiplayer Play Mode (MPPM)** | Unity 공식. 에디터 하나에서 가상 플레이어 최대 3개 추가. **외부 도구·프로젝트 복제 불필요** |

> ⚠️ MPPM 제약: 가상 플레이어에서는 **GameObject 생성·수정과 Package Manager가 안 된다.** 수정은 메인 에디터에서. 첫 회차에 반드시 공지.

## 🗓 회차 배분

| 회차 | 주제 |
|---|---|
| 106–107 | 왜 멀티는 어려운가 — "각자 화면에서 따로 도는 게임 2개"라는 감각 |
| 108–109 | NGO 설치, NetworkManager, NetworkObject, 첫 로컬 접속 |
| 110–111 | **MPPM 세팅** — 한 PC 2인 테스트 (이후 모든 실습의 기본기) |
| 112–113 | `NetworkTransform` — 두 캐릭터가 서로 보인다 |
| 114–115 | Ownership — `IsOwner`, 내 캐릭터만 내가 조종 |
| 116–118 | `NetworkVariable` / `Rpc` — 체력·웨이브·업그레이드 동기화 |
| 119–120 | **호스트 권한 스폰** — 적을 호스트만 생성 (**Phase 4 규칙 ①의 회수**) |
| 121 | Relay + 접속 코드 입장 |
| 122 | **싱글/협동 모드 통합** — 타이틀 분기, [혼자 하기] = 호스트 1인 |
| 123 | 원격 합동 플레이 & 버그 잡기 (**[혼자 하기] 정상 동작 재확인**) |

> 📌 **주 1회 "합동 플레이 데이" 고정 편성.** 실제로 서로 접속해 노는 시간이 이 구간의 이탈을 막는다.

## ✅ 종료 조건

- [ ] 방을 만들면 접속 코드가 나온다
- [ ] 다른 사람이 코드로 입장한다
- [ ] 둘 다 움직이는 게 서로 보인다
- [ ] 적이 양쪽 화면에 똑같이 나온다
- [ ] 체력이 서로 보이고, 쓰러진 동료를 부활시킬 수 있다
- [ ] 둘 다 쓰러지면 게임오버가 된다
- [ ] **[혼자 하기]도 여전히 정상 동작한다** ← 통합 후 반드시 재확인

## 📦 스냅샷 — `Snapshot_P8_step1` ~ `_step4`

이 Phase는 **회차 단위 스냅샷을 더 촘촘히** 배포한다. 네트워크는 한 번 꼬이면 학생 혼자 못 푼다.

| 스냅샷 | 시점 |
|---|---|
| step1 | NGO 설치 + 로컬 접속 성공 (109) |
| step2 | 두 캐릭터 동기화 + Ownership (115) |
| step3 | 호스트 권한 적 스폰 (120) |
| step4 | Relay + 모드 통합 (122) |

## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **강사가 학생 화면 2개를 동시에 못 봄** | 이 Phase 구조적 난점 | **MPPM 표준화.** 학생이 혼자 2인 재현 가능해야 질문이 성립. 가상 플레이어 화면을 그대로 스크린샷 제출 |
| 접속이 안 되는 학생 | 네트워크 환경 문제 | Relay 사용, 포트포워딩 금지. 안 되면 그날은 로컬 2인으로 진행 |
| "동기화가 안 되는데 에러는 없어요" | 네트워크 버그의 전형 | 눈에 안 보이는 버그다. **`Debug.Log`에 `IsServer`/`IsOwner`를 찍는 습관**을 108회차부터 강제 |
| 통합하다 싱글을 깨먹음 | 🔴 이 구조의 유일한 함정 | 122회차 직전 백업. 123회차 재확인을 절대 생략하지 않는다 |
| Phase 4 규칙 ①②를 안 지킨 학생 | 전면 재작성 위기 | 해당 학생은 **step3 스냅샷으로 갈아탄다.** 고치는 것보다 빠르다 |
| 진도 포기자 발생 | 예상된 것 | **Phase 7 완성본이 있다.** "넌 이미 게임 하나 만들었다"를 명확히 말해줄 것 |
