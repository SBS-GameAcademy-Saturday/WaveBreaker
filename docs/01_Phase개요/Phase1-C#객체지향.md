## 🚨 위험 신호 (강사용)

| 신호 | 의미 | 대응 |
|---|---|---|
| **상속에서 반이 무너짐** | 정상. 첫 추상 개념 | 다이어그램 금지. **중복 코드를 복사해 부모로 올리는 과정을 실시간으로** 보여준다 |
| "인터페이스 왜 써요? 상속으로 되는데" | 좋은 질문 | "몬스터랑 플레이어는 부모가 다른데 둘 다 맞아야 하잖아요" — 한 문장이면 된다 |
| property를 왜 쓰는지 모름 | 흔함 | "필드를 그냥 열면 아무나 체력을 -999로 바꿉니다"로 접근 |
| static을 남용하기 시작 | 위험 | 카운터·설정값 정도로 제한. "편해 보이지만 나중에 꼬입니다" |
| 6주차에 유니티 기대가 최고조 | 좋은 신호 | 7주차 예고를 확실히. "다음 주부터 화면에서 움직입니다" |
