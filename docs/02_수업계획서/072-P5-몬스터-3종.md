## 00:00–00:10 · 복습 퀴즈 + 오늘의 그림

### 복습 퀴즈 (5분)

1. 부모 메서드를 자식이 바꿔 쓰는 키워드 두 개는? → **`virtual`** / **`override`**
2. 부모 것도 같이 실행하려면? → **`base.메서드()`** (070)
3. 지난 시간에 이동 코드를 왜 `Move()` 로 뺐나? → **오늘 자식마다 바꾸려고**

### 오늘의 그림 (5분)

```
                    Enemy (abstract)
                  Move / Attack / TakeDamage
                    ↑        ↑        ↑
        ChargerEnemy    RunnerEnemy    TankEnemy
         Attack 만        Move 만      TakeDamage 만
          바꾼다          바꾼다          바꾼다
```

> 💬 "부모가 세 개를 열어뒀습니다. 자식은 **각각 하나씩만** 바꿔요."
> 💬 "그래서 자식 파일이 **열 줄 남짓**입니다."

| 몬스터 | 성격 | 바꾸는 것 |
|---|---|---|
| **돌진형** `ChargerEnemy` | 부딪히면 아프다 | `Attack()` — 070에서 이미 했다 |
| **러너** `RunnerEnemy` | 빠른데 **안 꺾는다** | `Move()` |
| **탱커** `TankEnemy` | 느리고 **단단하다** | `TakeDamage()` |

## 00:10–00:50 · 같이 하기 ★

### ① 러너 — `Move()` 를 바꾼다 (12분)

`Scripts/Enemy/RunnerEnemy.cs`

```csharp
using UnityEngine;

public class RunnerEnemy : Enemy
{
    private Vector2 chargeDir;
    private bool aimed;

    protected override void Start()
    {
        base.Start();
        Debug.Log($"{name} : 러너 등장 (체력 {maxHealth}, 속도 {moveSpeed})");
    }

    protected override void Move()
    {
        // 처음 한 번만 플레이어를 본다. 그 뒤로는 안 꺾는다.
        if (!aimed)
        {
            chargeDir = ((Vector2)player.position - rb.position).normalized;
            sprite.flipX = chargeDir.x < 0f;
            aimed = true;
        }

        rb.linearVelocity = chargeDir * moveSpeed;
    }
}
```

| 조각 | 뜻 |
|---|---|
| `bool aimed` | **한 번만** 실행하게 막는 표시 (057·061의 그 패턴) |
| `chargeDir` | 처음 정한 방향을 **기억한다** |
| `override void Move` | 부모의 `Move` 대신 이게 실행된다 |

> 💬 "**071에서 `Move()` 를 안 빼놨으면** 여기서 `FixedUpdate` 를 통째로 복사해야 했어요."

**Inspector 값**: `Max Health 4` · `Move Speed 5.5` — 빠르지만 약하다.

▶ Play → 러너는 **처음 본 방향으로 직진**한다. 옆으로 피하면 그냥 지나간다.

> 🎉 여기서 반응이 온다. **피할 수 있는 적**이 생겼다.

### ② 탱커 — `TakeDamage()` 를 바꾼다 (12분)

먼저 **부모를 한 글자 고친다.**

```csharp
// Enemy.cs
public virtual void TakeDamage(int amount)   // public void → public virtual void
```

> 💬 "부모가 `virtual` 을 안 붙여두면 자식이 못 바꿉니다. 열어줘야 해요."

`Scripts/Enemy/TankEnemy.cs`

```csharp
using UnityEngine;

public class TankEnemy : Enemy
{
    [SerializeField, Range(0f, 0.9f)] private float damageReduction = 0.5f;

    protected override void Start()
    {
        base.Start();
        Debug.Log($"{name} : 탱커 등장 (체력 {maxHealth}, 피해 감소 {damageReduction:P0})");
    }

    public override void TakeDamage(int amount)
    {
        // 아무리 단단해도 최소 1 은 들어간다. 안 그러면 절대 안 죽는다.
        int reduced = Mathf.Max(Mathf.RoundToInt(amount * (1f - damageReduction)), 1);

        Debug.Log($"{name} : 단단하다!  {amount} → {reduced}");

        base.TakeDamage(reduced);   // 나머지 처리는 부모에게 맡긴다
    }
}
```

| 조각 | 뜻 |
|---|---|
| `[SerializeField, Range(0f, 0.9f)]` | Inspector 에 **슬라이더**가 생긴다 |
| `Mathf.RoundToInt` | 소수를 정수로 반올림 |
| `Mathf.Max(..., 1)` | **최소 1** 은 들어가게 (061의 `Mathf.Max` 와 같다) |
| `base.TakeDamage(reduced)` | **깎는 건 부모가 한다.** 나는 숫자만 줄인다 |

> 🚨 **`Mathf.Max(..., 1)` 이 없으면 감소율 100% 짜리 무적 몬스터**가 만들어진다.
> `Range(0f, 0.9f)` 로 슬라이더도 막아뒀지만, 두 겹으로 막는다.

> 🔑 **`base.TakeDamage(reduced)` 가 오늘의 정점이다.**
> 💬 "탱커는 **체력을 직접 안 깎습니다.** 숫자만 줄여서 부모한테 넘겨요."
> 💬 "부모 코드가 바뀌면 **탱커도 자동으로 같이 바뀝니다.**"

**Inspector 값**: `Max Health 30` · `Move Speed 1.1` · `Damage 2` — 느리고 단단하다.

### ⭐ 도전 미션 — 네 번째 몬스터를 직접 만든다

> 🎯 **이게 오늘의 진짜 과제다.** 이름과 성격을 스스로 정하고, **딱 한 군데만** `override` 한다.

- [ ] **분열형** — `Die()` 를 override 해서 죽을 때 로그를 다르게 남긴다
- [ ] **겁쟁이** — `Move()` 를 override 해서 **도망간다** (방향을 뒤집는다)
- [ ] **지그재그** — `Move()` 에서 `Mathf.Sin(Time.time * 5f)` 로 좌우로 흔들며 온다
- [ ] **가속형** — `Move()` 에서 매 프레임 `moveSpeed += 0.01f`
- [ ] **유리대포** — `TakeDamage()` 를 override 해서 **피해를 2배로** 받는다 (체력은 높게)
- [ ] **부활형** — `Die()` 를 override 해서 체력을 절반 채우고 한 번만 되살아난다
- [ ] 만든 몬스터를 프리팹으로 만들고 씬에 놓는다

> 💡 **부모 파일(`Enemy.cs`)을 안 고치고** 만들 수 있으면 성공이다.
> 고쳐야 했다면 **어디를 왜 고쳤는지** 데모 때 말하게 한다. 그것도 좋은 답이다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| `no suitable method found to override` | 부모가 `virtual` 이 아님 | **오늘 1등.** `TakeDamage` 에 `virtual` |
| **첫 대미지에 죽음** | `base.Start()` 누락 | **오늘 2등.** 070과 같은 사고 |
| 탱커가 안 죽음 | `Mathf.Max(..., 1)` 누락 + 감소율 100% | 최소 1 을 보장한다 |
| 탱커 체력이 안 깎임 | `base.TakeDamage` 를 안 부름 | 숫자만 줄이고 넘겨야 한다 |
| **무한 재귀 / 유니티 멈춤** | `TakeDamage` 안에서 `TakeDamage(...)` 를 부름 | `base.` 를 빠뜨렸다. **자기를 무한히 부른다** |
| 러너가 계속 꺾음 | `aimed` 를 `true` 로 안 만듦 | 표시를 세워야 한 번만 실행된다 |
| 러너가 안 움직임 | `chargeDir` 이 계산 전 | `if (!aimed)` 블록 안을 확인 |
| 셋이 다 똑같이 움직임 | 프리팹에 스크립트를 안 바꿈 | Inspector 에서 컴포넌트 확인 |
| 프리팹 색이 다 같음 | `Sprite Renderer` `Color` 미변경 | 프리팹 안에서 바꾼다 (046) |
| `player` / `rb` 가 자식에서 안 보임 | `private` 으로 선언 | `protected` 로 (070) |
| **몬스터끼리 서로 때림** | 정상. 073에서 고친다 | 오늘은 손대지 않는다 |
