### ② 한 줄부터 (9분)

빈 GameObject `BrickSpawner` 를 만들고 스크립트를 붙인다.

```csharp
using UnityEngine;

public class BrickSpawner : MonoBehaviour
{
    [SerializeField] private GameObject brickPrefab;
    [SerializeField] private int columns = 10;
    [SerializeField] private float spacingX = 1.2f;

    void Start()
    {
        for (int col = 0; col < columns; col++)
        {
            float x = col * spacingX;

            Instantiate(brickPrefab, new Vector3(x, 3f, 0f), Quaternion.identity);
        }
    }
}
```

▶ Play → **블록 10개가 한 줄로 깔린다.** 그런데 **오른쪽으로 치우쳐 있다.**

> 💬 "왼쪽 끝이 `0`이라 그렇습니다. **가운데로 맞추는 계산**을 넣어야 해요."

```csharp
float startX = -(columns - 1) * spacingX / 2f;
float x = startX + col * spacingX;
```

> 💬 "전체 폭이 `(개수-1) × 간격` 이죠. 그 **절반만큼 왼쪽으로** 밀면 가운데가 됩니다."
> 💬 "3주차 산술 연산 그대로예요. **`-1`을 하는 이유**가 뭘까요? 블록 10개면 **간격은 9개**니까요."

> ⚠️ **`-1`을 빼먹는 게 오늘 계산 사고 1등**이다. 칠판에 블록 3개를 그려서 간격이 2개인 걸 보여준다.

### ③ 2중 `for` — 행을 늘린다 (11분) — 오늘의 핵심

**4주차 콘솔 코드를 옆에 띄운다.**

```csharp
// 4주차 · 콘솔 — 2차원 배열 출력
for (int row = 0; row < 3; row++)
{
    for (int col = 0; col < 4; col++)
    {
        Console.Write(map[row, col]);
    }
    Console.WriteLine();
}
```

```csharp
// 058회차 · 유니티 — 블록 배치
for (int row = 0; row < rows; row++)
{
    for (int col = 0; col < columns; col++)
    {
        float x = startX + col * spacingX;
        float y = startY - row * spacingY;

        Instantiate(brickPrefab, new Vector3(x, y, 0f), Quaternion.identity);
    }
}
```

> 💬 "**구조가 똑같습니다.** 바깥이 행, 안쪽이 열. 콘솔에서는 글자를 찍었고 여기서는 블록을 놓아요."
> 💬 "`Console.Write`가 `Instantiate`로 바뀐 것뿐입니다."

| 콘솔 (4주차) | 유니티 (오늘) |
|---|---|
| `map[row, col]` 읽기 | `row`, `col` 로 **좌표를 계산** |
| `Console.Write` | `Instantiate` |
| 줄바꿈 | `y` 를 한 칸 내린다 |

> 🚨 **`y`는 `-` 다.** 행이 늘어날수록 아래로 내려가야 한다.
> 💬 "032회차에 **위가 +y**라고 했죠. 그래서 **아래로 가려면 빼야** 합니다."

▶ Play → **5행 10열, 블록 50개.** `rows`를 `8`로 바꾸면 80개가 된다.

> 🎉 "숫자 하나 바꿨더니 30개가 늘었습니다. **이게 반복문을 쓰는 이유**예요."

> 💬 "`%` 는 3주차에 배운 나머지죠. 036에서 `updateCount % 60` 으로도 썼습니다."
> 💬 "색이 5개인데 행이 8개여도 **에러가 안 납니다.** 0,1,2,3,4,0,1,2 로 돌아가요."

```csharp
using UnityEngine;

public class BrickSpawner : MonoBehaviour
{
    [SerializeField] private GameObject brickPrefab;

    [SerializeField] private int rows = 5;
    [SerializeField] private int columns = 10;
    [SerializeField] private float spacingX = 1.2f;
    [SerializeField] private float spacingY = 0.6f;
    [SerializeField] private float startY = 3f;

    [SerializeField] private Color[] rowColors;

    void Start()
    {
        float startX = -(columns - 1) * spacingX / 2f;

        for (int row = 0; row < rows; row++)
        {
            for (int col = 0; col < columns; col++)
            {
                float x = startX + col * spacingX;
                float y = startY - row * spacingY;

                GameObject brick = Instantiate(brickPrefab, new Vector3(x, y, 0f), Quaternion.identity);

                if (rowColors.Length > 0)
                {
                    brick.GetComponent<SpriteRenderer>().color = rowColors[row % rowColors.Length];
                }
            }
        }
    }
}
```
</details>

## 01:35–01:50 · 데모 + 정리

학생 2명 데모. **2차원 배열로 모양을 만든 학생**을 우선한다.

**마무리 정리 (한 장)**

| 인덱스 | 좌표로 바꾸는 법 |
|---|---|
| `col` (열) | `startX + col * spacingX` — **오른쪽으로** |
| `row` (행) | `startY - row * spacingY` — **아래로 (빼기)** |
| 가운데 정렬 | `startX = -(columns - 1) * spacingX / 2` |

> 💬 "**인덱스를 좌표로 바꾸는 것** — 이게 오늘의 전부입니다."
> 💬 "타일맵, 인벤토리 칸, 미니맵 — 격자로 뭘 놓는 건 전부 이 계산이에요."

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **블록이 한 자리에 겹침** | 위치 계산을 안 하고 `Instantiate` | `x`, `y` 를 넣었는지 |
| 블록이 오른쪽으로 치우침 | `startX` 없음 | 가운데 정렬 계산 |
| 가운데가 살짝 안 맞음 | `-1`을 빼먹음 | 블록 3개 그림으로 설명 |
| 블록이 위로 쌓임 | `y`에 `+` 를 씀 | `startY - row * spacingY` |
| **`IndexOutOfRangeException`** | `rowColors` 가 비었는데 접근 | `Length > 0` 확인 또는 Inspector 채우기 |
| 색이 다 똑같음 | `row` 대신 `col` 을 씀 | 행 번호로 |
| 블록이 50개인데 화면 밖 | `spacingX` 가 큼 | `1.2` 정도부터 |
| Hierarchy가 지저분함 | 자식으로 안 넣음 | ⭐도전. `SetParent` |
| `Instantiate` 결과를 못 받음 | 반환 타입 | `GameObject brick = Instantiate(...)` |
| Play 할 때마다 블록이 두 배 | `Start`가 두 번 (스크립트 두 개) | Inspector 확인 |
| 2중 for 에서 변수명 혼동 | `i`, `j` 를 씀 | **`row`, `col`** 로 쓰게 한다. 훨씬 안 헷갈린다 |
| 공이 없어서 심심해함 | 정상 | "다음 시간에 공 넣습니다" |
