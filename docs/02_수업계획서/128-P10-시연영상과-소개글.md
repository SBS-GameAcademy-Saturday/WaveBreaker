1. **화면 녹화**로 시연 영상을 만든다 (설치할 프로그램 없음)

> 🔑 **오늘은 "만드는 실력" 이 아니라 "보여주는 실력" 이다.**

## 00:10–00:40 · 같이 하기 ① 녹화 ★

### ① 뭘로 녹화하나 (5분)

> 💬 "**아무것도 설치 안 합니다.** 윈도우에 이미 들어 있어요."

| 방법 | 설치 | 추천 |
|---|---|---|
| **Win + G** (Xbox Game Bar) | 없음 | 🔴 **오늘 이걸 쓴다** |
| OBS Studio | 필요 | 나중에 관심 있으면 |
| Unity Recorder | 패키지 설치 | 에디터 화면만 찍힌다 |

> 💬 "Unity Recorder 는 **에디터 안**만 찍습니다. 우리는 **빌드된 게임**을 보여줄 거예요."

### ② 녹화한다 (15분)

```
1. WaveBreaker.exe 를 켠다
2. Win + G  →  캡처 위젯  →  ● 녹화 시작
3. 게임을 한다
4. Win + Alt + R  로 정지
5. 영상 → 캡처 폴더에 저장된다
```

> 🚨 **게임 창을 클릭해서 활성화한 뒤에** 녹화를 시작한다. Game Bar 는 "지금 앞에 있는 창" 을 찍는다.

### ③ 30초 구성 (10분) — 🔑 순서가 정해져 있다

| 초 | 보여줄 것 | 왜 |
|---|---|---|
| 0–5 | **타이틀 화면** | 게임 이름 |
| 5–15 | **몬스터가 몰려오고 자동 공격** | 핵심 재미 |
| 15–22 | **레벨업 카드 세 장 → 선택** | 성장 요소 |
| 22–30 | **협동 2인** 또는 결과 화면 | 차별점 |

> 🔴 💬 "**첫 5초에 게임 화면이 안 나오면 사람들이 나갑니다.**"
> 💬 "로딩, 메뉴 뒤적거리기, 마우스 헤매기 — 다 자르세요."

> 💬 "한 번에 잘 나오는 사람은 없어요. **세 번 찍고 제일 나은 걸 고르세요.**"

## 00:50–01:15 · 같이 하기 ② GIF 와 스크린샷

> 💬 "itch.io 페이지에서 **GIF 는 자동으로 움직입니다.** 영상은 눌러야 재생돼요."

| | GIF | 영상 |
|---|---|---|
| 자동 재생 | ✅ | ❌ 클릭 필요 |
| 소리 | ❌ | ✅ |
| 길이 | 5~10초 | 30초~ |
| 용도 | **페이지 첫인상** | 발표·유튜브 |

> 🔑 **둘 다 만든다.** GIF 는 페이지에, 영상은 발표에.

### ② GIF 만들기 (10분)

```
ezgif.com  →  Video to GIF
   ① 방금 만든 mp4 업로드
   ② 제일 좋은 구간 5~8초를 자른다
   ③ 크기 640px · 15fps
   ④ Convert → 저장
```

| 설정 | 값 | 왜 |
|---|---|---|
| 길이 | **5~8초** | 길면 파일이 커진다 |
| 폭 | 640 px | 페이지에서 충분하다 |
| fps | 15 | 30 은 두 배로 무겁다 |

> 🚨 **GIF 가 10 MB 를 넘으면** 길이나 fps 를 줄인다. 페이지가 느려진다.

## 01:15–01:45 · 같이 하기 ③ 소개글 ★

### ① 나쁜 예 vs 좋은 예 (10분)

> 🚨 **나쁜 예**

```
유니티로 만든 게임입니다.
7개월 동안 배운 것을 활용했습니다.
부족한 점이 많지만 봐주세요.
C# 과 NGO 를 사용했습니다.
```

> 💬 "무슨 게임인지 **한 줄도 안 나왔죠.** 그리고 사과부터 합니다."

> ✅ **좋은 예**

```
몰려오는 것들을 버텨낸다.

위에서 내려다보는 생존 액션입니다. 무기는 자동으로 나갑니다.
당신이 하는 건 움직이는 것과, 레벨업 때 카드 한 장을 고르는 것뿐입니다.

▸ 10분을 버티면 승리
▸ 레벨업마다 카드 3장 중 1장 선택
▸ 친구와 2인 협동 — 쓰러진 동료를 3초간 곁에서 살릴 수 있습니다

이동 WASD · 일시정지 ESC
```

| 규칙 | |
|---|---|
| ① | **첫 줄은 한 문장.** 타이틀 문구를 그대로 써도 된다 |
| ② | 두 번째 문단에서 **뭘 하는 게임인지** |
| ③ | 특징은 **세 줄, 기호로** |
| ④ | 조작키는 반드시 |
| ⑤ | 🔴 **사과하지 않는다** |

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **Win+G 가 안 뜸** | Game Bar 가 꺼져 있다 | 설정 → 게임 → Xbox Game Bar 켜기 |
| 녹화 버튼이 회색 | 게임 창이 앞에 없다 | 게임을 클릭하고 다시 |
| 바탕화면이 녹화됨 | Game Bar 는 **창 단위**로 찍는다 | 게임 창을 활성화한 뒤 시작 |
| GIF 가 30 MB | 길이·fps 과다 | 5초 · 15fps · 640px |
| 영상이 3분 | 편집을 안 함 | **30초 제한을 강제한다** |
| 소개글에 사과가 있음 | 🔴 매우 흔함 | **그 자리에서 지우게 한다** |
| 스크린샷이 빈 화면 | 아무 때나 찍음 | 몬스터가 몰린 순간으로 |
| 녹화가 부담스러움 | 발생 가능 | **GIF 만으로도 통과**시킨다 |
