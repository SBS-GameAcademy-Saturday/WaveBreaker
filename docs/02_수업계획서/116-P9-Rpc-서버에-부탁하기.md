## 00:10–00:50 · 같이 하기 ★

### ① 부탁하는 문법 (12분)

```csharp
// 116회차 · 클라이언트가 부르면 서버로 전달돼 서버에서 실행된다.
[Rpc(SendTo.Server)]
public void RequestDamageRpc(int amount)
{
    // 여기부터는 서버다.
    TakeDamage(amount);
}
```

| 조각 | 뜻 |
|---|---|
| `[Rpc(...)]` | "이건 네트워크로 보내는 함수다" |
| `SendTo.Server` | **서버에서 실행해 달라** |
| 이름이 `...Rpc` 로 끝난다 | **규칙이다.** 안 지키면 컴파일 에러 |

> 🚨 **함수 이름은 반드시 `Rpc` 로 끝나야 한다.** NGO 가 이름으로 구분한다.

**부르는 쪽은 평범하다.**

```csharp
hp.RequestDamageRpc(7);    // 클라이언트에서 부른다
```

> 🔑 💬 "**부르는 건 그냥 함수 호출처럼 생겼습니다.**"
> 💬 "그런데 **몸통은 다른 컴퓨터에서 실행됩니다.** 그게 `Rpc` 예요."

### ② 어디서 실행되나 (12분) — 오늘의 핵심

**그림을 그린다.**

```
   클라이언트 (내 컴퓨터)              호스트 (친구 컴퓨터)
 ┌──────────────────────┐         ┌──────────────────────┐
 │ RequestDamageRpc(7)  │ ──────▶ │ RequestDamageRpc(7)  │
 │   호출만 한다         │  인터넷  │   ← 여기서 몸통이 돈다  │
 │   몸통은 안 돈다      │         │     TakeDamage(7)     │
 └──────────────────────┘         └──────────────────────┘
                                            │
                                    Health.Value 가 바뀐다
                                            │
                                   OnValueChanged 가
                                   양쪽에서 불린다 (115)
```

> 💬 "**호출한 곳과 실행되는 곳이 다릅니다.** 이게 처음엔 헷갈려요."
> 💬 "`Debug.Log` 를 몸통에 넣고 양쪽 Console 을 보면 확실해집니다."

**확인해 본다** — 몸통에 로그를 넣고 클라이언트에서 부른다.

```
클라이언트 Console  :  (아무것도 안 나온다)
호스트 Console      :  체력 20 → 13
```

> 🔑 💬 "**클라이언트에는 안 찍힙니다.** 몸통이 거기서 안 돌았으니까요."

### ③ `SendTo` — 어디로 보낼까 (10분)

| `SendTo` | 어디서 실행되나 | 언제 쓰나 |
|---|---|---|
| **`Server`** | 서버에서 | **클라이언트가 부탁할 때** ← 제일 많이 쓴다 |
| `ClientsAndHost` | 모두에게서 | 서버가 모두에게 알릴 때 (연출·소리) |
| `Owner` | 소유자에게서 | 그 사람에게만 알릴 때 |
| `NotServer` | 서버 빼고 | |

> 💬 "**방향이 두 가지**라고 기억하세요."
> 💬 "**올라가는 것**(클라 → 서버, 부탁)과 **내려오는 것**(서버 → 모두, 알림)."

**내려오는 예**

```csharp
[Rpc(SendTo.ClientsAndHost)]
private void PlayHitEffectRpc(Vector3 pos)
{
    // 모두의 화면에서 이펙트를 띄운다 (099 회수)
}
```

> 💡 값이 계속 유지되는 건 `NetworkVariable`, **한 번만 알리는 건 `Rpc`** 다.
> "체력" 은 변수, "맞았다는 이펙트" 는 Rpc.

### ④ 🚨 클라이언트 말을 믿으면 안 된다 (10분)

```csharp
[Rpc(SendTo.Server)]
private void AttackServerRpc(ulong targetId, int amount)
{
    // 🚨 실제 게임이라면 여기서 검사를 해야 한다.
    //    "정말 사거리 안인가?", "쿨타임을 지켰나?"
    //    클라이언트 말을 그대로 믿으면 치트가 된다.
    enemy.TakeDamage(amount);
}
```

> 💬 "클라이언트가 `amount` 에 **99999** 를 넣어 보내면?" → 그대로 들어간다.
> 💬 "**서버가 검사해야 합니다.** 그게 서버가 존재하는 이유예요."

**우리 수업에서는**

> 💬 "친구랑 하는 게임이니 검사를 다 넣지는 않습니다."
> 💬 "다만 **어디에 넣어야 하는지는 알아두세요.** 코드에 주석으로 남겨둡니다."

> 🔑 107회차의 "권한" 이 여기서 완성된다. **값을 서버가 갖는 것만으로는 부족하다.
> 서버가 검사도 해야 한다.**
