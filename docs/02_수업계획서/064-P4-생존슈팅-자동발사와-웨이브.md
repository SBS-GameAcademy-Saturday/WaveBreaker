## 00:10–00:45 · 같이 치기 ★

### ① 가장 가까운 적 찾기 (13분) — 오늘의 핵심

**4주차 콘솔 코드를 옆에 띄운다.**

```csharp
// 4주차 · 콘솔 — 가장 작은 값 찾기
int min = scores[0];

for (int i = 1; i < scores.Length; i++)
{
    if (scores[i] < min)
    {
        min = scores[i];
    }
}
```

```csharp
// 064회차 · 유니티 — 가장 가까운 적 찾기
private Transform FindNearestEnemy()
{
    GameObject[] enemies = GameObject.FindGameObjectsWithTag("Enemy");

    Transform nearest = null;
    float minDistance = float.MaxValue;

    foreach (GameObject e in enemies)
    {
        float d = Vector2.Distance(transform.position, e.transform.position);

        if (d < minDistance)
        {
            minDistance = d;
            nearest = e.transform;
        }
    }

    return nearest;
}
```

> 💬 "**구조가 똑같습니다.** 하나씩 보면서 '지금까지 중 제일 작은 것' 을 기록해요."
> 💬 "다른 건 **비교하는 게 숫자가 아니라 거리**라는 것뿐입니다."

| 콘솔 (4주차) | 유니티 (오늘) |
|---|---|
| `int min` | `float minDistance` |
| `scores[i]` | `Vector2.Distance(나, 적)` |
| 값을 기록 | **누구였는지도** 기록 (`nearest`) |

> ⚠️ **`float.MaxValue`로 시작하는 이유**를 짚는다.
> 💬 "첫 적이 무조건 이기게 하려고 **아주 큰 값**으로 시작합니다. 콘솔에서 `scores[0]`으로 시작한 것과 같은 이유예요."
> 💬 "적이 하나도 없으면? **`nearest`가 `null`** 로 돌아옵니다. 049 그대로 확인해야 해요."

> 🚨 **`FindGameObjectsWithTag`는 무겁다.** 060·063에서 두 번 나온 이야기다.
> 💬 "그래서 **`Update`가 아니라 코루틴에서** 부릅니다. 0.2초에 한 번이면 충분해요."

### ② 그쪽으로 쏜다 (11분)

```csharp
[SerializeField] private GameObject bulletPrefab;
[SerializeField] private Transform firePoint;
[SerializeField] private float fireInterval = 0.4f;

void Start()
{
    StartCoroutine(FireRoutine());
}

IEnumerator FireRoutine()
{
    while (true)
    {
        yield return new WaitForSeconds(fireInterval);

        Transform target = FindNearestEnemy();

        if (target == null) continue;

        Vector2 dir = ((Vector2)target.position - (Vector2)firePoint.position).normalized;

        GameObject bullet = Instantiate(bulletPrefab, firePoint.position, Quaternion.identity);

        bullet.transform.up = dir;
    }
}
```

▶ Play → **가만히 있어도 총이 나간다. 적을 향해서.**

> 🎉 여기서 반응이 크다. 뱀서라이크의 핵심 감각이 이거다.

**두 줄을 짚는다.**

| 줄 | 뜻 |
|---|---|
| `if (target == null) continue;` | 적이 없으면 **이번 바퀴는 건너뛴다** (3주차 `continue`) |
| `bullet.transform.up = dir;` | 총알의 **위쪽을 그 방향으로 돌린다** |

> 💬 "047에서 `Bullet`이 **`transform.up` 방향으로 날아간다**고 했죠. 그 `up`을 우리가 돌리는 겁니다."
> 💬 "`Quaternion` 계산 없이 **방향 벡터를 그냥 대입**하면 됩니다. 유니티가 알아서 회전을 만들어요."

> ⚠️ **`Quaternion.identity`로 만든 다음 돌리는 순서**를 짚는다.
> 💬 "만들고 → 돌립니다. 만들 때 회전을 넣어도 되는데, **이 순서가 읽기 쉬워요.**"

> 💡 총알은 **047~050에서 만든 그 `Bullet`** 을 그대로 쓴다. `targetTag`는 기본값 `Enemy`.
> 💬 "**055에서 장애물로 쓴 그 스크립트**입니다. 오늘은 다시 총알로 씁니다. 하나로 세 번째예요."

### ③ 웨이브 — 점점 어려워진다 (8분)

```csharp
public class SurvivalManager : MonoBehaviour
{
    [SerializeField] private EnemySpawner spawner;
    [SerializeField] private float rampInterval = 10f;
    [SerializeField] private float intervalStep = 0.15f;
    [SerializeField] private float minInterval = 0.25f;

    private int waveLevel = 1;

    IEnumerator RampRoutine()
    {
        while (true)
        {
            yield return new WaitForSeconds(rampInterval);

            waveLevel++;
            spawner.SpeedUp(intervalStep, minInterval);
        }
    }
}
```

`EnemySpawner`에 메서드를 하나 연다.

```csharp
public void SpeedUp(float step, float min)
{
    spawnInterval = Mathf.Max(spawnInterval - step, min);
}
```

> 💬 "**10초마다 스폰 간격이 0.15초씩 줄어듭니다.** 2초 → 1.85 → 1.7 ..."
> 💬 "`Mathf.Max`로 **하한**을 둡니다. 안 그러면 0이나 음수가 돼서 게임이 터져요."
> 💬 "050의 `Mathf.Clamp`와 같은 이야기입니다. **범위를 벗어나지 않게 막는다.**"

> 🚨 **`SpeedUp`이 `public`인 이유**를 짚는다.
> 💬 "매니저가 스포너를 **밖에서** 부릅니다. 그래서 `public`. **050의 `TakeDamage`와 같은 판단**이에요."

| 시간 | 웨이브 | 스폰 간격 |
|---|---|---|
| 0초 | 1 | 2.00초 |
| 10초 | 2 | 1.85초 |
| 60초 | 7 | 1.10초 |
| 120초 | 13 | **0.25초 (하한)** |

> 💬 "이게 **웨이브**입니다. 17주차에 여기에 **웨이브 번호 표시, 보스, 휴식 시간**이 붙어요."

### ⭐ 도전 미션

- [ ] 한 번에 **3발**을 부채꼴로 쏜다 (각도를 조금씩 돌린다)
- [ ] 적을 잡을 때마다 **점수**를 올린다 (`Health`가 죽을 때 알림 — 어렵다)
- [ ] 사거리를 둔다 — 너무 먼 적은 안 쏜다 (`minDistance > range` 면 `continue`)
- [ ] 웨이브가 오를 때 **적 속도도** 빨라지게 한다
- [ ] 웨이브 번호를 화면에 띄운다 (056)
- [ ] `fireInterval`을 웨이브마다 조금씩 줄여 **플레이어도 강해지게** 한다
- [ ] 가장 가까운 적이 아니라 **체력이 가장 낮은 적**을 쏘게 바꾼다
