## 00:15–00:45 · 같이 하기 ★

### ① 젬 프리팹을 만든다 (8분)

`Assets/_Project/Prefabs/Item/ExpGem.prefab`

| 항목 | 값 |
|---|---|
| `Sprite Renderer` | 젬 그림, 초록빛, Sorting Layer `Player` |
| `Rigidbody 2D` | **Body Type `Kinematic`**, Gravity Scale `0` |
| `Circle Collider 2D` | **`Is Trigger` 켬**, Radius `0.28` |
| `ExpGem` | 아래 스크립트 |

> 🚨 **왜 `Kinematic` Rigidbody 를 붙이나** — 반드시 묻는다.
> 젬은 **코드로 움직일 것**이다(082). 물리에 밀리면 안 되니 `Dynamic` 은 아니다.
> 그런데 Rigidbody 가 아예 없으면 유니티가 **"안 움직이는 물체"** 로 취급해서
> 움직일 때마다 계산을 다시 한다. `Kinematic` 이 정답이다.

### ② 죽은 자리에 떨군다 (10분) — 오늘의 핵심

`Enemy.cs` 의 `Die()` 에 두 가지를 더한다.

```csharp
[SerializeField] protected GameObject expGemPrefab;

protected virtual void Die()
{
    Debug.Log($"{name} 사망");

    if (GameManager.Instance != null)
    {
        GameManager.Instance.AddKill();
    }

    // 081회차 · 죽은 자리에 경험치 젬을 떨군다.
    if (expGemPrefab != null)
    {
        Instantiate(expGemPrefab, transform.position, Quaternion.identity);
    }

    Destroy(gameObject);
}
```

프리팹 3종(`Enemy_Charger` · `Enemy_Runner` · `Enemy_Tank`)의 `Exp Gem Prefab` 칸에 젬을 넣는다.

> 🔑 💬 "**부모의 `Die()` 한 곳**에만 넣었죠. 그런데 세 종류가 다 떨굽니다."
> 💬 "075에서 처치 수를 셀 때랑 **똑같습니다.** 상속을 쓰는 이유가 계속 나와요."

▶ Play → 몬스터가 죽은 자리에 **초록 젬**이 남는다.

> 🚨 **`if (expGemPrefab != null)` 이 필요하다.**
> 나중에 젬을 안 떨구는 몬스터(보스 등)를 만들 수 있다. 그때 칸을 비워두면 된다.

### ③ 밟으면 사라진다 (8분)

`Scripts/Item/ExpGem.cs`

```csharp
using UnityEngine;

public class ExpGem : MonoBehaviour
{
    [SerializeField] private int exp = 1;

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (!other.CompareTag("Player")) return;

        Debug.Log($"젬 획득 (+{exp})");

        Destroy(gameObject);
    }
}
```

▶ Play → 젬 위로 걸어가면 사라진다.

> 💬 "아직 **경험치는 안 셉니다.** 083에서 셀 거예요."
> 💬 "오늘은 '떨어지고, 주워진다' 까지입니다."

> 🚨 **칼도 젬을 먹으면 안 된다.**
> 칼 콜라이더는 플레이어 몸에 붙어 있지만, `Blade` 오브젝트의 Tag 는 `Player` 가 아니다.
> `CompareTag("Player")` 가 그걸 걸러준다. **태그 검사가 여기서 값을 한다.**

### ⭐ 도전 미션

- [ ] 탱커만 젬을 **3개** 떨구게 한다 (`Die()` 를 override — 072 방식)
- [ ] 젬이 떨어질 때 **살짝 흩어지게** 한다 (`Random.insideUnitCircle`)
- [ ] 젬에 **수명**을 준다 (30초 뒤 사라짐 — 048)
- [ ] 러너는 젬을 **안 떨구게** 한다 (프리팹 칸을 비운다)
- [ ] 젬 크기를 몬스터 종류마다 다르게 한다
- [ ] `exp` 값을 몬스터마다 다르게 준다 (탱커는 5)
- [ ] 씬에 젬이 몇 개 있는지 HUD 에 표시한다

> 💡 첫 번째 도전이 **072의 override 를 다시 쓰게** 한다. 부모 `Die()` 를 `base.Die()` 로 부르는 걸 잊지 않게 한다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **젬이 안 떨어짐** | 프리팹 칸이 비었다 | **오늘 1등.** 3종 전부 확인 |
| 한 종류만 떨어짐 | 프리팹 하나만 연결 | 프리팹 3개를 각각 |
| `NullReferenceException` | `null` 검사 없이 `Instantiate` | `if (expGemPrefab != null)` |
| **젬이 안 먹힘** | Collider `Is Trigger` 꺼짐 | 043 체크리스트 |
| 젬이 안 먹힘 (2) | 플레이어 Tag 확인 | `Player` |
| 젬이 플레이어를 밀어냄 | Trigger 가 아니거나 Dynamic | Kinematic + Trigger |
| **칼이 젬을 먹음** | 태그 검사 없음 | `CompareTag("Player")` |
| 젬이 화면에 가려짐 | Sorting Layer | `Player` 로 (045) |
| 젬이 몬스터 자리가 아닌 곳에 | `transform.position` 이 아닌 값 | 자기 자리를 쓴다 |
| 젬이 너무 많이 쌓임 | 정상 | 082에서 줄어든다. 수명은 도전 미션 |
| 프레임이 떨어짐 | 젬 + 몬스터 + 총알 | 정상. **풀링은 101회차** |
| 젬이 안 보임 | 스프라이트 미연결 | 프리팹 확인 |
