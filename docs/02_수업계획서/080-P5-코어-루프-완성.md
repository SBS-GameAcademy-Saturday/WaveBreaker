### ① 닿아 있는 동안 계속 때린다 (8분)

```csharp
private void OnCollisionStay2D(Collision2D collision)

```

> 💬 "076에서 칼에 한 거랑 **똑같습니다.** Enter → Stay."

▶ Play → 몬스터 무리에 들어간다. **체력이 순식간에 0이 된다.**

```
플레이어 : -3  (남은 체력 17)
플레이어 : -3  (남은 체력 14)
플레이어 : -3  (남은 체력 11)   ← 0.05초 만에
```

> 💬 "너무 빠르죠? 076에서는 **칼 쪽에 쿨다운**을 넣었습니다. 여기도 그럴까요?"
> 💬 "몬스터가 100마리면 **쿨다운도 100개**가 따로 돕니다. 소용이 없어요."
> 💬 "그래서 **맞는 쪽**에 넣습니다. 그게 **무적시간**이에요."

### ② 무적시간 (12분) — 오늘의 핵심

```csharp
[SerializeField] private float invincibleTime = 0.6f;
[SerializeField] private SpriteRenderer sprite;

public bool IsInvincible => Time.time < invincibleUntil;

private float invincibleUntil;

public void TakeDamage(int amount)
{
    if (IsInvincible) return;
    if (currentHealth <= 0) return;

    invincibleUntil = Time.time + invincibleTime;

    currentHealth = Mathf.Max(currentHealth - amount, 0);
    Debug.Log($"플레이어 : -{amount}  (남은 체력 {currentHealth})");

    if (currentHealth == 0)
    {
        Die();
    }
}
```

> 🔑 💬 "**때리는 쪽이 몇이든, 맞는 쪽이 0.6초에 한 번만 받습니다.**"
> 💬 "몬스터가 백 마리든 한 마리든 **똑같아요.** 이게 무적시간을 맞는 쪽에 두는 이유입니다."

**눈에 보이게 한다.**

```csharp
private void Update()
{
    if (sprite == null) return;

    sprite.color = IsInvincible ? new Color(1f, 1f, 1f, 0.35f) : Color.white;
}
```

▶ Play → 맞으면 **플레이어가 반투명하게 깜빡인다.**

> 💬 "숫자를 보는 것보다 **깜빡이는 게** 훨씬 빨리 이해됩니다. 078의 Gizmo 와 같은 이야기예요."

| 조각 | 뜻 |
|---|---|
| `Time.time < invincibleUntil` | 아직 무적 시간이다 |
| `if (currentHealth <= 0) return;` | **이미 죽었으면** 더 안 받는다 |
| `sprite.color` 의 `a` | 알파(투명도). `0.35` = 많이 투명 |

> 🚨 **`if (currentHealth <= 0) return;` 이 없으면 `Die()` 가 여러 번 불린다.**
> 게임오버가 겹쳐서 뜨거나 로그가 도배된다. 057의 `isGameOver` 와 같은 이야기다.

### ③ 게임오버 (10분)

`GameManager` 에 두 가지를 더한다.

```csharp
public void ChangeState(GameState next)
{
    State = next;

    Debug.Log("게임 상태: " + next);

    Time.timeScale = (next == GameState.GameOver) ? 0f : 1f;
}
```

`PlayerHealth.Die()` 에서 부른다.

```csharp
private void Die()
{
    Debug.Log("플레이어 사망");

    if (GameManager.Instance != null)
    {
        GameManager.Instance.ChangeState(GameState.GameOver);
    }
}
```

> 💬 "066에서 만든 `GameState` 기억나세요? **14주 전에 자리만 만들어 뒀던 게** 오늘 쓰입니다."
> 💬 "그때 '지금 안 쓰는데 왜 넣어요' 했죠. 이래서 넣었습니다."

**HUD 에 게임오버 문구를 띄운다.**

```csharp
bool over = GameManager.Instance.State == GameState.GameOver;

centerLabel.gameObject.SetActive(over);

if (over)
{
    centerLabel.text = $"게임 오버\n{GameManager.Instance.Kills}마리 처치\n\nR 키로 다시";
}
```

> 💡 **`Time.timeScale = 0` 이어도 `Update` 는 돈다.** 멈추는 건 물리와 `WaitForSeconds` 다.
> 그래서 HUD 갱신과 키 입력은 계속 동작한다. 057에서 배운 그대로다.

### ④ 재시작 (8분)

```csharp
void Update()
{
    if (State != GameState.GameOver) return;

    if (Input.GetKeyDown(KeyCode.R))
    {
        Restart();
    }
}

public void Restart()
{
    Time.timeScale = 1f;   // 이걸 빼면 다시 열어도 멈춰 있다
    SceneManager.LoadScene(SceneManager.GetActiveScene().name);
}
```

그리고 `Awake` 에도 한 줄.

```csharp
void Awake()
{
    ...
    Instance = this;

    // 게임오버로 멈춘 채 씬을 다시 열면 화면이 얼어 있다 (057).
    Time.timeScale = 1f;
}
```

> 🚨 **`Time.timeScale = 1f` 를 두 군데에 넣는 이유.**
> `Restart()` 에서 한 번, `Awake` 에서 또 한 번. **둘 중 하나만 있어도 되지만**,
> 나중에 다른 곳에서 씬을 열어도 안전하게 만든다. 057에서 학생 절반이 걸린 사고다.

> 🚨 **씬이 Build Settings 에 등록돼 있어야 한다** (057).
> `File → Build Profiles` → `Add Open Scenes`.

▶ Play → 죽는다 → 게임오버 → `R` → **처음부터 다시 시작한다.**
