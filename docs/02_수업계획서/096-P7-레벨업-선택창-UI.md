## 00:10–00:50 · 같이 하기 ★

### ① UI 는 층이다 (10분)

Hierarchy 에서 `HUD` 아래 순서를 본다.

```
HUD (Canvas)
 ├ LevelUpPanel      ← 먼저 그려진다
 ├ ExpBar
 ├ HealthBar
 ├ LevelLabel
 ├ TimeLabel
 └ KillLabel         ← 나중에 그려진다 = 맨 위
```

> 🔑 💬 "**Hierarchy 에서 아래에 있을수록 화면에서는 위에** 그려집니다."
> 💬 "종이를 쌓는 것과 같아요. 나중에 올린 게 위에 있죠."

▶ `LevelUpPanel` 을 맨 아래로 드래그해 보여준다. HUD 글자가 카드에 가려진다. 되돌린다.

**우리 선택**: `LevelUpPanel` 은 **위쪽에 둔다** → HUD 글자가 카드 위로 보인다.

> 💬 "왜 그렇게 할까요? 업그레이드를 고를 때 **내 체력과 레벨이 보여야** 하거든요."
> 💬 "일시정지 창은 반대입니다. 그때는 HUD 를 볼 이유가 없어요." (다음 회차)

### ② 배경 — 게임을 가린다 (10분)

`LevelUpPanel` 의 `Image` 를 고친다.

| 항목 | 값 | 왜 |
|---|---|---|
| Anchor | **사방 Stretch** (Min `(0,0)` Max `(1,1)`) | 화면 전체를 덮는다 |
| Left/Right/Top/Bottom | 전부 `0` | 여백 없이 |
| Source Image | `UI_Bar` | 094에서 만든 흰 사각형 |
| Color | `(0.03, 0.03, 0.06, 0.86)` | **알파 0.86** |
| **Raycast Target** | **✅ 켬** | ← 오늘의 핵심 |

> 🔑 💬 "**알파를 1.0 이 아니라 0.86 으로 둡니다.**"
> 💬 "완전히 까맣게 덮으면 '게임이 꺼졌나?' 싶어요. 살짝 비쳐야 **멈춰 있다**는 느낌이 납니다."

**`Raycast Target` 이 하는 일**

> 💬 "이걸 켜면 이 판때기가 **클릭을 먹습니다.** 뒤에 있는 건 클릭이 안 가요."
> 💬 "카드 사이 빈 곳을 눌러도 아무 일이 안 일어나는 게 **맞는 동작**입니다."

▶ 껐다 켜며 뒤쪽 버튼이 눌리는지 보여준다.

> 🚨 반대로, **글자(TMP)는 `Raycast Target` 을 꺼야 한다.** 글자가 클릭을 먹으면
> 그 위에 있는 버튼이 안 눌린다. **Phase 7 버튼 사고 2위**다.

### ③ 카드 3장 배치 (12분)

| 항목 | 값 |
|---|---|
| Anchor / Pivot | 전부 **가운데** `(0.5, 0.5)` |
| 크기 | **300 × 250** |
| Pos Y | `-30` |
| Pos X | `Card_0` = **-334** · `Card_1` = **0** · `Card_2` = **+334** |
| Color | `(0.14, 0.15, 0.20, 1)` |

> 💬 "**334 = 카드 폭 300 + 간격 34.** 손으로 눈대중하지 말고 계산합니다."
> 💬 "가운데 카드가 0 이고, 좌우로 한 칸씩 밀린 겁니다. 077에서 칼을 배치한 것과 같은 생각이에요."

**제목**

| 항목 | 값 |
|---|---|
| Anchor / Pivot | 위 가운데 `(0.5, 1)` |
| Pos | `(0, -150)` |
| 크기 | 54 · 색 `(1, 0.86, 0.35)` 노랑 |

> 🚨 **처음엔 Pos Y 를 `-80` 으로 뒀다가 `00:15` 시계와 겹쳤다.**
> 강사가 실제로 겪은 것이다. `-150` 으로 내려야 안 겹친다.
> 💬 "이래서 **눈으로 확인해야** 합니다. 숫자만 보면 절대 안 보여요."

**카드 안 글자**

| 항목 | 값 |
|---|---|
| Anchor | 사방 Stretch |
| Left/Right/Top/Bottom | 전부 `22` (안쪽 여백) |
| 크기 | 30 · 가운데 정렬 |

> 💬 "**Stretch 로 두고 여백 22.** 카드 크기를 바꿔도 글자가 알아서 따라옵니다." (092 회수)

### ④ 눌리는 느낌 (8분)

`Button` 컴포넌트의 **Transition** 을 본다.

| Transition | 뜻 |
|---|---|
| None | 아무 반응 없음 |
| **Color Tint** | **색이 변한다** ← 우리 것 |
| Sprite Swap | 그림이 바뀐다 |
| Animation | 애니메이터를 쓴다 |

| 상태 | 값 | 언제 |
|---|---|---|
| Normal | 흰색 | 평소 |
| **Highlighted** | `(1.35, 1.35, 1.45)` | **마우스를 올렸을 때** |
| Pressed | `(0.7, 0.7, 0.8)` | 누르는 중 |
| **Fade Duration** | **0.08** | 색이 변하는 데 걸리는 시간 |

> 💬 "Highlighted 색이 **1 을 넘습니다.** 색은 곱해지는 값이라 1.35 면 **밝아집니다.**"
> 💬 "Fade Duration 을 0 으로 두면 **딱딱 끊깁니다.** 0.08 이 부드럽고 빨라요."

> 🔑 💬 "이게 **눌린다는 걸 알려주는 유일한 신호**입니다. 없으면 학생들이 두 번 세 번 누릅니다."

### ⑤ 확인 (5분)

▶ Play → 레벨업 → 카드가 뜬다 → 마우스를 올려본다 → 클릭.

**재본 값**

```
클릭 대상 = Card_1        (EventSystem 을 통한 진짜 클릭)
클릭 후 → panel = False, timeScale = 1, state = Playing
```

> 💬 "085에서 만든 코드가 **그대로** 동작합니다. 우린 보이게만 했어요."

<details>
<summary>막히면 열기 (정답)</summary>

**작업 순서가 중요하다**

1. `LevelUpPanel` 을 **켜둔다** (Hierarchy 체크박스). 꺼져 있으면 아무것도 안 보인다
2. 배경 → 제목 → 카드 → 글자 순서로 고친다
3. 다 끝나면 **다시 끈다**

> 🚨 **끄는 걸 잊으면** 게임 시작하자마자 레벨업 창이 떠 있다.
> `LevelUpView.Start()` 가 꺼주긴 하지만, 씬 저장은 꺼둔 상태로 하는 게 맞다.

**Raycast Target 을 어디서 끄나**
TMP 텍스트를 클릭 → Inspector 의 `Extra Settings` 를 펼치면 맨 위에 있다.

**색 값 넣는 법**
Color 칸을 클릭 → 위쪽 `RGB 0-1.0` 로 바꾸면 `0.14` 같은 소수를 그대로 넣을 수 있다.
`Hexadecimal` 칸에 `24262F` 를 넣어도 된다.

**카드 위치가 안 맞으면**
Anchor 가 가운데인지 먼저 본다. 왼쪽 위 앵커에 Pos X `-334` 를 넣으면 화면 밖으로 나간다.

</details>

**확인 조건**: 레벨업 창이 떴을 때 **뒤가 안 눌리고**, 카드 사이 간격이 좌우 똑같다.

### ⭐ 도전 미션

- [ ] `Raycast Target` 을 끄고 카드 사이 빈 곳을 클릭해 본다 (그리고 되돌린다)
- [ ] 배경 알파를 `1.0` 과 `0.3` 으로 바꿔보고 어느 쪽이 나은지 쓴다
- [ ] `LevelUpPanel` 을 Hierarchy 맨 아래로 옮겨보고 무슨 일이 나는지 본다
- [ ] 카드에 **테두리**를 넣는다 (`Outline` 컴포넌트)
- [ ] 카드가 뜰 때 **작은 크기에서 커지는** 애니메이션을 넣는다 (`unscaledDeltaTime` 주의)
- [ ] 고른 카드만 **잠깐 반짝**이고 나서 창이 닫히게 한다
- [ ] `Horizontal Layout Group` 으로 카드 배치를 자동화한다

> 💡 다섯 번째는 `Time.timeScale = 0` 이라 **`Time.deltaTime` 이 0** 이다.
> `Time.unscaledDeltaTime` 을 써야 움직인다. 084의 내용을 다시 쓰는 자리다.
> 💡 일곱 번째가 진짜 UI 개발 방식이다. 해온 학생은 반드시 데모시킨다.
