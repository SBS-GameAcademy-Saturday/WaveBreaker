## 00:10–00:50 · 같이 하기 ★

### ① `PoolManager` — 서랍장 (15분)

`Scripts/Manager/PoolManager.cs`

```csharp
using System.Collections.Generic;
using UnityEngine;

public class PoolManager : MonoBehaviour
{
    public static PoolManager Instance { get; private set; }

    // 프리팹마다 서랍이 하나씩 있다.
    private readonly Dictionary<GameObject, Queue<GameObject>> drawers
        = new Dictionary<GameObject, Queue<GameObject>>();

    // 이 복사본이 어느 프리팹에서 나왔는지. 반납할 때 어느 서랍에 넣을지 알아야 한다.
    private readonly Dictionary<GameObject, GameObject> madeFrom
        = new Dictionary<GameObject, GameObject>();

    public int Created { get; private set; }
    public int Reused { get; private set; }

    private void Awake()
    {
        if (Instance != null && Instance != this) { Destroy(gameObject); return; }
        Instance = this;
    }

    // 매니저가 없어도 게임은 돌아가야 한다. 없으면 예전 방식으로 간다.
    public static GameObject Spawn(GameObject prefab, Vector3 position, Quaternion rotation)
    {
        if (prefab == null) return null;
        if (Instance == null) return Instantiate(prefab, position, rotation);
        return Instance.Take(prefab, position, rotation);
    }

    public static void Despawn(GameObject instance)
    {
        if (instance == null) return;
        if (Instance == null) { Destroy(instance); return; }
        Instance.Put(instance);
    }

    private GameObject Take(GameObject prefab, Vector3 position, Quaternion rotation)
    {
        if (!drawers.TryGetValue(prefab, out Queue<GameObject> drawer))
        {
            drawer = new Queue<GameObject>();
            drawers[prefab] = drawer;
        }

        GameObject go = null;

        // 씬을 다시 열면 서랍 속 물건이 없어져 있을 수 있다. 빈 칸은 건너뛴다.
        while (drawer.Count > 0 && go == null) go = drawer.Dequeue();

        if (go == null)
        {
            go = Instantiate(prefab, position, rotation);
            madeFrom[go] = prefab;
            Created++;
        }
        else
        {
            go.transform.SetPositionAndRotation(position, rotation);
            Reused++;
        }

        go.SetActive(true);   // 🚨 이 줄을 빼면 아무것도 안 나온다
        return go;
    }

    private void Put(GameObject go)
    {
        if (!madeFrom.TryGetValue(go, out GameObject prefab)) { Destroy(go); return; }

        if (!go.activeSelf) return;   // 두 번 반납하면 서랍에 같은 게 두 개 들어간다

        go.SetActive(false);
        drawers[prefab].Enqueue(go);
    }
}
```

| 조각 | 뜻 |
|---|---|
| `Dictionary<프리팹, 서랍>` | 몬스터 종류마다 서랍이 따로 (026 회수) |
| `Queue` | 먼저 넣은 걸 먼저 꺼낸다. `List` 여도 되지만 이게 자연스럽다 |
| `madeFrom` | **꺼낸 물건이 어느 서랍 것인지** 기억해 둔다 |
| `static Spawn / Despawn` | 부르는 쪽 코드가 한 줄로 끝난다 |
| `Instance == null` 이면 예전 방식 | **매니저를 안 놔도 게임이 돌아간다** |
| `if (!go.activeSelf) return` | 이중 반납 방지 |

> 🚨 **`go.SetActive(true)` 를 빼먹는 게 풀링 최다 사고다.**
> 일부러 지우고 실행해 보여준다. **몬스터가 한 마리도 안 나온다.**
> 로그도 에러도 없다. 그래서 더 헷갈린다.

### ③ 🔑 `Start` 는 한 번만 돈다 (15분) — 오늘의 핵심

> 💬 "**`Start` 는 언제 돌까요?**" → 오브젝트가 처음 생길 때
> 💬 "재활용하면 오브젝트가 **새로 안 생깁니다.** 그럼 `Start` 는?" → **안 돈다**

| 함수 | 언제 도는가 | 풀링에서 |
|---|---|---|
| `Awake` | 오브젝트가 생길 때 한 번 | **한 번만** |
| `Start` | 첫 `Update` 직전 한 번 | **한 번만** ← 문제 |
| **`OnEnable`** | **켜질 때마다** | ✅ **매번** |
| `OnDisable` | 꺼질 때마다 | 매번 |

**고친다** — `Enemy`

```csharp
// 전
protected virtual void Start()
{
    currentHealth = maxHealth;
    ...
}

// 후
protected virtual void OnEnable()
{
    AliveCount++;

    currentHealth = maxHealth;   // 이걸 안 하면 지난 판의 체력 0 을 그대로 갖고 나온다
    ...
}

protected virtual void OnDisable()
{
    AliveCount--;
}
```

자식 4종(`ChargerEnemy` `RunnerEnemy` `TankEnemy` `BossEnemy`)도 같이 바꾼다.

```csharp
protected override void OnEnable()
{
    base.OnEnable();   // 이걸 빼면 체력이 0 인 채로 시작한다 (072와 같은 사고)
    ...
}
```

> 💬 "**재활용 = 씻어서 다시 쓰기.** 씻는 자리가 `OnEnable` 입니다."

**무엇을 되돌려야 하나** — 학생에게 찾게 한다.

| 되돌려야 하는 것 | 왜 |
|---|---|
| **체력** | 죽은 채로 나온다 |
| 속도 (`linearVelocity`) | 이전 속도로 튀어나간다 |
| 색 (번쩍임 중이었다면) | 하얀 채로 나온다 |
| 수명 타이머 | 나오자마자 사라진다 |

> 💡 우리 `Enemy` 는 `Move()` 가 매 `FixedUpdate` 마다 속도를 새로 정해서 속도는 저절로 맞는다.
> **모든 게 저절로 맞지는 않는다.** 그래서 한 번씩 확인해야 한다.

## 01:35–01:50 · 데모 · 정리

학생 한 명이 화면 공유로 **`재사용` 숫자가 올라가는 것**을 보여준다.

**칠판 요약**

```
서랍에 넣기 = SetActive(false)   →  Despawn
꺼내기      = SetActive(true)    →  Spawn      ← 이 줄을 빼면 아무것도 안 나온다

Awake     오브젝트가 생길 때 한 번
Start     첫 Update 직전 한 번        ← 재활용하면 안 돈다
OnEnable  켜질 때마다                 ← 상태를 되돌리는 자리
```

> 💬 "오늘 프레임은 크게 안 좋아졌을 겁니다. **예고한 대로예요.**"

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **몬스터가 하나도 안 나옴** | `SetActive(true)` 누락 | **풀링 최다 사고.** 에러도 안 난다 |
| **두 번째부터 체력 0** | `Start` 를 그대로 뒀다 | **오늘의 수업 내용** |
| 자식만 체력 0 | `base.OnEnable()` 누락 | 072와 같은 사고. 네 번째다 |
| `NullReferenceException` | `PoolManager` 오브젝트 없음 | 씬에 만든다 (없어도 돌게 짰지만 확인) |
| 서랍이 계속 커짐 | 꺼내는 쪽이 다른 프리팹 | 같은 프리팹이어야 같은 서랍 |
| 몬스터가 겹쳐서 나옴 | 이중 반납 | `if (!go.activeSelf) return` |
| `Destroy` 예약이 남아 있음 | `Destroy(go, 2f)` | 풀링과 같이 못 쓴다 (103) |
| 프레임이 그대로 | **정상이다** | 개수는 103에서 잡는다 |
| 풀링을 이해 못 함 | 개념 난이도 | **서랍 비유로 돌아간다** |
