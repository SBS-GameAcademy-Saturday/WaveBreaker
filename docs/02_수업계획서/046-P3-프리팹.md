## 🎯 오늘의 목표

1. GameObject를 **프리팹으로 만든다**
2. **원본을 고치면 전부 바뀐다**는 걸 본다
3. 인스턴스만 바뀐 값(**Override**)과 원본에 반영(**Apply**)을 구분한다

> ⚠️ **오늘 안 하는 것**: `Instantiate`. **코드는 한 줄도 안 쓴다.**
> 프리팹은 코드 개념이 아니라 **에셋 개념**이다. 오늘 코드를 섞으면
> "프리팹이 뭔지"와 "코드로 만드는 법"이 뭉쳐서 둘 다 안 남는다. 코드는 047회차.
>
> 🔑 **설계 의도**: 045에서 학생은 총알 20개를 **손으로 복사**했다.
> 오늘은 그 20개의 색을 바꾸라고 시켜서 **손으로 고치는 고통을 먼저 겪게 한다.**
> 프리팹을 먼저 설명하면 "편한 기능" 정도로 흘려듣는다. **불편을 겪은 뒤에 준다.**

## 00:10–00:45 · 같이 하기 ★

### ① 손으로 고쳐 본다 (7분) — 오늘의 도입

`046_Prefab_Start` 를 연다. **똑같은 몬스터(빨간 Square) 10개**가 줄지어 있다.

> 💬 "기획자가 왔습니다. **몬스터 색을 보라색으로 바꿔주세요.** 그리고 크기도 조금 키워주세요."

**강사가 직접 10개를 하나씩 고친다.** 일부러 천천히. 5개쯤에서 멈춘다.

> 💬 "지금 몇 개 했죠? 다섯 개요. 그런데 실제 게임에는 **몬스터가 200마리** 나옵니다."
> 💬 "그리고 기획자가 내일 또 옵니다. **'역시 빨간색이 낫겠어요.'**"

> 🎯 여기서 학생 표정이 바뀐다. 그 뒤에 프리팹을 꺼낸다.

### ② 프리팹으로 만든다 (8분)

Hierarchy의 몬스터 하나를 **`Project` 창의 `Assets/_Project/Prefabs/Enemy/` 폴더로 드래그**한다.

**세 가지가 동시에 일어난다.**

| 어디 | 무슨 일 |
|---|---|
| Project 창 | `Enemy.prefab` 파일이 **생긴다** ← **이게 원본** |
| Hierarchy | 이름이 **파란색**으로 바뀐다 ← 이제 복사본이다 |
| Inspector | 위에 **`Open` `Select` `Overrides`** 버튼이 생긴다 |

> 💬 "**Project에 있는 게 원본, 씬에 있는 게 복사본**입니다. 이 문장을 오늘 열 번 말할 거예요."
> 💬 "파란색 이름 = **'나는 어떤 원본에서 나왔다'** 는 표시입니다."

나머지 9개는 **지우고**, 프리팹을 Hierarchy로 **9번 드래그**해서 다시 놓는다.

> ⚠️ **드래그 위치가 겹쳐서 하나로 보인다**는 학생이 나온다. 놓은 다음 X를 벌린다.
> `Ctrl+D` 복제도 프리팹 인스턴스를 만든다는 걸 같이 알려준다.

### ③ 원본을 고친다 (10분) — 오늘의 핵심

Project 창의 **`Enemy.prefab`을 더블클릭** → **프리팹 모드**로 들어간다.

> 💬 "배경이 바뀌고 위에 **화살표(←)** 가 생겼죠. **여기가 원본을 고치는 방**입니다."

색을 **보라색**으로, `Scale`을 `1.3`으로 바꾼다. 좌측 상단 **`<` 화살표**로 씬으로 돌아온다.

**10개가 전부 바뀌어 있다.**

> 🎉 여기서 반응이 온다. 서두르지 않는다.
> 💬 "한 번 고쳤습니다. 200마리여도 **똑같이 한 번**이에요."

> 💡 **프리팹 모드에 들어가지 않고 고치는 방법**도 있다는 걸 한 줄만: Inspector의 `Open` 버튼도 같은 곳으로 간다.

### ④ Override — 하나만 다르게 (10분)

씬의 몬스터 **한 마리만** 골라 색을 **노란색**으로 바꾼다.

Inspector 위쪽 **`Overrides`** 버튼을 누르면 **바뀐 항목 목록**이 나온다.

| 버튼 | 뜻 | 언제 |
|---|---|---|
| **`Revert`** | **내 변경을 버리고** 원본으로 돌아간다 | 실수로 바꿨을 때 |
| **`Apply`** | **내 변경을 원본에 밀어 넣는다** | 이게 더 낫다고 판단했을 때 |

> 🚨 **`Apply`는 되돌리기 어렵다.** 누르는 순간 다른 인스턴스가 전부 따라 바뀐다.
> 💬 "**`Apply`는 '전부 이걸로 해'** 라는 뜻입니다. 하나만 다르게 하고 싶으면 **누르면 안 됩니다.**"

**이제 원본 색을 초록으로 바꿔 본다.** → **9개는 초록, 노란 하나는 그대로 노랑.**

> 💬 "**한 번 손댄 항목은 원본을 따라가지 않습니다.** 그게 Override예요."
> 💬 "색만 바꿨으면 **색만** 안 따라갑니다. Scale은 여전히 따라가요. **항목 단위**입니다."

> ⚠️ 이게 오늘 가장 헷갈리는 부분이다. **"왜 얘만 안 바뀌죠?"** 가 반드시 나온다.
> 그때 `Overrides` 버튼을 눌러 **목록을 보여준다.** 목록에 있으면 그게 이유다.

## 00:55–01:35 · 개인 미션

### 필수 미션 — 몬스터 프리팹

`046_Prefab_Start` 에서 만든다.

1. 몬스터 하나를 `Assets/_Project/Prefabs/Enemy/` 로 드래그해 **`Enemy.prefab`** 을 만든다
2. 프리팹에 **`Circle Collider 2D`** 와 **Tag `Enemy`** 를 넣는다 (프리팹 모드에서)
3. 씬에 **10개**를 배치한다
4. 원본의 **색과 Scale**을 바꿔 **10개가 한꺼번에 바뀌는 것**을 확인한다
5. 그중 **한 마리만** 색을 다르게 하고, 다시 원본 색을 바꿔서 **그 하나만 안 따라오는 것**을 확인한다

**확인 조건**: 원본 한 번 수정 → 10개가 바뀐다. Override 건 하나는 안 바뀐다.

> 💡 **Tag `Enemy` 는 프리팹 모드 안에서 붙인다.** 씬에서 붙이면 그 인스턴스만 붙고
> Override가 된다. "원본에 넣을 건 원본 방에서" 를 습관으로 만든다.

### ⭐ 도전 미션

- [ ] `Bullet.prefab`도 만들어 둔다 (작은 흰 원 + `Circle Collider 2D` + `Is Trigger`)
- [ ] Override를 만든 뒤 **`Revert`** 를 눌러 원래대로 돌린다
- [ ] Override를 만든 뒤 **`Apply`** 를 눌러 나머지 9개가 어떻게 되는지 본다 (그리고 `Ctrl+Z`)
- [ ] 프리팹 인스턴스를 우클릭 → **`Prefab → Unpack`** 을 하고 이름 색이 어떻게 되는지 본다
- [ ] 씬에서 인스턴스를 지우면 원본이 지워지는지 확인한다 (안 지워진다)
- [ ] **원본을 지우면** 씬의 인스턴스가 어떻게 되는지 확인한다 (⚠️ 확인 후 `Ctrl+Z`)
- [ ] 프리팹 안에 **자식 오브젝트**를 넣어 본다 (몬스터 밑에 그림자용 Square)

## 01:35–01:50 · 데모 + 정리

학생 2명 데모. **`Apply`를 눌러본 학생**이 있으면 반드시 보여주게 한다.
"하나만 바꾸려다 전부 바뀌는" 사고를 다 같이 보는 게 안전 교육이 된다.

**마무리 정리 (한 장)**

| | 어디 있나 | 뭐라고 부르나 | 고치면 |
|---|---|---|---|
| **원본** | **Project 창** (`.prefab` 파일) | 프리팹 | **전부 바뀐다** |
| **복사본** | **Hierarchy** (파란 이름) | 인스턴스 | 그것만 바뀐다 (Override) |

> 💬 "앞으로 '프리팹 고치세요' 라고 하면 **Project 창에서 여세요.** 씬에서 고치면 그거 하나만 바뀝니다."

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **원본을 고쳤는데 하나만 안 바뀜** | **Override가 걸려 있음** | **오늘 1등.** `Overrides` 버튼 → 목록 확인 → `Revert` |
| 씬에서 고쳤는데 다른 게 안 바뀜 | 인스턴스를 고침 | "원본은 Project 창에 있습니다" |
| 프리팹을 만들었는데 Project에 없음 | 드래그를 씬 안에 놓음 | **Project 창 폴더 위**에 놓는다 |
| 인스턴스가 겹쳐서 하나로 보임 | 같은 자리에 드래그/복제 | X를 벌린다 |
| **`Apply` 눌러서 전부 바뀜** | 되돌리기 어려운 조작 | `Ctrl+Z`. 안 되면 원본을 다시 고친다 |
| 프리팹 모드에서 못 나옴 | 좌측 상단 `<` 를 못 찾음 | Hierarchy 맨 위 `<` 화살표 |
| 이름이 파란색이 아님 | Unpack 했거나 프리팹이 아님 | 다시 프리팹으로 만든다 |
| 원본을 지웠더니 인스턴스가 빨개짐 | 원본이 없어짐 (Missing Prefab) | `Ctrl+Z`. **원본은 지우지 않는다** |
| 프리팹 폴더를 못 찾음 | 경로 | `Assets/_Project/Prefabs/Enemy/` |
| 프리팹 이름에 한글 | 나중에 코드에서 곤란 | **영문으로.** `Enemy`, `Bullet` |
| Tag를 씬 인스턴스에 붙임 | 원본/복사본 혼동 | 프리팹 모드에서 다시 붙인다 |
