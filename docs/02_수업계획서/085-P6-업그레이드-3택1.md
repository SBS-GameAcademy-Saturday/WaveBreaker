### ④ 카드에 업그레이드를 올린다 (12분) — 오늘의 핵심

```csharp
public void Open()
{
    Time.timeScale = 0f;

    if (panel != null) panel.SetActive(true);

    List<UpgradeType> picked = PickThree();

    for (int i = 0; i < buttons.Length; i++)
    {
        UpgradeType type = picked[i];   // 반복문 변수를 그대로 쓰면 전부 마지막 값이 된다

        labels[i].text = Describe(type);

        buttons[i].onClick.RemoveAllListeners();
        buttons[i].onClick.AddListener(() => Choose(type));
    }
}
```

**한 조각씩 짚는다.**

| 조각 | 뜻 |
|---|---|
| `onClick.RemoveAllListeners()` | **이전에 붙인 걸 지운다** |
| `onClick.AddListener(...)` | 눌렀을 때 실행할 코드를 붙인다 |
| `() => Choose(type)` | "누르면 `Choose(type)` 을 해라" 라는 **코드 덩어리** |
| `UpgradeType type = picked[i];` | **for 변수를 그대로 쓰면 안 된다** |

> 🚨 **`RemoveAllListeners()` 를 빼면 레벨업할 때마다 쌓인다.**
> 3레벨이 되면 카드 하나를 눌렀는데 **업그레이드가 3개** 적용된다.
> 077에서 칼이 쌓이던 것과 **같은 종류의 사고**다.
>
> 💬 "**뭔가를 다시 붙일 때는 먼저 지운다.** 이번 Phase 에서 두 번째예요."

> 💡 `() => ...` 는 **람다**라고 부른다. 지금은 **"누르면 이걸 해라" 라고 적어두는 방법**으로만 안다.
> 깊이 들어가지 않는다.

**서로 다른 3개를 뽑는 부분**

```csharp
private List<UpgradeType> PickThree()
{
    List<UpgradeType> all = new List<UpgradeType>
    {
        UpgradeType.BladeCount, UpgradeType.FireRate, UpgradeType.MoveSpeed
    };

    List<UpgradeType> result = new List<UpgradeType>();

    while (result.Count < 3 && all.Count > 0)
    {
        int index = Random.Range(0, all.Count);
        result.Add(all[index]);
        all.RemoveAt(index);   // 뽑은 건 빼야 중복이 안 나온다
    }

    return result;
}
```

> 💬 "**뽑은 건 목록에서 뺍니다.** 안 그러면 같은 카드가 두 장 나와요."
> 💬 "지금은 종류가 3개뿐이라 매번 다 나옵니다. **086에서 8종이 되면** 이 코드가 진짜 일을 해요."
