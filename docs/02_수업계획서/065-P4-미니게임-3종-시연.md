## 00:00–00:35 · 같이 치기 ★

### ① 세 번째 매니저 (12분)

> 💬 "매니저를 **세 번째** 만듭니다. 이번엔 여러분이 먼저 말해보세요."
> 💬 "**시작 / 진행 / 끝 / 다시** — 각각 뭘로 하면 될까요?"

학생 답을 받아 칠판에 채운다. 대부분 스스로 채운다.

| | 무엇 | 뭘로 |
|---|---|---|
| 시작 | 씬을 연다 | (자동) |
| 진행 | **버틴 시간이 점수** | `Time.deltaTime` (056) |
| 끝 | **플레이어가 죽으면** | `player == null` (057) |
| 다시 | `R` | `LoadScene` (057) |

> 🎯 **이걸 학생이 채우는 게 오늘의 확인 시험이다.** 세 번째라 대부분 채운다.
> 못 채우는 학생이 있으면 057·060 매니저를 옆에 띄워준다.

```csharp
public class SurvivalManager : MonoBehaviour
{
    [SerializeField] private TextMeshProUGUI hudText;
    [SerializeField] private TextMeshProUGUI resultText;
    [SerializeField] private GameObject player;
    [SerializeField] private EnemySpawner spawner;

    [SerializeField] private float rampInterval = 10f;
    [SerializeField] private float intervalStep = 0.15f;
    [SerializeField] private float minInterval = 0.25f;

    private float survivedTime;
    private int shownTime = -1;
    private int waveLevel = 1;
    private bool isOver;

    void Start()
    {
        StartCoroutine(RampRoutine());
        UpdateHud();
    }

    void Update()
    {
        if (isOver)
        {
            if (Input.GetKeyDown(KeyCode.R))
            {
                Time.timeScale = 1f;
                SceneManager.LoadScene(SceneManager.GetActiveScene().name);
            }
            return;
        }

        if (player == null)
        {
            Finish();
            return;
        }

        survivedTime += Time.deltaTime;

        int now = Mathf.FloorToInt(survivedTime);

        if (now != shownTime)
        {
            shownTime = now;
            UpdateHud();
        }
    }
}
```

> 💬 "**057과 거의 같은 코드**죠. 세 번째라 이제 눈에 익을 겁니다."

### ② 웨이브를 화면에 (8분)

```csharp
private void UpdateHud()
{
    hudText.text = "생존 " + shownTime + "초     웨이브 " + waveLevel;
}

IEnumerator RampRoutine()
{
    while (true)
    {
        yield return new WaitForSeconds(rampInterval);

        if (isOver) yield break;          // 게임이 끝났으면 코루틴도 끝낸다

        waveLevel++;
        spawner.SpeedUp(intervalStep, minInterval);

        UpdateHud();
    }
}
```

> ⚠️ **`yield break`** 를 처음 쓴다.
> 💬 "**코루틴을 끝내는 것**입니다. `return` 이랑 같은 자리예요."
> 💬 "게임이 끝났는데 웨이브가 계속 오르면 이상하니까요."

> 💡 `Time.timeScale = 0`이면 `WaitForSeconds`가 멈추니 안 넣어도 되긴 한다.
> **그래도 명시하는 게 낫다** — 나중에 timeScale을 안 쓰는 방식으로 바꿀 수도 있다.

### ③ 결과 화면 (8분)

```csharp
private void Finish()
{
    isOver = true;

    resultText.text = shownTime + "초 버텼습니다\n웨이브 " + waveLevel + " 도달\n\nR 키로 다시";
    resultText.gameObject.SetActive(true);

    Time.timeScale = 0f;
}
```

> 💬 "`\n` 은 **줄바꿈**입니다. 1주차에 콘솔에서 봤던 그거예요."
> 💬 "결과에 **숫자를 보여주면** 다시 하고 싶어집니다. '30초 버텼네, 한 번 더' 가 되죠."

> 🔑 **이게 게임 디자인의 첫 경험**이라는 걸 짚는다.
> 💬 "기술이 아니라 **판단**입니다. 뭘 보여줄지 정하는 거예요."

### ④ 숫자 맞추기 (7분)

**다 같이 Play하면서 숫자를 조절한다.**

| 값 | 너무 쉬우면 | 너무 어려우면 |
|---|---|---|
| `fireInterval` | 늘린다 | 줄인다 |
| `moveSpeed` (적) | 올린다 | 내린다 |
| `rampInterval` | 줄인다 (빨리 어려워짐) | 늘린다 |
| `maxHealth` (플레이어) | 줄인다 | 올린다 |

> 💬 "**30초 정도 버티면 적당합니다.** 5초에 죽으면 화나고, 5분을 버티면 지겨워요."
> 💬 "이걸 **밸런싱**이라고 합니다. 코드가 아니라 **숫자를 만지는 일**이에요. Phase 6에서 제대로 합니다."
