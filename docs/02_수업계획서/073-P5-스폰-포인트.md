## 🎯 오늘의 목표

1. 몬스터를 **화면 밖에서** 만든다
2. 스폰 포인트를 **카메라 자식**으로 둔다 — 무한 맵 때문에

> ⚠️ **오늘 안 하는 것**: 계속 나오는 것(074). 오늘은 **버튼(또는 메뉴)을 누를 때 한 마리**다.

> ② 몬스터를 여러 마리 소환하면 → **자기들끼리 싸워서 죽는다**
> 둘 다 보여준 뒤에 고친다. 미리 답부터 주면 아무것도 안 남는다.

## 00:10–00:50 · 같이 하기 ★

### ① 만드는 곳은 한 곳뿐이다 (10분)

빈 오브젝트 `WaveManager` 를 만들고 `Scripts/Manager/WaveManager.cs` 를 붙인다.

```csharp
using UnityEngine;

public class WaveManager : MonoBehaviour
{
    [SerializeField] private GameObject[] enemyPrefabs;   // 0 돌진 · 1 러너 · 2 탱커
    [SerializeField] private Transform[] spawnPoints;

    public void SpawnOne()
    {
        if (enemyPrefabs.Length == 0 || spawnPoints.Length == 0) return;

        GameObject prefab = enemyPrefabs[Random.Range(0, enemyPrefabs.Length)];
        Transform point = spawnPoints[Random.Range(0, spawnPoints.Length)];

        Instantiate(prefab, point.position, Quaternion.identity);
    }

    [ContextMenu("한 마리 소환")]
    private void SpawnFromMenu() => SpawnOne();
}
```

> 🔑 **이 프로젝트의 규칙: 몬스터를 만드는 곳은 여기 하나뿐이다.**
> 💬 "여기저기서 `Instantiate` 하면 나중에 **누가 만들었는지 못 찾습니다.**"
> 💬 "지금은 불편해 보여도, 몇 달 뒤에 이 규칙이 여러분을 살립니다."

> 💡 `[ContextMenu]` 는 048에서 썼다. Inspector 컴포넌트 오른쪽 **⋮ 메뉴**에 항목이 생긴다.
> 실행 중에도 누를 수 있어 테스트가 편하다.

### ② 스폰 포인트를 만든다 (8분)

빈 오브젝트 `SpawnPoints` 아래에 빈 오브젝트 8개를 **원형으로** 둔다.

| 항목 | 값 |
|---|---|
| 개수 | 8개 (45도 간격) |
| 반지름 | **14** |
| 그림 | 없다 (위치만) |

> 💬 "왜 14일까요? 카메라가 보는 범위가 가로로 약 **±8.9**, 세로로 **±5** 입니다."
> 💬 "모서리까지가 약 10.2 니까, **14면 확실히 화면 밖**이에요."

`WaveManager` 의 `Enemy Prefabs` 에 프리팹 3개, `Spawn Points` 에 포인트 8개를 넣는다.

▶ Play → ⋮ 메뉴 → `한 마리 소환` → **화면 밖에서 몬스터가 걸어 들어온다.**

### ③ 문제 ① — 멀리 가면 몬스터가 안 온다 (8분)

> 💬 "이제 **오른쪽으로 한참 달려보세요.**"

▶ Play → 오른쪽으로 20초 달린 뒤 소환 → **아무것도 안 보인다.**

> 💬 "왜 그럴까요?"
> 학생 답을 기다린다.
> 💬 "스폰 포인트가 **처음 그 자리에 그대로** 있어요. 우리는 멀리 왔고요."

**고치는 법 — `SpawnPoints` 를 `Main Camera` 의 자식으로 끌어 넣는다.**

▶ Play → 어디로 가도 **화면 밖에서 나타난다.**

> 🔑 💬 "부모가 움직이면 자식도 같이 움직입니다. **033에서 로봇팔로 배운 그거예요.**"
> 💬 "무한 맵에서는 **'화면 밖' 이 계속 바뀝니다.** 그래서 카메라에 붙였어요."

> ⚠️ 스폰 포인트의 **`z` 는 신경 쓰지 않아도 된다.** `Instantiate` 할 때 `point.position` 의
> z 가 그대로 들어가지만, 2D 라 보이는 데는 영향이 없다. 신경 쓰이면 z 를 `0` 으로 맞춘다.

### ④ 문제 ② — 몬스터끼리 싸운다 (12분) — 오늘의 핵심

> 💬 "이번엔 **스무 마리쯤** 소환해 봅시다." (⋮ 메뉴를 여러 번 누른다)

▶ Play → 잠시 두고 보면 **몬스터가 저절로 줄어든다.** Console 에 사망 로그가 쌓인다.

```
Enemy_Charger(Clone) : 돌진! 3 피해
Enemy_Runner(Clone) : -3  (남은 체력 1)
Enemy_Runner(Clone) 사망
```

> 💬 "우리는 아무것도 안 했는데 **몬스터가 죽고 있어요.** 왜죠?"
> 학생 답을 기다린다.

**칠판**

```
ChargerEnemy.OnCollisionEnter2D
   부딪힌 게 IDamageable 이면 때린다
                ↑
        몬스터도 IDamageable 이다!
```

> 💬 "070에서 **'몬스터는 상대가 누군지 모른다'** 고 했죠. 그게 여기서 문제가 됩니다."
> 💬 "몬스터 입장에선 **다른 몬스터도 '맞을 수 있는 무언가'** 예요."

**고치는 법 — Layer 로 편을 가른다 (045 회수)**

1. `Layers → Add Layer` 에서 **`Enemy`** 레이어를 만든다
2. 프리팹 3종의 **Layer 를 `Enemy`** 로 바꾼다
3. `Project Settings → Physics 2D → Layer Collision Matrix` 에서
   **`Enemy` × `Enemy` 체크를 끈다**

▶ Play → 스무 마리를 소환해도 **아무도 안 죽는다.** 서로 통과해 지나간다.

> 💬 "코드를 **한 줄도 안 고쳤습니다.** 설정으로 해결했어요."
> 💬 "045에서 '총알이 벽을 통과하게' 했던 거랑 **똑같은 방법**입니다."

> 🚨 **왜 코드로 안 막았나** — 반드시 나오는 질문이다.
> "`if (상대가 몬스터면 return)` 을 넣을 수도 있어요. 그런데 몬스터가 열 종류가 되면
> **그 조건을 열 군데 관리**해야 합니다. 레이어는 **한 곳**이에요."

> ⚠️ **부작용도 말해준다.** 이제 몬스터끼리 **겹쳐서 지나간다.** 뭉치면 한 덩어리로 보인다.
> 뱀서라이크에서는 흔한 처리다. 밀치게 하고 싶으면 나중에 따로 만든다.

### ⭐ 도전 미션

- [ ] 스폰 포인트를 **16개**로 늘린다 (원이 촘촘해진다)
- [ ] 반지름을 `9` 로 줄여 **화면 안에서 튀어나오는 걸** 확인한다 (그리고 되돌린다)
- [ ] `Enemy` × `Enemy` 를 **다시 켜고** 20마리를 소환해 서로 죽는 걸 다시 본다
- [ ] 스폰 포인트를 코드로 만든다 — `for` 로 8개, `Mathf.Cos` / `Mathf.Sin` (069 도전)
- [ ] `SpawnOne` 을 `Update` 에서 **`N` 키**로 부르게 한다
- [ ] `Instantiate` 한 몬스터를 `WaveManager` 의 자식으로 만든다 — Hierarchy 가 깨끗해진다
- [ ] 프리팹마다 나올 확률을 다르게 만든다 (탱커는 드물게)

> 💡 네 번째 도전을 한 학생이 있으면 데모시킨다. 069의 2중 `for` 와 같은 발상이다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **소환해도 아무것도 안 나옴** | Inspector 배열이 비어 있음 | **오늘 1등.** 프리팹·포인트를 꽂았는지 |
| `IndexOutOfRangeException` | 빈 배열에 `Random.Range` | `if (Length == 0) return;` |
| **멀리 가면 안 나옴** | `SpawnPoints` 가 카메라 자식이 아님 | **오늘 2등.** Hierarchy 를 보여준다 |
| 몬스터가 화면 안에 뿅 나타남 | 반지름이 너무 작다 | `14` 이상 |
| 몬스터가 영영 안 옴 | 반지름이 너무 크다 | `14` 정도가 적당 |
| **몬스터가 저절로 죽음** | `Enemy` × `Enemy` 가 켜져 있음 | **오늘의 수업 내용.** 매트릭스 확인 |
| 레이어를 바꿨는데 그대로임 | 씬 인스턴스만 바꿈 | **프리팹 원본**을 바꾼다 (046) |
| 플레이어가 몬스터를 통과함 | 실수로 Player 레이어까지 껐다 | `Enemy` × `Default` 는 켜져 있어야 한다 |
| 몬스터가 다 겹쳐 보임 | 정상. 충돌을 껐으니 | 뱀서라이크에서는 흔하다 |
| Hierarchy 가 몬스터로 도배됨 | 정상 | 도전 미션 6번으로 정리한다 |
| 프레임이 떨어짐 | 몬스터가 너무 많다 | 정상. **풀링은 101회차** |
| `[ContextMenu]` 가 안 보임 | 컴포넌트 ⋮ 메뉴를 못 찾음 | Inspector 오른쪽 점 세 개 |
