### ② `HUDView` 를 고친다 (10분)

```csharp
[Header("바 (094)")]
[SerializeField] private StatBar healthBar;
[SerializeField] private StatBar expBar;

[Header("글자 (095)")]
[SerializeField] private TMP_Text levelLabel;
[SerializeField] private TMP_Text timeLabel;
[SerializeField] private TMP_Text killLabel;
[SerializeField] private TMP_Text centerLabel;

private void Update()
{
    if (GameManager.Instance == null) return;

    if (healthBar != null && playerHealth != null)
        healthBar.Set(playerHealth.Current, playerHealth.Max);

    if (expBar != null && playerLevel != null)
        expBar.Set(playerLevel.Exp, playerLevel.NeedExp);

    if (levelLabel != null && playerLevel != null)
        levelLabel.text = $"Lv.{playerLevel.Level}";

    if (timeLabel != null && waveManager != null)
    {
        // 초를 분:초로. 00 은 "두 자리로, 빈 자리는 0으로" 라는 뜻이다.
        int total = Mathf.FloorToInt(waveManager.Elapsed);
        timeLabel.text = $"{total / 60:00}:{total % 60:00}";
    }

    if (killLabel != null)
        killLabel.text = $"처치 {GameManager.Instance.Kills}";

    // ... centerLabel 부분은 그대로
}
```

| 조각 | 뜻 |
|---|---|
| `statusLabel` 이 사라졌다 | 긴 문자열 조립이 통째로 없어졌다 |
| `total / 60` | 분 (정수 나눗셈을 **일부러** 쓴다) |
| `total % 60` | 초 (나머지) |
| `:00` | **두 자리로, 앞을 0 으로 채운다** → `07` |

> 💬 "094에선 `(float)` 를 안 써서 사고가 났는데, **여기선 정수 나눗셈이 정답입니다.**"
> 💬 "`95 / 60 = 1`. 1분이 맞죠. `95 % 60 = 35`. 35초. 합쳐서 `01:35`."

> 💡 `$"{값:00}"` 은 **서식 지정자**다. `:00` 을 빼면 `1:5` 가 나온다.

**Inspector 배선** — 다섯 칸을 새로 연결한다.

### ④ 카메라를 목록 방식으로 (10분)

```csharp
using System.Collections.Generic;
using UnityEngine;

// 068회차 · 플레이어를 부드럽게 따라간다.
// 095회차 · "하나를 따라간다" 를 "목록의 중심을 따라간다" 로 바꿨다.
//   목록에 하나만 넣으면 동작이 068과 완전히 같다.
public class CameraFollow : MonoBehaviour
{
    [SerializeField] private List<Transform> targets = new List<Transform>();
    [SerializeField] private float smoothTime = 0.15f;

    private Vector3 velocity;

    void LateUpdate()
    {
        if (targets.Count == 0) return;

        Vector3 center = Center();

        Vector3 goal = new Vector3(center.x, center.y, -10f);

        transform.position = Vector3.SmoothDamp(transform.position, goal, ref velocity, smoothTime);
    }

    // 목록의 평균 위치. 원소가 하나면 그 하나의 위치와 같은 값이 나온다.
    private Vector3 Center()
    {
        Vector3 sum = Vector3.zero;
        int count = 0;

        foreach (Transform t in targets)
        {
            if (t == null) continue;   // 죽어서 사라진 플레이어는 건너뛴다

            sum += t.position;
            count++;
        }

        if (count == 0) return transform.position;

        return sum / count;
    }
}
```

| 조각 | 뜻 |
|---|---|
| `List<Transform>` | 여러 개를 받는다 (021~030 회수) |
| `Center()` | 평균 위치 |
| `if (t == null) continue` | 죽어서 사라진 대상은 건너뛴다 (051 회수) |
| `count == 0` → 제자리 | 전멸했을 때 카메라가 원점으로 튀는 걸 막는다 |

> 💬 "**지금은 목록에 한 명만 넣습니다.** 평균을 내도 그 한 명이죠."
> 💬 "동작이 068과 **한 픽셀도 안 다릅니다.** 재보면 카메라와 플레이어 거리가 `0.00` 이에요."
>
> 🔑 💬 "그럼 왜 바꿨을까요? **Phase 9 에서 협동을 붙일 때 이 파일을 안 고치려고요.**"
> 💬 "그때는 목록에 **한 명 더 넣기만** 하면 됩니다. 카메라가 둘 사이 가운데를 봅니다."

> 🚨 **Inspector 배선이 풀린다.** 필드 이름이 `target` → `targets` 로 바뀌었기 때문이다.
> `Main Camera` 의 `Targets` 목록 크기를 `1` 로 하고 `Player` 를 넣는다.
> 💬 "이름을 바꾸면 **Unity 가 못 찾습니다.** 037에서 배운 그거예요."

▶ Play → 카메라가 전과 똑같이 따라간다.

**실측**: `camera=(0.00, 0.00, -10.00)  player=(0.00, 0.00, 0.00)  거리=0.00`

<summary>막히면 열기 (정답)</summary>

`HUDView` 와 `CameraFollow` 코드는 위 ②·④ 블록 그대로다.

**시간 서식이 헷갈리면**

```csharp
int total = 95;

total / 60   →  1     // 분
total % 60   →  35    // 초

$"{total / 60:00}:{total % 60:00}"   →  "01:35"
```

`:00` 을 빼면 `1:35` 가 된다. 앞자리 0 이 없어서 숫자가 흔들려 보인다.

**배선 확인표**

| 오브젝트 | 컴포넌트 | 채울 칸 |
|---|---|---|
| `HUD` | `HUDView` | Health Bar, Exp Bar, Level Label, Time Label, Kill Label, Center Label |
| `Main Camera` | `CameraFollow` | Targets → Size `1` → Element 0 = `Player` |

> 🚨 `Targets` 를 안 채우면 **카메라가 아예 안 움직인다.** `targets.Count == 0` 이라 바로 `return` 한다.
