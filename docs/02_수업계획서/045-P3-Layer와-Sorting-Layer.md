# 045회차 · Layer와 Sorting Layer — 안 부딪히게, 앞에 보이게 (9주차 정리)

| | |
|---|---|
| **Phase** | 3 · 유니티 2D 핵심 **(9주차 마지막)** |
| **소요** | 2시간 (비대면) |
| **선행** | 044회차 (충돌 이벤트 · Tag) |
| **오늘 배우는 것** | `Layer`, **Layer Collision Matrix**, `Sorting Layer`, `Order in Layer` |
| **씬** | 시작 `045_Layer_Start` · 완성 `045_Layer_Done` |
| **준비물(강사)** | Layer Collision Matrix 화면, 스프라이트가 앞뒤로 겹치는 시연 |

> 🚨 **강사 사전 확인 (필수)**: `Layer Collision Matrix`는 **씬이 아니라 프로젝트 설정**이다.
> 그래서 레퍼런스 프로젝트에는 **전부 켜진 기본 상태**로만 들어 있다 — 끈 상태를 저장하면
> `045_Layer_Start`(총알끼리 부딪히는 걸 보여주는 씬)가 망가지기 때문이다.
> **`045_Layer_Done`을 시연하려면 수업 중에 강사가 직접 체크를 끈다.** 시연이 끝나면 다시 켠다.
>
> 같은 이유로 **Tag(`Coin`·`Wall`) · Layer(`Bullet`·`Wall`) · Sorting Layer 5종은 이미 등록돼 있다.**
> 학생의 `Snapshot_P2`에는 없으므로, **만드는 과정은 반드시 화면 공유로 같이 한다.**

## 🎯 오늘의 목표

1. **Layer Collision Matrix**로 "아예 안 부딪히는" 관계를 만든다
2. `Tag`와 `Layer`가 **무엇이 다른지** 말한다
3. `Sorting Layer` · `Order in Layer`로 **누가 앞에 보일지** 정한다

> ⚠️ **오늘 안 하는 것**: Sprite 임포트 설정, Animator. **051회차**다.
> 오늘 그리는 건 여전히 흰 Square다. **순서만** 다룬다.
>
> 🔑 **설계 의도**: 앞의 넷은 "되게 만드는" 회차였고, 오늘은 **"안 되게 만드는"** 회차다.
> 총알 200발이 서로 부딪히면 게임이 멈춘다는 걸 **실제로 보여준 뒤** Matrix를 끈다.
> 그리고 9주차를 닫으면서 **충돌 체크리스트 5단계를 완성**한다.

## 📦 오늘의 제출물

## 00:10–00:45 · 같이 하기 ★

### ① 문제를 먼저 본다 (7분)

`045_Layer_Start` 를 연다. `Player`, 벽, 그리고 **총알 역할의 작은 Square 20개**가 있다.
전부 `Circle Collider 2D` + `Rigidbody 2D (Dynamic, Gravity Scale 0)` 다.

▶ Play → **총알들이 서로를 밀어내며 흩어진다.** 겹쳐 있던 20개가 순식간에 벌어진다.

> 📊 실측: 시작할 때 중심에서 **0.35** 안에 뭉쳐 있던 총알이 **0.76** 까지 벌어지고 멈춘다.
> 튀어 날아가는 게 아니라 **서로 밀어내고 자리를 잡는다.** 과장하지 말고 그대로 보여준다.

> 💬 "총알이 **서로 부딪히고 있습니다.** 게임에서 이런 일이 있으면 안 되죠."
> 💬 "Tag로 막을 수 있을까요? **없습니다.** Tag는 **부딪힌 다음에** 골라내는 거예요."
> 💬 "오늘은 **애초에 검사조차 안 하게** 만듭니다."

### ② Layer를 만든다 (8분)

1. 총알 하나 선택 → Inspector **맨 위 오른쪽 `Layer` 드롭다운** → **`Add Layer...`**
2. 빈 칸(`User Layer 6` 부터)에 **`Bullet`** 입력
3. **총알 20개를 전부 선택**해서 Layer를 `Bullet` 으로

> 💡 **여러 개 한 번에 선택**: Hierarchy에서 첫 번째 클릭 → 마지막을 `Shift+클릭`.
> Inspector에서 한 번에 바꿀 수 있다. 이걸 모르면 20번 클릭한다.

> 🚨 **Tag와 똑같은 함정.** `Add Layer`는 **목록에 등록만** 한다. 오브젝트에 붙이는 건 별개다.
> 044에서 한 실수를 그대로 반복하는 학생이 나온다. **"만들었다 ≠ 붙였다"** 를 다시 말한다.

**같은 방식으로 `Wall`, `Player` Layer도 만든다.** (`Player` Layer는 유니티 기본 목록에 이미 있다)

### ③ Layer Collision Matrix (12분) — 오늘의 핵심

**`Edit → Project Settings → Physics 2D`** → 아래로 스크롤 → **`Layer Collision Matrix`**

체크박스가 삼각형으로 깔려 있다.

> 💬 "이 표는 **누가 누구랑 부딪힐지**를 정하는 곳입니다. 체크가 켜져 있으면 **검사한다**는 뜻이에요."
> 💬 "지금은 **전부 켜져 있습니다.** 그래서 총알끼리도 부딪히는 거예요."

**`Bullet` × `Bullet` 칸의 체크를 끈다.** → ▶ Play → **총알들이 서로 통과한다.**

> 🎉 "끝났습니다. 코드 한 줄 안 썼어요."

| 관계 | 체크 | 이유 |
|---|---|---|
| Bullet × Bullet | ❌ 끈다 | 총알끼리 부딪힐 이유가 없다 |
| Bullet × Wall | ✅ 켠다 | 총알이 벽에 맞아야 한다 |
| Bullet × Player | ❌ 끈다 | 내 총알에 내가 맞으면 안 된다 |
| Player × Wall | ✅ 켠다 | 벽에 막혀야 한다 |

**`Bullet` × `Player` 도 꺼본다.** 총알이 플레이어를 통과한다.

> 💬 "이게 왜 중요하냐면 — **성능**입니다. 총알이 200발이면 서로 검사하는 것만
> 200 × 200 = **4만 번**이에요. 매 프레임. 체크 하나 끄면 그게 통째로 사라집니다."

### ④ Tag와 Layer — 뭐가 다른가 (5분)

| | Tag | Layer |
|---|---|---|
| 무엇인가 | **이름표** | **소속 그룹** |
| 몇 개 붙나 | 오브젝트당 **1개** | 오브젝트당 **1개** |
| 개수 제한 | 사실상 없음 | **32개** (고정) |
| 쓰는 곳 | **코드**에서 `CompareTag` | **물리 설정**(Matrix), 카메라, 조명 |
| 언제 작동 | **부딪힌 다음** 골라낸다 | **부딪히기 전** 아예 막는다 |

> 💬 "한 문장으로: **Layer는 검사 자체를 막고, Tag는 검사 결과를 골라냅니다.**"
> 💬 "둘 다 씁니다. Layer로 큰 그물을 치고, Tag로 세부를 골라요."

### ⑤ Sorting Layer — 누가 앞에 보이나 (8분)

씬을 열면 **`Background`(큰 회색 Square)** 가 화면 가운데를 덮고 있다.

**캐릭터도 총알도 그 뒤에 있어서 아예 안 보인다.** Hierarchy에는 있는데 화면에는 없다.

> 📌 시작 씬은 `Background`의 `Order in Layer`가 **`1`** 로 되어 있어 **항상 앞에 그려진다.**
> 순서가 같으면 깜빡거리기만 해서 시연이 안 되므로 일부러 덮게 해뒀다.
>
> 💬 "Hierarchy에는 Player가 있죠. **지워진 게 아니라 뒤에 있는 겁니다.**"

> 💬 "2D는 전부 **같은 평면**에 그립니다. 그래서 **누굴 먼저 그릴지**를 따로 정해줘야 해요."

`Sprite Renderer` 컴포넌트를 본다. 아래쪽에 두 칸이 있다.

| 칸 | 뜻 |
|---|---|
| **`Sorting Layer`** | 큰 묶음. **배경 / 바닥 / 캐릭터 / 이펙트** |
| **`Order in Layer`** | 같은 묶음 안에서의 순서. **숫자가 클수록 앞** |

`Sorting Layer` 드롭다운 → `Add Sorting Layer...` → 위에서부터 순서대로 만든다.

```
Background   ← 제일 뒤
Ground
Enemy
Player
Effect       ← 제일 앞
```

> 🚨 **목록의 위아래 순서가 곧 그리는 순서다.** 위에 있는 게 뒤에 그려진다.
> 순서를 잘못 만들면 드래그해서 바꿀 수 있다. 만들 때 한 번에 맞추는 게 낫다.

배경을 `Background`, 캐릭터를 `Player` 로 지정 → **캐릭터가 앞에 보인다.**

> 💬 "032회차에 `Z` 좌표를 배웠죠. 2D에서도 Z가 먹긴 하는데, **Sorting Layer가 우선**입니다."
> 💬 "Z로 관리하면 나중에 뒤죽박죽이 돼요. **Sorting Layer로 하세요.**"

> 💡 **깜빡거림(Z-fighting)** 을 본 학생이 있으면: "둘의 순서가 똑같아서 유니티도 헷갈리는 겁니다.
> `Order in Layer`를 다르게 주면 멈춰요."

## 00:55–01:35 · 개인 미션

### 필수 미션 — 총알 정리 + 화면 정리

`045_Layer_Start` 에서 만든다.

**A. Layer**

1. Layer `Bullet` · `Wall` 을 만들고 오브젝트에 **붙인다**
2. `Physics 2D → Layer Collision Matrix` 에서
   - `Bullet` × `Bullet` **끈다**
   - `Bullet` × `Player` **끈다**
   - `Bullet` × `Wall` **켠 채로 둔다**
3. ▶ Play → 총알끼리 통과하고, **벽에는 막힌다**

**B. Sorting Layer**

4. Sorting Layer를 `Background` / `Ground` / `Player` / `Effect` 순으로 만든다
5. 배경 Square를 `Background`, `Player`를 `Player` 로 지정
6. 배경과 겹쳐도 **캐릭터가 앞에 보인다**

**확인 조건**: 총알이 서로 통과하고 벽에는 막힌다. 캐릭터가 배경 앞에 보인다.
Layer Collision Matrix 스크린샷에 꺼진 칸이 보인다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
