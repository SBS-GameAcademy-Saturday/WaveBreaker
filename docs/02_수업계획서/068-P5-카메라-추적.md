### ② 왜 떨리나 — 실행 순서 (11분) — 오늘의 핵심

**칠판에 한 프레임의 순서를 그린다.**

```
한 프레임 안에서 일어나는 일

   Update()        ← 일반 스크립트
   FixedUpdate()   ← 물리 (한 프레임에 0~여러 번)
   물리 계산       ← Rigidbody 가 실제로 움직인다
   LateUpdate()    ← 모든 Update 가 끝난 뒤
   화면 그리기
```

> 💬 "플레이어는 **물리로** 움직입니다(`FixedUpdate` + Rigidbody)."
> 💬 "카메라를 `Update` 에서 옮기면 — **플레이어가 아직 안 움직인 상태**를 보고 따라갈 수 있어요."
> 💬 "그래서 한 프레임 늦게 따라가고, 그게 **떨림**으로 보입니다."

**`LateUpdate` 로 바꾼다.**

```csharp
void LateUpdate()
{
    transform.position = new Vector3(target.position.x, target.position.y, -10f);
}
```

▶ Play → **떨림이 사라진다.**

> 🎉 이 비교를 반드시 눈으로 보여준다. 말로만 하면 안 남는다.

| 메서드 | 언제 | 쓰는 곳 |
|---|---|---|
| `Update` | 매 프레임 | 입력, 일반 로직 |
| `FixedUpdate` | 물리 주기 (1초 50번) | Rigidbody |
| **`LateUpdate`** | **모든 Update 가 끝난 뒤** | **카메라, 따라다니는 것** |

> 💬 "규칙 하나 더: **남을 따라다니는 건 `LateUpdate`.**"
> 💬 "042에서 '`rb.` 으로 시작하는 줄은 `FixedUpdate`' 라고 했죠. 그 짝입니다."

### ③ 부드럽게 (12분)

딱 붙어 있으면 **멀미가 난다.** 카메라가 살짝 늦게 따라오게 한다.

```csharp
[SerializeField] private float smoothTime = 0.15f;

private Vector3 velocity;

void LateUpdate()
{
    Vector3 goal = new Vector3(target.position.x, target.position.y, -10f);

    transform.position = Vector3.SmoothDamp(transform.position, goal, ref velocity, smoothTime);
}
```

▶ Play → **살짝 늦게, 부드럽게 따라온다.**

| 조각 | 뜻 |
|---|---|
| `Vector3.SmoothDamp(지금, 목표, ref 속도, 시간)` | 목표까지 **부드럽게** 이동 |
| `ref velocity` | 함수가 **속도를 기억**하려고 쓰는 칸 |
| `smoothTime` | **따라잡는 데 걸리는 대략의 시간(초)** |

> 💬 "`ref` 는 **'이 변수를 함수가 직접 고칠 수 있게'** 넘기는 겁니다. 5주차 매개변수의 특별한 형태예요."
> 💬 "지금은 **'속도를 기억하는 칸을 빌려준다'** 로만 아세요."

**숫자를 만져 본다.**

| `smoothTime` | 느낌 |
|---|---|
| `0.05` | 거의 딱 붙는다 |
| **`0.15`** | **적당하다** |
| `0.5` | 너무 늘어진다. 화면 밖으로 나간다 |

> 💬 "**정답은 없습니다. 눈으로 고르세요.** 054의 `Samples` 와 같아요."

### ④ `Lerp` 와 뭐가 다른가 (5분)

검색하면 `Lerp` 방식이 더 많이 나온다.

```csharp
transform.position = Vector3.Lerp(transform.position, goal, followSpeed * Time.deltaTime);
```

| | `Lerp` | `SmoothDamp` |
|---|---|---|
| 코드 | 짧다 | 변수가 하나 더 필요 |
| 느낌 | 처음이 빠르고 끝이 느리다 | **일정하게 부드럽다** |
| 프레임률 영향 | `deltaTime` 을 곱해도 완전히 같지는 않다 | 거의 같다 |

> 💬 "**둘 다 씁니다.** 카메라에는 `SmoothDamp` 가 조금 더 낫다고들 해요."
> 💬 "`Lerp` 는 **'A와 B 사이 어디쯤'** 을 구하는 함수예요. 앞으로 체력바·페이드에서 계속 나옵니다."

> ⚠️ 여기서 보간을 깊이 설명하지 않는다. **"둘 다 되고 느낌이 조금 다르다"** 까지.

## 01:35–01:50 · 데모 + 정리

학생 2명 데모. **`Update` 로 되돌려 떨림을 재현한 학생**을 우선한다.
비교를 다 같이 보면 `LateUpdate` 의 이유가 굳는다.

**마무리 정리 (한 장) — 세 가지 Update**

| | 언제 | 여기에 쓰는 것 |
|---|---|---|
| `Update` | 매 프레임 | **입력** (`PlayerInput`) |
| `FixedUpdate` | 물리 주기 | **Rigidbody** (`PlayerController`) |
| **`LateUpdate`** | 전부 끝난 뒤 | **따라다니는 것** (`CameraFollow`) |

> 💬 "042에서 두 개를 배웠고 오늘 셋이 됐습니다. **이게 전부예요.** 더 안 나옵니다."
