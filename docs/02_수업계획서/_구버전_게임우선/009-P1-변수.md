## 00:10–00:45 · 같이 치기 ★

### ① 불편함 먼저 (7분) — 오늘의 도입

004회차 코드를 그대로 띄운다.

```csharp
void Update()
{
    transform.position = transform.position + new Vector3(0.01f, 0, 0);
}
```

**강사가 학생들에게 시킨다**: "속도를 두 배로 해보세요." → 다들 `0.02f`로 고친다.
"다시 절반으로." → 또 고친다.
"이번엔 0.03으로." → 또 고친다.

> 💬 "지금 뭐가 불편하죠?"
> → **"매번 코드를 고쳐야 하고, 저장하고, 기다려야 하고, 숫자가 어디 있는지 찾아야 한다."**

> 💬 "이걸 해결하는 게 오늘 배울 **변수**입니다."

### ② 변수 만들기 (10분)

```csharp
public class Mover : MonoBehaviour
{
    float speed = 0.01f;   // ← 클래스 안, 함수 밖. "이 스크립트가 기억하는 값"

    void Update()
    {
        transform.position = transform.position + new Vector3(speed, 0, 0);
    }
}
```

> 💬 "`speed`라는 **이름표를 붙인 상자**를 만들고 0.01을 넣어뒀어요. 이제 아래에선 `speed`라고만 쓰면 됩니다."

**여기서 짚을 것 3가지**

| 포인트 | 설명 |
|---|---|
| 어디에 쓰나 | **함수 밖, 클래스 안.** 함수 안에 쓰면 매 프레임 초기화된다 (지금은 "여기에 쓰세요"까지만) |
| 이름 규칙 | 영어, 공백 X, 숫자로 시작 X. **의미 있는 이름으로** (`a`, `b` 금지) |
| `float`의 `f` | "소수점 있는 숫자는 뒤에 `f`를 붙입니다. 규칙이에요" — **부동소수점 설명 금지** |

### ③ `[SerializeField]` (15분) — 오늘의 하이라이트

```csharp
[SerializeField] float speed = 0.01f;
```

저장 → Unity → **Inspector에 `Speed` 칸이 생긴다.**

**Play 상태에서 숫자를 바꿔 보인다** → 큐브 속도가 실시간으로 바뀐다.

> 💬 "코드 안 고치고, 저장 안 하고, 기다리지 않고 바꿨죠. **이게 게임 만들 때 제일 많이 쓰는 방법입니다.** 나중에 무기 데미지, 적 체력 전부 이렇게 조절해요."

> ⚠️ **바로 이어서 경고**: "단, **Play 중에 바꾼 값은 저장 안 됩니다.** 003회차에 배운 거 기억나죠? 마음에 드는 숫자를 찾았으면 **Play 끄고 다시 입력**하세요."

> 💡 `public float speed;`로도 Inspector에 뜨지만 **`[SerializeField] float`을 표준으로 가르친다.** 이유는 Phase 4에서 설명(지금은 "이게 더 안전한 방식"까지만). 처음부터 좋은 습관을 들이는 게 나중에 고치는 것보다 싸다.

### ④ 자료형 4종 (5분)

Inspector에 어떻게 뜨는지 **직접 보여주며** 진행. 표만 읽지 말 것.

```csharp
[SerializeField] float speed = 0.01f;      // 소수점 O
[SerializeField] int hp = 100;             // 소수점 X (정수)
[SerializeField] bool isAlive = true;      // 참 / 거짓 → 체크박스로 뜬다!
[SerializeField] string playerName = "코딩왕";  // 글자
```

> `bool`이 Inspector에서 **체크박스**로, `string`이 **입력칸**으로 뜨는 걸 보여주면 자료형 구분이 한 번에 이해된다.

## 01:35–01:50 · 데모 + 정리

학생 2명 데모. 그중 한 명은 **⭐도전 미션 한 학생**으로 골라 `Range` 슬라이더를 보여주게 한다 — 도전 미션을 하면 자랑거리가 생긴다는 걸 반 전체가 학습한다.

마무리 정리 (칠판 한 장):

| 자료형 | 쓰는 곳 | 예 |
|---|---|---|
| `float` | 소수점 있는 수 | 속도, 시간 |
| `int` | 정수 | 체력, 점수, 개수 |
| `bool` | 참/거짓 | 살았나 죽었나 |
| `string` | 글자 | 이름, 대사 |

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| `Literal of type double cannot be...` | `float`인데 `f`를 안 붙임 | 오늘 가장 많이 나온다. "소수점 뒤엔 `f`" 반복 |
| Inspector에 안 뜸 | `[SerializeField]` 오타 / 대소문자 / 컴파일 에러 | **Console 먼저 확인.** 에러가 하나라도 있으면 아무것도 갱신 안 된다 |
| **Inspector 값이 코드보다 우선한다** | 코드에서 `= 0.05f`로 고쳤는데 Inspector가 그대로라 안 바뀜 | **오늘 가장 헷갈리는 지점.** "한 번 붙인 뒤엔 **Inspector가 이깁니다.** 코드 기본값은 처음 붙일 때만 적용돼요." 톱니바퀴 > `Reset` 알려주기 |
| 변수를 `Update` 안에 선언 | 매 프레임 초기화됨 | 지금은 "함수 밖, 클래스 안"이라는 **위치 규칙**으로만. 스코프 설명은 Phase 4 |
| 변수명에 한글/공백 | 에러 | 영어 소문자로 시작, 띄어쓰기 대신 대문자(`moveSpeed`) |
| "`public`이랑 `[SerializeField]`랑 뭐가 달라요?" | 좋은 질문 | "둘 다 Inspector에 뜹니다. `[SerializeField]`가 더 안전한 방식이고 **이유는 4단계에서**." 적어두게 시킨다 |
| 진도 빠른 학생이 `private`, `static` 물어봄 | — | 답해주되 **반 전체에 공유하지 않는다.** 개별 DM 또는 도전 미션으로 |
