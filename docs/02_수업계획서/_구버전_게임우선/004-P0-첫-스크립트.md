## 00:10–00:45 · 같이 치기 ★

**강사가 치는 걸 학생도 동시에 친다. 복붙 금지 — 오타를 내봐야 에러를 배운다.**

### ① 스크립트 만들고 붙이기 (10분)

1. `Project` 창 > `+` > `C# Script` > 이름 **`Mover`**
2. ⚠️ **이름을 만들 때 바로 정한다.** 나중에 파일명을 바꾸면 클래스명과 달라져서 안 붙는다 — **오늘 가장 흔한 사고**
3. Hierarchy의 Cube에 스크립트를 **드래그해서 놓는다**
4. Inspector에 `Mover (Script)`가 생긴 걸 확인

> 💬 "003회차에 Rigidbody 붙였죠? **똑같습니다.** 우리가 만든 부품을 붙인 거예요."

### ② Console에 글자 띄우기 (10분)

더블클릭해서 편집기를 열고, `Start` 안에 한 줄:

```csharp
void Start()
{
    Debug.Log("안녕하세요 병필입니다");
}
```

**저장(`Ctrl + S`) → Unity로 돌아가기 → 잠깐 기다리기(컴파일) → Play**

> ⚠️ **"저장하고 Unity로 돌아가서 잠깐 기다린다"를 3번 반복해서 말할 것.** 저장 안 하고 Play 눌러놓고 "안 돼요" 하는 게 오늘 질문의 절반이다.

### ③ Start vs Update (10분) — 오늘의 핵심 개념

```csharp
void Start()
{
    Debug.Log("나는 한 번만");
}

void Update()
{
    Debug.Log("나는 계속");
}
```

Play → Console이 미친 듯이 쌓이는 걸 **보여준다.**

> 💬 "`Start`는 **시작할 때 딱 한 번.** `Update`는 **1초에 60번쯤 계속.** 이 두 개가 Unity의 전부예요."

> ⚠️ 확인 후 `Update`의 Log는 **바로 지운다.** 안 지우면 이후 실습 내내 Console이 도배돼서 진짜 에러를 못 본다.

### ④ 코드 한 줄로 움직이기 (15분)

```csharp
void Update()
{
    transform.position = transform.position + new Vector3(0.01f, 0, 0);
}
```

Play → **큐브가 오른쪽으로 스르륵 간다.**

> 💬 "`transform`은 003회차에 본 그 Transform 부품이에요. **위치를 조금씩 더하고 있는 겁니다.** `0.01f`의 `f`가 왜 붙는지는 다음 주에 배웁니다."

숫자를 `0.05f`로 바꿔서 **빨라지는 걸 같이 확인.** 여기서 "내가 숫자를 바꾸면 게임이 바뀐다"는 감각이 생긴다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **스크립트가 안 붙음** ("Can't add script...") | **파일명 ≠ 클래스명.** 파일 만들 때 이름 확정 안 하고 Enter 침 | 파일 지우고 다시 만들게 한다. 이름 바꾸기보다 빠르다 |
| `; expected` | 세미콜론 누락 | 줄 번호 읽는 법 훈련 기회로 활용 |
| `The name 'debug' does not exist` | **대소문자.** `Debug` | "C#은 대소문자를 구분합니다" — 오늘 처음이자 마지막으로 이 규칙만 말해둔다 |
| 저장했는데 반영 안 됨 | Unity로 전환 안 함 / 컴파일 중 | 우하단 스피너 확인시키기 |
| Console이 도배돼서 아무것도 안 보임 | `Update`의 Log를 안 지움 | Console 좌상단 `Clear` + `Collapse` 알려주기 |
| 편집기가 안 열림 / 자동완성 없음 | VS Code 연동 미설정 | `Edit > Preferences > External Tools` 확인. **자동완성 없이 진행하지 말 것** — 오타 지옥이 된다 |
| "이게 무슨 뜻이에요? `public class`가 뭐예요?" | 호기심 (좋은 신호) | **"다음 주 통째로 그거 배웁니다."** 로 미룬다. 궁금한 걸 적어두게 시키고 Phase 1에서 회수 |
| 움직이긴 하는데 너무 빠름/느림 | 프레임마다 더하는 값 문제 | 숫자만 바꾸게 한다. `Time.deltaTime`은 **아직 꺼내지 않는다** |
