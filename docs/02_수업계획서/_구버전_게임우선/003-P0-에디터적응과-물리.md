## 00:10–00:45 · 같이 하기

### ① 에디터 6개 창 (10분)

강사가 창을 하나씩 **클릭해서 흔들며** 설명. 표만 읽지 말 것.

| 창 | 한 줄 설명 | 학생에게 하는 비유 |
|---|---|---|
| **Hierarchy** | 지금 씬에 있는 것들의 목록 | 출연자 명단 |
| **Scene** | 배치·편집하는 작업 화면 | 무대 뒤에서 세팅하는 곳 |
| **Game** | 실제로 플레이어가 보는 화면 | 관객석에서 보이는 것 |
| **Inspector** | 선택한 것의 속성 | 그 출연자의 신상명세서 |
| **Project** | 프로젝트의 모든 파일 | 창고 |
| **Console** | 로그·에러 | **여러분이 앞으로 제일 많이 볼 창** |

> 💬 "레이아웃이 망가지면 우상단 `Layout > Default`. **못 부숩니다.**"

### ② 씬 조작 (10분) — 손에 익히기

| 조작 | 방법 |
|---|---|
| 회전 | 마우스 우클릭 드래그 |
| 이동 | 마우스 휠 클릭 드래그 |
| 확대/축소 | 휠 스크롤 |
| **선택한 것으로 순간이동** | 대상 클릭 후 **`F`** |
| 이동/회전/크기 기즈모 | `W` / `E` / `R` |

> ⚠️ **`F` 키를 반드시 훈련시킬 것.** 노베이스가 "물체를 잃어버렸어요"로 5분씩 날리는 걸 막는 유일한 키다. 일부러 카메라를 멀리 보낸 뒤 `F`로 돌아오는 걸 3번 반복시킨다.

### ③ GameObject & Component (15분)

**시연 순서 — 말보다 이 순서가 설명이다.**

1. `Hierarchy > + > 3D Object > Cube` → 큐브 생성
2. Inspector를 보여주며: "지금 이 큐브가 가진 **부품 목록**입니다"
   - `Transform` — 위치/회전/크기 (모든 GameObject가 무조건 가짐)
   - `Mesh Renderer` — **눈에 보이게 하는 부품**
3. **Mesh Renderer 체크를 끈다** → 큐브가 사라짐
   > 💬 "없어진 게 아니라 **안 보이는 겁니다.** Hierarchy엔 그대로 있죠? 부품 하나 뗐을 뿐이에요."
4. 다시 켠다
5. `Add Component > Rigidbody` → **Play** → 큐브가 떨어진다
   > 💬 "코드 한 줄도 안 썼어요. **부품 하나 붙였을 뿐입니다.** Unity는 이렇게 만듭니다."

> 🔑 **오늘 심어야 할 문장**: "GameObject는 **빈 그릇**이고, Component는 **기능 부품**이다. 우리가 앞으로 짤 코드도 결국 **부품 하나**다."

### ④ Play 모드 함정 (5분) — 반드시 오늘 짚는다

1. Play를 누른 상태에서 큐브 위치를 바꾼다
2. Play를 끈다 → **원래대로 돌아간다**

> 💬 "**Play 중에 바꾼 건 저장 안 됩니다.** 입문자가 가장 많이 당하는 겁니다. 한 시간 작업하고 Play 끄면 다 날아가요. Play 중엔 상단 바 색이 살짝 바뀌는 것도 기억해두세요."

`Ctrl + S` 습관도 여기서 같이 잡는다.

## 00:55–01:35 · 개인 미션

### 필수 미션 — 도미노

1. 바닥 만들기: `3D Object > Plane`
2. 얇은 Cube를 하나 만들고 크기를 도미노처럼 (`Scale` 예: `0.2 / 1 / 0.5`)
3. `Rigidbody` 추가
4. **`Ctrl + D`로 복제**해서 일렬로 10개 세우기
5. 맨 앞에 공(`Sphere` + Rigidbody)을 놓고 살짝 띄운 뒤 Play
6. 안 무너지면 간격을 좁힌다

> 위치를 숫자로 입력하는 게 어려운 학생은 **기즈모 드래그로 배치**해도 된다. 오늘은 정확도보다 성공 경험이 우선.

### ⭐ 도전 미션 (빨리 끝난 학생용)

- [ ] 도미노를 **곡선**으로 배치하기
- [ ] `Material`을 만들어 도미노마다 다른 색 입히기 (`Project > + > Material` → 색 지정 → 드래그)
- [ ] Rigidbody의 `Mass`를 바꿔가며 **무거운 도미노가 어떻게 다른지** 관찰하고 `#자랑`에 한 줄 소감
- [ ] `Physics Material`로 잘 튀는 공 만들기

> 도전 미션은 **답을 알려주지 않는다.** "Inspector 뒤져보세요"까지만.
