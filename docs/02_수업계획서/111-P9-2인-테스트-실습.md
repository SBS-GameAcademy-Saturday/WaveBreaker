### ④ 귀찮다 → 자동화 (12분)

> 💬 "테스트할 때마다 창 두 개에서 버튼을 눌러야 합니다. **하루에 오십 번 합니다.**"

**MPPM 태그를 쓴다.** 가상 플레이어마다 이름표를 붙일 수 있다.

```
Multiplayer Play Mode 창 → Player 2 → Tags 에 "Client" 추가
```

`Scripts/Network/NetworkAutoConnect.cs`

```csharp
using Unity.Netcode;
using UnityEngine;

#if UNITY_EDITOR
using Unity.Multiplayer.PlayMode;
#endif

public class NetworkAutoConnect : MonoBehaviour
{
    [SerializeField] private bool enableAutoConnect = true;
    [SerializeField] private GameObject buttonRoot;

    private void Start()
    {
        if (!enableAutoConnect) return;

#if UNITY_EDITOR
        // Tags 는 이 가상 플레이어에 붙은 태그 목록이다. 메인 에디터는 비어 있다.
        bool isClient = false;
        foreach (string tag in CurrentPlayer.Tags)
        {
            if (tag == "Client") { isClient = true; break; }
        }

        if (isClient)
        {
            Debug.Log("태그 Client — 클라이언트로 자동 접속");
            NetworkManager.Singleton.StartClient();
        }
        else
        {
            Debug.Log("태그 없음 — 호스트로 자동 시작");
            NetworkManager.Singleton.StartHost();
        }

        if (buttonRoot != null) buttonRoot.SetActive(false);
#endif
    }
}
```

| 조각 | 뜻 |
|---|---|
| `#if UNITY_EDITOR` | **태그는 에디터에만 있다.** 빌드에는 이 코드가 안 들어간다 |
| `CurrentPlayer.Tags` | 이 창에 붙은 태그. **메인 에디터는 비어 있다** |
| 태그가 없으면 호스트 | 메인 에디터가 자동으로 호스트가 된다 |

> 🚨 **`#if UNITY_EDITOR` 를 빼면 빌드가 안 된다.** `CurrentPlayer` 는 에디터 전용이다.
> 💡 빌드한 게임에서는 이 스크립트가 아무것도 안 한다. **버튼으로 접속한다.**

▶ Play 한 번으로 **양쪽이 자동 접속**된다.

**실측 로그**

```
메인 에디터   : 태그 없음 — 호스트로 자동 시작
가상 플레이어 : 태그 Client — 클라이언트로 자동 접속
```
