## 01:40–01:50 · 🔴 원본 백업 — 같이 한다

> 💬 "**지금 다 같이 합니다.** 집에 가서 하겠다고 하면 안 하게 돼요."

### ① 무엇을 압축하나

```
✅ 넣는 것            ❌ 빼는 것
   Assets/              Library/     ← 3.2 GB
   ProjectSettings/     Temp/
   Packages/            Builds/
                        Logs/  obj/
```

### ② 왜 `Library` 를 빼나 — 강사가 잰 값

```
Assets + ProjectSettings + Packages =    10.2 MB   →  zip  2.5 MB
Library                             = 3,206.7 MB
Temp                                =    81.8 MB
```

> 🔑 💬 "**1310배 차이입니다.**"
> 💬 "`Library` 는 **유니티가 자동으로 다시 만드는 폴더**예요. 넣을 필요가 없습니다."
> 💬 "빼고 압축하면 **2.5 MB.** 메일로도 보낼 수 있어요."

### ③ 다시 열어본다 (검증)

```
1. zip 을 다른 폴더에 푼다
2. Unity Hub → Add → 그 폴더를 고른다
3. 열린다.  첫 실행은 몇 분 걸린다 (Library 를 다시 만드는 중)
```

> 💬 "**처음 열 때 오래 걸리는 게 정상**입니다. `Library` 를 새로 만드는 거예요."
