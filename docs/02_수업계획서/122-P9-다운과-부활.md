## 00:10–00:50 · 같이 하기 ★

### ① 다운은 "상태" 다 (12분)

> 💬 "죽으면 오브젝트를 없앨까요?" → **아니다.** 부활해야 하니까 남겨둔다.
> 💬 "그럼 **'쓰러져 있다' 는 상태**를 들고 있어야 합니다."

```csharp
// 다운 상태는 모두가 알아야 한다.
public NetworkVariable<bool> IsDown = new NetworkVariable<bool>(
    false, NetworkVariableReadPermission.Everyone, NetworkVariableWritePermission.Server);

// 부활까지 남은 시간. 화면에 게이지로 보여주려고 동기화한다.
public NetworkVariable<float> ReviveProgress = new NetworkVariable<float>(
    0f, NetworkVariableReadPermission.Everyone, NetworkVariableWritePermission.Server);
```

> 💬 "`ReviveProgress` 도 동기화합니다. **게이지 바를 보여주려면** 상대도 알아야 하거든요."

**체력이 0이 되면 다운으로 바꾼다** — 서버에서만 구독한다.

```csharp
private void OnHealthChanged(int before, int after)
{
    if (after > 0 || IsDown.Value) return;

    IsDown.Value = true;
    ReviveProgress.Value = 0f;

    CheckAllDown();
}
```

**보여주는 일은 각자 한다** (099·115 회수)

```csharp
// 양쪽 화면에서 불린다. 보여주는 일은 각자 한다.
private void OnDownChanged(bool before, bool after)
{
    if (sprite != null) sprite.color = after ? new Color(0.35f, 0.35f, 0.4f) : aliveColor;

    Debug.Log($"[{(IsServer ? "호스트" : "클라이언트")}] 소유자 {OwnerClientId} " + (after ? "다운" : "부활"));
}
```

> 🔑 💬 "**판정은 서버, 표시는 각자.** 이번 Phase 내내 반복되는 구조입니다."

### ② 곁에 누가 있나 (14분)

```csharp
private void Update()
{
    // 🔑 판정은 서버만. 클라이언트는 IsDown 색만 보고 있으면 된다.
    if (!IsServer) return;
    if (!IsDown.Value) return;

    // 곁에 살아 있는 동료가 있나?
    bool helperNear = false;

    foreach (var client in NetworkManager.Singleton.ConnectedClientsList)
    {
        var obj = client.PlayerObject;
        if (obj == null || obj == NetworkObject) continue;      // 나 자신은 제외

        if (!obj.TryGetComponent(out NetworkPlayerDown other)) continue;
        if (other.IsDown.Value) continue;                        // 같이 쓰러진 사람은 못 살린다

        if (Vector2.Distance(transform.position, obj.transform.position) > reviveRange) continue;

        helperNear = true;
        break;
    }
    ...
}
```

**세 가지를 걸러낸다.**

| 검사 | 왜 |
|---|---|
| `obj == NetworkObject` | **자기 자신이 자기를 살릴 수 없다** |
| `other.IsDown.Value` | 같이 쓰러진 사람은 못 살린다 |
| 거리 > `reviveRange` | 곁에 있어야 한다 |

> 💬 "두 번째를 빼면 **둘 다 쓰러졌는데 서로 살려줍니다.** 게임이 안 끝나요."

### ③ 떨어지면 처음부터 (8분)

```csharp
if (!helperNear)
{
    // 떨어지면 처음부터. 그래야 "곁에 있어야 한다" 가 성립한다.
    ReviveProgress.Value = 0f;
    return;
}

ReviveProgress.Value += Time.deltaTime;

if (ReviveProgress.Value < reviveTime) return;

Revive();
```

> 💬 "**떨어지면 0으로 되돌립니다.** 안 그러면 왔다갔다 하면서 살릴 수 있어요."
> 💬 "3초간 **계속** 곁에 있어야 한다는 게 규칙이니까요."

> 💡 이게 협동의 긴장감을 만든다. 몬스터가 몰려오는데 3초를 버텨야 한다.

### ④ 부활과 전멸 (8분)

```csharp
private void Revive()
{
    IsDown.Value = false;
    ReviveProgress.Value = 0f;

    health.SetHealth(reviveHealth);   // 기획서 — 체력 30

    Debug.Log($"[호스트] 소유자 {OwnerClientId} 부활 — 체력 {reviveHealth}");
}

// 둘 다 다운이면 게임 오버.
private void CheckAllDown()
{
    foreach (var client in NetworkManager.Singleton.ConnectedClientsList)
    {
        var obj = client.PlayerObject;
        if (obj == null) continue;

        if (!obj.TryGetComponent(out NetworkPlayerDown d)) continue;
        if (!d.IsDown.Value) return;   // 한 명이라도 서 있으면 계속한다
    }

    Debug.Log("[호스트] 전멸 — 게임 오버");
}
```

> 💬 "`return` 이 '게임 계속' 이라는 게 좀 헷갈리죠. **한 명이라도 서 있으면 끝이 아니다** 는 뜻입니다."

코드는 위 ①~④ 블록 그대로다.

**증상별 원인표**

| 증상 | 원인 |
|---|---|
| **혼자서 부활함** | 자기 자신 제외를 안 했다 |
| 둘 다 다운인데 서로 살림 | `other.IsDown` 검사 누락 |
| 게임이 안 끝남 | `CheckAllDown` 의 `return` 위치 |
| 색이 한쪽만 바뀜 | `OnValueChanged` 구독 누락 |
| 부활 체력이 20 | `SetHealth` 가 `maxHealth` 로 자른다 |
| 왔다갔다 하며 살림 | 게이지 초기화 누락 |
| 다운인데 계속 움직임 | 이동 쪽에 다운 검사가 없다 (도전 과제) |

**`SetHealth` 주의**

```csharp
public void SetHealth(int value)
{
    if (!IsServer) return;

    Health.Value = Mathf.Max(value, 0);   // 부활 체력은 부르는 쪽이 정한다
}
```

`maxHealth` 로 `Clamp` 하면 30이 20으로 잘린다. **부활 체력이 최대 체력보다 클 수 있다.**

</details>
