## 🎯 오늘의 목표

1. **GameObject는 빈 그릇, Component가 능력**인 구조를 안다
2. 컴포넌트를 **추가·제거**한다
3. Transform이 **왜 못 지워지는지** 안다

> ⚠️ **오늘 안 하는 것**: 스크립트. 물리 심화(충돌·힘)는 **9주차(Phase 3)** 로 미룬다.
> 오늘 Rigidbody는 "부품을 붙이면 능력이 생긴다"는 **예시로만** 쓴다.
>
> 🔑 **설계 의도**: 031~033에서 학생은 **Transform만** 만졌다. 그래서 "물체 = Transform"으로 오해한다.
> 오늘은 **부품을 빼봐서** 뭐가 사라지는지 겪게 한다. 조립이 아니라 **분해**로 가르친다.

## 00:10–00:45 · 같이 치기 ★

### ① 진짜 빈 그릇 (8분) — 오늘의 도입

Hierarchy 우클릭 → **Create Empty** (이름 `Empty`)

Inspector에 **Transform 하나만** 있다. Scene에 **아무것도 안 보인다.**

> 💬 "이게 진짜 빈 그릇입니다. 이름이랑 좌표만 있어요. **왜 안 보일까요?**"
>
> 학생 답을 기다린다. "그림이 없어서"가 나오면 최고.

**Add Component → `Sprite Renderer`** → Sprite 칸의 동그라미 → `Square` 선택 → **보인다.**

> 💬 "**보이는 것도 능력이고, 그것도 부품입니다.**"
> 💬 "지금까지 만든 Square는 유니티가 **부품을 미리 붙여준** 거였어요. 직접 만들면 이렇게 아무것도 없습니다."

### ② 부품 하나 = 능력 하나 (10분)

`Empty`에 부품을 하나씩 붙이며 능력이 늘어나는 걸 보여준다.

| 붙이는 부품 | 생기는 능력 |
|---|---|
| Transform | 어디에 / 얼마나 돌아서 / 얼마나 크게 **(못 뗀다)** |
| \+ **Sprite Renderer** | **보인다** |
| \+ **Box Collider 2D** | **부딪히는 몸이 생긴다** |
| \+ **Rigidbody 2D** | **중력을 받는다** |

Rigidbody 2D를 붙이고 ▶ Play → **떨어진다.**

> 💬 "코드 한 줄 없이 중력이 생겼죠. **유니티가 물리를 대신 해줍니다.**"
> 💬 "이건 9주차에 제대로 합니다. 오늘은 '부품을 붙이면 능력이 생긴다'만 보세요."

> ⚠️ **Add Component 검색창 쓰는 법**을 반드시 알려준다. 목록에서 찾는 학생은 못 찾는다.
> 💬 "`rigid`만 쳐도 나옵니다. **`2D`가 붙은 걸 고르세요.**" ← 3D를 고르는 학생이 반드시 나온다

### ③ 분해 — 빼보면 안다 (8분)

**떨어지는 상태에서 Rigidbody 2D를 지운다.** (컴포넌트 우측 `⋮` → Remove Component)

▶ Play → **안 떨어진다.**

> 💬 "능력이 사라졌죠. 그럼 그 능력은 **상자가 갖고 있던 게 아니라 부품이 갖고 있던** 겁니다."

다시 넣는다 → 떨어진다. **한 번 더 뺐다 넣는다.**

**Sprite Renderer도 빼본다** → 안 보인다. 하지만 Play하면 **여전히 떨어지고 있다.**

> 💬 "안 보이는데 떨어지고 있어요. **보이는 것과 존재하는 것은 다릅니다.**"
> → 나중에 "총알은 있는데 안 보여요" 같은 버그를 이해하는 바탕이 된다

### ④ Transform은 왜 못 지우나 (5분)

Transform의 `⋮` 를 눌러보면 **Remove Component가 없다.**

> 💬 "이건 못 뺍니다. **어디에 있는지가 없는 물체**는 존재할 수가 없으니까요."
> 💬 "그래서 032·033에서 Transform부터 배운 겁니다. **모든 물체가 반드시 갖고 있는 유일한 부품**이에요."

### ⑤ 6주차와 연결 (4분)

> 💬 "6주차에 클래스 배웠죠. `Enemy` 클래스 안에 체력, 공격력, `Attack()` 메서드가 있었어요."
> 💬 "유니티에서는 그게 **GameObject 하나에 부품 여러 개**로 나뉩니다."

| 콘솔 (5~6주차) | 유니티 |
|---|---|
| `Enemy` 객체 하나 | **GameObject** 하나 |
| 그 안의 기능들 | **Component** 여러 개 |

> 💬 "다음 시간부터는 **없는 부품을 여러분이 직접 만듭니다.** C#으로요."

## 00:55–01:35 · 개인 미션

### 필수 미션 — 부품 조합 4종

**Create Empty로만** 4개를 만들고 조합을 다르게 준다. (Square를 쓰지 않는다)

| 이름 | 부품 | 기대 동작 |
|---|---|---|
| `Invisible` | Transform만 | 안 보이고 아무것도 안 함 |
| `Decoration` | \+ Sprite Renderer | 보이지만 통과됨 |
| `Wall` | \+ Sprite Renderer + Box Collider 2D | 안 떨어지고 부딪힘 |
| `Falling` | \+ Sprite Renderer + Box Collider 2D + Rigidbody 2D | 떨어지고 부딪힘 |

- [ ] 4개를 전부 `Create Empty`로 만들었다
- [ ] `Wall`을 아래에, `Decoration`을 중간에, `Falling`을 위에 배치했다
- [ ] ▶ Play → `Falling`이 `Decoration`은 **통과**하고 `Wall`에서 **멈춘다**
- [ ] 씬을 저장했다

**확인 조건**: 떨어지는 물체가 장식은 통과하고 벽에서 멈춘다.

<details>
<summary>막히면 열기</summary>

- **안 멈추면**: `Wall`과 `Falling` **양쪽 다** Box Collider 2D가 있는지 본다. 한쪽만 있으면 통과한다
- **바닥도 같이 떨어지면**: `Wall`에 Rigidbody 2D를 잘못 넣은 것이다. 지운다
- **안 보이면**: Sprite Renderer의 Sprite 칸이 `None`인지 본다. 동그라미 → `Square`
- **3D를 넣었으면**: `Rigidbody` 와 `Rigidbody 2D` 는 다르다. **2D가 붙은 것**으로 다시
</details>

### ⭐ 도전 미션

- [ ] `Falling`의 Collider를 `Circle Collider 2D`로 바꿔 굴러가게 한다
- [ ] `Wall`을 Rotation Z로 기울여 미끄러지게 한다
- [ ] Rigidbody 2D의 **Gravity Scale**을 `3`으로 바꾸고 뭐가 달라지는지 한 줄로 쓴다
- [ ] Rigidbody 2D의 **Body Type**을 `Kinematic`으로 바꾸고 관찰한다
- [ ] 컴포넌트 우측 **체크박스**를 끄면 어떻게 되는지 확인한다 (지우는 것과 뭐가 다른가)
- [ ] `Falling`을 20개로 늘려 쌓아본다

## 01:35–01:50 · 데모 + 부품표 정리

학생 2명 데모. 굴러가는 원(⭐도전)을 한 학생을 반드시 포함한다.

**마무리 정리 (한 장)**

| 부품 | 없으면 | 있으면 |
|---|---|---|
| **Transform** | **존재 불가** (못 지운다) | 위치·회전·크기 |
| **Sprite Renderer** | 안 보인다 (있긴 하다) | 그림이 보인다 |
| **Collider 2D** | 통과한다 | 부딪힌다 |
| **Rigidbody 2D** | 가만히 있는다 | 중력을 받는다 |

> 💬 "벽이랑 떨어지는 상자의 차이는 **부품 하나**예요."

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| 빈 GameObject가 안 보임 | 정상 | **의도된 것.** "Sprite Renderer가 없으니까요" |
| Sprite Renderer 넣어도 안 보임 | Sprite 칸이 `None` | 동그라미 → `Square` |
| **3D Rigidbody를 넣음** | 검색 결과 첫 줄을 고름 | **오늘 최다.** "`2D`가 붙은 것" |
| 떨어지는데 안 멈춤 | 떨어지는 쪽에 Collider 없음 | **양쪽 다** 필요하다 |
| 바닥도 같이 떨어짐 | `Wall`에 Rigidbody | Remove Component |
| Add Component 목록에서 헤맴 | 검색을 안 씀 | 검색창에 타이핑하게 한다 |
| Remove Component를 못 찾음 | `⋮` 위치 | 화면 공유로 한 번 짚어준다 |
| 체크박스와 삭제를 혼동 | 개념 차이 | "끈 건 되돌릴 수 있고, 지운 건 다시 붙여야 한다" |
| Play 중 부품을 붙임 | 멈추면 사라진다 | **037회차에 정식으로 다룬다.** 오늘은 "Stop하고 하세요" |
| 물리가 재밌어서 계속 파고듦 | 좋은 신호 | ⭐도전으로. **충돌 이벤트는 9주차** |
