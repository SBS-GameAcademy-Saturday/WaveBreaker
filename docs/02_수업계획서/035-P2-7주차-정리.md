## 00:00–00:15 · 7주차 전체 복습 (퀴즈 8문제)

1. 물체가 안 보일 때 → **클릭하고 `F`**
2. 창을 잃어버렸을 때 → **Window → Layouts → Default**
3. X가 음수면 → **왼쪽**
4. Y가 커지면 → **위**
5. 2D에서 쓰는 회전축은 → **Z**
6. Scale X에 `-1`을 넣으면 → **뒤집힌다**
7. 자식의 좌표 기준은 → **부모**
8. 못 지우는 부품은 → **Transform**

> 한 문제라도 못 맞히는 학생이 3명 이상이면 **그 항목을 다시 시연한다.** 오늘은 그래도 되는 날이다.

## 00:15–00:40 · 같이 치기 ★ — 막혔을 때 확인 순서

새 문법 대신 **자가 진단 절차**를 가르친다. 이게 오늘의 진짜 수업이다.

### "안 돼요"가 나왔을 때 확인 순서 5단계

> 💬 "앞으로 6개월 동안 계속 막힙니다. 그때마다 저를 부르기 전에 **이 순서로 먼저 보세요.**"

| 순서 | 확인 | 어떻게 |
|---|---|---|
| **1** | **물체가 화면 안에 있나** | Hierarchy 클릭 → `F` |
| **2** | **Inspector 값이 이상하지 않나** | Scale이 0인가, Rotation X/Y가 돌았나, Position Z가 큰가 |
| **3** | **부품이 다 붙어 있나** | 안 보이면 Sprite Renderer, 안 부딪히면 Collider |
| **4** | **체크박스가 켜져 있나** | 오브젝트 이름 왼쪽, 컴포넌트 왼쪽 **둘 다** |
| **5** | **Console에 빨간 줄이 있나** | 있으면 **더블클릭** |

**강사가 각 단계를 일부러 고장 내서 시연한다.**

- Scale을 0으로 → 사라짐 → 1로 복구
- Rotation X를 45로 → 납작 → Reset
- Sprite Renderer를 뗌 → 안 보임 → 다시 붙임
- 체크박스를 끔 → 사라짐 → 켬
- Position Z에 100 → 이상해짐 → 0으로

> 💬 "이 다섯 개로 **열 번 중 아홉 번은** 해결됩니다. 나머지 한 번만 저를 부르세요."
>
> 📌 이 표를 **채팅에 고정**하거나 공지에 박아둔다. 다음 주부터 여기에 항목이 더 붙는다.

## 00:50–01:35 · 개인 미션 (45분)

### 필수 미션 — "내 놀이터" 만들기

새 씬 `Playground`를 만들고 **7주차에 배운 것만으로** 장면을 구성한다.

**요구 조건**

- [ ] 바닥이 있다 (Sprite Renderer + Collider, **Rigidbody 없음**)
- [ ] 떨어지는 물체가 **3개 이상** 있다 (Rigidbody + Collider)
- [ ] **부모자식 구조**가 최소 한 곳 있다 (부모를 옮기면 자식이 따라온다)
- [ ] **회전된 물체**가 하나 있다 (Rotation Z)
- [ ] **뒤집힌 물체**가 하나 있다 (Scale 음수)
- [ ] 모든 오브젝트 이름을 알아보게 지었다
- [ ] Position 값이 **정수**로 정리돼 있다
- [ ] `Assets/_Project/Scenes/Playground.unity` 로 저장했다

**확인 조건**: ▶ Play하면 물체들이 떨어져 바닥에 쌓인다. 부모를 옮기면 자식이 따라온다.

<details>
<summary>막히면 열기 (조립 순서)</summary>

1. `File → New Scene → Basic 2D` → **바로 저장** (`Playground`)
2. 바닥: Square → 이름 `Ground` → Position `(0, -4)` → Scale `(12, 0.5, 1)` → **Box Collider 2D만**
3. 떨어질 것 3개: Square → 각각 **Rigidbody 2D + Box Collider 2D** → Position을 위쪽에 흩어 놓는다
4. 부모자식: 빈 오브젝트 `Tower` 만들고 그 아래 Square 3개를 자식으로 → `Tower`를 옮겨 확인
5. 하나는 Rotation Z `30`, 하나는 Scale X `-1`
6. Play → 확인 → **Stop** → 정리 → `Ctrl+S`

안 되면 **위의 5단계 확인 순서**를 먼저 돌린다.
</details>
