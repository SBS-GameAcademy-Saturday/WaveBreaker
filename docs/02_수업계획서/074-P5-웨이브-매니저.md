## 00:10–00:50 · 같이 하기 ★

### ① 계속 나오게 만든다 (10분)

`WaveManager` 에 코루틴을 붙인다.

```csharp
using System.Collections;
using UnityEngine;

public class WaveManager : MonoBehaviour
{
    [SerializeField] private GameObject[] enemyPrefabs;
    [SerializeField] private Transform[] spawnPoints;
    [SerializeField] private float spawnInterval = 2f;

    private void Start()
    {
        StartCoroutine(SpawnRoutine());
    }

    private IEnumerator SpawnRoutine()
    {
        while (true)
        {
            SpawnOne();
            yield return new WaitForSeconds(spawnInterval);
        }
    }

    // SpawnOne() 은 073에서 만든 그대로
}
```

▶ Play → 2초마다 한 마리씩 계속 나온다.

> 💬 "052에서 만든 거랑 **똑같습니다.** 새로울 게 없어요."

> 🚨 **`while` 안에 `yield` 가 없으면 유니티가 통째로 멈춘다** (051).
> Play 전에 **`Ctrl+S`** 는 습관이다.

### ② 웨이브 — 코루틴을 하나 더 돌린다 (15분) — 오늘의 핵심

> 💬 "이제 **시간이 지나면 더 자주** 나오게 하고 싶어요. 어디에 코드를 넣을까요?"

학생들은 보통 `SpawnRoutine` 안에 넣으려 한다. **그걸 먼저 해보게 한다.**

```csharp
// 학생들이 흔히 짜는 것
private IEnumerator SpawnRoutine()
{
    float timer = 0f;
    while (true)
    {
        SpawnOne();
        timer += spawnInterval;          // ← 이게 정확할까?
        if (timer > 15f) { ... }
        yield return new WaitForSeconds(spawnInterval);
    }
}
```

> 💬 "되긴 됩니다. 그런데 **간격이 변하니까 시간 계산이 자꾸 어긋나요.**"
> 💬 "그리고 **한 함수가 두 가지 일**을 하고 있죠. 소환도 하고, 시간도 재고."

**코루틴을 하나 더 만든다.**

```csharp
[SerializeField] private float minInterval = 0.4f;
[SerializeField] private float intervalStep = 0.3f;
[SerializeField] private float waveDuration = 15f;

public int Wave { get; private set; } = 1;

private void Start()
{
    StartCoroutine(SpawnRoutine());
    StartCoroutine(WaveRoutine());     // ← 두 개를 동시에 돌린다
}

private IEnumerator WaveRoutine()
{
    while (true)
    {
        yield return new WaitForSeconds(waveDuration);

        Wave++;
        spawnInterval = Mathf.Max(spawnInterval - intervalStep, minInterval);

        Debug.Log($"웨이브 {Wave}  (간격 {spawnInterval:F2}초)");
    }
}
```

> 🔑 **코루틴은 몇 개든 동시에 돌릴 수 있다.**
> 💬 "하나는 **소환만**, 하나는 **시계만** 봅니다. 각자 자기 일만 해요."
> 💬 "이렇게 나누면 나중에 **웨이브 규칙만 바꾸고 싶을 때** 그 함수만 보면 됩니다."

**실측 (강사 화면에서 보여준다)**

```
웨이브 2  (간격 1.70초)
웨이브 3  (간격 1.40초)
웨이브 4  (간격 1.10초)
웨이브 5  (간격 0.80초)
웨이브 6  (간격 0.50초)
웨이브 7  (간격 0.40초)   ← 여기서 더 안 줄어든다
```

> 💬 "7웨이브에서 멈췄죠? **`Mathf.Max` 가 0.4 아래로 못 내려가게** 막고 있어요."
> 💬 "이게 없으면 **간격이 0이 되고, 그 다음엔 음수**가 됩니다. 게임이 터져요."

### ③ 웨이브가 오르면 종류가 늘어난다 (10분)

```csharp
// 웨이브가 오를수록 나오는 종류가 늘어난다. 1웨이브엔 돌진형만 나온다.
private int KindCount()
{
    return Mathf.Min(Wave, enemyPrefabs.Length);
}

public void SpawnOne()
{
    if (enemyPrefabs.Length == 0 || spawnPoints.Length == 0) return;

    GameObject prefab = enemyPrefabs[Random.Range(0, KindCount())];
    Transform point = spawnPoints[Random.Range(0, spawnPoints.Length)];

    Instantiate(prefab, point.position, Quaternion.identity);
}
```

| 웨이브 | 나오는 종류 |
|---|---|
| 1 | 돌진형만 |
| 2 | 돌진형 · 러너 |
| 3 이상 | 돌진형 · 러너 · 탱커 |

> 💬 "**배열 순서가 곧 등장 순서**입니다. Inspector 에서 순서를 바꾸면 등장 순서가 바뀌어요."
> 💬 "`Mathf.Min` 은 **배열 밖으로 나가는 걸** 막습니다. 웨이브가 100이 돼도 3까지만."

> 🚨 `Random.Range(0, KindCount())` 의 **두 번째 값은 포함되지 않는다** (052).
> `KindCount()` 가 `2` 면 `0`과 `1` 만 나온다. 딱 맞다.

```csharp
using System.Collections;
using UnityEngine;

public class WaveManager : MonoBehaviour
{
    [SerializeField] private GameObject[] enemyPrefabs;
    [SerializeField] private Transform[] spawnPoints;
    [SerializeField] private float spawnInterval = 2f;
    [SerializeField] private float minInterval = 0.4f;
    [SerializeField] private float intervalStep = 0.3f;
    [SerializeField] private float waveDuration = 15f;

    public int Wave { get; private set; } = 1;
    public float Interval => spawnInterval;

    private void Start()
    {
        StartCoroutine(SpawnRoutine());
        StartCoroutine(WaveRoutine());
    }

    private IEnumerator SpawnRoutine()
    {
        while (true)
        {
            SpawnOne();
            yield return new WaitForSeconds(spawnInterval);
        }
    }

    private IEnumerator WaveRoutine()
    {
        while (true)
        {
            yield return new WaitForSeconds(waveDuration);

            Wave++;
            spawnInterval = Mathf.Max(spawnInterval - intervalStep, minInterval);

            Debug.Log($"웨이브 {Wave}  (간격 {spawnInterval:F2}초, 종류 {KindCount()}가지)");
        }
    }

    private int KindCount()
    {
        return Mathf.Min(Wave, enemyPrefabs.Length);
    }

    public void SpawnOne()
    {
        if (enemyPrefabs.Length == 0 || spawnPoints.Length == 0) return;

        GameObject prefab = enemyPrefabs[Random.Range(0, KindCount())];
        Transform point = spawnPoints[Random.Range(0, spawnPoints.Length)];

        Instantiate(prefab, point.position, Quaternion.identity);
    }

    [ContextMenu("한 마리 소환")]
    private void SpawnFromMenu() => SpawnOne();
}
```

## 01:35–01:50 · 데모 + 정리

학생 3~4명 데모. **숫자를 바꾼 이유**를 말하게 한다.

**마무리 정리 (한 장)**

| 코루틴 | 하는 일 | 주기 |
|---|---|---|
| `SpawnRoutine` | 소환만 | `spawnInterval` (변한다) |
| `WaveRoutine` | 시계만 | `waveDuration` (고정) |

| 안전장치 | 막는 것 |
|---|---|
| `Mathf.Max(간격, minInterval)` | 간격이 0 이나 음수가 되는 것 |
| `Mathf.Min(Wave, 개수)` | 배열 밖으로 나가는 것 |

> 💬 "함수 하나가 **한 가지 일**만 하게 나누세요. 그게 나중에 고치기 쉬운 코드입니다."

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **유니티가 통째로 멈춤** | `while` 안에 `yield` 없음 | **오늘 1등.** 작업 관리자로 종료. Play 전 `Ctrl+S` |
| 몬스터가 안 나옴 | `StartCoroutine` 을 안 부름 | 코루틴은 **불러야** 돈다 (051) |
| 한 마리만 나옴 | `while (true)` 가 아님 | `if` 로 썼는지 확인 |
| **간격이 음수가 됨** | `Mathf.Max` 누락 | **오늘 2등.** 화면이 몬스터로 꽉 찬다 |
| `IndexOutOfRangeException` | `Mathf.Min` 누락 | 웨이브가 배열 크기를 넘었다 |
| 웨이브가 안 오름 | `WaveRoutine` 을 안 시작함 | `Start` 에 두 줄 다 있는지 |
| 웨이브가 너무 빨리 오름 | `waveDuration` 이 작다 | Inspector 확인 |
| 3웨이브인데 한 종류만 나옴 | 배열에 프리팹이 하나만 | Inspector 확인 |
| 프레임이 뚝뚝 떨어짐 | 몬스터가 100마리 넘음 | **정상.** 풀링은 101회차 |
| 몬스터가 화면에 안 보임 | 스폰 포인트가 너무 멀다 | 073 확인 |
| 코루틴이 두 번 돎 | `Start` 와 `OnEnable` 양쪽에서 시작 | 한 곳에서만 |
| Play 를 껐다 켜니 웨이브가 1 | 정상 | 저장되는 값이 아니다 |
