## 00:10–00:45 · 같이 치기 ★

**강사가 치는 걸 학생도 동시에 친다. 복붙 금지 — 오타를 내봐야 에러를 배운다.**

### ① 콘솔 프로젝트 만들기 (10분)

1. Visual Studio → 새 프로젝트 만들기
2. **콘솔 앱 (C#)** 선택 — ⚠️ ".NET Framework" 말고 그냥 **콘솔 앱**
3. 프로젝트 이름 `HelloCSharp`
4. 위치: **경로에 한글·공백 없는 곳** (예: `C:\CSharp\`)

> ⚠️ **한글 경로 금지를 오늘 못 박는다.** 21주차 빌드에서 터진다. "지금 5초 아끼면 다섯 달 뒤에 하루 날립니다."

### ② 화면에 글자 띄우기 (10분)

```csharp
using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("안녕하세요");
    }
}
```

**Ctrl + F5로 실행** → 검은 창에 글자가 뜬다.

> 💬 "지금 여러분이 프로그램을 만든 겁니다. 진짜로요."

> ⚠️ **F5(디버그 실행)가 아니라 Ctrl+F5**를 먼저 가르친다. F5는 창이 바로 닫혀서 노베이스가 "아무것도 안 떠요"로 15분을 쓴다.

### ③ 위에서 아래로 실행된다 (10분)

```csharp
Console.WriteLine("첫 번째 줄");
Console.WriteLine("두 번째 줄");
Console.WriteLine("세 번째 줄");
```

순서를 바꿔서 다시 실행 → **출력 순서도 바뀐다.**

> 💬 "프로그램은 위에서 아래로 한 줄씩 실행됩니다. 이게 전부예요."

### ④ 규칙 3개 (5분)

| 규칙 | 설명 |
|---|---|
| `;` | 한 줄 끝에 반드시. "문장의 마침표" |
| `{ }` | 짝이 맞아야 한다. 열었으면 닫는다 |
| **대소문자 구분** | `Console` ≠ `console` |

> 이 3개만 말하고 넘어간다. 문법 설명은 하지 않는다.
