### ② `AudioManager` (12분)

```csharp
using UnityEngine;

// 100회차 · 소리를 내는 곳을 한 군데로 모은다.
//
// 몬스터마다 AudioSource 를 붙이면 30마리가 동시에 죽을 때 소리가 30개 겹쳐 시끄럽다.
// 여기 하나만 두고, 같은 소리는 최소 간격을 두고 낸다.
public class AudioManager : MonoBehaviour
{
    public static AudioManager Instance { get; private set; }

    [SerializeField] private AudioSource source;
    [SerializeField] private float minGap = 0.05f;

    // 어떤 소리를 마지막으로 언제 냈는지. 소리별로 따로 센다.
    private readonly Dictionary<AudioClip, float> lastPlayed = new Dictionary<AudioClip, float>();

    private void Awake()
    {
        if (Instance != null && Instance != this) { Destroy(gameObject); return; }
        Instance = this;

        if (source == null) source = GetComponent<AudioSource>();
    }

    public void Play(AudioClip clip, float volume = 1f)
    {
        if (clip == null || source == null) return;

        if (lastPlayed.TryGetValue(clip, out float last))
        {
            if (Time.unscaledTime - last < minGap) return;
        }

        lastPlayed[clip] = Time.unscaledTime;

        source.PlayOneShot(clip, volume);
    }
}
```

| 조각 | 뜻 |
|---|---|
| `static Instance` | 066의 싱글톤과 같은 방식 |
| `PlayOneShot` | **겹쳐서 재생된다.** `Play()` 는 앞 소리를 끊는다 |
| `Dictionary<AudioClip, float>` | 소리마다 마지막 재생 시각을 따로 센다 |
| `Time.unscaledTime` | **멈춰 있어도 소리는 나야 한다** (버튼음) |
| `minGap` | 같은 소리는 0.05초 안에 두 번 안 낸다 |

> 🔑 💬 "**`Dictionary` 를 쓴 이유**는 소리마다 따로 세야 하기 때문입니다."
> 💬 "타격음이 방금 났다고 해서 **버튼음까지 막으면** 안 되잖아요."
> 💡 `Dictionary` 는 026회차에서 배웠다. **"열쇠로 값을 찾는 것."**

**`AudioSource` 설정**

| 항목 | 값 | 왜 |
|---|---|---|
| Play On Awake | **끔** | 켜면 시작하자마자 소리가 난다 |
| Spatial Blend | **0 (2D)** | 3D 로 두면 카메라 거리에 따라 볼륨이 변한다 |

> 🚨 **`AudioListener` 는 씬마다 하나여야 한다.** 보통 `Main Camera` 에 붙어 있다.
> 두 개면 **경고가 뜨고 소리가 이상해진다.**

### ④ 겹침을 막는다 (8분)

▶ `minGap` 을 `0` 으로 두고 웨이브 5까지 가본다.

> 💬 "**시끄럽죠.** 칼 네 자루가 초당 수십 번 맞으면 소리가 수십 개 겹칩니다."

`minGap = 0.05` 로 되돌린다.

> 💬 "0.05초면 **초당 최대 20번**입니다. 그 이상은 사람이 구분도 못 해요."

> 💡 `Play()` 대신 `PlayOneShot()` 을 쓴 이유도 같이 짚는다.
> `Play()` 는 앞 소리를 **끊고** 새로 시작한다. 효과음이 뚝뚝 잘린다.
