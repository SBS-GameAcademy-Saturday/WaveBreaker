## 00:10–00:50 · 같이 하기 ★

### ① 총알 프리팹 (8분)

`Projectile` 프리팹을 만든다.

| 항목 | 값 |
|---|---|
| `Sprite Renderer` | 탄 그림, Sorting Layer `Player` |
| `Rigidbody 2D` | **Gravity Scale `0`** |
| `Circle Collider 2D` | **`Is Trigger` 켬**, Radius `0.16` |
| `Projectile` | 아래 스크립트 |

```csharp
using UnityEngine;

public class Projectile : MonoBehaviour
{
    [SerializeField] private float speed = 12f;
    [SerializeField] private int damage = 3;
    [SerializeField] private float lifeTime = 2f;

    private Rigidbody2D rb;

    private void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    private void Start()
    {
        rb.linearVelocity = transform.up * speed;
        Destroy(gameObject, lifeTime);
    }

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (!other.CompareTag("Enemy")) return;
        if (!other.TryGetComponent(out IDamageable target)) return;

        target.TakeDamage(damage);
        Destroy(gameObject);
    }
}
```

> 💬 "**047의 `Bullet.cs` 랑 거의 똑같죠.** 달라진 건 `IDamageable` 을 쓴다는 것뿐입니다."

> 🚨 **`Destroy(gameObject, lifeTime)` 를 빼면 총알이 영원히 날아간다.**
> 화면 밖으로 나가도 살아 있다. 몇 분이면 수천 개가 쌓인다 (048).

### ② 쏜다 (8분)

`AutoGun` 에 발사를 붙인다.

```csharp
[SerializeField] private GameObject projectilePrefab;

private void Fire()
{
    if (CurrentTarget == null) return;

    Vector2 dir = ((Vector2)CurrentTarget.position - (Vector2)transform.position).normalized;

    GameObject shot = Instantiate(projectilePrefab, transform.position, Quaternion.identity);
    shot.transform.up = dir;
}
```

> 🔑 **`shot.transform.up = dir;`** — 064에서 배운 그 한 줄이다.
> 💬 "방향 벡터를 `up` 에 그냥 넣으면 **유니티가 회전을 만들어 줍니다.**
> `Quaternion` 계산을 직접 할 필요가 없어요."

> 🚨 **이 줄을 빼면 총알이 전부 위로만 날아간다.** 일부러 빼고 한 번 실행해 보여준다.

### ③ 코루틴으로 옮긴다 (10분) — 078의 숙제

**지금 상태의 문제를 먼저 본다.**

> 💬 "`Update` 에서 매 프레임 조준하고 있죠. 몬스터 100마리면 초당 6000번 거리 계산입니다."
> 💬 "그런데 **총은 0.5초에 한 번만** 쏴요. 나머지 계산은 전부 버려집니다."

```csharp
using System.Collections;
using UnityEngine;

public class AutoGun : MonoBehaviour
{
    [SerializeField] private GameObject projectilePrefab;
    [SerializeField] private float range = 8f;
    [SerializeField] private float fireInterval = 0.5f;

    public Transform CurrentTarget { get; private set; }

    private void Start()
    {
        StartCoroutine(FireRoutine());
    }

    private IEnumerator FireRoutine()
    {
        while (true)
        {
            yield return new WaitForSeconds(fireInterval);

            CurrentTarget = FindNearest();

            // 사거리 안에 아무도 없으면 아낀다.
            if (CurrentTarget == null) continue;

            Vector2 dir = ((Vector2)CurrentTarget.position - (Vector2)transform.position).normalized;

            GameObject shot = Instantiate(projectilePrefab, transform.position, Quaternion.identity);
            shot.transform.up = dir;
        }
    }

    // FindNearest 는 078에서 만든 그대로
}
```

▶ Play → **0.5초마다 가장 가까운 적에게 총알이 날아간다.**

| 바뀐 점 | |
|---|---|
| `Update` 삭제 | 매 프레임 조준을 그만둔다 |
| `FireRoutine` | **쏘기 직전에만** 조준한다 |
| `continue` | 적이 없으면 **다음 바퀴로** (051의 `yield break` 와 다르다) |

> 💬 "064에서 만든 `AutoShooter` 랑 **구조가 똑같습니다.** 코루틴 안에서 찾고, 쏘고, 기다리고."

> 🚨 **`yield` 를 `while` 안에서 빼먹으면 유니티가 멈춘다** (051). Play 전에 `Ctrl+S`.

> ⚠️ **Gizmo 조준선이 뚝뚝 끊겨 보인다.** 이제 0.5초마다만 갱신하니 정상이다.
> 매끄럽게 보고 싶으면 `Update` 로 되돌리면 되지만, **성능을 택했다**고 설명한다.

### ④ 관통 (12분) — 오늘의 핵심

▶ Play → 몬스터가 몰려오면 **총알 하나에 한 마리씩**밖에 못 잡는다.

> 💬 "몬스터가 100마리인데 한 발에 한 마리면 감당이 안 되죠."
> 💬 "총알이 **뚫고 지나가게** 만듭시다."

```csharp
[SerializeField] private int pierce = 2;      // 몇 마리까지 뚫는가

private void OnTriggerEnter2D(Collider2D other)
{
    if (!other.CompareTag("Enemy")) return;
    if (!other.TryGetComponent(out IDamageable target)) return;

    target.TakeDamage(damage);

    pierce--;

    if (pierce <= 0)
    {
        Destroy(gameObject);
    }
}
```

> 💬 "**남은 관통 수를 세고, 0이 되면 사라집니다.** 그게 전부예요."
> 💬 "061에서 목숨을 셌던 거랑 같은 구조입니다. 숫자를 깎고, 0이면 끝."

| `pierce` | 결과 |
|---|---|
| `1` | 한 마리 맞고 사라진다 (047과 같다) |
| `2` | **두 마리를 뚫는다** |
| `999` | 화면 끝까지 다 뚫는다 — 너무 세다 |

> 🚨 **`pierce--` 를 빼면 총알이 영원히 뚫는다.** `lifeTime` 이 끝날 때까지.
> 실제로 해보면 **한 발로 화면을 쓸어버린다.** 재미없다는 걸 보여준다.

> 💡 **프리팹 값이 아니라 복사본 값이 깎인다.** 총알마다 자기 `pierce` 를 갖고 있다 (046).
> 프리팹 원본은 그대로다.
