## 00:10–00:45 · 같이 치기 ★

### ① Rotation — Z만 쓴다 (10분)

`Square` 하나를 놓고 Rotation을 하나씩 건드린다. **순서가 중요하다.**

| 넣을 값 | 결과 | 반응 |
|---|---|---|
| **Z = `45`** | 마름모처럼 기울어진다 | "이게 우리가 쓸 거예요" |
| **X = `45`** | **납작해진다** | "어? 이상하죠" |
| **Y = `45`** | 역시 납작 | "이것도요" |
| X, Y를 `0`으로 | 정상 복귀 | |

> 💬 "X랑 Y로 돌리면 물체가 **화면 안쪽으로 누워버립니다.** 3D라면 맞는 동작인데, 2D에서는 쓸 일이 없어요."
> 💬 "**2D는 Z만.** 시계 방향으로 도는 게 아니라 **반시계 방향**이 양수입니다."

`Z = 90`, `Z = 180`, `Z = -90`을 넣어보게 한다.

> ⚠️ **X·Y를 0으로 되돌리는 법을 반드시 같이 알려준다.** 안 그러면 "납작해졌어요"가 남는다.
> Position 때와 같이 Transform 우측 `⋮` → **Reset**.

**회전 툴** `E` 키도 짚는다. 파란 원을 끌면 Z가 돈다.

> 💬 "빨강·초록 원은 건드리지 마세요. **파란 원만.**"

### ② Scale — 크기와 뒤집기 (10분)

| 넣을 값 | 결과 |
|---|---|
| Scale `1, 1, 1` | 기본 크기 |
| Scale `2, 2, 1` | 두 배 |
| Scale `0.5, 0.5, 1` | 절반 |
| Scale `3, 0.5, 1` | **가로로 늘어난 납작한 것** |
| **Scale `-1, 1, 1`** | **좌우로 뒤집힌다** |

> 💬 "`1`이 기본입니다. 2면 두 배, 0.5면 절반."
> 💬 "**X에 마이너스를 넣으면 거울처럼 뒤집힙니다.** 이거 나중에 캐릭터가 왼쪽 볼 때 씁니다." ← Phase 5 복선

**뒤집기를 반드시 실습시킨다.** 좌우 비대칭 도형(입 달린 얼굴 등)으로 해야 눈에 보인다.

> ⚠️ Scale에 `0`을 넣으면 사라진다. "크기가 0이면 없는 거죠"로 설명하고 되돌린다.
> ⚠️ Scale Z는 2D에서 의미 없다. **`1`로 두게 한다.**

### ③ 부모자식 — 오늘의 핵심 (15분)

**Hierarchy에서 오브젝트를 다른 오브젝트 위로 끌어다 놓으면** 자식이 된다.

**시연 순서 (태양-지구)**

1. `Sun` (큰 원), `Earth` (작은 원)을 따로 만든다
2. 둘 다 움직여 본다 → **따로 논다**
3. Hierarchy에서 `Earth`를 `Sun` **위로 드래그** → 들여쓰기 되며 자식이 된다
4. `Sun`의 Position을 바꾼다 → **`Earth`가 따라온다**
5. `Sun`의 Rotation Z를 돌린다 → **`Earth`가 궤도를 돈다**
6. `Sun`의 Scale을 키운다 → **`Earth`도 같이 커진다**

> 💬 "부모를 움직이면 자식이 따라옵니다. **부모가 세상의 기준이 되는** 거예요."
> 💬 "캐릭터가 움직이면 체력바도 따라와야 하죠. 그때 이걸 씁니다."

**여기서 반드시 짚을 것 — 좌표가 바뀐다**

자식으로 넣는 순간 `Earth`의 Position 숫자가 **달라진다.**

| | 부모 없을 때 | `Sun`의 자식일 때 |
|---|---|---|
| Position `(3, 0)`의 의미 | **원점**에서 오른쪽 3 | **`Sun`에서** 오른쪽 3 |

> 💬 "자식이 되면 좌표를 **부모 기준으로 셉니다.** `(0, 0)`은 원점이 아니라 **부모가 있는 자리**예요."
>
> 🚨 이 한 문장이 오늘의 핵심이다. **판서하듯 채팅에 고정한다.**
>
> ⚠️ "로컬 좌표계"라는 용어는 **쓰지 않는다.** 물어보는 학생에게만 개별로 알려준다.

**자식에서 빼는 법**: Hierarchy에서 밖으로 드래그. 빼면 좌표가 또 바뀐다.

## 00:55–01:35 · 개인 미션

### 필수 미션 — 로봇팔 만들기

부모자식으로 **3단 로봇팔**을 만든다. 어깨를 돌리면 팔 전체가 돌아야 한다.

```
Shoulder (어깨)          ← 부모
└── UpperArm (윗팔)      ← Shoulder 의 자식
    └── LowerArm (아랫팔) ← UpperArm 의 자식
        └── Hand (손)     ← LowerArm 의 자식
```

- [ ] Square 4개로 위 계층을 만든다
- [ ] 각 마디가 이어져 보이게 Position을 잡는다
- [ ] `Shoulder`의 **Rotation Z를 돌리면 팔 전체가** 돌아간다
- [ ] `UpperArm`의 Rotation Z를 돌리면 **그 아래만** 돌아간다
- [ ] 마디마다 색을 다르게 준다
- [ ] 씬을 저장한다

**확인 조건**: `Shoulder`만 돌렸는데 손까지 따라 움직인다.

<details>
<summary>막히면 열기 (값 예시)</summary>

| 오브젝트 | Position (부모 기준) | Scale |
|---|---|---|
| `Shoulder` | `0, 0, 0` | `0.5, 0.5, 1` |
| `UpperArm` | `1.5, 0, 0` | `1, 0.6, 1` |
| `LowerArm` | `1.5, 0, 0` | `1, 0.8, 1` |
| `Hand` | `1.2, 0, 0` | `0.8, 0.8, 1` |

**순서가 중요하다.** 먼저 4개를 만들어 계층부터 만들고, **그다음** 좌표를 넣는다.
좌표를 먼저 넣고 자식으로 만들면 위치가 튄다.

팔이 흩어져 보이면 → 자식의 Position은 **부모 기준**이라는 걸 다시 확인한다.
`(1.5, 0)`은 "원점에서 1.5"가 아니라 "**부모에서** 1.5"다.
</details>

### ⭐ 도전 미션

- [ ] `Hand`에 손가락 3개를 자식으로 더 붙인다
- [ ] `Shoulder`의 Scale을 키우면 팔 전체가 커지는지 확인한다
- [ ] `Hand`의 Scale X에 `-1`을 줘서 뒤집는다
- [ ] 로봇팔을 통째로 복제(`Ctrl+D`)해서 반대쪽 팔을 만든다 (**Scale X = -1** 로 미러링)
- [ ] `UpperArm`을 부모에서 **빼내면** 좌표가 어떻게 바뀌는지 관찰하고 한 줄로 쓴다
- [ ] 태양–지구–달 3단 계층을 만들어 달이 지구를 도는 구조를 만든다

## 01:35–01:50 · 데모 + Transform 3줄 정리

학생 3명 데모. **어깨를 돌려서** 팔 전체가 도는 걸 보여주게 한다.

**마무리 정리 (한 장)**

| 줄 | 뜻 | 2D에서 |
|---|---|---|
| **Position** | 어디에 | X(가로), Y(세로). **Z는 0** |
| **Rotation** | 얼마나 돌았나 | **Z만.** 반시계가 양수 |
| **Scale** | 얼마나 큰가 | `1`이 기본. **음수면 뒤집힘** |

> 💬 "그리고 자식은 **부모 기준**으로 셉니다. 이거 하나만 더 기억하세요."

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| 물체가 납작해짐 | Rotation X 또는 Y | Transform Reset. **"2D는 Z만"** |
| 물체가 사라짐 | Scale에 `0` | `1`로 되돌린다 |
| 자식으로 넣었더니 위치가 튐 | **부모 기준으로 바뀜** | **오늘의 핵심.** "부모에서부터 센다" |
| 자식으로 넣었더니 크기가 변함 | 부모 Scale이 1이 아님 | 부모 Scale을 1로 두고 시작하게 한다 |
| 드래그했는데 자식이 안 됨 | 오브젝트 **위**가 아니라 사이에 놓음 | 이름 위에 정확히 겹쳐 놓게 한다 |
| 실수로 자식이 됨 | Hierarchy 드래그 오조작 | 밖으로 다시 드래그. **자주 일어난다** |
| 팔 마디가 흩어짐 | 좌표를 원점 기준으로 계산 | 부모 기준임을 다시 짚는다 |
| 계층을 먼저 안 만들고 좌표부터 넣음 | 순서 문제 | **계층 먼저, 좌표 나중** |
| Rotation이 시계 방향인 줄 앎 | 방향 혼동 | `Z = 90`을 같이 넣어 확인 |
| "로컬 좌표계가 뭐예요" | 용어를 어디서 봄 | 개별로만 답한다. 반 전체에 안 꺼낸다 |
