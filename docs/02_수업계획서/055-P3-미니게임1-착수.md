## 00:10–00:35 · 같이 하기 ★

### ① 뭘 만들지 정한다 (7분)

> 💬 "**위에서 장애물이 떨어지고, 좌우로 움직여 피합니다.** 맞으면 체력이 깎이고 0이면 끝."

**칠판에 필요한 것을 적고, 학생에게 "그거 몇 회차에 했죠?" 를 묻는다.**

| 필요한 것 | 몇 회차에 했나 |
|---|---|
| 좌우로 움직이는 플레이어 | **042** (`linearVelocity`) |
| 장애물이 떨어진다 | **041** (`Gravity Scale`) |
| 부딪힌 걸 알아챈다 | **044** (`OnTriggerEnter2D`) |
| 원본 하나로 여러 개 | **046** (프리팹) |
| 코드로 만든다 | **047** (`Instantiate`) |
| 화면 밖 정리 | **048** (`Destroy`, `lifeTime`) |
| 체력을 깎는다 | **050** (`Health` · `GetComponent`) |
| 계속 떨어진다 | **052** (코루틴) |
| 그림과 애니메이션 | **053 · 054** |

> 💬 "**전부 했습니다.** 오늘 새로 배우는 건 없어요. **조립만** 합니다."

> 🎯 이 표를 **수업 내내 화면에 띄워둔다.** 막힌 학생에게 "몇 번째 줄에서 막혔어요?" 로 물으면
> 학생이 스스로 해당 회차 강의안을 찾아간다. 강사가 답을 주는 것보다 이게 낫다.

### ② 장애물 프리팹 — 있는 걸 다시 쓴다 (13분)

**새 스크립트를 만들지 않는다.** 총알에 쓰던 `Bullet`을 그대로 쓴다.

> 💬 "떨어지는 장애물이 뭐죠? **부딪히면 상대 체력을 깎고 사라지는 것**입니다."
> 💬 "그거 **우리 총알이랑 똑같지 않나요?**"

`Bullet` 스크립트에 **칸이 하나 늘어 있다.**

```csharp
[SerializeField] private string targetTag = "Enemy";
```

> 💬 "누구를 맞힐지 **Inspector에서 정할 수 있게** 열어뒀습니다."
> 💬 "총알은 `Enemy`, **장애물은 `Player`**. 코드는 하나인데 용도가 둘이에요."

**`Obstacle` 프리팹을 만든다.** (`Assets/_Project/Prefabs/Enemy/`)

| 항목 | 값 | 몇 회차 |
|---|---|---|
| `Sprite Renderer` | 아무 그림 | 053 |
| `Circle Collider 2D` | **`Is Trigger` 켬** | 043 |
| `Rigidbody 2D` | **`Gravity Scale = 1`** ← 떨어진다 | **041** |
| `Bullet` → `Speed` | **`0`** (중력이 대신 떨어뜨린다) | 047 |
| `Bullet` → `Life Time` | `5` | 048 |
| `Bullet` → `Damage` | `10` | 050 |
| `Bullet` → **`Target Tag`** | **`Player`** | 오늘 |

> 💡 `Speed`를 `0`으로 두면 `Start`에서 속도를 `(0,0)`으로 넣고 **그 뒤는 중력이 처리**한다.
> 041에서 배운 `Gravity Scale`이 여기서 쓰인다.

**`Player`에 `Health`를 붙인다.** (050에서 몬스터에 붙였던 그것)

> 💬 "050에서 뭐라고 했죠? **'이 코드, 플레이어에도 그대로 붙습니다.'** 오늘 그걸 합니다."

### ③ 나머지는 각자 (5분)

스포너는 **052의 `EnemySpawner`를 그대로** 쓰고 `Enemy Prefab` 칸만 `Obstacle`로 바꾼다.

### 필수 — 피하기 게임 뼈대

| # | 만들 것 | 참고 회차 |
|---|---|---|
| 1 | 플레이어가 **좌우로만** 움직인다 (위아래 고정) | 042 |

| 3 | 스포너가 **1초마다** 위쪽 랜덤 위치에 장애물을 떨어뜨린다 | 052 |
| 4 | 맞으면 플레이어 체력이 깎이고 Console에 남은 체력이 찍힌다 | 050 |
| 5 | 체력이 0이면 플레이어가 사라진다 | 050 |
| 6 | 장애물이 화면 밖으로 나가면 저절로 없어진다 | 048 |

**확인 조건**: 10초 동안 피하면서 버틸 수 있다. 맞으면 Console에 체력이 찍힌다.
Hierarchy에 장애물이 무한히 쌓이지 않는다.

> 💡 **위아래 고정**은 042 코드에서 `v`를 빼면 된다.
> ```csharp
> rb.linearVelocity = new Vector2(h, 0f) * moveSpeed;
> ```
> 이걸 알려주지 말고 **학생이 스스로 찾게 한다.** 대부분 찾는다.
