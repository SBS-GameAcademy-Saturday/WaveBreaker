## 00:10–00:50 · 같이 하기 ★

### ① 누구를 때렸는지 어떻게 전하나 (12분)

> 💬 "`Rpc` 로 뭘 보내야 할까요? **몬스터를 통째로?**"
> 💬 "못 보냅니다. `GameObject` 는 **내 컴퓨터의 주소**라서 상대 컴퓨터에선 의미가 없어요."

| 보낼 수 있는 것 | 못 보내는 것 |
|---|---|
| `int` `float` `bool` `ulong` | `GameObject` |
| `Vector3` `Quaternion` | `Transform` |
| **`NetworkObjectId`** (숫자) | `MonoBehaviour` |

> 🔑 💬 "**모든 네트워크 오브젝트에는 번호가 있습니다.** `NetworkObjectId`."
> 💬 "양쪽 컴퓨터에서 **같은 번호**예요. 그래서 이걸 보냅니다."

```
클라이언트 : "26번 몬스터를 3만큼 때렸어요"
서버       : 26번을 찾아서 → 체력을 깎는다
```

### ② 공격 Rpc (14분)

```csharp
private void Update()
{
    // 공격을 시도하는 건 내 캐릭터만 (114 회수).
    if (!IsOwner) return;

    if (Time.time < nextFire) return;

    NetworkEnemy target = FindNearest();
    if (target == null) return;

    nextFire = Time.time + interval;

    // 🔑 여기가 오늘의 핵심.
    //    내가 직접 target.TakeDamage(damage) 를 부르지 않는다.
    //    "저 몬스터를 때렸다" 고 서버에 알린다.
    AttackServerRpc(target.NetworkObjectId, damage);
}

[Rpc(SendTo.Server)]
private void AttackServerRpc(ulong targetId, int amount, RpcParams rpcParams = default)
{
    // 여기부터는 서버다. 아래 코드는 호스트 컴퓨터에서만 돈다.
    if (!NetworkManager.SpawnManager.SpawnedObjects.TryGetValue(targetId, out NetworkObject obj)) return;

    if (!obj.TryGetComponent(out NetworkEnemy enemy)) return;

    enemy.TakeDamage(amount);
}
```

| 조각 | 뜻 |
|---|---|
| `target.NetworkObjectId` | 그 오브젝트의 번호 |
| `SpawnManager.SpawnedObjects` | **번호 → 오브젝트** 사전 |
| `TryGetValue` | 이미 죽어서 없을 수도 있다 |

> 🚨 **`TryGetValue` 를 꼭 쓴다.** 내가 보내는 사이에 그 몬스터가 죽었을 수 있다.
> 인터넷은 시간이 걸리니까. **`[targetId]` 로 바로 꺼내면 에러가 난다.**

> 💡 `SpawnedObjects` 는 `Dictionary` 다. 026회차에서 배운 그것이고,
> 100회차 `AudioManager` 에서도 썼다.

### ③ 서버가 검사해야 한다 (8분)

```csharp
// 🚨 실제 게임이라면 여기서 검사를 해야 한다.
//    "정말 사거리 안인가?", "쿨타임을 지켰나?"
//    클라이언트 말을 그대로 믿으면 치트가 된다.
enemy.TakeDamage(amount);
```

> 💬 "116회차에서 말한 그 자리입니다. **여기가 치트를 막는 곳**이에요."

**넣는다면 이렇게 생겼다**

```csharp
float dist = Vector2.Distance(transform.position, obj.transform.position);
if (dist > range * 1.5f) return;        // 사거리 검사 (여유를 준다)
if (amount > 10) return;                // 말도 안 되는 값 거르기
```

> 💬 "**사거리에 여유를 주는 이유**는 인터넷 지연 때문입니다."
> 💬 "클라이언트가 때렸을 땐 사거리 안이었는데, 서버에 도착하니 몬스터가 움직였을 수 있어요."
> 💬 "너무 빡빡하게 검사하면 **정상 플레이가 씹힙니다.**"

> 💡 우리 수업 코드에는 **주석으로만** 남겼다. 친구랑 하는 게임이라 치트가 없다.
> 어디에 넣어야 하는지만 알면 된다.

### ④ 몬스터의 반격 (8분)

```csharp
private void OnCollisionStay2D(Collision2D collision)
{
    if (!IsServer) return;
    if (Time.time < nextHitTime) return;

    if (!collision.gameObject.TryGetComponent(out NetworkHealthDemo hp)) return;

    nextHitTime = Time.time + 0.5f;
    hp.TakeDamage(contactDamage);
}
```

> 💬 "몬스터가 때리는 건 **Rpc 가 필요 없습니다.** 왜죠?"
> 💬 "**몬스터가 이미 서버 것**이니까요. 서버가 직접 판정하면 됩니다."

> 🔑 💬 "**부탁이 필요한 건 클라이언트뿐입니다.** 서버는 그냥 하면 돼요."

| 누가 때리나 | 어떻게 |
|---|---|
| 클라이언트 → 몬스터 | **`Rpc` 로 부탁** |
| 호스트 → 몬스터 | 바로 (이미 서버) |
| 몬스터 → 플레이어 | 바로 (몬스터가 서버 것) |

> 💡 `nextHitTime` 은 080회차의 무적시간과 같은 생각이다. 초당 60번 맞으면 즉사한다.
