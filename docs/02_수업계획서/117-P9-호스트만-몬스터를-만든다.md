public class NetworkWaveManager : NetworkBehaviour

### ② 🚨 `Instantiate` 만으로는 안 된다 (14분) — 오늘의 진짜 함정

```csharp
GameObject go = Instantiate(enemyPrefab, pos, Quaternion.identity);
```

▶ 실행 → **호스트 화면에만 몬스터가 있다.** 클라이언트 화면은 비어 있다.

> 💬 "왜일까요?"

> 🔑 💬 "**`Instantiate` 는 내 컴퓨터에 오브젝트를 만드는 함수**입니다."
> 💬 "유니티는 그게 네트워크 물건인지 몰라요. **알려줘야 합니다.**"

```csharp
GameObject go = Instantiate(enemyPrefab, pos, Quaternion.identity);

// 🚨 Instantiate 만으로는 내 화면에만 생긴다.
//    Spawn() 을 불러야 네트워크에 등록돼 모두에게 보인다.
go.GetComponent<NetworkObject>().Spawn();
```

| 함수 | 하는 일 |
|---|---|
| `Instantiate` | **내 컴퓨터에** 만든다 |
| `NetworkObject.Spawn()` | **네트워크에 등록**한다 → 모두에게 생긴다 |
| `NetworkObject.Despawn()` | 네트워크에서 뺀다 → 모두에게서 사라진다 |

> 💬 "없앨 때도 마찬가지예요. **`Destroy` 가 아니라 `Despawn`** 입니다."

> 💡 102회차의 `Instantiate` / `PoolManager.Spawn` 과 **이름이 겹쳐 헷갈린다.**
> 그건 우리가 만든 서랍이고, 이건 NGO 의 네트워크 등록이다.

### ④ 몬스터는 서버가 움직인다 (8분)

```csharp
private void FixedUpdate()
{
    // 🔑 움직이는 것도 서버만. 클라이언트가 같이 움직이면 위치가 싸운다.
    if (!IsServer) return;

    ...
    rb.linearVelocity = dir * moveSpeed;
}
```

그리고 프리팹의 `NetworkTransform` 을 **Authority = Server** 로 둔다.

| 오브젝트 | Authority | 왜 |
|---|---|---|
| 플레이어 | **Owner** | 반응이 빨라야 한다 (107) |
| **몬스터 · 젬** | **Server** | 주인이 따로 없다. 서버 것이다 |

> 💬 "플레이어는 소유자, 몬스터는 서버. **107회차에서 나눈 표 그대로**입니다."

### 문지기를 하나 만든다 (10분)

`Scripts/Network/NetworkRole.cs`

```csharp
public static class NetworkRole
{
    public static bool IsServerOrOffline
    {
        get
        {
            NetworkManager nm = NetworkManager.Singleton;

            // 씬에 NetworkManager 가 없다 = 싱글 모드다
            if (nm == null) return true;

            // 있어도 접속을 안 했으면 싱글과 같다
            if (!nm.IsListening) return true;

            return nm.IsServer;
        }
    }
}
```

> 🔑 💬 "**싱글은 '호스트 혼자 하는 게임' 으로 취급합니다.**"
> 💬 "그러면 본 게임 코드에 `if / else` 분기가 **하나도 안 생깁니다.**"
