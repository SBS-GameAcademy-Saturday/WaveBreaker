## 🎯 오늘의 목표

1. "화면이 두 개" 가 아니라 **"게임이 두 개"** 라는 걸 안다
2. 그래서 **알려줘야** 한다는 걸 안다
3. 무엇을 알려주고 무엇을 안 알려줄지 감을 잡는다

> ⚠️ **오늘은 코드를 한 줄도 안 친다.** 유니티를 안 켜도 된다.
>
> 🔑 **설계 의도**: 네트워크에서 학생이 막히는 이유는 문법이 아니라 **그림이 안 그려져서**다.
> `IsOwner` 를 몰라서 막히는 게 아니라, **"내 게임" 과 "상대 게임" 이 따로 돈다는 걸 모르니까** 막힌다.
> 오늘 한 회차를 통째로 그림에 쓴다.

## 00:15–00:50 · 같이 하기 ★ (그림만)

### ① 가장 큰 오해 (10분)

칠판에 **틀린 그림**을 먼저 그린다.

```
              ┌──────────────┐
              │   게임 하나   │
              └──────┬───────┘
                ┌────┴────┐
            화면 A       화면 B
```

> 💬 "많은 분이 이렇게 생각합니다. 게임이 하나 있고 화면만 두 개."
> 💬 "**틀렸습니다.**"

**맞는 그림**

```
   내 컴퓨터                        친구 컴퓨터
 ┌────────────┐                 ┌────────────┐
 │  게임 하나  │                 │  게임 하나  │
 │  (완전한)   │  ←── 인터넷 ──→  │  (완전한)   │
 └────────────┘                 └────────────┘
```

> 🔑 💬 "**게임이 두 개입니다.** 각자 자기 컴퓨터에서 따로 돌아요."
> 💬 "여러분 게임에 있는 몬스터랑 친구 게임에 있는 몬스터는 **다른 물건**입니다."
> 💬 "그래서 **일일이 알려줘야** 합니다. 그게 앞으로 20회차 동안 할 일이에요."

### ② 알려주지 않으면 어떻게 되나 (10분)

**상황을 하나씩 그려본다.** 학생에게 물어가며 채운다.

| 내 게임에서 일어난 일 | 안 알려주면 친구 화면에서는 |
|---|---|
| 내가 오른쪽으로 걸었다 | **내가 제자리에 서 있다** |
| 몬스터를 잡았다 | 그 몬스터가 **아직 살아 있다** |
| 젬을 먹었다 | 젬이 **바닥에 그대로** 있다 |
| 레벨업해서 칼이 4개가 됐다 | 여전히 **칼이 3개** |
| 내가 죽었다 | 내가 **멀쩡하게 서 있다** |

> 💬 "**두 사람이 완전히 다른 게임을 하고 있는 거죠.**"

### ③ 그럼 몬스터는 누가 만드나 (10분) — 오늘의 핵심 질문

> 💬 "두 사람이 같이 합니다. 몬스터를 누가 만들까요?"

**학생에게 세 가지 안을 주고 고르게 한다.**

| 안 | 무슨 일이 나나 |
|---|---|
| ① 둘 다 각자 만든다 | 🚨 **몬스터가 두 배로 나온다.** 서로 다른 자리에 |
| ② 나만 만든다 | 친구가 나가면 몬스터가 안 나온다 |
| ③ **한 명을 정해서 그 사람만 만든다** | ✅ |

> 🔑 💬 "**③번이 답입니다.** 그 '한 명' 을 **호스트** 라고 불러요."
> 💬 "호스트가 만들고, **'몬스터 생겼다' 고 알려줍니다.**"

> 💡 💬 "이 얘기 어디서 들어보셨죠?" → **073회차. 스폰은 매니저 한 곳에서만.**
> 💬 "그때 왜 그렇게 하라고 했는지 **오늘 답이 나옵니다.**"

### ④ 뭘 알려주고 뭘 안 알려주나 (10분)

> 💬 "전부 다 알려주면 어떻게 될까요?" → **느려진다.** 인터넷으로 보내는 건 비싸다.

| 알려줘야 하는 것 | 안 알려줘도 되는 것 |
|---|---|
| 플레이어 위치 | 칼이 도는 각도 (각자 계산해도 같다) |
| 몬스터가 생겼다 / 죽었다 | 화면 흔들림 (각자 알아서) |
| 체력 · 레벨 | 파티클 조각이 날아간 방향 |
| 젬을 먹었다 | 버튼에 마우스를 올렸다 |

> 🔑 💬 "기준은 하나입니다. **'이걸 모르면 두 사람이 다른 게임을 하게 되는가?'**"
> 💬 "칼 각도는 몰라도 됩니다. 양쪽이 같은 규칙으로 돌리면 알아서 같아지거든요."

<details>
<summary>막히면 열기 (참고 답)</summary>

**① 알려줘야 하는 것**

| 무엇 | 왜 |
|---|---|
| 플레이어 위치 | 모르면 상대가 제자리에 서 있다 |
| 몬스터 생성 | 모르면 한쪽에만 몬스터가 있다 |
| 몬스터 사망 | 모르면 한쪽에서 유령을 때린다 |
| 체력 | 모르면 죽은 사람이 살아 있어 보인다 |
| 경험치 · 레벨 | 협동은 경험치를 공유한다 (기획서 11장) |
| 젬 획득 | 모르면 같은 젬을 둘이 먹는다 |

**② 안 알려줘도 되는 것**

| 무엇 | 왜 |
|---|---|
| 칼 회전 각도 | 양쪽이 같은 규칙으로 돌리면 같아진다 |
| 화면 흔들림 | 내 화면 연출이다. 상대와 같을 필요가 없다 |
| 죽음 이펙트 조각의 방향 | 랜덤이라도 상관없다 |
| UI 버튼 하이라이트 | 완전히 내 화면 일이다 |

**③ 호스트가 하는 일**
1. 몬스터를 만든다
2. 누가 맞았는지 판정한다
3. 접속을 받아준다

**④ 상황별**

| 상황 | 무슨 일 |
|---|---|
| 각자 몬스터를 만든다 | 몬스터가 **두 배**로 나오고 서로 다른 자리에 있다 |
| 친구가 내 캐릭터를 조종 | 한 키를 누르면 **둘 다 움직인다** |
| 호스트가 껐다 | 몬스터를 만들 사람이 없다 → 게임이 멈춘다 |

</details>
