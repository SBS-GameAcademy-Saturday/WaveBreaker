## 00:10–00:45 · 같이 치기 ★

### ① 프레임이 뭔가 (8분)

```csharp
private int frameCount;

void Update()
{
    frameCount++;
    if (frameCount % 60 == 0)
    {
        Debug.Log("프레임: " + frameCount);
    }
}
```

> 💬 "게임 화면은 **정지 그림을 빠르게 갈아 끼우는** 겁니다. 만화책 넘기기랑 같아요."
> 💬 "그림 한 장이 **1프레임**이고, `Update`는 그때마다 한 번씩 실행됩니다."

**초당 프레임 수를 눈으로 보여준다.**

```csharp
void Update()
{
    Debug.Log("1초에 " + (1f / Time.deltaTime) + " 장");
}
```

> 학생마다 다른 숫자가 나온다. 60, 144, 90, 240...
>
> 💬 "**이게 원인입니다.**"

### ② 원인 (7분) — 오늘의 핵심

> 💬 "`moveStep = 0.05`는 **'한 장 그릴 때마다 0.05만큼'** 이라는 뜻이었어요."

| 컴퓨터 | 1초에 그리는 장 수 | 1초에 가는 거리 |
|---|---|---|
| A (60프레임) | 60장 | `0.05 × 60` = **3** |
| B (144프레임) | 144장 | `0.05 × 144` = **7.2** |

> 💬 "**좋은 컴퓨터일수록 빨리 갑니다.** 게임에서 이건 최악이에요. 사양 좋은 사람이 유리해지니까요."
> 💬 "우리가 원한 건 '한 장마다 얼마'가 아니라 **'1초에 얼마'** 였습니다."

### ③ `Time.deltaTime` 이 뭔가 (5분)

> 💬 "`Time.deltaTime`은 **직전 한 장을 그리는 데 걸린 시간(초)** 입니다."

| 컴퓨터 | 1초에 장 수 | `Time.deltaTime` |
|---|---|---|
| A | 60장 | `1/60` = 약 `0.0167` 초 |
| B | 144장 | `1/144` = 약 `0.0069` 초 |

> 💬 "1초에 60장을 그리면 한 장에 60분의 1초가 걸린 거죠. **그게 deltaTime 입니다.**"
> 💬 "**빠른 컴퓨터일수록 이 값이 작습니다.** 더 자주 그리니까 한 번에 걸리는 시간이 짧아요."

**직접 찍어서 보여준다.** 학생마다 다른 숫자가 나온다.

```csharp
void Update()
{
    Debug.Log("deltaTime: " + Time.deltaTime + " / fps: " + (1f / Time.deltaTime));
}
```

### ④ 왜 곱하면 해결되나 (7분) — 오늘의 핵심

> 🚨 **여기가 이 회차의 전부다.** 곱하라고만 하고 넘어가면 문법 암기가 된다.

**질문부터 던진다.**

> 💬 "`deltaTime`을 **1초 동안 전부 더하면** 얼마가 될까요?"

학생이 답하게 둔다. 답은 **1초**다.

| 컴퓨터 | 1초 동안 프레임 | `deltaTime` | 전부 더하면 |
|---|---|---|---|
| A | 60번 | `0.0167` | `0.0167 × 60` = **1초** |
| B | 144번 | `0.0069` | `0.0069 × 144` = **1초** |

> 💬 "당연하죠. **한 장 그리는 데 걸린 시간을 다 더하면 그게 총 걸린 시간**이니까요."
> 💬 "프레임이 60번이든 144번이든, **1초 동안 더한 deltaTime 은 항상 1**입니다."

**그래서 곱한다.**

```csharp
transform.position = transform.position + moveDir * moveSpeed * Time.deltaTime;
```

매 프레임 `moveSpeed × deltaTime` 만큼 더한다. 1초 동안 다 더하면?

```
moveSpeed × (deltaTime 을 1초 동안 전부 더한 값)
= moveSpeed × 1
= moveSpeed
```

| 컴퓨터 | 한 장당 이동 | 1초 동안 |
|---|---|---|
| A | `3 × 0.0167` = 0.05 | `0.05 × 60` = **3** |
| B | `3 × 0.0069` = 0.0207 | `0.0207 × 144` = **3** |

> 💬 "**둘 다 1초에 3만큼.** 프레임 수가 몇이든 상관없어요."
> 💬 "빠른 컴퓨터는 **더 자주 움직이는 대신 한 번에 조금씩** 갑니다. 결국 같은 거리예요."
>
> 🔑 **한 문장으로 정리한다 (채팅 고정)**
> 💬 "**`deltaTime`을 1초 동안 더하면 1이다. 그래서 곱하면 값이 '초당'이 된다.**"

> 📌 **강사 확인용 실측** — 이 프로젝트에서 재본 값이다.
> `frameCount=267`, `deltaTime 평균=0.0070`, `평균 × 프레임수 = 1.871` = 그때의 `Time.time`.
> **deltaTime 의 합이 곧 경과 시간**이라는 게 숫자로 확인된다.

### ⑤ 변수 이름과 값을 바꾼다 (5분)

`Time.deltaTime`을 곱하면 값의 **의미가 바뀐다.** 이름도 바꿔야 한다.

| | 이전 | 이후 |
|---|---|---|
| 이름 | `moveStep` (한 장당) | **`moveSpeed`** (초당) |
| 값 | `0.05` | **`3`** |
| 뜻 | 프레임마다 0.05 | **1초에 3만큼** |

> 💬 "값이 갑자기 커져서 놀라는데, **단위가 바뀐 겁니다.** 0.05를 60번 하면 3이죠."
>
> ⚠️ 이름을 안 바꾸면 나중에 `moveStep = 3`을 보고 "왜 이렇게 크지?"가 된다. **이름을 꼭 바꾸게 한다.**

**회전도 똑같이 고친다.**

```csharp
// 037회차 Spinner
transform.Rotate(0f, 0f, rotateSpeed * Time.deltaTime);   // rotateSpeed = 90  → 초당 90도
```

> 💬 "`90`이면 **1초에 90도**, 그러니까 4초에 한 바퀴예요. **숫자를 보면 속도가 읽힙니다.**"

### ⑥ 언제 안 곱하나 (3분)

> 💬 "`Update` 안에서 **계속 조금씩** 하는 것에만 곱합니다."

| 곱한다 | 안 곱한다 |
|---|---|
| 이동, 회전, 크기 변화 | 순간이동 (`position = new Vector3(...)`) |
| 체력이 초당 닳는 것 | 한 번만 하는 것 (`Start` 안) |

## 00:55–01:35 · 개인 미션

### 필수 미션 — 지금까지 만든 것 전부 고치기

`Mover`, `Spinner`, `Bouncer` 세 개를 전부 `Time.deltaTime` 기준으로 고친다.

- [ ] `Mover`: `moveStep` → `moveSpeed`, 값 `3`, `* Time.deltaTime`
- [ ] `Spinner`: `rotateStep` → `rotateSpeed`, 값 `90`, `* Time.deltaTime`
- [ ] `Bouncer`: `scaleStep` → `scaleSpeed`, 값 `0.5`, `* Time.deltaTime`
- [ ] 세 개 다 Play해서 **부드럽게** 동작하는지 확인
- [ ] `Spinner`가 **4초에 정확히 한 바퀴** 도는지 초를 세어 확인

**확인 조건**: `rotateSpeed = 90`일 때 눈으로 세어 4초에 한 바퀴 돈다.

<details>
<summary>막히면 열기 (Mover 정답)</summary>

```csharp
using UnityEngine;

public class Mover : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 3f;          // 초당 3
    [SerializeField] private Vector3 moveDir = Vector3.right;

    void Update()
    {
        transform.position = transform.position + moveDir * moveSpeed * Time.deltaTime;
    }
}
```

**이름을 바꾸면 Inspector 값이 초기화된다.** 새 이름의 기본값이 들어가므로,
바꾼 뒤 Inspector를 한 번 확인한다.
</details>

### ⭐ 도전 미션

- [ ] `Application.targetFrameRate = 10;` 을 `Start`에 넣고 **`deltaTime` 있는 것과 없는 것**을 비교한다
- [ ] `1f / Time.deltaTime` 을 화면에 계속 찍어 내 컴퓨터가 초당 몇 장인지 확인한다
- [ ] `Time.timeScale = 0.5f;` 를 넣어보고 무슨 일이 생기는지 한 줄로 쓴다
- [ ] `moveSpeed`를 `1`로 두고 **3초 뒤 정확히 3만큼** 갔는지 좌표로 확인한다
- [ ] `Time.deltaTime` 대신 `Time.fixedDeltaTime`을 써보고 차이를 관찰한다
- [ ] 물체 2개 중 하나만 `deltaTime`을 빼고, 프레임을 떨어뜨렸을 때 어긋나는 걸 보여준다

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| 곱했더니 **거의 안 움직임** | 값을 안 바꿈 (`0.05` 그대로) | **오늘 1등.** "단위가 바뀌었어요. `3`으로" |

| `Time.deltaTime()` | 괄호를 붙임 | 메서드가 아니라 값이다. 괄호 없음 |
