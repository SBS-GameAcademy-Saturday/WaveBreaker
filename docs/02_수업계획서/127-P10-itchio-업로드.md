## 00:10–00:30 · 같이 하기 ① 압축 ★

### ① 왜 압축하나 (5분)

> 💬 "빌드 폴더에 파일이 **245개** 있었죠. 그걸 다 올릴 순 없어요."

```
WaveBreaker_Final/          ← 245개 파일
 ├ WaveBreaker.exe
 ├ UnityPlayer.dll
 ├ WaveBreaker_Data/
 └ ...
        ↓ 압축
WaveBreaker_v1.0.0_Windows.zip   ← 파일 1개
```

### ② 압축한다 (8분)

**빌드 폴더 안으로 들어가서 → 전체 선택 → 우클릭 → 압축**

> 🚨 **폴더 자체를 압축하면 안 된다.** 폴더 *안의 것들* 을 압축한다.

```
🚨 나쁜 예                       ✅ 좋은 예
zip 안에                        zip 안에
 └ WaveBreaker_Final/            ├ WaveBreaker.exe
     ├ WaveBreaker.exe           ├ UnityPlayer.dll
     └ ...                       └ WaveBreaker_Data/
   → 압축을 풀면 폴더가 두 겹
```

> 💬 "두 겹이어도 게임은 돌아가요. 근데 **친구가 `.exe` 를 못 찾습니다.**"

**이름은 이렇게 짓는다.**

```
WaveBreaker_v1.0.0_Windows.zip
   이름      버전     플랫폼
```

### ③ 얼마나 줄었나 (7분) — 강사가 잰 값

```
원본 폴더 = 108.8 MB
zip      =  41.3 MB      ← 62.1% 줄었다
압축 시간 =   8.8초
```

> 💬 "**절반 넘게 줄었죠.** `.dll` 이나 데이터 파일은 압축이 잘 먹습니다."
> 💬 "itch.io 무료 계정은 **파일 하나에 1 GB** 까지예요. 41 MB 면 넉넉합니다."

> 💬 "사용자 이름은 **나중에 이력서에 적을 주소**예요. `qwer1234` 말고 이름으로 하세요."


| Short description | 몰려오는 것들을 버텨낸다 (타이틀 문구 그대로) |
| Classification | **Games** |
| Kind of project | **Downloadable** |
| Release status | **Released** |
| Pricing | 🔴 **No payments** |

> 🚨 **`Kind of project` 를 `HTML` 로 두면 안 된다.** 그건 WebGL 용이다.
> 우리는 `.zip` 을 받아서 실행하는 방식이므로 **Downloadable** 이다.

> 🔴 **Pricing 은 반드시 `No payments`.** 돈을 받으려면 세금 정보가 필요하고, 수업에서 할 일이 아니다.

### ② 설치 안내를 적는다 (7분)

**Install instructions 칸에 이렇게 적는다.**

```
1. zip 파일을 받아서 압축을 풉니다.
2. WaveBreaker.exe 를 실행합니다.
3. 이동 WASD · 일시정지 ESC
4. Windows 에서 "PC 보호" 창이 뜨면
   [추가 정보] → [실행] 을 누르세요.
```

> 🔑 💬 "네 번째 줄을 꼭 넣으세요."
> 💬 "**서명 없는 `.exe` 라 윈도우가 경고를 띄웁니다.** 이걸 안 적으면 친구가 겁먹고 안 합니다."
