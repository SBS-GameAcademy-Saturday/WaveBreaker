### ② Product Name 이 로그 경로를 정한다 (8분) — 🔑 오늘의 숨은 지식

> 💬 "빌드한 게임이 안 켜지면 어디를 봐야 할까요? **`Player.log`** 입니다."

```
C:\Users\<이름>\AppData\LocalLow\<Company Name>\<Product Name>\Player.log
```

**우리 프로젝트는 이렇게 된다.**

```
C:\Users\user\AppData\LocalLow\WaveBreaker Class\웨이브 브레이커\Player.log
                                └ Company Name ┘ └ Product Name ┘
```

> 🔑 💬 "**폴더 이름이 Player Settings 에서 그대로 옵니다.**"
> 💬 "Product Name 이 한글이면 폴더도 한글이에요. 그래도 잘 만들어집니다."

> 💡 **`AppData` 는 숨김 폴더다.** 탐색기 주소창에 `%LOCALAPPDATA%\..\LocalLow` 를 붙여넣으면 바로 간다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **씬을 못 찾는다** | Build Settings 미등록 | 097 회수 |
| 빌드 크기가 200 MB 넘음 | 연습 씬이 켜져 있다 | 체크박스 해제 |
| **폰트 에셋이 매번 변경됨** | TMP 가 빌드 때 아틀라스를 비운다 | **정상이다.** 아래 참고 |
| 빌드는 되는데 검은 화면 | 0번 씬이 Title 이 아니다 | 순서 확인 |
| `Player.log` 를 못 찾음 | `AppData` 가 숨김 폴더 | `%LOCALAPPDATA%\..\LocalLow` |
| **WebGL 하겠다고 함** | 🔴 1등 사고 | **PC 빌드 확정 후에** |
| 빌드가 30분 넘게 걸림 | Backend 가 IL2CPP | Mono 로 되돌린다 |
| 백신이 `.exe` 를 지움 | 서명 없는 실행 파일 | 예외 등록 안내 |

### 🔑 폰트 에셋이 매번 바뀌는 이유 (강사 참고)

```
TMP Settings → Clear Dynamic Data On Build = True
```

**Dynamic 폰트는 필요한 글자만 아틀라스에 그려 넣는다**(093회차). 게임을 돌릴수록 글자가 쌓인다.
TMP 는 빌드할 때 그걸 **다시 비운다** — 빌드에 안 쓰는 글자를 넣지 않으려고.

강사 환경 실측: 빌드 전 **96자** → 빌드 후 **55자**, 에셋 파일 2512 KB.
그래서 빌드만 해도 `Pretendard SDF.asset` 이 변경된 것으로 뜬다. **버그가 아니다.**
