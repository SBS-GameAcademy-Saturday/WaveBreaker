### ② 공을 만든다 (7분)

`Ball` 프리팹을 만든다.

| 항목 | 값 |
|---|---|
| Scale | `0.4` |
| `Circle Collider 2D` | **`Is Trigger` 끔** ← 튕겨야 하니까 |
| `Rigidbody 2D` | `Gravity Scale = 0`, `Freeze Rotation Z` 체크 |
| `Linear Damping` | **`0`** |

> 🚨 **`Is Trigger`를 켜면 안 된다.** 043에서 배운 그대로다.
> 💬 "동전은 통과해야 하니까 Trigger였죠. **공은 튕겨야 하니까 Trigger가 아닙니다.**"

```csharp
using UnityEngine;

public class Ball : MonoBehaviour
{
    [SerializeField] private float speed = 8f;

    private Rigidbody2D rb;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Start()
    {
        rb.linearVelocity = new Vector2(1f, 1f).normalized * speed;
    }
}
```

▶ Play → 공이 대각선으로 날아가서 **벽에 닿고 멈춘다.**

> 💬 "**안 튑니다.** 그냥 붙어버렸죠. 왜일까요?"

### ③ Physics Material 2D (11분) — 오늘의 핵심

> 💬 "유니티 물리에서 **부딪힌 뒤 어떻게 되느냐**는 따로 정해줘야 합니다. 그게 **물리 재질**이에요."

`Project` 창 → `Assets/_Project/Materials/` 우클릭 → **Create → 2D → Physics Material 2D**
이름 **`BouncyBall`**

| 항목 | 값 | 뜻 |
|---|---|---|
| **`Friction`** | **`0`** | 마찰 없음 — 스치면서 안 느려진다 |
| **`Bounciness`** | **`1`** | **부딪힌 만큼 그대로 튄다** |

`Ball` 프리팹의 `Circle Collider 2D` → **`Material`** 칸에 드래그한다.

▶ Play → **튄다.**

> 💬 "`Bounciness`가 `0`이면 안 튀고, `1`이면 온전히 튑니다. `0.5`면 절반씩 죽어요."
> 💬 "`Friction`을 `0`으로 두는 게 중요합니다. 안 그러면 벽을 스치면서 **점점 느려집니다.**"

> ⚠️ **벽에도 같은 재질을 줄지** 묻는 학생이 있다.
> 💬 "**한쪽만 있어도 됩니다.** 유니티가 둘을 섞어서 계산해요. 그런데 확실하게 하려면 둘 다 주는 게 낫습니다."

### ④ 그래도 느려진다 — 속도 유지 (10분)

▶ Play를 **30초** 두고 본다. 공이 **조금씩 느려지거나 빨라진다.**

> 💬 "`Bounciness = 1`인데도 완벽하진 않습니다. 물리 계산에 오차가 쌓여요."
> 💬 "벽돌깨기에서 공이 느려지면 **게임이 지루해집니다.** 강제로 잡아줍니다."

```csharp
void FixedUpdate()
{
    rb.linearVelocity = rb.linearVelocity.normalized * speed;
}
```

> 💬 "**`.normalized`** — 040과 042에서 미뤄둔 겁니다. 오늘 제대로 씁니다."
> 💬 "**방향은 그대로 두고 길이를 1로** 만드는 거예요. 거기에 `speed`를 곱하면 **방향은 유지, 속도는 고정**."

**칠판에 그린다.**

| | 벡터 | 길이 |
|---|---|---|
| 지금 속도 | `(6, 4)` | 약 7.2 |
| `.normalized` | `(0.83, 0.55)` | **1** |
| `× speed(8)` | `(6.6, 4.4)` | **8** |

> 💬 "040에서 **대각선이 빠른 문제**가 있었죠. 원인이 이겁니다. `(1,1)`은 길이가 1.41이라서요."
> 💬 "그때 눈치챈 사람만 알려줬는데, **오늘 반 전체가 알게 됐습니다.**"

> ⚠️ **물리를 만지니까 `FixedUpdate`.** 042의 규칙 그대로다.

### ⑤ 블록을 깬다 (6분)

블록 프리팹에 **Tag `Brick`** 과 `Health`(maxHealth `10`)가 붙어 있는지 확인한다.

```csharp
[SerializeField] private int damage = 10;

private void OnCollisionEnter2D(Collision2D collision)
{
    if (collision.gameObject.CompareTag("Brick"))
    {
        Health health = collision.gameObject.GetComponent<Health>();

        if (health != null)
        {
            health.TakeDamage(damage);
        }
    }
}
```

▶ Play → **공이 블록을 깬다.**

> 💬 "**050에서 총알이 하던 것과 똑같습니다.** 다른 건 `OnTrigger`가 아니라 `OnCollision`이라는 것뿐."
> 💬 "총알은 통과하면서 맞혔고, 공은 **튕기면서** 맞힙니다. 그래서 `Collision`이에요."

| | 총알 (050) | 공 (오늘) |
|---|---|---|
| 메서드 | `OnTriggerEnter2D` | **`OnCollisionEnter2D`** |
| 매개변수 | `Collider2D other` | **`Collision2D collision`** |
| 상대 | `other.gameObject` | **`collision.gameObject`** |
| 맞은 뒤 나는 | 사라진다 | **튕긴다** |

> 💬 "044에서 표로 봤던 그 차이가 **실제로 갈리는 자리**입니다."

```csharp
using UnityEngine;

public class Ball : MonoBehaviour
{
    [SerializeField] private float speed = 8f;
    [SerializeField] private int damage = 10;

    private Rigidbody2D rb;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Start()
    {
        rb.linearVelocity = new Vector2(1f, 1f).normalized * speed;
    }

    void FixedUpdate()
    {
        rb.linearVelocity = rb.linearVelocity.normalized * speed;
    }

    private void OnCollisionEnter2D(Collision2D collision)
    {
        if (collision.gameObject.CompareTag("Brick"))
        {
            Health health = collision.gameObject.GetComponent<Health>();

            if (health != null)
            {
                health.TakeDamage(damage);
            }
        }
    }
}
```

에셋·프리팹 설정도 같이 확인한다.

| 어디 | 확인할 것 |
|---|---|
| `BouncyBall` (Physics Material 2D) | `Friction 0` · `Bounciness 1` |
| `Ball` 의 `Circle Collider 2D` | `Material` 칸에 `BouncyBall`, **`Is Trigger` 꺼짐** |
| `Ball` 의 `Rigidbody 2D` | `Gravity Scale 0` · `Linear Damping 0` · `Freeze Rotation Z` |
| `Brick` 프리팹 | Tag `Brick` · `Box Collider 2D` · `Health` |

</details>

## 01:35–01:50 · 데모 + 정리

학생 2명 데모. **속도 유지를 지워본 학생**을 우선한다. 느려지는 걸 다 같이 보면 그 줄의 이유가 굳는다.

**마무리 정리 (한 장)**

| 튀게 하려면 | |
|---|---|
| 1 | `Is Trigger` **끈다** (통과하면 안 되니까) |
| 2 | **Physics Material 2D** 를 만들어 `Bounciness 1`, `Friction 0` |
| 3 | Collider의 `Material` 칸에 넣는다 |
| 4 | `FixedUpdate`에서 **`.normalized * speed`** 로 속도를 고정 |

> 💬 "`.normalized`는 앞으로 계속 나옵니다. **방향만 쓰고 싶을 때** 항상 이걸 씁니다."
