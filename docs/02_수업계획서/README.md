# 회차별 수업계획서

[Phase 개요](../01_Phase개요/)의 회차 배분을 하루 단위 강의안으로 푼 문서들. **해당 Phase 문서를 먼저 읽고 쓴다.**

> 새 회차는 [`_템플릿.md`](./_템플릿.md)를 복사해서 시작한다.

## 파일 규칙

`{회차3자리}-{Phase}-{제목}.md` — 예: `001-P0-오리엔테이션.md`

회차는 **001부터 140까지 통 번호**. Phase별로 다시 1번부터 세지 않는다.

## 문서 구조 (전 회차 공통)

| 섹션 | 용도 |
|---|---|
| 상단 표 | 회차 / Phase / 소요 / 준비물 |
| 🎯 오늘의 목표 | 3개 이하. 많으면 노베이스는 아무것도 못 가져간다 |
| 📦 오늘의 제출물 | 학생이 수업 끝에 올릴 **스크린샷/GIF 1개**. 이게 곧 출석 |
| ⏱ 타임테이블 | 고정 6블록 (10/35/10/40/15/10) |
| 블록별 상세 | 강사 시연 포인트 + 학생 미션(필수 / ⭐도전) |
| 💻 코드 | 골격 + `// TODO` 빈칸 → 힌트 → 정답 |
| ✅ 체크리스트 | 학생 자기점검. 통과해야 다음 회차 |
| 🚨 흔한 사고 & 대응 | **강사용.** 이 반에서 실제로 터질 것들 |
| 📮 다음 시간 예고 | 1~2줄 |
