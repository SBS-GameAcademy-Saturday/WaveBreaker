## 🎯 오늘의 목표

1. 5분 발표를 **설계한다** (즉흥으로 하지 않는다)
2. 라이브 시연이 **안 될 때를 대비**한다
3. **한 번 해본다** — 오늘 안 해보면 내일 못 한다

> ⚠️ **오늘 안 하는 것**: 게임 수정, 슬라이드 디자인, 발표 기술 강의.
> 🔴 **126회차부터 기능 동결이다.** 오늘 코드를 열지 않는다.

> 🔴 **발표가 부담스러운 사람은 오늘 말한다.**
> 💬 "**녹화 영상 제출로 대체할 수 있습니다.** 강요하지 않아요."
> 💬 "다만 오늘 리허설은 **모두** 합니다. 영상으로 낼 사람도 한 번은 해봐야 찍을 수 있어요."

```
발표 시작 전에 이미 해둘 것
  ☑ 게임을 켜서 타이틀 화면에 두기

  ☑ 알림 끄기 (윈도우 + 메신저)

```

> 🚨 **발표 시작하고 게임을 켜면 안 된다.** 로딩 30초가 발표 시간의 10%다.

### ② 백업 영상 (5분) — 🔴 전원 필수

> 💬 "**128회차에 만든 영상을 백업으로 쓰세요.**"

| 시연이 실패하는 이유 | 대비 |
|---|---|
| 게임이 안 켜진다 | **영상 재생** |
| 화면 공유가 안 된다 | 영상 링크를 채팅에 |
| 협동 상대가 안 붙는다 | **혼자 하기로 전환** |
| 너무 긴장해서 조작을 못 한다 | 영상 재생 |

> 🔴 💬 "**백업 영상이 없으면 발표를 못 하는 상황이 생깁니다.** 오늘 반드시 준비하세요."

### ③ 협동 시연 짝 (5분)

**강사가 짝을 배정한다.**

```
발표자 A  →  같이 붙어줄 사람 B (미리 정해둔다)
   B 는 발표 전에 미리 대기하고 있는다
```

> 💬 "협동 시연은 **90초 중 30초**면 됩니다. 둘이 화면에 같이 보이면 끝이에요."
>
> ⚠️ "협동이 잘 안 되는 분은 **혼자 하기만 시연**하세요. **그것도 완성작입니다.**"
> 💬 "**Phase 8 빌드가 제출물**이라고 21주차부터 말씀드렸죠. 그 약속 그대로예요."
