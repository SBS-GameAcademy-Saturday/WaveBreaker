## 00:10–00:45 · 같이 치기 ★

### ① 스폰된 적은 나를 모른다 (9분) — 오늘의 첫 문제

`063_Survival_Start` 를 연다. 플레이어와 `EnemySpawner`(052)가 있다.

> 💬 "적이 플레이어를 향해 오려면 **플레이어가 어디 있는지** 알아야 합니다."
> 💬 "042에서는 Inspector에 드래그했죠. **그런데 적은 게임 중에 생깁니다.** 드래그할 수가 없어요."

```csharp
using UnityEngine;

public class EnemyChaser : MonoBehaviour
{
    private Transform target;

    void Start()
    {
        GameObject player = GameObject.FindWithTag("Player");

        if (player != null)
        {
            target = player.transform;
        }
    }
}
```

| 조각 | 뜻 | 어디서 |
|---|---|---|
| `FindWithTag("Player")` | **Tag가 Player인 오브젝트를 씬에서 찾는다** | 오늘 |
| `if (player != null)` | 못 찾을 수도 있다 | **049** |
| `player.transform` | 위치를 알려면 Transform | 032 |

> 💬 "044에서 Tag로 **골라냈죠.** 오늘은 Tag로 **찾습니다.** 같은 Tag를 다른 데 쓰는 거예요."

> 🚨 **`FindWithTag`는 무거운 함수다.** 060에서 `FindGameObjectsWithTag`를 코루틴으로 옮긴 것과 같은 이유.
> 💬 "**`Start`에서 한 번만** 찾습니다. `Update`에서 매 프레임 찾으면 적 200마리일 때 게임이 멈춰요."
> 💬 "049에서 `GetComponent`를 `Awake`에 넣은 것과 **똑같은 이유**입니다."

### ② 향해서 온다 (11분) — 오늘의 핵심

```csharp
[SerializeField] private float moveSpeed = 2f;

private Rigidbody2D rb;

void Awake()
{
    rb = GetComponent<Rigidbody2D>();
}

void FixedUpdate()
{
    if (target == null) return;

    Vector2 dir = ((Vector2)target.position - rb.position).normalized;

    rb.linearVelocity = dir * moveSpeed;
}
```

▶ Play → **적이 플레이어를 따라온다.**

> 🎉 여기서 반응이 온다. 도망다니게 둔다.

**한 줄을 세 조각으로 나눠 짚는다.**

| 조각 | 뜻 |
|---|---|
| `target.position - rb.position` | **"나에서 목표까지" 화살표** |
| `.normalized` | 그 화살표의 **방향만** 남긴다 (059) |
| `* moveSpeed` | 그 방향으로 **얼마나 빨리** |

> 💬 "**빼기가 방향을 만듭니다.** '목표 빼기 나' 예요. 순서를 바꾸면 반대로 도망갑니다."
> 💬 "032에서 좌표를 배웠죠. **좌표끼리 빼면 방향이 나옵니다.** 이게 오늘 제일 중요한 문장이에요."

> ⚠️ **순서를 바꿔서 도망가게 해본다.** 일부러 `rb.position - target.position` 으로 바꿔 Play.
> 💬 "이렇게 하면 도망갑니다. **어느 게 맞는지 헷갈리면 한 번 뒤집어 보세요.**"

> 💡 `target == null` 확인이 왜 필요한지: **플레이어가 죽으면 적이 쫓을 대상이 없다.**
> 057의 `player == null`과 같은 상황이다.

> 💬 "**050에서 총알이 하던 것과 똑같습니다.** 대상만 반대예요."

> ⚠️ **적이 왜 사라져야 하는지** 짚는다.
> 💬 "안 사라지면 어떻게 될까요? **닿아 있는 동안 계속 데미지**를 줍니다. 순식간에 죽어요."
> 💬 "그래서 오늘 적은 **부딪히면 같이 사라집니다.** 본 프로젝트에서는 '초당 데미지'로 제대로 만듭니다."

### ④ 사방에서 나오게 (8분)

052의 스포너는 **위에서만** 나온다. 원형으로 바꾼다.

```csharp
private Vector3 RandomEdgePosition()
{
    float angle = Random.Range(0f, Mathf.PI * 2f);

    return new Vector3(Mathf.Cos(angle), Mathf.Sin(angle), 0f) * spawnRadius;
}
```

> 💬 "각도를 랜덤으로 하나 뽑고, **그 각도의 원 위 한 점**을 구합니다."
> 💬 "`Cos`, `Sin` 은 **원 위의 점을 구하는 공식**입니다. 지금은 그냥 외우세요."
> 💬 "`spawnRadius`를 화면보다 크게 두면 **화면 밖에서** 나옵니다."

| 값 | 결과 |
|---|---|
| `spawnRadius = 4` | 화면 안에서 튀어나온다 (안 좋다) |
| **`spawnRadius = 12`** | **화면 밖에서 걸어 들어온다** |

> ⚠️ **삼각함수를 설명하려 들지 않는다.** "원 위의 점" 까지만.
> 궁금해하는 학생에게만 개별로 "각도를 x, y로 바꿔주는 함수" 라고 답한다.

```csharp
using UnityEngine;

public class EnemyChaser : MonoBehaviour
{
    [SerializeField] private float moveSpeed = 2f;
    [SerializeField] private int damage = 10;

    private Rigidbody2D rb;
    private Transform target;

    void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Start()
    {
        GameObject player = GameObject.FindWithTag("Player");

        if (player != null)
        {
            target = player.transform;
        }
    }

    void FixedUpdate()
    {
        if (target == null) return;

        Vector2 dir = ((Vector2)target.position - rb.position).normalized;

        rb.linearVelocity = dir * moveSpeed;
    }

    private void OnTriggerEnter2D(Collider2D other)
    {
        if (other.CompareTag("Player"))
        {
            Health health = other.GetComponent<Health>();

            if (health != null)
            {
                health.TakeDamage(damage);
            }

            Destroy(gameObject);
        }
    }
}
```

프리팹 설정도 확인한다.

| 항목 | 값 |
|---|---|
| Tag | `Enemy` |
| `Circle Collider 2D` | **`Is Trigger` 켬** |
| `Rigidbody 2D` | `Gravity Scale 0` · `Freeze Rotation Z` |
| `EnemyChaser` | `moveSpeed 2` · `damage 10` |

</details>

**확인 조건**: 적이 사방에서 나와 플레이어를 향해 온다. 닿으면 체력이 깎이고 적이 사라진다.
플레이어가 죽어도 **에러가 안 난다**.

### ⭐ 도전 미션

- [ ] 방향 계산 순서를 바꿔 **도망가는 적**을 만든다 (그리고 되돌린다)
- [ ] 적 속도를 랜덤으로 준다 (`Random.Range`)
- [ ] 적이 **플레이어 쪽을 바라보게** 한다 (`transform.up = dir`)
- [ ] 빠른 적(작고 빠름)과 느린 적(크고 느림) **두 종류**를 만든다
- [ ] 적이 서로 겹치지 않게 한다 (Layer Matrix — 045)
- [ ] 화면 밖으로 너무 멀어진 적을 지운다 (`Vector2.Distance`)
- [ ] 스폰 위치를 원이 아니라 **화면 네 변**에서 뽑는다

## 01:35–01:50 · 데모 + 정리
