## 00:10–00:45 · 같이 하기 ★

### ① `RectTransform` 은 Transform 이 아니다 (6분)

UI 오브젝트를 클릭하면 Inspector 맨 위가 `Rect Transform` 이다.

| Transform (033) | Rect Transform |
|---|---|
| Position | **Pos X / Pos Y** (앵커로부터의 거리) |
| — | **Width / Height** |
| — | **Anchors** (Min / Max) |
| — | **Pivot** |
| Rotation / Scale | 그대로 있다 |

> 💬 "`Rect Transform` 은 `Transform` 을 **상속한** 것입니다. 070에서 배운 그 상속이에요."
> 💬 "그래서 Rotation·Scale 은 똑같이 있고, **위치 정하는 방식만** 달라졌습니다."

### ② Anchor — 화면의 어디에 붙어 있을지 (14분)

Inspector 왼쪽 위의 **네모 아이콘**을 누르면 앵커 프리셋 창이 열린다.

> 💬 **"Anchor 는 '이 UI 가 화면(부모)의 어디에 붙어 있을지' 를 정하는 겁니다."**
> 💬 "화면이 커지거나 작아질 때, **앵커에 붙어 있는 쪽을 기준으로 따라갑니다.**"

**비유** — 벽에 붙인 포스트잇

| 상황 | Anchor |
|---|---|
| 벽 **한가운데**에 붙였다 | 벽이 넓어지면 포스트잇도 가운데에 남는다 |
| 벽 **오른쪽 위 모서리**에 붙였다 | 벽이 넓어져도 **오른쪽 위 모서리**에 남는다 |

**Anchor Min / Max 숫자로 보기**

| 값 | 뜻 |
|---|---|
| Min `(0.5, 0.5)` · Max `(0.5, 0.5)` | 화면 **정가운데** 한 점 (기본값) |
| Min `(0, 1)` · Max `(0, 1)` | **왼쪽 위** 한 점 |
| Min `(1, 1)` · Max `(1, 1)` | **오른쪽 위** 한 점 |
| Min `(0, 0)` · Max `(1, 0)` | **아래쪽 가로 전체** ← 늘어난다 |
| Min `(0, 0)` · Max `(1, 1)` | **화면 전체** ← 사방으로 늘어난다 |

> 🔑 💬 "**Min 과 Max 가 같으면 '점'** 입니다. 크기는 Width/Height 로 정합니다."
> 💬 "**Min 과 Max 가 다르면 '범위'** 예요. 화면이 커지면 **UI 도 같이 늘어납니다.**"
> 💬 "이걸 **Stretch** 라고 부릅니다. 경험치 바를 그렇게 만들 거예요."

**우리 HUD 의 앵커 배치**

| 요소 | Anchor | 왜 |
|---|---|---|
| `ExpBar` | Min `(0,1)` Max `(1,1)` | 위쪽 **가로 전체로 늘어난다** |
| `LevelLabel` | `(0,1)` 점 | 왼쪽 위에 붙는다 |
| `TimeLabel` | `(0.5,1)` 점 | 위 가운데 |
| `KillLabel` | `(1,1)` 점 | 오른쪽 위 |
| `HealthBar` | `(0.5,0)` 점 | 아래 가운데 |
| `CenterText` | `(0.5,0.5)` 점 | 정가운데 — **여긴 가운데가 맞다** |

> 💬 "가운데 앵커가 **틀린 게 아닙니다.** 가운데에 있어야 하는 건 가운데로 잡는 거예요."
> 💬 "틀린 건 **모서리에 있어야 할 걸 가운데로 잡은 것**입니다."

**⚠️ 앵커 프리셋을 누를 때 `Alt` / `Shift`**

| 누르는 키 | 효과 |
|---|---|
| 그냥 클릭 | 앵커만 바뀐다. **위치는 그대로** |
| **`Alt` + 클릭** | 앵커를 바꾸고 **그 자리로 이동까지** 한다 |
| **`Shift` + 클릭** | 앵커를 바꾸고 **Pivot 도 같이** 맞춘다 |
| `Alt`+`Shift` + 클릭 | 셋 다 |

> 🚨 **그냥 클릭하면 UI 가 안 움직여서 "안 먹었나?" 한다.** 실제로는 먹었다.
> Pos X / Pos Y 값이 이상한 숫자로 바뀐 걸 보여준다.
> 💡 **처음엔 `Alt`+`Shift` 클릭을 쓰라고 한다.** 원하는 자리에 딱 붙는다.

### ③ Pivot — 자기 몸의 어디를 잡고 있을지 (8분)

> 💬 "Anchor 가 **'벽의 어디'** 였다면, Pivot 은 **'포스트잇의 어디를 잡고 있나'** 입니다."

| Pivot | 뜻 |
|---|---|
| `(0.5, 0.5)` | 한가운데를 잡고 있다 (기본값) |
| `(0, 1)` | **왼쪽 위 귀퉁이**를 잡고 있다 |
| `(1, 1)` | **오른쪽 위 귀퉁이**를 잡고 있다 |

**Pivot 이 왜 필요한가** — 오른쪽 위 `처치 N` 으로 시연한다.

숫자가 `처치 9` → `처치 128` 로 길어질 때:

| Pivot | 글자가 길어지면 |
|---|---|
| `(0.5, 0.5)` | **양쪽으로 벌어진다** → 오른쪽이 화면 밖으로 |
| **`(1, 1)`** | **왼쪽으로만 자란다** → ✅ 오른쪽 끝이 고정 |

> 💬 "그래서 오른쪽 위 글자는 **Pivot 도 `(1,1)`** 로 둡니다."
> 💬 "회전시켜 보면 더 명확해요. **Pivot 이 회전의 중심**입니다."

▶ Pivot 을 `(0,0)` 으로 두고 Rotation Z 를 돌려 보여준다.

### ④ Stretch — 경험치 바를 가로 전체로 (7분)

`ExpBar` 를 클릭하고 앵커 프리셋에서 **맨 윗줄 오른쪽 끝(가로 stretch)** 을 고른다.

Anchor 를 범위로 잡으면 Inspector 의 칸 이름이 **바뀐다.**

| 점 앵커일 때 | 범위 앵커일 때 |
|---|---|
| Pos X / Width | **Left / Right** |
| Pos Y / Height | **Top / Bottom** |

> 🔑 💬 "**Left 5, Right 5 로 두면 '양쪽에서 5픽셀 띄우고 나머지 전부'** 라는 뜻입니다."
> 💬 "화면이 넓어지면 바도 넓어져요. 숫자를 다시 안 고쳐도 됩니다."

**실측** — 우리 `ExpBar` 는 Left 0 / Right 0 / Height 20 이다.

| 해상도 | ExpBar 의 화면 x 범위 |
|---|---|
| 640×480 | `0 ~ 640` |
| 1280×720 | `0 ~ 1280` |
| 1920×1080 | `0 ~ 1920` |

> 💬 "**항상 화면 폭 전체입니다.** 이게 Stretch 예요."

## 01:35–01:50 · 데모 · 정리

학생 한 명이 화면 공유로 **해상도를 `1280x720` → `640x480` → `1920x1080`** 순서로 바꾼다.

> 💬 "네 모서리가 **딱 붙어 있죠.** 이게 오늘 한 일 전부입니다."

**칠판 요약**

```
Anchor  — 화면(부모)의 어디에 붙어 있나
          Min == Max  →  점  (크기는 Width/Height)
          Min != Max  →  범위 (Stretch, Left/Right/Top/Bottom)

Pivot   — 자기 몸의 어디를 잡고 있나
          위치·회전·크기의 기준점
```

> 💬 "Anchor 는 **바깥**, Pivot 은 **안쪽**. 이 한 줄만 기억하세요."
