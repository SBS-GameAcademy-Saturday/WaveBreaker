### ② ③번 — 끊김을 만들어 본다 (12분)

`NetworkTransform` 의 **Interpolate 를 끈다.**

▶ 실행 → 상대 캐릭터가 **뚝뚝 끊겨 보인다.**

> 💬 "왜 끊길까요?"

```
위치는 초당 30번만 보낸다  (Tick Rate 30)

보낸 것:   ● ---- ● ---- ● ---- ●      (초당 30개 점)
받은 쪽:   ● ---- ● ---- ● ---- ●      끊겨 보인다
Interpolate: ●━━━━●━━━━●━━━━●         점 사이를 이어준다
```

> 🔑 💬 "**Interpolate 는 점과 점 사이를 채워주는 겁니다.**"
> 💬 "받은 위치로 순간이동하는 대신, **부드럽게 걸어가게** 하는 거예요."

Interpolate 를 다시 켠다. 부드러워진다.

**Tick Rate 도 만져본다** — `NetworkManager` → `Tick Rate`

| Tick Rate | 느낌 | 데이터 |
|---|---|---|
| 5 | 눈에 띄게 끊긴다 | 적다 |
| **30** | ✅ 기본값. 괜찮다 | 보통 |
| 60 | 조금 더 부드럽다 | **두 배** |

> 💬 "높이면 좋아 보이지만 **데이터가 그만큼 늘어납니다.**"
> 💬 "30이면 충분해요. Interpolate 가 나머지를 채워주거든요."

### ③ ①번 — 왜 둘 다 움직이나 (10분)

> 💬 "어제 힌트를 드렸죠. 다시 봅시다."

```csharp
void Update()
{
    float h = Input.GetAxisRaw("Horizontal");
    MoveInput = new Vector2(h, v).normalized;
}
```

**그림으로 설명한다.**

```
내 화면 (호스트)
 ┌─────────────────────────────────┐
 │  네모 A (내 것)   ← 이 스크립트가 돈다  │
 │  네모 B (남의 것) ← 이 스크립트도 돈다  │  🚨
 └─────────────────────────────────┘
        내가 D 키를 누르면 → 둘 다 오른쪽으로
```

> 🔑 💬 "**스크립트는 네모마다 하나씩 붙어 있습니다.**"
> 💬 "제 키보드 입력은 **제 화면의 모든 네모**가 읽어요. 구분을 안 해줬으니까요."

> 💬 "그럼 어떻게 구분하죠?" → **`IsOwner`**
> 💬 "109회차에 로그로 찍어봤던 그 값입니다. 다음 시간에 씁니다."

### ④ 프로파일러를 연다 (12분)

```
Window → Analysis → Profiler  →  Network 모듈 추가
```

또는 `Window → Multiplayer → Network Profiler` (Multiplayer Tools)

| 볼 것 | 뜻 |
|---|---|
| **Bytes Sent / Received** | 초당 주고받는 양 |
| **RTT** | 왕복 시간 (핑) |
| Objects | 동기화 중인 오브젝트 수 |

> 💬 "로컬 테스트라 RTT 가 **0에 가깝습니다.** 진짜 인터넷이 아니니까요."
> 💬 "그래서 **진짜 문제를 못 봅니다.** 그래서 도구가 하나 더 있어요."

**Network Simulator** — 일부러 나쁜 인터넷을 흉내낸다.

```
Window → Multiplayer → Network Simulator  (또는 NetworkManager 의 Simulator 설정)

Packet Delay   : 100 ms     ← 느린 인터넷
Packet Jitter  : 30 ms      ← 들쭉날쭉
Packet Loss    : 5 %        ← 데이터가 사라진다
```

▶ 이 상태로 움직여 본다.

> 💬 "**이게 진짜 인터넷입니다.** 친구랑 할 땐 이럴 수 있어요."
> 💬 "지금 로컬에서 멀쩡한 게 진짜로도 멀쩡하다는 뜻은 아닙니다."

> 💡 **수업에서는 이 설정을 다시 끈다.** 켜두면 개발이 괴롭다.
