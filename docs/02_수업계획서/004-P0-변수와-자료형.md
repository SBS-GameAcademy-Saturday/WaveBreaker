## 00:10–00:45 · 같이 치기 ★

### ① 불편함 먼저 (7분) — 오늘의 도입

```csharp
Console.WriteLine("용사의 체력: 100");
Console.WriteLine("남은 체력: 100");
Console.WriteLine("최대 체력: 100");
```

**강사가 시킨다**: "체력을 150으로 바꾸세요." → 세 군데 고친다.
"다시 200으로." → 또 세 군데.
"이번엔 80으로." → 또 세 군데.

> 💬 "지금 뭐가 불편하죠?"
> → **"같은 걸 여러 번 고쳐야 하고, 하나 빠뜨리면 값이 안 맞는다."**

> 💬 "이걸 해결하는 게 오늘 배울 **변수**입니다."

### ② 변수 만들기 (10분)

```csharp
int hp = 100;

Console.WriteLine("용사의 체력: " + hp);
Console.WriteLine("남은 체력: " + hp);
Console.WriteLine("최대 체력: " + hp);
```

이제 **맨 윗줄 하나만** 고치면 전부 바뀐다.

> 💬 "`hp`라는 **이름표를 붙인 자리**를 만들고 100을 넣어뒀어요. 아래에선 `hp`라고만 쓰면 됩니다."

**여기서 짚을 것**

| 포인트 | 설명 |
|---|---|
| `int` | "이 자리에 들어갈 것의 종류". 정수 |
| `hp` | 이름. 영어, 공백 X, 숫자로 시작 X, **의미 있게** |
| `=` | 같다는 뜻이 아니라 **"넣는다"** ← 노베이스가 가장 헷갈리는 지점 |
| `+` | 글자와 값을 이어 붙인다 |

> ⚠️ `=`를 "같다"로 오해하는 학생이 반드시 나온다. **"오른쪽 걸 왼쪽에 넣는다"** 로 반복.

### ③ 자료형 4종 (13분)

```csharp
int   hp     = 100;      // 정수 — 체력, 점수, 개수
float speed  = 5.5f;     // 소수 — 이동 속도  (뒤에 f)
bool  isAlive = true;    // 참/거짓 — 살았나 죽었나
string name  = "용사";    // 글자 — 이름, 대사
```

각각 출력해서 **화면에 어떻게 나오는지 직접 보여준다.**

> ⚠️ `float`의 `f`: **"소수점 있는 숫자는 뒤에 f를 붙입니다. 규칙이에요."** 부동소수점 설명 금지.
> ⚠️ `string`은 큰따옴표 `"`, `char`는 작은따옴표 — 오늘은 `string`만.

### ④ 입력 받기 (5분)

```csharp
Console.Write("이름을 입력하세요: ");
string playerName = Console.ReadLine();

Console.WriteLine(playerName + "님, 환영합니다!");
```

> 💬 "이제 프로그램이 **여러분 말을 듣습니다.**"

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| `Literal of type double cannot be...` | `float`인데 `f` 누락 | **오늘 가장 많이 나온다.** "소수점 뒤엔 f" 반복 |
| `Cannot implicitly convert 'string' to 'int'` | `ReadLine` 결과를 `int`에 넣음 | 형 변환은 **다음 주(2주차)**. 오늘은 "문자로만 받으세요"로 막는다 |
| `=`를 "같다"로 이해 | 노베이스 최대 오해 | "오른쪽을 왼쪽에 넣는다"를 손으로 여러 번 |
| 변수명에 한글·공백 | 에러 | 영어 소문자로 시작, 띄어쓰기 대신 대문자(`moveSpeed`) |
| 변수 선언 전에 사용 | 순서 문제 | 003회차 "위에서 아래로"와 연결해 설명 |
| `ReadLine` 후 창이 바로 닫힘 | Ctrl+F5 안 씀 | 003회차 복습 |
| 진도 빠른 학생이 `var`, 형 변환 물어봄 | 좋은 신호 | 답해주되 **반 전체에 공유하지 않는다.** 도전 미션으로 |
