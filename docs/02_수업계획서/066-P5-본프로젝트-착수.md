### ④ `GameManager` — 게임 상태 (8분)

빈 GameObject `GameManager` 를 만들고 스크립트를 붙인다.

```csharp
using UnityEngine;

public enum GameState
{
    Title,
    Playing,
    Upgrading,
    Paused,
    GameOver,
    Clear
}

public class GameManager : MonoBehaviour
{
    public static GameManager Instance { get; private set; }

    public GameState State { get; private set; } = GameState.Playing;

    void Awake()
    {
        if (Instance != null && Instance != this)
        {
            Destroy(gameObject);
            return;
        }

        Instance = this;
    }

    public void ChangeState(GameState next)
    {
        State = next;

        Debug.Log("게임 상태: " + next);
    }
}
```

**`enum` 을 처음 쓴다.**

> 💬 "`enum` 은 **정해진 값 중 하나**를 담는 타입입니다. 3주차의 `switch` 기억나죠? 그때 나왔던 거예요."
> 💬 "게임 상태를 `int` 로 두면 `0` 이 뭔지 아무도 모릅니다. `GameState.Playing` 은 읽으면 압니다."

**`static Instance` — 싱글톤.**

> 💬 "**어디서든 `GameManager.Instance` 로 부를 수 있게** 하는 겁니다."
>
> 🚨 **여기서 못을 박는다.**
> 💬 "**이 프로젝트에서 `static` 은 `GameManager` 하나만 씁니다.** 다른 데 쓰지 마세요."
> 💬 "편해 보여서 여기저기 쓰면 **나중에 누가 언제 바꿨는지 못 찾습니다.** 특히 2인 협동에서요."

> ⚠️ `Awake` 의 중복 확인이 왜 필요한지: **씬을 다시 열면 두 개가 될 수 있다.** 057의 `LoadScene` 을 쓰니까.

> 학생: "스포너요."

```

```

**왜 그런가 — 학생에게는 이렇게 설명한다.**

> 💬 "여기저기서 몬스터를 만들면 **나중에 누가 만들었는지 못 찾습니다.**"
> 💬 "'몬스터가 너무 많이 나와요' 라는 버그가 났을 때, **찾아볼 곳이 한 군데면** 5분이고 열 군데면 하루예요."

> 🔑 **강사만 아는 진짜 이유**: 22주차에 `WaveManager` 에 `if (!IsServer) return;` **한 줄**을 넣으면
> 서버 권한 스폰이 끝난다. 스폰이 흩어져 있으면 그때 전부 찾아 고쳐야 한다.
> **학생에게 네트워크 얘기는 지금 한마디도 하지 않는다.** 117회차에 회수한다.

### 규칙 ② 입력 읽는 일과 움직이는 일은 다른 일이다 (12분)

```
PlayerInput       키보드를 읽어 방향 값만 보관한다
PlayerController  그 값을 받아 움직인다
```

> 💬 "042에서는 한 스크립트에서 **읽고 바로 움직였죠.** 앞으로는 나눕니다."
> 💬 "**키보드를 읽는 일**과 **몸을 움직이는 일**은 다른 일이에요."

**왜 나누는가 — 학생에게는 이렇게.**

| 나누면 | 이득 |
|---|---|
| 키보드 → 게임패드로 바꿀 때 | **읽는 쪽만** 고치면 된다 |
| 이동을 고칠 때 | **움직이는 쪽만** 본다 |
| 버그를 찾을 때 | "값이 잘못 들어왔나" / "값은 맞는데 이상하게 움직이나" 로 나뉜다 |

> 🔑 **강사만 아는 진짜 이유**: 25주차에 다른 사람의 캐릭터를 움직일 때,
> **입력 값만 네트워크로 보내면** 이동 코드는 그대로 쓴다. 114회차에 회수한다.
