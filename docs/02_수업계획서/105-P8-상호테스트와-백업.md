## 00:00–00:10 · 빌드 확인

**전원이 채팅에 한 줄씩 적는다.**

```
✅ 빌드 됨 / 실행 됨
🚨 빌드 안 됨 — (증상)
```

> 🔴 **안 된 학생이 있으면 지금 잡는다.** 오늘 이후로는 기회가 없다.

| 증상 | 즉시 대응 |
|---|---|
| 경로에 한글 | 폴더를 옮기고 다시 빌드 (10분) |
| 검은 화면 | Build Settings 0번이 `Title` 인지 |
| 빌드가 안 끝남 | Scripting Backend 를 **Mono** 로 |
| 아예 못 함 | **강사 화면을 공유해 같이 한다.** 넘어가지 않는다 |

## 00:10–00:25 · 파일 나누기

**빌드 폴더를 통째로 압축한다.**

```
Builds\WaveBreaker_Single\   →   우클릭 → 압축 → WaveBreaker_<이름>.zip
```

> 🚨 **`.exe` 만 압축하면 안 된다.** 폴더 전체다. (104 회수)

**공유 방법** (강사가 하나를 정한다)

| 방법 | 주의 |
|---|---|
| 구글 드라이브 공유 폴더 | 링크 권한을 "링크가 있는 모든 사용자" 로 |
| 카카오톡 / 디스코드 | 100 MB 넘으면 안 올라간다 |

> 💡 105 MB 정도라 **메신저 첨부는 대체로 막힌다.** 드라이브를 권한다.

> 🚨 **백신이 남의 `.exe` 를 지울 수 있다.** 서명이 없어서 그렇다.
> 💬 "여러분이 만든 게 위험해서가 아니라, **누가 만들었는지 증명이 없어서**입니다."
> 압축을 풀 폴더를 백신 예외로 등록하거나, "실행" 을 눌러 통과시킨다.

## 00:25–01:05 · 상호 플레이

**두 명씩 짝을 지어 서로의 게임을 40분간 한다.**

### 볼 것 — 피드백 양식

각자 **받은 게임**에 대해 아래를 채운다.

```
게임 만든 사람 :
플레이한 시간   :        분
최고 기록       : 생존       / 처치       / 레벨

① 재밌었던 것 (구체적으로 하나)
②

② 어려웠던 것 / 헷갈린 것
②

③ 버그를 봤다면
③

④ 내 게임과 다른 점 하나
④
```

> 💬 "**'재밌어요' 는 피드백이 아닙니다.** '3분쯤에 칼이 4개가 되니까 확 시원했다' 가 피드백이에요."

### 강사가 볼 것

브레이크아웃을 돌며 아래를 확인한다.

| 확인 | 왜 |
|---|---|
| 10분을 버티는 사람이 있나 | 너무 어렵지 않은가 |
| 1분 만에 죽는 사람이 있나 | 밸런스 |
| 보스를 만난 사람이 있나 | `bossTimes` 를 되돌렸는가 |
| 프레임이 떨어지나 | 103의 상한이 걸렸는가 |

## 01:35–01:55 · 🔴 백업 ⭐

> 💬 "이제 이 과정에서 **가장 중요한 20분**입니다."

### 백업할 것 두 가지

| 이름 | 무엇 | 어떻게 |
|---|---|---|
| `WaveBreaker_Single.zip` | **빌드된 게임** | 아까 압축한 그 파일 |
| `Snapshot_P8_Final_Single.zip` | **프로젝트 전체** | 아래 방법대로 |

### 프로젝트 압축하는 법

**압축할 것**

```
✅ Assets\
✅ Packages\
✅ ProjectSettings\
```

**빼도 되는 것** (용량이 몇 배 차이 난다)

```
❌ Library\      다시 만들어진다. 수 GB 다
❌ Temp\  obj\   임시 파일
❌ Builds\       따로 압축했다
❌ Logs\  UserSettings\
```

> 💡 세 폴더만 있으면 **어느 컴퓨터에서든 프로젝트가 열린다.** 처음 여는 데 몇 분 걸릴 뿐이다.

### 어디에 두나 — **두 군데 이상**

| 곳 | 왜 |
|---|---|
| 클라우드 (구글 드라이브 / OneDrive) | 컴퓨터가 고장 나도 남는다 |
| USB 또는 외장 하드 | 인터넷이 없어도 된다 |
| **GitHub** (해본 학생) | 변경 이력까지 남는다 |

> 🔴 💬 "**한 군데만 두면 백업이 아닙니다.** 그 한 군데가 고장 나면 끝이에요."

### 🔴 한 명씩 눈으로 확인한다

> 💬 "이제 한 분씩 **화면을 공유해서** 백업 파일을 보여주세요."

**강사 체크표**

| 학생 | 빌드 zip | 프로젝트 zip | 클라우드 | 두 번째 위치 |
|---|---|---|---|---|
| | ☐ | ☐ | ☐ | ☐ |

> 🔴 **"백업했어요" 라는 대답을 믿지 않는다.** 파일을 보여주게 한다.
> 💬 "의심해서가 아닙니다. **이게 안 되면 7개월이 날아가서** 그래요."
>
> 🔑 **이 20분이 7개월 과정에서 가장 값어치 있는 20분이다.**
