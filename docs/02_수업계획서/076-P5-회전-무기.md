> 💬 "칼을 플레이어 자식으로 두고, **플레이어를 돌리면**... 어떻게 될까요?"
> 💬 "플레이어 그림도 같이 돕니다. 그건 싫죠. **그래서 중간에 하나를 더 둡니다.**"

### ② 구조를 만든다 (8분)

```
Player                ← 안 돈다
  └ Blades            ← 이게 돈다 (빈 오브젝트)
      └ Blade         ← 칼. 중심에서 2만큼 떨어져 있다
```

1. `Player` 아래에 빈 오브젝트 `Blades` 를 만든다 (Position `0, 0, 0`)
2. `Blades` 아래에 칼 오브젝트 `Blade` 를 만들고 **Position `(2, 0, 0)`** 을 준다

| `Blade` 항목 | 값 |
|---|---|
| `Sprite Renderer` | 칼 그림, Sorting Layer `Player` |
| `Box Collider 2D` | **`Is Trigger` 켬**, Size `0.55 × 1.05` |
| Rotation Z | `-90` (칼끝이 바깥을 보게) |

> 💬 "`Blades` 는 **눈에 안 보이는 축**입니다. Sprite Renderer 도 없어요."
> 💬 "`Blade` 의 Position 이 `(2, 0)` 이죠. **부모에서 2만큼 떨어져 있다**는 뜻입니다 (033)."

> 🚨 **`Blade` 에 `Rigidbody 2D` 를 붙이지 않는다.**
> 부모인 `Player` 가 이미 갖고 있어서, 칼의 Collider 는 **플레이어 몸의 일부**로 붙는다.
> 그래서 Trigger 가 정상 동작한다 (043).

### ③ 돌린다 (8분)

`Scripts/Weapon/MeleeRing.cs` 를 `Blades` 에 붙인다.

```csharp
using UnityEngine;

public class MeleeRing : MonoBehaviour
{
    [SerializeField] private float rotateSpeed = 180f;   // 초당 각도

    private void Update()
    {
        transform.Rotate(0f, 0f, rotateSpeed * Time.deltaTime);
    }
}
```

▶ Play → **칼이 돈다.**

> 🎉 세 줄이다. 여기서 반응이 온다.

| 조각 | 뜻 |
|---|---|
| `transform.Rotate(0, 0, z)` | z축(화면 방향)으로 회전 (033) |
| `* Time.deltaTime` | **초당** 각도로 만든다 (039) |
| `180f` | 2초에 한 바퀴 |

> 🚨 **`Time.deltaTime` 을 빼면 컴퓨터마다 속도가 다르다.** 039에서 배운 그대로다.
> 빼고 한 번 실행해서 미친 듯이 도는 걸 보여준다.

### ④ 베게 만든다 (10분) — 오늘의 핵심

`Scripts/Weapon/Blade.cs` 를 `Blade` 에 붙인다.

**먼저 `Enter` 로 해본다.**

```csharp
private void OnTriggerEnter2D(Collider2D other)
{
    if (!other.CompareTag("Enemy")) return;
    if (!other.TryGetComponent(out IDamageable target)) return;

    target.TakeDamage(damage);
}
```

▶ Play → 벤다. 그런데 **칼 궤도 안에 갇힌 몬스터는 한 대만 맞고 안 죽는다.**

> 💬 "왜 한 대만 맞을까요?"
> 💬 "`Enter` 는 **닿는 순간 한 번**입니다 (044). 계속 닿아 있으면 다시 안 불려요."

**`Stay` 로 바꾸고 쿨다운을 붙인다.**

```csharp
using UnityEngine;

public class Blade : MonoBehaviour
{
    [SerializeField] private int damage = 3;
    [SerializeField] private float hitInterval = 0.3f;

    private float nextHitTime;

    private void OnTriggerStay2D(Collider2D other)
    {
        if (Time.time < nextHitTime) return;
        if (!other.CompareTag("Enemy")) return;
        if (!other.TryGetComponent(out IDamageable target)) return;

        nextHitTime = Time.time + hitInterval;
        target.TakeDamage(damage);
    }
}
```

| 함수 | 언제 불리나 |
|---|---|
| `OnTriggerEnter2D` | 닿는 **순간 한 번** |
| `OnTriggerStay2D` | 닿아 있는 **동안 계속** |
| `OnTriggerExit2D` | 떨어지는 **순간 한 번** (069에서 썼다) |

> 🚨 **`Stay` 에 쿨다운이 없으면 매 프레임 피해가 들어간다.**
> 075에서 Space 를 꾹 눌렀을 때와 **똑같은 문제**다. 해결도 똑같이 `Time.time` 이다.

> 💡 지금 쿨다운은 **칼 한 자루에 하나**다. 여러 마리에 동시에 닿아도 0.3초에 한 번만 나간다.
> 몬스터별로 따로 세는 방법도 있지만 지금은 필요 없다. **간단한 게 낫다.**

### ⭐ 도전 미션

- [ ] `rotateSpeed` 를 `-180` 으로 바꿔 **반대로 돌린다**
- [ ] `radius`(칼 Position x)를 `4` 로 늘려 **넓게** 돈다 — 뭐가 나빠지는지 쓴다
- [ ] `hitInterval` 을 `0.05` 로 낮춰 **너무 센 무기**를 만들어본다 (그리고 되돌린다)
- [ ] `Blades` 를 `Player` 밖으로 빼서 **따라오지 않는 걸** 확인한다 (그리고 되돌린다)
- [ ] `Time.deltaTime` 을 지우고 실행 → 무슨 일이 나는지 쓴다 (039)
- [ ] 칼 크기를 키우고 `Box Collider 2D` 도 **같이** 맞춘다
- [ ] `rotateSpeed` 를 웨이브에 따라 빨라지게 한다 (`WaveManager.Wave` 를 읽는다)

> 💡 네 번째 도전이 **033의 핵심을 다시 확인시킨다.** 부모가 없으면 따라오지 않는다.
