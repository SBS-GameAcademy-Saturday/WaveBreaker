### ② 타이틀에 버튼 하나 (10분)

```csharp
// 097회차 · 타이틀 화면. 하는 일이 두 개뿐이라 스크립트도 두 줄이다.
// 125회차 · [같이 하기] 가 붙었다. 기획서 3장의 모드 구조가 여기서 완성된다.
public class TitleView : MonoBehaviour
{
    // 혼자 하기 — 21주차에 완성한 그 게임. 네트워크가 전혀 안 끼어든다.
    public void StartGame()
    {
        SceneManager.LoadScene("Game");
    }

    // 같이 하기 — 협동 씬. 호스트/클라이언트 또는 Relay 코드로 붙는다.
    public void StartCoop()
    {
        SceneManager.LoadScene("Coop");
    }
}
```

> 💬 "**함수 하나 추가입니다.** 097에서 만든 구조 그대로예요."

**Build Settings 에 `Coop` 을 추가한다.**

```
0  Title
1  Game
2  Result
3  Coop     ← 추가
```

> 🚨 **여기 없으면 [같이 하기] 를 눌러도 검은 화면**이다. 097회차의 그 사고다.

### ③ 왜 씬을 나눴나 (12분) — 정직하게 말한다

> 💬 "여기서 솔직하게 말씀드릴 게 있습니다."

| | |
|---|---|
| 이상적인 모습 | `Game.unity` **하나**에서 혼자도 하고 같이도 한다 |
| 지금 우리 모습 | `Game.unity`(혼자) 와 `Coop.unity`(같이) **두 개** |

> 💬 "왜 하나로 못 합쳤을까요?"
>
> 💬 "본 게임의 몬스터·젬은 **오브젝트 풀**에서 나옵니다(102·103).
> 협동에서는 **`NetworkObject.Spawn()`** 으로 만들어야 하고요(117)."
> 💬 "이 둘을 한 코드로 합치려면 **스폰 경로를 통째로 갈아엎어야** 합니다."
>
> 🔴 💬 "그런데 그걸 하다가 실패하면 **21주차의 완성작이 깨집니다.**"
> 💬 "그래서 **안 합쳤습니다.** 이건 실력의 문제가 아니라 **판단**이에요."

> 🔑 💬 "다만 **합칠 준비는 해뒀습니다.**"

```csharp
// NetworkRole.cs — 117회차
public static bool IsServerOrOffline
{
    if (nm == null) return true;          // 씬에 없다 = 싱글 모드다
    if (!nm.IsListening) return true;     // 접속 안 했으면 싱글과 같다
    return nm.IsServer;
}
```

> 💬 "본 게임의 `WaveManager` 는 이미 이 문지기를 씁니다."
> 💬 "**싱글은 '호스트 혼자 하는 게임'** 으로 취급되고 있어요. 합치려면 여기서 이어가면 됩니다."

> 💬 "카메라도 마찬가지죠. `CameraFollow` 는 **한 파일로 둘 다** 처리합니다."
