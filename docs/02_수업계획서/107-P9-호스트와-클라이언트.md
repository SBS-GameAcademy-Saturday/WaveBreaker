## 00:10–00:50 · 같이 하기 ★

### ① 세 단어 (12분)

| 단어 | 하는 일 | 비유 |
|---|---|---|
| **서버** | 판정한다. 몬스터를 만든다. **진짜를 갖고 있다** | 심판 |
| **클라이언트** | 입력을 보내고, 받은 걸 보여준다 | 선수 |
| **호스트** | **서버 + 클라이언트를 겸한다** | 심판 겸 선수 |

```
[전용 서버 방식]                    [호스트 방식]  ← 우리 것

   서버 (아무도 안 함)                호스트 = A (심판 겸 선수)
    ↙        ↘                              ↕
클라A       클라B                        클라B
```

> 💬 "큰 온라인 게임은 회사가 **서버 컴퓨터**를 따로 둡니다. 심판이 따로 있는 거죠."
> 💬 "우리는 그럴 돈이 없어요. **둘 중 한 명이 심판을 겸합니다.** 그게 호스트예요."

> 🚨 💬 "그래서 **호스트가 게임을 끄면 다 끝납니다.** 심판이 사라진 거니까요."
> 💬 "여러분이 해본 게임에서 '방장이 나가서 게임이 터졌다' 는 게 이겁니다."

### ② 진짜는 하나뿐 (12분) — 오늘의 핵심

**질문을 던진다.**

> 💬 "몬스터 체력이 10입니다. 내가 3을 때렸고, 친구도 동시에 3을 때렸어요."
> 💬 "**몬스터 체력은 얼마죠?**"

학생들이 답한다. 4 라고 하면 맞다. 그런데 —

> 💬 "그럼 **누가 그 4를 계산하죠?**"

| 방식 | 무슨 일이 나나 |
|---|---|
| 각자 계산 | 내 화면 7, 친구 화면 7. **둘 다 틀렸다** |
| 각자 계산 (순서가 다르면) | 내 화면 4, 친구 화면 7. **둘이 다르다** |
| **서버가 계산하고 알려준다** | ✅ 둘 다 4 |

> 🔑 💬 "**진짜 값은 서버에만 있습니다.** 내 화면에 보이는 건 '서버가 알려준 사본' 이에요."
> 💬 "이걸 **권한(authority)** 이라고 합니다. '이 값은 누구 말이 맞는가'."

**그림**

```
      서버 (진짜 값)
   몬스터 체력 = 4
        │
   ┌────┴────┐
   ↓         ↓
 내 화면    친구 화면
  4 (사본)   4 (사본)
```

> 💬 "사본은 **틀릴 수 있습니다.** 인터넷이 느리면 잠깐 옛날 값이 보여요."
> 💬 "그래도 **금방 맞춰집니다.** 진짜가 하나뿐이니까요."

### ③ 그럼 내 캐릭터는? (10분)

> 💬 "내 캐릭터 위치도 서버가 정하나요?"

**두 가지 방식이 있다.**

| 방식 | 어떻게 | 장단점 |
|---|---|---|
| **서버 권한** | 입력을 서버에 보내고, 서버가 움직여서 알려준다 | 안전하다. **반응이 느리다** |
| **소유자 권한** | 내가 직접 움직이고 결과를 알려준다 | 빠르다. 치트에 약하다 |

> 🔑 💬 "**우리는 소유자 권한을 씁니다.**"
> 💬 "친구랑 하는 게임에 치트를 쓸 사람도 없고, **반응이 느리면 재미가 없거든요.**"

> 💬 "여기서 중요한 게 나옵니다. **'내 것' 이라는 개념.**"
> 💬 "내 캐릭터는 내가 움직이고, 친구 캐릭터는 친구가 움직입니다."
> 💬 "**그걸 안 나누면?**" → 한 키를 누르면 둘 다 움직인다.

> 💡 그게 114회차에서 배울 `IsOwner` 다. 오늘은 이름만 알아둔다.

### ④ 우리 게임을 나눠본다 (12분)

**칠판에 표를 만들고 학생과 같이 채운다.**

| 항목 | 누구 것 | 왜 |
|---|---|---|
| 내 캐릭터 위치 | **소유자(나)** | 반응이 빨라야 한다 |
| 몬스터 생성 | **서버** | 안 그러면 두 배로 나온다 |
| 몬스터 위치 | **서버** | 진짜가 하나여야 한다 |
| 몬스터 체력 | **서버** | 동시에 때리면 계산이 꼬인다 |
| 젬 생성 | **서버** | 몬스터가 죽는 곳이 서버다 |
| 젬 획득 판정 | **서버** | 둘이 동시에 먹으면 안 된다 |
| 플레이어 체력 | **서버** | 죽었는지를 둘 다 알아야 한다 |
| 경험치 · 레벨 | **서버** | 협동은 경험치를 공유한다 |
| 칼 회전 각도 | **각자** | 같은 규칙이면 알아서 같아진다 |
| 화면 흔들림 | **각자** | 내 화면 연출이다 |
| 죽음 이펙트 | **각자** | 위치만 맞으면 된다 |
| 버튼 하이라이트 | **각자** | 완전히 내 화면 일이다 |

> 🔑 💬 "**서버 것이 압도적으로 많죠.** 그래서 '기본은 서버, 예외가 각자' 로 외우면 됩니다."

### ⑤ 우리 코드가 이미 준비된 이유 (4분)

```
073회차 · 스폰은 매니저 한 곳에서만
   → 117회차에 if (!IsServer) return;  한 줄이면 끝난다

067회차 · 입력 읽는 곳과 움직이는 곳을 분리
   → 114회차에 if (!IsOwner) return;   한 줄이면 끝난다
```

> 💬 "만약 몬스터를 **여기저기서** 만들었다면 오늘 표의 절반을 다 뜯어고쳐야 합니다."

## 01:00–01:35 · 개인 미션

### 필수 미션 — 종이 과제

```
① 서버 / 클라이언트 / 호스트를 각각 한 문장으로 설명하세요.

② 우리 게임의 항목 10개 이상을 "서버 것 / 각자 것" 으로 나누고 이유를 쓰세요.
   (수업에서 한 것 말고 여러분이 찾은 것도 넣으세요)

③ 아래가 왜 문제인지 쓰세요.
   "플레이어 체력을 각자 계산했다."
   "몬스터 위치를 각자 계산했다."

④ 호스트가 유리한 점 하나, 불리한 점 하나를 쓰세요.
```

<details>
<summary>막히면 열기 (참고 답)</summary>

**①**

| 단어 | 한 문장 |
|---|---|
| 서버 | 진짜 값을 갖고 판정하는 쪽 |
| 클라이언트 | 입력을 보내고 받은 걸 보여주는 쪽 |
| 호스트 | 서버와 클라이언트를 겸하는 사람 |

**③**

| 상황 | 문제 |
|---|---|
| 체력을 각자 계산 | 내 화면에선 살아 있는데 친구 화면에선 죽어 있다. **누가 맞는지 알 수 없다** |
| 몬스터 위치를 각자 계산 | 랜덤·물리 때문에 금방 어긋난다. 내가 때린 몬스터가 친구 화면에선 딴 데 있다 |

**④**

| | |
|---|---|
| 유리 | **핑이 0이다.** 내 입력이 바로 반영된다 |
| 불리 | 서버 일까지 하니 **컴퓨터가 더 힘들다.** 그리고 나가면 게임이 끝난다 |

</details>

**확인 조건**: 표에 **이유**가 다 적혀 있고, "기본은 서버" 라는 감각이 잡혔다.
