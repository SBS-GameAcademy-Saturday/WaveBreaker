## 00:10–00:45 · 같이 치기 ★

### ① 닿은 순간을 받는다 (9분)

`044_Trigger_Start` 를 연다. `Player`(042 완성)와 **노란 동전 3개**(`Is Trigger` 켜짐)가 있다.

`Player`에 새 스크립트 **`Collector`** 를 붙인다.

```csharp
using UnityEngine;

public class Collector : MonoBehaviour
{
    private void OnTriggerEnter2D(Collider2D other)
    {
        Debug.Log("뭔가에 닿았다!");
    }
}
```

▶ Play → 동전 위를 지나가면 **Console에 찍힌다.**

> 💬 "이 메서드, **제가 어디서도 부르지 않았습니다.**"
> 💬 "036회차의 `Start`, `Update`랑 똑같아요. **유니티가 알아서 불러줍니다.**"
> 💬 "다른 점은 **'매 프레임'이 아니라 '닿는 순간'** 에 부른다는 거예요."

> ⚠️ **메서드 이름 오타가 오늘 1등 사고다.** 대소문자 하나만 틀려도 유니티가 못 찾고,
> **컴파일 에러도 안 난다.** 그냥 조용히 아무 일도 안 일어난다.
> 💬 "`OnTriggerEnter2D` — **On, T, E, 2D 전부 대문자**입니다. 그리고 **`2D`를 빠뜨리면 안 됩니다.**"
>
> 💡 **비주얼 스튜디오에서 `OnTri` 까지 치면 자동완성이 뜬다.** 손으로 치지 말고
> **자동완성으로 넣는 습관**을 오늘 들인다. 이게 오타 사고를 절반으로 줄인다.

### ② 무엇에 닿았는지 알아낸다 (7분)

```csharp
private void OnTriggerEnter2D(Collider2D other)
{
    Debug.Log(other.name + " 에 닿았다");
}
```

▶ Play → **`Coin`**, **`Coin (1)`** 처럼 **상대의 이름**이 찍힌다.

| 조각 | 뜻 |
|---|---|
| `Collider2D other` | **닿은 상대**가 여기 들어온다 |
| `other.name` | 상대 오브젝트의 이름 |
| `other.gameObject` | 상대 **오브젝트 전체** |

> 💬 "괄호 안의 `other`는 **유니티가 넣어주는 값**입니다. '이거랑 닿았어' 하고 건네주는 거예요."
> 💬 "5주차에 배운 **매개변수** 기억나죠? 그거예요. 다만 **부르는 사람이 유니티**입니다."

### ③ `Tag` — 몬스터만 골라내기 (12분) — 오늘의 핵심

씬에 **벽**도 하나 놓고 `Is Trigger`를 켜 본다. ▶ Play → **벽에 닿아도 찍힌다.**

> 💬 "동전만 먹고 싶은데 **벽에도 반응하죠.** 어떻게 구분할까요?"
> 💬 "이름으로 구분하면 될 것 같지만, 몬스터 이름은 `Enemy`, `Enemy (1)`, `Enemy (37)`... **끝이 없습니다.**"

**Tag를 만든다.**

1. `Coin` 선택 → Inspector **맨 위 `Tag` 드롭다운** → **`Add Tag...`**
2. `+` → **`Coin`** 입력 → `Save`
3. **다시 `Coin` 오브젝트를 선택** → Tag 드롭다운에서 **`Coin` 선택**

> 🚨 **3번을 빼먹는 게 오늘 2등 사고다.** `Add Tag`는 **목록에 이름을 등록만** 할 뿐,
> 그 오브젝트에 붙지 않는다. 화면 공유로 **"만들었다 ≠ 붙였다"** 를 두 번 보여준다.

```csharp
private void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Coin"))
    {
        Debug.Log("동전을 먹었다!");
        other.gameObject.SetActive(false);
    }
}
```

▶ Play → **동전만 사라지고**, 벽은 아무 반응이 없다.

> 💬 "`SetActive(false)` — **040회차에 스페이스로 껐다 켰던** 그겁니다. 새로 배우는 거 아니에요."
> 💬 "진짜로 없애는 `Destroy`는 046회차에 합니다. 오늘은 끄는 걸로 충분해요."

**`CompareTag` vs `tag ==` 를 짚는다.**

```csharp
if (other.tag == "Coin")        // 이것도 되지만
if (other.CompareTag("Coin"))   // 이걸 쓴다
```

> 💬 "둘 다 됩니다. 그런데 **`CompareTag`를 쓰세요.** 더 빠르고, **없는 Tag를 쓰면 에러로 알려줍니다.**"
> 💬 "`==` 로 쓰면 Tag 이름을 오타 내도 **조용히 아무 일도 안 일어나요.** 못 찾습니다."

### ④ `Collision`과 `Trigger` — 뭐가 다른가 (7분)

벽의 `Is Trigger`를 **끈다.** 그리고 메서드를 하나 더 추가한다.

```csharp
private void OnCollisionEnter2D(Collision2D collision)
{
    Debug.Log("부딪혔다: " + collision.gameObject.name);
}
```

▶ Play → **벽에 부딪히면** 이쪽이 찍히고, **동전을 통과하면** 아까 것이 찍힌다.

| | 언제 불리나 | 매개변수 타입 | 상대 오브젝트 |
|---|---|---|---|
| `OnTriggerEnter2D` | `Is Trigger` **켜짐** — 통과 | **`Collider2D`** | `other.gameObject` |
| `OnCollisionEnter2D` | `Is Trigger` **꺼짐** — 막힘 | **`Collision2D`** | `collision.gameObject` |

> 🚨 **매개변수 타입이 다르다.** `Collider2D`와 `Collision2D` — **글자 한 개 차이**다.
> 💬 "이거 진짜 헷갈립니다. **Trigger는 `Collider2D`, Collision은 `Collision2D`.**"
> 💬 "그래서 **자동완성으로 넣으세요.** 손으로 치면 반드시 틀립니다."

> 💡 `Enter` 말고 **`Stay`(닿아 있는 동안) / `Exit`(떨어질 때)** 도 있다는 걸 이름만 알려준다.
> 💬 "`Enter`는 닿는 **순간 한 번**, `Stay`는 닿아 **있는 동안 계속**, `Exit`는 **떨어질 때**.
> 040의 `GetKeyDown` / `GetKey`랑 같은 구조예요." — 코드는 ⭐도전으로 미룬다.
