## 00:00–00:15 · 복습 퀴즈 + 039 다시 보기

### 복습 퀴즈 (5분)

1. 초당 일정한 속도로 움직이려면 뭘 곱하나? → **`Time.deltaTime`** (039)
2. 057에서 게임오버 때 뭘 `0` 으로 만들었나? → **`Time.timeScale`**
3. 재시작 전에 꼭 되돌려야 하는 것은? → **`Time.timeScale = 1f`** (057·080)

### 039를 연다 (10분) — 오늘의 뿌리

`039_deltaTime` 실습 씬을 열고 코드를 띄운다.

```csharp
transform.position += Vector3.right * moveSpeed * Time.deltaTime;
```

> 💬 "`Time.deltaTime` 이 뭐였죠?"
> 💬 "**지난 프레임부터 지금까지 흐른 시간**입니다. 보통 0.016초쯤 되죠."

**여기서 질문을 던진다.**

> 💬 "그럼 `Time.deltaTime` 이 **0** 이 되면 어떻게 될까요?"

학생 답을 기다린다.

> 💬 "**아무것도 안 움직입니다.** 0을 곱하니까요."
> 💬 "그게 `Time.timeScale = 0` 입니다. **`Time.deltaTime` 을 0으로 만드는 스위치**예요."

**칠판**

```
Time.timeScale = 1    →   Time.deltaTime ≈ 0.016   →   정상 속도
Time.timeScale = 0.5  →   Time.deltaTime ≈ 0.008   →   절반 속도 (슬로우 모션)
Time.timeScale = 0    →   Time.deltaTime  = 0      →   아무것도 안 움직인다
```

> 🔑 💬 "**게임이 꺼지는 게 아닙니다.** `Update` 는 계속 돌아요."
> 💬 "그런데 `Time.deltaTime` 이 0이라 **곱한 값이 전부 0**이 됩니다."

### ① 멈춘다 (8분)

`Scripts/UI/LevelUpView.cs` 를 만들어 `HUD` 에 붙인다.

```csharp
using UnityEngine;

public class LevelUpView : MonoBehaviour
{
    [SerializeField] private GameObject panel;

    public bool IsOpen => panel != null && panel.activeSelf;

    private void Start()
    {
        if (panel != null) panel.SetActive(false);
    }

    public void Open()
    {
        // 시간이 멈춘다. Update 는 계속 돌지만 Time.deltaTime 이 0 이라 아무것도 안 움직인다.
        Time.timeScale = 0f;

        if (panel != null) panel.SetActive(true);
    }
}
```

`PlayerLevel` 에서 부른다.

```csharp
[SerializeField] private LevelUpView levelUpView;
```

### ② 뭐가 멈추고 뭐가 안 멈추나 (14분) — 오늘의 핵심

**멈춘 상태에서 하나씩 확인한다.**

| | 멈추나? | 왜 |
|---|---|---|
| 몬스터 이동 | **멈춘다** | `rb.linearVelocity` 는 물리. `FixedUpdate` 가 안 돈다 |
| 칼 회전 | **멈춘다** | `Time.deltaTime` 을 곱했다 (076) |
| 젬 자석 | **멈춘다** | `Time.deltaTime` 을 곱했다 (082) |
| 총 발사 | **멈춘다** | `WaitForSeconds` 는 timeScale 을 따른다 |
| 웨이브 진행 | **멈춘다** | 같은 이유 |
| **`Update` 자체** | **안 멈춘다** | 계속 돈다. 값이 0일 뿐 |
| **HUD 갱신** | **안 멈춘다** | `Update` 에서 글자만 바꾼다 |
| **키 입력** | **안 멈춘다** | `Input` 은 시간과 무관 |
| **UI 버튼 클릭** | **안 멈춘다** | 085에서 이게 중요해진다 |
| `Time.time` | **안 는다** | 게임 시간이라 멈춘다 |
| `Time.unscaledTime` | **는다** | 실제 시간. timeScale 을 무시한다 |

> 🔑 💬 "**`Update` 는 돕니다.** 그래서 HUD 도 갱신되고 키도 먹혀요."
> 💬 "**움직이는 것만** 멈춥니다. `Time.deltaTime` 을 곱한 것들이요."

**직접 확인시킨다.**

```csharp
private void Update()
{
    if (!IsOpen) return;

    Debug.Log($"Update 는 돈다. deltaTime={Time.deltaTime}  time={Time.time:F2}  unscaled={Time.unscaledTime:F2}");
}
```

▶ 멈춘 상태에서 Console 을 본다 —

```
Update 는 돈다. deltaTime=0  time=42.13  unscaled=45.80
```

> 💬 "`deltaTime` 이 **0**이죠. `time` 은 **안 늘고**, `unscaled` 는 **늘어납니다.**"
> 💬 "이 세 줄이 오늘 배운 전부입니다."

> ⚠️ **확인 뒤에는 이 `Debug.Log` 를 지운다.** 매 프레임 찍혀서 Console 이 넘친다.

### ③ 다시 흐르게 한다 (10분)

```csharp
public void Close()
{
    if (panel != null) panel.SetActive(false);

    Time.timeScale = 1f;   // 이걸 빼면 게임이 영영 멈춰 있다
}

private void Update()
{
    if (!IsOpen) return;

    // 오늘은 아무 키나. 085에서 카드 버튼으로 바뀐다.
    if (Input.anyKeyDown)
    {
        Close();
    }
}
```

▶ Play → 레벨업 → 멈춤 → 아무 키 → **다시 흐른다.**

> 🚨 **`Time.timeScale = 1f` 를 빼면 게임이 영영 멈춘다.**
> 057·080에서 **두 번** 겪은 사고다. 세 번째다.
> 일부러 빼고 실행해서 "이제 아무것도 못 한다" 를 보여준다.

> 🚨 **왜 `Input` 은 먹히나** — 반드시 나온다.
> "`Input` 은 **키보드를 직접 읽습니다.** 시간이랑 아무 상관이 없어요."
> "그래서 멈춘 상태에서도 키를 누를 수 있습니다. **085에서 이게 꼭 필요합니다.**"

### ④ 게임오버와 겹치면? (8분)

> 💬 "게임오버도 `timeScale = 0` 이었죠(080). **둘이 겹치면** 어떻게 될까요?"

| 상황 | 지금 동작 |
|---|---|
| 레벨업 창이 떠 있는데 죽는다 | 몬스터가 안 움직이니 **죽을 수 없다** |

> 💬 "**멈춘 동안엔 아무 일도 안 일어나니까** 겹칠 수가 없습니다. 운이 좋았어요."
> 💬 "그런데 이런 건 **직접 확인해봐야** 압니다. 상태가 두 개 이상이면 늘 겹침을 의심하세요."
