### ② 점수를 만든다 (10분)

`DodgeGameManager` 라는 빈 GameObject를 만들고 스크립트를 붙인다.

```csharp
using UnityEngine;
using TMPro;

public class DodgeGameManager : MonoBehaviour
{
    [SerializeField] private TextMeshProUGUI scoreText;

    private float score;

    void Update()
    {
        score = score + Time.deltaTime;

        scoreText.text = "점수 " + Mathf.FloorToInt(score);
    }
}
```

`ScoreText`를 Inspector의 `Score Text` 칸에 드래그한다.

▶ Play → **점수가 올라간다.**

**한 줄씩 짚는다.**

| 조각 | 뜻 | 어디서 배웠나 |
|---|---|---|
| `using TMPro;` | TextMeshPro를 쓰려면 필요 | 051의 `using System.Collections` 과 같은 자리 |
| `TextMeshProUGUI scoreText` | 화면의 글자를 담는 칸 | 042의 `Rigidbody2D rb` 와 같은 방식 |
| `score += Time.deltaTime` | **1초에 1씩 늘어난다** | **039** |
| `Mathf.FloorToInt` | 소수점을 버린다 | 오늘 |
| `scoreText.text = ...` | 글자를 바꾼다 | 049의 `sr.color = ...` 와 같다 |

> 💬 "**039에서 `Time.deltaTime`을 다 더하면 1초가 된다**고 했죠. 그게 여기서 점수가 됩니다."
> 💬 "`.text` 에 넣으면 화면 글자가 바뀝니다. 049에서 `.color` 에 넣어서 색을 바꾼 거랑 똑같아요."

> ⚠️ **`Text`(구 UI)와 `TextMeshProUGUI`는 다른 타입**이다. 검색하면 옛날 `Text` 자료가 나온다.
> 💬 "우리는 **TMP**를 씁니다. `using TMPro;` 가 있어야 해요."

### ③ 소수점이 지저분하다 (6분)

`Mathf.FloorToInt` 를 빼면 `점수 3.847261` 처럼 나온다. 일부러 한 번 보여준다.

| 방법 | 결과 |
|---|---|
| `score` 그대로 | `3.847261` |
| `Mathf.FloorToInt(score)` | **`3`** |
| `score.ToString("F1")` | `3.8` |

> 💬 "**보기 좋게 만드는 것도 완성의 일부**입니다. Phase 4가 그런 걸 챙기는 구간이에요."

### ④ 매 프레임 글자를 바꿔도 되나 (5분)

> 💬 "`Update`에서 매 프레임 글자를 바꾸고 있습니다. **괜찮을까요?**"

> 💬 "지금은 괜찮습니다. 글자 하나니까요."
> 💬 "그런데 **글자가 바뀔 때만 갱신**하는 게 원칙이에요. 실제로 게임이 커지면 이게 렉이 됩니다."

```csharp
private int shownScore = -1;

void Update()
{
    score += Time.deltaTime;

    int now = Mathf.FloorToInt(score);

    if (now != shownScore)
    {
        shownScore = now;
        scoreText.text = "점수 " + now;
    }
}
```

> 💬 "숫자가 **바뀔 때만** 글자를 건드립니다. 1초에 60번이 1번이 됐어요."
> 💬 "이런 걸 **최적화**라고 합니다. Phase 8에서 제대로 합니다. 오늘은 습관만 들여요."
>
> 💡 어려워하는 학생은 **④번 없이 제출해도 통과**시킨다. 필수는 점수가 보이는 것까지다.
