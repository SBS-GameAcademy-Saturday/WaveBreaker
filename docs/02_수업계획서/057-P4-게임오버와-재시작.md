## 00:10–00:40 · 같이 치기 ★

### ① 죽었는지 어떻게 아나 (8분) — 오늘의 핵심

> 💬 "플레이어가 죽으면 `Health`가 `Destroy(gameObject)` 를 합니다. 그럼 **어떻게 알까요?**"
>
> 학생 답을 기다린다. "없어진 걸 확인한다"가 나오면 최고.

```csharp
[SerializeField] private GameObject player;

private bool isGameOver;

void Update()
{
    if (isGameOver) return;

    if (player == null)
    {
        GameOver();
        return;
    }

    // 점수 계산 (056 그대로)
}
```

> 💬 "**049에서 배운 `null` 확인**입니다. 없어졌으면 `null` 이 되죠."
> 💬 "새로 배우는 게 아니에요. **없는 걸 만지지 마라**가 여기서는 **없어졌으면 게임오버**가 됩니다."

> ⚠️ **`isGameOver` 가 왜 필요한지** 짚는다.
> 💬 "이게 없으면 `GameOver()`가 **매 프레임 불립니다.** 한 번만 하려고 표시를 남기는 거예요."
> 💬 "036의 `Start`와 `Update` — **한 번이냐 계속이냐**. 그 이야기가 또 나옵니다."

### ② 멈춘다 (7분)

```csharp
private void GameOver()
{
    isGameOver = true;

    gameOverText.SetActive(true);

    Time.timeScale = 0f;
}
```

`Canvas` 아래에 TMP 글자를 하나 더 만든다. 이름 **`GameOverText`**, 내용 `게임 오버  —  R 키로 다시`.
**체크를 꺼둔다** (Inspector 맨 위 체크박스).

▶ Play → 장애물에 세 번 맞으면 **화면이 멈추고 글자가 뜬다.**

| 조각 | 뜻 | 어디서 |
|---|---|---|
| `SetActive(true)` | 꺼둔 오브젝트를 켠다 | **040** |
| `Time.timeScale = 0f` | **시간을 0배로** — 전부 멈춘다 | 오늘 |

> 💬 "`Time.timeScale`은 **게임 시간의 배속**입니다. `1`이 보통, `0.5`면 슬로우모션, `0`이면 정지."
> 💬 "물리도 코루틴도 다 멈춥니다. **`WaitForSeconds`도 안 갑니다** — 051에서 말한 그거예요."

> 🚨 **`Time.timeScale`은 씬을 바꿔도 안 돌아온다.** 이게 오늘 최다 사고다.
> 💬 "**`0`으로 두고 재시작하면 새 씬도 멈춰 있습니다.** 되돌리는 걸 반드시 같이 씁니다."

### ③ 다시 시작 (10분)

```csharp
using UnityEngine.SceneManagement;

void Update()
{
    if (isGameOver)
    {
        if (Input.GetKeyDown(KeyCode.R))
        {
            Time.timeScale = 1f;                                  // ← 먼저 되돌린다

            SceneManager.LoadScene(SceneManager.GetActiveScene().name);
        }
        return;
    }

    // ...
}
```

| 조각 | 뜻 |
|---|---|
| `using UnityEngine.SceneManagement;` | 씬을 다루려면 필요 |
| `GetActiveScene().name` | **지금 씬의 이름** |
| `LoadScene(이름)` | 그 씬을 **처음부터 다시** 연다 |

> 💬 "**씬을 다시 여는 게 곧 재시작**입니다. 모든 게 처음 상태로 돌아가요."
> 💬 "`Time.timeScale = 1f` 를 **먼저** 씁니다. 안 그러면 새 씬도 멈춰 있어요."

> 🚨 **여기서 반 전체가 동시에 막힌다.**
> ```
> Scene 'xxx' couldn't be loaded because it has not been added to the Build Settings
> ```
> **`File → Build Profiles`(또는 `Build Settings`) → 열려 있는 씬을 `Add Open Scenes`.**
>
> 💬 "**빌드에 포함된 씬만 코드로 열 수 있습니다.** 목록에 없으면 못 엽니다."
> 💬 "이 에러 메시지는 **친절한 편**이에요. 읽으면 답이 그대로 나와 있습니다."
>
> ⚠️ 강사가 **일부러 재현**해서 에러 메시지를 다 같이 읽는다. Phase 0의 "에러 읽는 습관"으로 연결한다.

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;
using TMPro;

public class DodgeGameManager : MonoBehaviour
{
    [SerializeField] private TextMeshProUGUI scoreText;
    [SerializeField] private GameObject gameOverText;
    [SerializeField] private GameObject player;

    private float score;
    private int shownScore = -1;
    private bool isGameOver;

    void Update()
    {
        if (isGameOver)
        {
            if (Input.GetKeyDown(KeyCode.R))
            {
                Time.timeScale = 1f;
                SceneManager.LoadScene(SceneManager.GetActiveScene().name);
            }
            return;
        }

        if (player == null)
        {
            GameOver();
            return;
        }

        score += Time.deltaTime;

        int now = Mathf.FloorToInt(score);

        if (now != shownScore)
        {
            shownScore = now;
            scoreText.text = "점수 " + now;
        }
    }

    private void GameOver()
    {
        isGameOver = true;

        gameOverText.SetActive(true);

        Time.timeScale = 0f;
    }
}
```

**점수도 0부터** 시작한다. 재시작한 게임도 정상 속도로 돈다.
