## 00:10–00:50 · 같이 하기 ★

### ① `BossEnemy` — 네 번째 자식 (12분)

`Scripts/Enemy/BossEnemy.cs`

```csharp
using UnityEngine;

public class BossEnemy : Enemy
{
    [SerializeField] private int contactDamage = 8;
    [SerializeField] private bool isFinal;

    protected override void Start()
    {
        base.Start();

        string title = data != null ? data.title : name;
        Debug.Log($"보스 등장 — {title} (체력 {maxHealth})");
    }

    public override void Attack(IDamageable target)
    {
        target.TakeDamage(contactDamage);
    }

    private void OnCollisionStay2D(Collision2D collision)
    {
        if (collision.gameObject.TryGetComponent(out IDamageable target))
        {
            Attack(target);
        }
    }

    protected override void Die()
    {
        string title = data != null ? data.title : name;
        Debug.Log($"보스 처치! — {title}");

        base.Die();   // 처치 수 · 젬 드롭 · 제거는 부모가 한다

        if (isFinal && GameManager.Instance != null)
        {
            GameManager.Instance.ChangeState(GameState.Clear);
        }
    }
}
```

> 💬 "**30줄입니다.** 이게 보스의 전부예요."
> 💬 "체력·이동·피격·사망·젬 드롭 — 전부 `Enemy` 가 이미 갖고 있습니다."

| 조각 | 어디서 왔나 |
|---|---|
| `: Enemy` | 070 상속 |
| `override Attack` | 072 (돌진형과 같은 방식) |
| `OnCollisionStay2D` | 080 (초당 피해) |
| `base.Die()` | 072 (탱커의 `base.TakeDamage` 와 같다) |
| `isFinal` | 오늘 — 마지막 보스만 클리어를 띄운다 |

> 🚨 **`base.Die()` 를 빼먹으면 보스가 안 죽는다.** 처치 수도 안 오르고 젬도 안 나온다.
> 072의 `base.TakeDamage` 와 **같은 사고**다. 세 번째다.

### ③ 시각에 맞춰 소환한다 (12분)

`WaveManager` 에 시계를 붙인다.

```csharp
[Header("보스 (090회차)")]
[SerializeField] private GameObject[] bossPrefabs;
[SerializeField] private float[] bossTimes = { 180f, 360f, 600f };

public float Elapsed { get; private set; }

private int nextBoss;

private void Update()
{
    if (GameManager.Instance != null && GameManager.Instance.State != GameState.Playing) return;

    Elapsed += Time.deltaTime;

    if (nextBoss >= bossTimes.Length) return;
    if (Elapsed < bossTimes[nextBoss]) return;

    SpawnBoss(nextBoss);
    nextBoss++;
}

public void SpawnBoss(int index)
{
    if (bossPrefabs == null || index >= bossPrefabs.Length) return;
    if (bossPrefabs[index] == null || spawnPoints.Length == 0) return;

    Transform point = spawnPoints[Random.Range(0, spawnPoints.Length)];

    Instantiate(bossPrefabs[index], point.position, Quaternion.identity);
}
```

| 조각 | 뜻 |
|---|---|
| `Elapsed += Time.deltaTime` | 흐른 시간을 센다 (039) |
| `State != Playing` → `return` | 멈춰 있을 땐 시계도 멈춘다 |
| `nextBoss` | **다음에 나올 보스 번호.** 한 번씩만 나온다 |
| `SpawnBoss` 가 `public` | 테스트할 때 직접 부를 수 있다 |

> 🚨 **`nextBoss++` 를 빼면 매 프레임 보스가 쏟아진다.**
> 일부러 빼고 실행해 보여준다. 순식간에 화면이 보스로 찬다.

> 💡 **테스트할 땐 `bossTimes` 를 `{5, 10, 15}` 로 줄인다.**
> 3분씩 기다리며 개발할 수는 없다. **제출 전에 되돌리는 걸 잊지 않는다.**

### ⑤ 🐛 오늘 잡은 진짜 버그 (5분) — 실측 공유

보스를 잡아보니 로그가 이렇게 나왔다.

```
보스 처치! — 보스 III     ← 5번
게임 상태: Clear          ← 4번
kills = 5                 ← 1마리 잡았는데
```

> 💬 "왜 다섯 번일까요?"

**원인**: `Destroy(gameObject)` 는 **프레임 끝**에 처리된다.
같은 프레임에 칼 네 자루와 총알이 동시에 맞으면 `TakeDamage` 가 여러 번 불리고,
체력이 이미 0 이하인데 **`Die()` 가 또 불린다.**

**고친 것** — `Enemy.TakeDamage` 첫 줄에 한 줄.

```csharp
public virtual void TakeDamage(int amount)
{
    // 한 프레임에 칼 여러 자루와 총알이 동시에 맞으면 Die() 가 여러 번 불린다.
    // Destroy 는 프레임 끝에 처리되기 때문이다. 080에서 플레이어에 넣은 검사와 같다.
    if (currentHealth <= 0) return;

    currentHealth -= amount;
    ...
}
```

**재측정**: `보스 처치!` 1번, `게임 상태: Clear` 1번, `kills = 1`.

> 🔑 💬 "**080에서 플레이어에 넣었던 그 검사**입니다. 몬스터엔 안 넣었었어요."
> 💬 "칼이 하나였을 땐 안 드러났습니다. **칼이 네 개가 되니 드러난 거죠.**"
> 💬 "이런 버그는 **게임이 커져야 보입니다.** 그래서 자주 돌려봐야 해요."
