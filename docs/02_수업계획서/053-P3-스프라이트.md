## 🎯 오늘의 목표

1. 이미지를 넣고 **`Sprite Renderer`에 끼운다**
2. **`Pixels Per Unit`** 이 크기를 정한다는 걸 안다
3. **`Filter Mode`** 를 바꿔 흐릿한 걸 또렷하게 만든다

> ⚠️ **오늘 안 하는 것**: 애니메이션. **054회차**다.
> 오늘은 **한 장짜리 그림**을 붙이고 설정을 맞추는 데까지.
> 슬라이스(자르기)는 054를 위한 준비로 **마지막 10분에만** 한다.
>
> 🔑 **설계 의도**: 학생은 11주 동안 흰 네모만 봤다. 오늘 그림이 붙으면 **몰입이 확 올라간다.**
> 그런데 임포트 설정을 모르면 **흐릿하고 크기가 이상한 그림**이 나오고 오히려 실망한다.
> 그래서 **설정 세 개(PPU · Filter Mode · Compression)** 만 확실히 잡는다.

## 00:10–00:45 · 같이 하기 ★

### ① 그림을 넣는다 (7분)

`053_Sprite_Start` 를 연다. 052 완성 상태(흰 네모들)다.

배포받은 스프라이트를 **`Assets/_GameAssets/Sprites/` 아래로 드래그**한다.

> 💬 "유니티는 이미지를 넣으면 **자동으로 스프라이트로 인식**합니다. 이 프로젝트가 2D라서요."

Inspector에서 확인한다.

| 항목 | 값 | 뜻 |
|---|---|---|
| **Texture Type** | `Sprite (2D and UI)` | 2D 그림으로 쓰겠다 |
| Sprite Mode | `Single` | 한 장에 그림 하나 |

`Player`를 선택 → `Sprite Renderer`의 **`Sprite`** 칸에 그림을 드래그한다.

**흰 네모가 그림으로 바뀐다.**

> 🎉 11주 만이다. 반응이 온다. 잠깐 둔다.

> ⚠️ **`Sprite` 칸에는 이미지 파일이 아니라 그 안의 스프라이트를 넣는다.** 파일 왼쪽
> **`>` 화살표를 펼치면** 안에 든 스프라이트가 보인다. Single일 땐 하나뿐이라 헷갈리지 않지만,
> 오늘 마지막에 Multiple을 하면 달라진다. 미리 한 번 펼쳐서 보여준다.

### ② 크기가 이상하다 — Pixels Per Unit (11분) — 오늘의 핵심

그림이 **너무 크거나 작게** 나온다. Scale을 만지고 싶어진다. **참는다.**

> 💬 "Scale로 맞추면 안 됩니다. **원인이 다른 데 있어요.**"

Inspector의 **`Pixels Per Unit`** 을 본다. 기본값은 **`100`** 이다.

> 💬 "**'몇 픽셀을 1유닛으로 볼 거냐'** 는 뜻입니다."
> 💬 "32×32 그림인데 PPU가 100이면? **32 나누기 100 = 0.32유닛**. 아주 작게 나옵니다."

**같이 계산한다.**

| 그림 크기 | PPU | 화면에서 |
|---|---|---|
| 32×32 | **100** | 0.32 × 0.32 유닛 — **너무 작다** |
| 32×32 | **32** | **1 × 1 유닛** — 딱 맞다 |
| 32×32 | 16 | 2 × 2 유닛 — 두 배 |

**`Pixels Per Unit`을 `32`로 바꾸고 `Apply`.** → 흰 네모와 **같은 크기**가 된다.

> 💬 "032회차에 **1유닛이 뭔지** 배웠죠. 흰 Square가 1×1이었습니다. 이제 그림도 1×1이에요."
> 💬 "**PPU를 프로젝트 전체에서 하나로 통일**하세요. 섞이면 캐릭터마다 크기가 제각각이 됩니다."

> 🚨 **`Apply`를 안 누르면 반영되지 않는다.** Inspector 아래쪽 `Apply` 버튼.
> 💬 "임포트 설정은 **`Apply`를 눌러야** 적용됩니다. 이거 오늘 세 번 말할게요."

### ③ 흐릿하다 — Filter Mode (10분)

확대해 보면 **그림이 뿌옇다.**

**`Filter Mode`** 를 본다. 기본값은 `Bilinear`.

| Filter Mode | 어떻게 보이나 | 언제 |
|---|---|---|
| `Bilinear` | **부드럽게 뭉갠다** | 큰 일러스트 |
| **`Point (no filter)`** | **픽셀이 또렷하다** | **픽셀 아트** |

**`Point (no filter)`로 바꾸고 `Apply`.** → 또렷해진다.

> 💬 "유니티가 **친절하게 부드럽게** 만들어 준 겁니다. 픽셀 아트에는 그게 독이에요."
> 💬 "인터넷에서 '유니티 픽셀아트 흐릿' 로 검색하면 나오는 답이 **이거 하나**입니다."

**`Compression`** 도 같이 잡는다.

| Compression | |
|---|---|
| `Normal Quality` | 용량을 줄이려고 **화질을 깎는다** |
| **`None`** | **원본 그대로** — 작은 2D 아트는 이쪽 |

> 💬 "그림이 몇 KB밖에 안 되는데 압축할 이유가 없습니다. **`None`으로 두세요.**"

> ⚠️ 여기까지가 오늘 **반드시 가져가야 할 세 줄**이다. 칠판에 남긴다.
> ```
> Pixels Per Unit  = 32   (프로젝트에서 통일)
> Filter Mode      = Point (no filter)
> Compression      = None
> ```

### ④ Collider가 안 맞는다 (5분)

그림을 바꿨더니 **Collider(초록 선)가 그림과 어긋난다.**

> 💬 "043에서 뭐라고 했죠? **초록 선이 실제 판정 경계**입니다. 그림이 바뀌어도 **선은 안 바뀌어요.**"

`Box Collider 2D` 우측 `⋮` → **`Reset`** → 그림에 맞게 다시 잡힌다.

> 💡 안 맞으면 043의 **`Edit Collider`** 로 직접 조절한다. 그림보다 **조금 작게**가 게임 느낌이 좋다.

### ⑤ 한 장에 여러 그림 — Multiple (7분) — 054 준비

걷기 그림은 **한 파일에 여러 장**이 붙어 있다.

1. `Sprite Mode` → **`Multiple`**
2. **`Sprite Editor`** 버튼 → 창이 열린다
3. 좌측 상단 **`Slice`** → Type **`Grid By Cell Size`** → `32 × 32` → `Slice`
4. 우측 상단 **`Apply`**

Project 창에서 그 파일의 **`>` 화살표를 펼치면** 잘린 그림들이 보인다.

> 💬 "**한 파일 안에 여러 스프라이트**가 생겼습니다. 다음 시간에 이걸로 걷는 애니메이션을 만듭니다."
> 💬 "오늘은 **잘라두는 것까지**만 하세요."

> ⚠️ `Sprite Editor`가 안 보이면 **2D Sprite 패키지**가 필요하다. 이 프로젝트에는 이미 들어 있다.

## 00:55–01:35 · 개인 미션

### 필수 미션 — 게임에 그림 입히기

1. 스프라이트를 `Assets/_GameAssets/Sprites/` 아래에 넣는다
2. **`Pixels Per Unit = 32`**, **`Filter Mode = Point (no filter)`**, **`Compression = None`** → `Apply`
3. **`Player` 프리팹**과 **`Enemy` 프리팹**의 `Sprite` 칸을 그림으로 바꾼다
   (⚠️ **프리팹 모드에서** — 046 그대로)
4. Collider를 `Reset` 하거나 `Edit Collider`로 다시 맞춘다
5. 걷기 시트를 `Multiple`로 바꾸고 **`32 × 32`로 슬라이스**한다
6. ▶ Play → 그림이 붙은 채로 **총알·체력·자동 스폰이 그대로 동작**한다

**확인 조건**: 화면에 흰 네모가 하나도 없다. 그림이 또렷하고 크기가 서로 맞는다.
쏘면 여전히 죽고, 몬스터는 여전히 2초마다 나온다.

> 💡 **총알은 흰 네모로 둬도 된다.** 작아서 티가 안 나고, 오늘 목표는 캐릭터다.
> 다 한 학생만 총알까지 바꾼다.

### ⭐ 도전 미션

- [ ] `Filter Mode`를 `Bilinear`로 되돌리고 확대해서 **차이를 스크린샷으로** 남긴다
- [ ] `Pixels Per Unit`을 `16`과 `64`로 바꿔보고 크기가 어떻게 되는지 확인한다
- [ ] `Sprite Renderer`의 **`Flip X`** 를 켜서 캐릭터를 뒤집는다 (040 ⭐도전의 Scale 음수와 비교)
- [ ] `Sprite Renderer`의 **`Color`** 로 몬스터 색을 바꿔 **다른 종류처럼** 보이게 한다
- [ ] 몬스터 프리팹의 Sorting Layer를 확인하고 플레이어가 항상 앞에 오게 한다 (045)
- [ ] 배경 그림을 깔고 `Background` Sorting Layer에 넣는다
- [ ] `Sprite Editor`에서 **`Pivot`** 을 `Bottom`으로 바꿔보고 뭐가 달라지는지 쓴다
