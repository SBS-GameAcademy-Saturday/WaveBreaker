### ② 바꾸는 창구를 연다 (18분) — 오늘의 핵심

**각 스크립트에 `public` 메서드를 하나씩 연다.**

```csharp
// MeleeRing.cs
public void AddBlade(int count)
{
    bladeCount += count;
    Build();
}

public void AddRotateSpeed(float step)
{
    rotateSpeed += step;
    Debug.Log($"칼 회전 상승 — 초당 {rotateSpeed:F0}도");
}

public void AddBladeDamage(int step)
{
    bladeDamage += step;
    Build();   // 이미 달린 칼에도 적용되게 다시 만든다
    Debug.Log($"칼 피해 상승 — {bladeDamage}");
}
```

> 🚨 **칼 피해를 올렸는데 안 세지는 사고** — 반드시 나온다.
> 이미 씬에 달려 있는 칼은 **자기 `damage` 를 갖고 있다.** 값만 바꾸면 새 칼부터 적용된다.
> 그래서 `Build()` 로 **다시 만든다.** 077에서 만든 함수가 여기서 또 쓰인다.

칼이 값을 받게 한다.

```csharp
// Blade.cs
public void Setup(int newDamage, float newInterval)
{
    damage = newDamage;
    hitInterval = newInterval;
}
```

```csharp
// MeleeRing.Build() 안, 칼을 만든 직후
if (blade.TryGetComponent(out Blade b))
{
    b.Setup(bladeDamage, hitInterval);
}
```

```csharp
// AutoGun.cs
public void AddDamage(int step)
{
    damage += step;
    Debug.Log($"총알 피해 상승 — {damage}");
}

public void AddPierce(int step)
{
    pierce += step;
    Debug.Log($"관통 상승 — {pierce}마리");
}
```

총알도 값을 받게 한다.

```csharp
// Projectile.cs
public void Setup(int newDamage, int newPierce)
{
    damage = newDamage;
    pierce = newPierce;
}
```

```csharp
// AutoGun.FireRoutine 안, 총알을 만든 직후
if (shot.TryGetComponent(out Projectile p))
{
    p.Setup(damage, pierce);
}
```

> 🔑 💬 "총알은 **만들어질 때마다** 새 값을 받습니다. 프리팹은 그대로예요."
> 💬 "079에서 배운 그대로죠 — **복사본의 값이 바뀌는 것**이지 원본이 바뀌는 게 아닙니다."

```csharp
// PlayerHealth.cs — 086회차
public void AddMaxHealth(int step)
{
    maxHealth += step;
    currentHealth = Mathf.Min(currentHealth + step, maxHealth);

    Debug.Log($"최대 체력 상승 — {currentHealth}/{maxHealth}");
}
```

> 💬 "최대 체력만 올리면 **체감이 없습니다.** 그래서 올린 만큼 회복도 시켜요."
> 💬 "이런 게 게임 디자인입니다. 숫자가 아니라 **느낌**을 만드는 것."

### ③ 8종을 연결한다 (12분)

`LevelUpView.Apply()` 의 `switch` 를 8갈래로 늘린다.

```csharp
private void Apply(UpgradeType type)
{
    switch (type)
    {
        case UpgradeType.BladeCount:  meleeRing.AddBlade(1);            break;
        case UpgradeType.BladeSpeed:  meleeRing.AddRotateSpeed(45f);    break;
        case UpgradeType.BladeDamage: meleeRing.AddBladeDamage(1);      break;
        case UpgradeType.FireRate:    autoGun.SpeedUp(0.06f, 0.12f);    break;
        case UpgradeType.GunDamage:   autoGun.AddDamage(1);             break;
        case UpgradeType.Pierce:      autoGun.AddPierce(1);             break;
        case UpgradeType.MoveSpeed:   playerController.SpeedUp(0.6f);   break;
        case UpgradeType.MaxHealth:   playerHealth.AddMaxHealth(5);     break;
    }
}
```

`Describe()` 도 8갈래로 늘린다. `PickThree()` 의 목록에도 8개를 다 넣는다.

> ⚠️ **`null` 검사를 빼먹지 않는다.** `if (meleeRing != null)` 같은 식으로 막아둔다.
> Inspector 한 칸만 비어도 `NullReferenceException` 이 뜬다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **칼 피해가 안 오름** | `Build()` 를 안 부름 | **오늘 1등.** 이미 달린 칼은 옛 값 |
| **총알 피해가 안 오름** | `Projectile.Setup` 을 안 부름 | 만들 때 넘겨야 한다 |
| `NullReferenceException` | Inspector 한 칸이 비었다 | `playerHealth` 를 자주 빠뜨린다 |
| 카드가 3장 미만 | `PickThree` 목록에 8개를 안 넣음 | 목록 확인 |
| 같은 카드가 두 장 | `RemoveAt` 누락 | 085 확인 |
| 연사가 음수 | `Mathf.Max` 누락 | 074·085과 같은 사고 |
| 최대 체력만 오르고 안 회복됨 | `currentHealth` 를 안 올림 | 체감이 없다 |
| 체력이 최대를 넘음 | `Mathf.Min` 누락 | 상한을 막는다 |
| `switch` 에 `break` 누락 | 컴파일 에러 | C# 은 fall-through 금지 |
| 카드 글자가 안 바뀜 | `Describe` 를 8갈래로 안 늘림 | 빠진 종류 확인 |
