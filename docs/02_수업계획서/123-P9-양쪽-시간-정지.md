> 💬 "다만 **전제가 달라진 겁니다.** 게임이 하나일 때만 통하는 방법이었어요."

> **'맞는 답' 이 아니라 '그 상황에서 맞는 답' 이었던 거죠.**"

### ② 멈춤도 동기화한다 (14분)

> 💬 "그럼 어떻게 할까요?" → **멈춤을 서버가 들고 있는다**

```csharp
// 123회차 · 협동에서는 Time.timeScale 로 못 멈춘다. 서버가 "멈춤" 상태를 들고 있는다.
public NetworkVariable<bool> Paused = new NetworkVariable<bool>(
    false, NetworkVariableReadPermission.Everyone, NetworkVariableWritePermission.Server);

// 멈춰 있나. 몬스터와 스폰이 이걸 본다.
public static bool IsPaused => Instance != null && Instance.Paused.Value;
```

**그리고 움직이는 것들이 이 값을 본다.**

```csharp
// NetworkEnemy.FixedUpdate
if (NetworkTeam.IsPaused) { rb.linearVelocity = Vector2.zero; return; }

// NetworkWaveManager.SpawnOne
if (NetworkTeam.IsPaused) return;   // 멈춰 있으면 안 만든다

// NetworkPlayerMove.FixedUpdate
if (NetworkTeam.IsPaused) { rb.linearVelocity = Vector2.zero; return; }
```

> 💬 "**세 군데뿐입니다.** 움직이는 게 몬스터·스폰·플레이어 셋이니까요."
> 💬 "`timeScale` 은 유니티가 전부 알아서 멈춰줬는데, 이번엔 **우리가 정해야** 합니다."

> 🚨 **이게 `timeScale` 보다 나은 점도 있다.** 무엇을 멈추고 무엇을 안 멈출지 **우리가 고를 수 있다.**
> 예를 들어 UI 애니메이션은 계속 돌게 둘 수 있다. `timeScale` 로는 그게 안 된다 (084의 그 문제).

### ③ 양쪽에 창이 뜬다 (10분)

```csharp
// 🔑 양쪽 화면에서 다 불린다(115). 그래서 둘 다 카드가 뜬다.
private void OnLevelChanged(int before, int after)
{
    // 서버가 게임을 멈춘다. 클라이언트는 부탁할 필요가 없다 —
    // 어차피 서버에서도 이 함수가 불리기 때문이다.
    if (IsServer)
    {
        chosenCount = 0;
        NetworkTeam.Instance.SetPaused(true);
    }

    Open(after);
}
```

> 💬 "115회차에서 배웠죠. **`OnValueChanged` 는 양쪽에서 불립니다.**"
> 💬 "그래서 **따로 알릴 필요가 없어요.** 팀 레벨이 오르면 양쪽이 알아서 압니다."

> 💡 `Rpc` 를 쓸 필요가 없는 자리다. 116회차의 "값이 유지되면 `NetworkVariable`" 규칙 그대로다.

### ④ 둘 다 골라야 재개 (10분)

```csharp
public void Choose(int index)
{
    if (panel != null) panel.SetActive(false);

    // 내가 골랐다고 서버에 알린다 (116 회수).
    ChoiceRpc(index);
}

[Rpc(SendTo.Server)]
private void ChoiceRpc(int index)
{
    // 여기부터 서버다.
    chosenCount++;

    int total = NetworkManager.Singleton.ConnectedClientsIds.Count;

    Debug.Log($"[호스트] 선택 {chosenCount}/{total}");

    // 🔑 둘 다 골라야 다시 움직인다. 한 명만 고르고 기다리는 게 협동이다.
    if (chosenCount < total) return;

    NetworkTeam.Instance.SetPaused(false);
}
```

> 💬 "**내 창은 바로 닫힙니다.** 그런데 게임은 아직 안 움직여요."
> 💬 "친구가 고민 중이니까요. **기다려주는 게 협동입니다.**"
