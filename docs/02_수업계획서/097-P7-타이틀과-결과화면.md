## 🎯 오늘의 목표

1. 타이틀 → 게임 → 결과가 **끊김 없이** 연결된다
2. **씬이 바뀌면 오브젝트가 사라진다**는 걸 몸으로 안다
3. `static` 으로 성적을 넘긴다

> ⚠️ **오늘 안 하는 것**: 최고 기록 저장(`PlayerPrefs`). 게임을 껐다 켜면 사라져도 된다.

>
> 🔑 **설계 의도**: 이 회차는 **원칙 4번(불편을 먼저)의 마지막 적용 지점**이다.

`GameManager` 는 끝나면 결과 씬으로 보낸다.

public void ChangeState(GameState next)

### ⑤ 고친다 — `static` 은 씬을 안 탄다 (12분)

`Scripts/Manager/RunResult.cs`

```csharp
// 097회차 · 씬을 넘겨도 안 사라지는 자리.
//
// GameManager 는 Game 씬의 오브젝트다. 씬이 바뀌면 통째로 사라지고,
// 그 안에 들어 있던 처치 수도 같이 사라진다.
//
// static 은 오브젝트가 아니라 "클래스 자체" 에 붙는다. 씬과 상관없이 살아 있다.
// 게임이 완전히 꺼지면 사라진다. 그건 우리가 원하는 동작이다.
public static class RunResult
{
    public static float Time;
    public static int Kills;
    public static int Level;
    public static bool Cleared;

    public static void Record(float time, int kills, int level, bool cleared)
    {
        Time = time;
        Kills = kills;
        Level = level;
        Cleared = cleared;
    }
}
```

| 조각 | 뜻 |
|---|---|
| `static class` | **인스턴스를 못 만든다.** 오브젝트가 아니다 |
| `static` 필드 | 클래스 자체가 들고 있다. 씬이 바뀌어도 안 사라진다 |
| `MonoBehaviour` 상속 안 함 | 씬에 붙일 수 없다. **붙일 이유도 없다** |

> 💬 "022회차에서 `static` 을 배웠죠. **'모든 인스턴스가 같이 쓰는 것'** 이라고요."
> 💬 "여기선 인스턴스가 아예 없습니다. **클래스 하나가 값 네 개를 들고 있을 뿐**이에요."

**넘길 때 적는다** — `GameManager.GoResult`

```csharp
private void GoResult()
{
    RunResult.Record(
        waveManager != null ? waveManager.Elapsed : 0f,
        Kills,
        playerLevel != null ? playerLevel.Level : 1,
        State == GameState.Clear);

    Time.timeScale = 1f;

    SceneManager.LoadScene("Result");
}
```

**받는 쪽은 `RunResult` 에서 읽는다**

```csharp
private void Start()
{
    Time.timeScale = 1f;   // 앞 씬에서 0 으로 두고 넘어왔을 수도 있다

    titleLabel.text = RunResult.Cleared ? "클리어!" : "게임 오버";

    int total = Mathf.FloorToInt(RunResult.Time);
    timeLabel.text = $"생존 시간   {total / 60:00}:{total % 60:00}";

    killLabel.text = $"처치 수   {RunResult.Kills}";
    levelLabel.text = $"최종 레벨   {RunResult.Level}";
}
```

> 🔑 💬 "**적는 곳과 읽는 곳이 다릅니다.** `Game` 씬이 적고, `Result` 씬이 읽어요."
> 💬 "가운데에 `RunResult` 가 **우편함처럼** 있는 거죠."

▶ Play → 잡고 → 죽고 → 결과 확인.

**재본 값**

```
죽기 전  — 시간 8.7초  처치 2  Lv.4
죽은 뒤  — 체력 0  state = GameOver
RunResult — 시간 8.7  처치 2  Lv.4  클리어 = False

결과 화면 — 생존 시간 00:08 / 처치 수 2 / 최종 레벨 4
```

> 💬 "**숫자가 그대로 넘어왔습니다.**"
