## 🎯 오늘의 목표

1. **Visual Studio** 설치를 끝내고 콘솔 프로젝트가 실행되는 걸 확인한다 ← **오늘 1순위**
2. Unity Hub + Unity 6 LTS 설치를 끝낸다 (7주차부터 사용)
3. 안 되는 사람을 **오늘 안에 찾아낸다**

> 📌 **순서 주의**: 1~6주차는 Visual Studio만 쓴다. **Visual Studio를 먼저 확실히 끝내고**, Unity는 다운로드만 걸어둔 뒤 7주차에 점검해도 된다.

> ⚠️ **오늘은 진도를 나가지 않는다.** 2시간을 다 써도 된다. 여기서 대충 넘어가면 이후 7개월 내내 "제 화면은 다른데요"가 나온다.

## 📦 오늘의 제출물

**Visual Studio 콘솔 앱이 실행된 화면 스크린샷** (검은 창에 아무 글자나) → `#제출`
> Unity 설치 완료 스크린샷은 다운로드가 끝나는 대로 추가 제출. 채널

## 00:10–00:50 · 같이 설치 ① — Unity Hub

**진행 방식: 강사 화면공유 → 한 단계 → "된 사람 채팅에 1"**

노베이스 반 설치는 **반드시 단계마다 확인**하며 간다. 끝까지 시켜놓고 확인하면 뒤처진 사람이 어디서 막혔는지 못 찾는다.

| 단계 | 확인 신호 |
|---|---|
| 1. `unity.com/download` 에서 Unity Hub 받기 | 다운로드 시작됨 → "1" |
| 2. Hub 설치 | Hub 창이 떴다 → "2" |
| 3. Unity 계정 생성 / 로그인 | 우상단에 내 아이디가 보인다 → "3" |
| 4. **Personal 라이선스 활성화** | Preferences > Licenses 에 라이선스가 뜬다 → "4" |

> 💬 강사 대사: "지금 5분 기다립니다. **안 되는 분 지금 말하세요.** 지금 말 안 하면 두 달 뒤에 더 힘들어집니다."

## 01:00–01:35 · 같이 설치 ② — 에디터

**Hub > Installs > Install Editor > Unity 6 LTS (`6000.x.xx`)**

체크할 모듈 — **이 화면에서 학생 절반이 헤맨다. 강사가 항목을 하나씩 읽어준다.**

| 모듈 | 체크 | 이유 |
|---|---|---|
| Microsoft Visual Studio / VS Code 연동 | ✅ | 코드 편집기 |
| **WebGL Build Support** | ✅ | 5개월차 빌드 배포에 쓴다 |
| Windows Build Support (IL2CPP) | ✅ | PC 빌드 |
| Android / iOS | ❌ | 안 쓴다. 용량만 먹는다 |
| Documentation | ❌ | 온라인으로 본다 |
| 언어팩(한국어) | ❌ | **영문 유지.** 검색·튜토리얼이 전부 영문 UI 기준이다 |

> ⚠️ **언어팩을 깔지 않는 이유를 반드시 설명할 것.** "한국어로 하면 편하지 않나요?"가 매 기수 나온다. → "구글에 검색하면 전부 영어 화면이 나옵니다. 지금 조금 불편한 게 나중에 훨씬 편해요."

**다운로드가 오래 걸린다(10~30분).** 이 시간에:

- 사양 미달자 개별 상담 (DM)
- 이미 끝난 학생은 `#자랑` 채널에서 서로 인사
- 강사는 화면공유 유지한 채 잡담 — **정적이 흐르면 학생이 이탈한다**

## 01:35–01:50 · 첫 프로젝트 + 전원 점검

1. Hub > New Project > **3D (Built-in Render Pipeline)** > 이름 `MyFirstProject`
2. 저장 위치: **경로에 한글·공백이 없는 곳** (예: `C:\Unity\MyFirstProject`)
3. 에디터가 켜지면 끝

> ⚠️ **한글 경로 금지를 강조.** 바탕화면(`C:\Users\사용자이름\Desktop`)에 만들면 계정명이 한글인 학생에게서 나중에 빌드 에러가 난다. 1회차에 막는 게 싸다.

**전원 점검** — 학생 한 명씩 화면공유 5초. 20명이면 이 시간이 부족하니 **소회의실 4개로 쪼개 조교/자율 점검** 또는 스크린샷 제출로 대체.

## 🚨 흔한 사고 & 대응 (강사용)

| 상황 | 대응 |
|---|---|
| **디스크 용량 부족** | Unity 에디터 1개 ≈ 10GB+. 사전 공지에 "여유 30GB" 명시. 당일엔 다른 드라이브 설치 안내 |
| **다운로드가 안 끝남 (회사/학교 방화벽)** | 개인 네트워크 사용 권유. 그래도 안 되면 **다음 회차까지 개별 세션** 잡기 |
| 계정 이메일 인증 안 됨 | 스팸함 확인 → 다른 메일로 재가입 |
| 이미 다른 버전을 깔아옴 | **지우게 하지 말고** Hub에서 6 LTS를 추가 설치. 프로젝트만 6 LTS로 연다 |
| 맥/윈도우 화면이 달라 혼란 | 강사는 **윈도우 기준으로 진행**하고, 맥 사용자 수를 파악해 단축키 대응표(`Ctrl`↔`Cmd`)를 `#자료`에 고정 |
| 사양 미달 (구형 노트북) | 공개 채널에서 다루지 않는다. DM으로 → 저사양 설정 안내, 또는 기관에 실습 장비 요청 |
| 설치가 끝난 학생이 심심해함 | "에디터 아무거나 눌러보세요. **못 부숩니다.**" — 탐색을 권장 |
