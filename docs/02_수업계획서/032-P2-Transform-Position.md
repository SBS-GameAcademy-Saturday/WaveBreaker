## 🎯 오늘의 목표

1. **월드 원점(0, 0)이 어디인지** 안다
2. X는 가로, Y는 세로, **Z는 2D에서 안 쓴다**를 안다
3. 목표 좌표를 듣고 **그 자리에 물체를 놓는다**
4. Inspector의 Position이 **무엇을 기준으로 한 값인지** 안다

> ⚠️ **오늘 안 하는 것**: Rotation, Scale. "다음 시간에요."
> 오늘 셋을 다 하면 좌표 감각이 안 붙는다.
>
> 🔑 **설계 의도**: 앞으로 나올 거의 모든 코드가 **좌표를 다룬다.**
> 총알이 나가는 방향, 몬스터가 오는 위치, UI 배치 — 전부 좌표다.
> 여기서 "X를 늘리면 오른쪽"이 몸에 안 붙으면 038회차 코드 이동에서 통째로 막힌다.
> 기관 교육과정(한국디지털컨버전스협회)도 **트랜스폼에만 3강**을 쓴다.

## 00:10–00:45 · 같이 치기 ★

### ① 월드 원점 찾기 (6분)

`032_Position_Start` 씬을 연다. `Square` 하나를 만들고 **Position을 `0, 0, 0`으로** 맞춘다.

Scene 창을 축소해서 **가운데 격자 교차점**을 보여준다.

> 💬 "여기가 **월드 원점**입니다. 좌표 `(0, 0)`. **이 게임 세계 전체의 기준점**이에요."
> 💬 "수학 시간에 배운 그 좌표평면 맞습니다. **1사분면만 쓰는 게 아니라 네 방향 다 씁니다.**"
>
> 🔑 **"월드"라는 말을 오늘부터 붙여서 쓴다.** 그냥 "원점"이 아니라 "월드 원점".
> 다음 시간에 **다른 기준점(로컬)** 이 나오기 때문이다. 지금 이름을 붙여두면 그때 헷갈리지 않는다.

Inspector의 Position 우측 `⋮` → **Reset** 을 알려준다.

> 💬 "물체를 잃어버리면 Reset하면 원점으로 돌아옵니다. `F`랑 같이 기억하세요."

### ② X축 — 가로 (7분)

**한 명씩 값을 부르고 다 같이 넣는다.**

| 넣을 값 | 어디로 가나 |
|---|---|
| X = `3` | 오른쪽 |
| X = `-3` | **왼쪽** |
| X = `0` | 가운데로 복귀 |

> 💬 "**양수면 오른쪽, 음수면 왼쪽.** 이건 7개월 내내 씁니다."
>
> ⚠️ 음수 개념에서 멈추는 학생이 있다. **"마이너스는 반대 방향"** 한 문장으로만 설명한다.

### ③ Y축 — 세로 (7분)

| 넣을 값 | 어디로 가나 |
|---|---|
| Y = `2` | 위 |
| Y = `-2` | **아래** |

> 🚨 **여기서 반드시 짚는다.**
> 💬 "**Y가 커지면 위로 갑니다.** 나중에 화면 좌표를 다룰 때는 반대인 경우도 있는데, 지금 우리가 쓰는 건 **위가 +** 입니다."

**네 방향을 한 번에 정리한다.**

```
            Y +2  (위)
              │
   X -3 ──────┼────── X +3
   (왼)       │       (오른)
            Y -2  (아래)
```

**받아쓰기 5문제.** 강사가 좌표를 부르면 학생이 물체를 옮긴다.

`(2, 3)` → `(-2, 3)` → `(-2, -3)` → `(0, 4)` → `(5, 0)`

> 화면 공유로 몇 명 확인한다. **틀리는 학생이 절반이면 한 번 더 돈다.**

### ④ Z는 왜 있나 (4분)

Z에 `5`를 넣어본다. **거의 아무 변화가 없다.**

> 💬 "유니티는 원래 3D 엔진이에요. 우리가 2D로 쓰는 것뿐입니다. **Z는 깊이**인데, 2D에서는 거의 안 씁니다."
> 💬 "**Z는 0으로 두세요.** 건드려서 좋을 일이 없습니다."

> ⚠️ Z에 큰 값을 넣어 물체가 사라진 학생이 나온다. Position Reset 또는 Z를 0으로.
> ⚠️ "그럼 앞뒤 순서는 어떻게 정해요?"라는 질문이 나오면 → **`Order in Layer`** 를 한 줄만 언급하고 Phase 3로 미룬다.

### ⑤ 지금 보는 Position은 "월드 좌표"다 (4분)

> 💬 "지금 Inspector에 뜨는 Position은 **월드 원점에서부터 잰 값**입니다. 이걸 **월드 좌표**라고 해요."

**한 문장으로 못 박는다.**

| | |
|---|---|
| **월드 좌표** | 게임 세계의 원점 `(0,0)`에서부터 잰 위치 |
| 지금까지 만진 것 | **전부 월드 좌표** |

> 💬 "그런데 다음 시간에 **이 숫자가 월드 좌표가 아니게 되는 경우**가 나옵니다."
> 💬 "같은 자리에 있는 물체 두 개인데 Inspector 숫자가 다른 상황이요. 그때 이유를 봅니다."

> 🚨 **여기서 설명하지 않는다.** 궁금한 상태로 두는 게 033회차의 도입이다.
> 물어보면 → **"내일 그것만 다룹니다."**

### ⑥ Move 툴과 스냅 (7분)

`W` 키 → 이동 툴. 화살표를 끌어 옮긴다.

| 조작 | 결과 |
|---|---|
| **빨강 화살표** 드래그 | X축으로만 이동 |
| **초록 화살표** 드래그 | Y축으로만 이동 |
| 가운데 사각형 드래그 | 자유 이동 |
| `Ctrl` 누른 채 드래그 | **한 칸씩 딱딱** (스냅) |

> 💬 "손으로 끌면 `2.03718` 같은 지저분한 값이 나옵니다. **`Ctrl`을 누르고 끌면 정수로 딱딱** 떨어져요."
> 💬 "값이 지저분해도 게임은 돌아갑니다. 다만 **나중에 찾기 어려워지니** 정리하는 습관을 들이세요."

## 00:55–01:35 · 개인 미션

### 필수 미션 — 좌표로 도형 그리기

`Square` 5개를 **지정된 좌표에 정확히** 놓아 십자가를 만든다.

| 이름 | Position (X, Y, Z) |
|---|---|
| `Center` | `0, 0, 0` |
| `Up` | `0, 2, 0` |
| `Down` | `0, -2, 0` |
| `Left` | `-2, 0, 0` |
| `Right` | `2, 0, 0` |

- [ ] 5개를 정확한 좌표에 놓았다 (**소수점 없이**)
- [ ] Hierarchy 이름을 표대로 바꿨다
- [ ] 가운데만 색을 다르게 줬다
- [ ] 씬을 저장했다

**확인 조건**: Inspector의 Position이 **정확히** 표의 값이다. `1.99`도 틀린 것으로 본다.

<details>
<summary>막히면 열기</summary>

- 값은 **손으로 끌지 말고 Inspector에 직접 타이핑**한다. 그게 제일 빠르고 정확하다
- 물체가 겹쳐 보이면 → 만들 때마다 원점에 생기기 때문. 만들자마자 좌표를 넣는다
- 5개를 하나씩 만들기 귀찮으면 → `Ctrl+D`로 복제한 뒤 좌표만 바꾼다
</details>

### ⭐ 도전 미션

- [ ] 십자가를 **대각선 4개**를 더해 별 모양으로 만든다 (`1.4, 1.4` 같은 값)
- [ ] `Ctrl` 스냅으로만 배치해서 계단 모양을 만든다
- [ ] Position Y를 `100`으로 주고 `F`로 찾아온다
- [ ] 물체 10개를 **가로 한 줄**로 1칸 간격 배치한다 (X = -5 ~ 4)
- [ ] 원점에서 같은 거리에 물체 8개를 놓아 **원처럼** 배치한다
- [ ] 좌표를 소수점 둘째 자리까지 써서 아주 미세하게 옮겨본다

## 01:35–01:50 · 데모 + 좌표 맞히기 게임

**좌표 맞히기** — 강사가 Scene에 물체를 하나 놓고 화면을 공유한다.
학생들이 **채팅에 좌표를 예상해서 쓴다.** 그다음 Inspector를 열어 정답 공개.

3~4번 반복하면 좌표 감각이 눈에 붙는다.

> 💬 "이 감각이 있으면 나중에 '몬스터를 화면 위쪽에서 스폰' 같은 말이 바로 숫자로 떠오릅니다."

## ✅ 체크리스트 (학생)

- [ ] **월드 원점** `(0, 0)`이 어디인지 안다
- [ ] Inspector의 Position이 **월드 원점 기준**이라는 걸 안다
- [ ] X 양수 = 오른쪽, 음수 = 왼쪽
- [ ] Y 양수 = 위, 음수 = 아래
- [ ] 2D에서 Z는 0으로 둔다
- [ ] Position을 Inspector에 직접 입력할 수 있다
- [ ] `Ctrl` 드래그로 정수 스냅을 쓸 수 있다
- [ ] Position Reset을 안다
- [ ] 제출했다

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| 물체가 사라짐 | Z에 큰 값 / 화면 밖 | Position Reset 또는 `F` |
| 좌표가 `2.03718` | 손으로 끌었음 | **직접 타이핑**하거나 `Ctrl` 스냅 |
| 음수를 못 넣음 | 개념 막힘 | "마이너스는 반대 방향" 한 문장만 |
| Y 방향을 반대로 앎 | 화면 좌표와 혼동 | "**우리는 위가 +**" 반복 |
| 새 물체가 전부 겹침 | 전부 원점 생성 | 만들자마자 좌표 입력하는 습관 |
| 화살표를 못 잡음 | Move 툴이 아님 | `W` 키 |
| 화살표를 끌었는데 두 축이 같이 움직임 | 가운데 사각형을 잡음 | 축 화살표 끝을 잡게 한다 |
| Z를 계속 건드림 | 호기심 | "0으로 두세요"를 3번 반복 |
| 앞뒤 가림 순서를 물음 | 좋은 질문 | `Order in Layer` 한 줄만. **Phase 3로 미룬다** |
| 진도 빠른 학생이 지루해함 | 개념이 단순 | ⭐도전의 "원처럼 배치"를 시킨다. 은근히 어렵다 |
