### ② 각도를 나눈다 (10분) — 오늘의 계산

**칠판**

```
칼이 3개면 :  360 ÷ 3 = 120도 간격    →  0도, 120도, 240도
칼이 6개면 :  360 ÷ 6 =  60도 간격    →  0도, 60도, 120도, 180도, 240도, 300도

i 번째 칼의 각도  =  360 / 개수 * i
```

> 💬 "**069에서 타일을 원형으로 놓아본 사람**, 이 계산 봤죠. 똑같습니다."

**각도를 좌표로 바꾼다.**

```
x = cos(각도) × 반지름
y = sin(각도) × 반지름
```

> 🚨 **`Mathf.Cos` 는 도(degree)가 아니라 라디안(radian)을 받는다.**
> `Mathf.Deg2Rad` 를 곱해서 바꿔준다. 이걸 빼면 **칼이 엉뚱한 데 몰린다.**
>
> 💬 "라디안이 뭔지는 지금 몰라도 됩니다. **각도를 넣을 땐 `* Mathf.Deg2Rad`** — 그거 하나만 외우세요."

### ③ 코드로 배치한다 (15분)

```csharp
using UnityEngine;

public class MeleeRing : MonoBehaviour
{
    [SerializeField] private GameObject bladePrefab;
    [SerializeField] private int bladeCount = 3;
    [SerializeField] private float radius = 2f;
    [SerializeField] private float rotateSpeed = 180f;

    private void Start()
    {
        Build();
    }

    private void Update()
    {
        transform.Rotate(0f, 0f, rotateSpeed * Time.deltaTime);
    }

    [ContextMenu("칼 다시 배치")]
    public void Build()
    {
        // 이미 달려 있는 칼을 전부 치운다. 안 그러면 부를 때마다 쌓인다.
        for (int i = transform.childCount - 1; i >= 0; i--)
        {
            Destroy(transform.GetChild(i).gameObject);
        }

        for (int i = 0; i < bladeCount; i++)
        {
            float angle = 360f / bladeCount * i;
            float rad = angle * Mathf.Deg2Rad;

            GameObject blade = Instantiate(bladePrefab, transform);

            blade.transform.localPosition =
                new Vector3(Mathf.Cos(rad) * radius, Mathf.Sin(rad) * radius, 0f);

            blade.transform.localRotation = Quaternion.Euler(0f, 0f, angle - 90f);
        }
    }
}
```

▶ Play → 칼 3자루가 **정확히 120도 간격**으로 돈다.
`Blade Count` 를 `6` 으로 바꾸고 ⋮ 메뉴 → `칼 다시 배치` → **즉시 6자루**가 된다.

> 🎉 여기가 오늘의 정점이다. 개수를 1 → 3 → 6 → 12 로 바꿔가며 보여준다.

**한 조각씩 짚는다.**

| 조각 | 뜻 |
|---|---|
| `Instantiate(bladePrefab, transform)` | **`transform`(나) 의 자식으로** 만든다 |
| `localPosition` | **부모 기준** 위치 (033) |
| `360f / bladeCount * i` | i 번째 칼의 각도 |
| `Mathf.Deg2Rad` | 도 → 라디안 |
| `angle - 90f` | 칼끝이 바깥을 보게 (그림이 위쪽이 칼끝이라) |
| **거꾸로 도는 `for`** | 지우면서 목록이 줄어드니 **뒤에서부터** 지운다 |

> 🚨 **`for (int i = 0; i < childCount; i++)` 로 지우면 절반만 지워진다.**
> 지울 때마다 개수가 줄어 인덱스가 밀린다. **뒤에서부터** 지우면 안전하다.
> 일부러 앞에서부터 지워 보여주면 바로 이해한다.

> 💡 `[ContextMenu]` 는 073에서 썼다. 실행 중에 눌러 즉시 다시 배치할 수 있어 테스트가 편하다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
