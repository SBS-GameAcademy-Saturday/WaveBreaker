## 00:10–00:40 · 같이 하기 ★

### ① 095회차 코드를 띄운다 (10분)

**19주차에 이렇게 짰다.**

```csharp
// CameraFollow.cs — 095회차
// 095회차 · "하나를 따라간다" 를 "목록의 중심을 따라간다" 로 바꿨다.
//   목록에 하나만 넣으면 동작이 068과 완전히 같다. 지금은 실제로 하나만 넣는다.
//   Phase 9 에서 협동을 붙일 때 이 파일은 안 고치고 목록에 하나 더 넣기만 하면 된다.

[SerializeField] private List<Transform> targets = new List<Transform>();

void LateUpdate()
{
    if (targets.Count == 0) return;

    Vector3 center = Center();
    Vector3 goal = new Vector3(center.x, center.y, -10f);

    transform.position = Vector3.SmoothDamp(transform.position, goal, ref velocity, smoothTime);
}

// 목록의 평균 위치. 원소가 하나면 그 하나의 위치와 같은 값이 나온다.
private Vector3 Center()
{
    Vector3 sum = Vector3.zero;
    int count = 0;

    foreach (Transform t in targets)
    {
        if (t == null) continue;   // 죽어서 사라진 플레이어는 건너뛴다
        sum += t.position;
        count++;
    }

    if (count == 0) return transform.position;
    return sum / count;
}
```

> 💬 "**주석을 읽어보세요.** 19주차에 제가 뭐라고 써뒀죠?"
> 💬 "**'Phase 9 에서 이 파일은 안 고치고 목록에 하나 더 넣기만 하면 된다.'**"

> 🔑 💬 "**계산 코드는 오늘 한 글자도 안 고칩니다.**"

### ② 고치는 것 — 문 두 개 (10분)

목록에 **넣고 빼는 방법**만 있으면 된다.

```csharp
// 120회차 · 접속한 플레이어가 스스로 등록한다.
public void AddTarget(Transform t)
{
    if (t == null || targets.Contains(t)) return;

    targets.Add(t);
}

public void RemoveTarget(Transform t)
{
    targets.Remove(t);
}
```

> 💬 "**이게 전부입니다.** 두 함수, 여섯 줄."
> 💬 "`Contains` 검사는 왜 넣었을까요?" → 두 번 등록되면 평균이 그쪽으로 쏠린다

### ③ 누가 등록하나 (10분)

**플레이어가 스스로** 등록한다. 109회차에 만든 `OnNetworkSpawn` 자리다.

```csharp
public override void OnNetworkSpawn()
{
    // 120회차 · 내 화면의 카메라 목록에 나를 넣는다.
    //   "내 것" 만 넣는 게 아니라 둘 다 넣는다 — 카메라는 둘의 중심을 봐야 하니까.
    CameraFollow cam = Camera.main != null ? Camera.main.GetComponent<CameraFollow>() : null;
    if (cam != null) cam.AddTarget(transform);

    ...
}

public override void OnNetworkDespawn()
{
    CameraFollow cam = Camera.main != null ? Camera.main.GetComponent<CameraFollow>() : null;
    if (cam != null) cam.RemoveTarget(transform);

    ...
}
```

> 🚨 💬 "**`IsOwner` 검사를 넣으면 안 됩니다.**"
> 💬 "내 캐릭터만 넣으면 **다시 한 명만 따라가게** 돼요. 둘 다 넣어야 중심이 나옵니다."
>
> 💬 "114회차에 `IsOwner` 를 배웠다고 아무 데나 넣으면 안 됩니다.
> **'이 동작이 나만의 것인가'** 를 매번 물어야 해요. 카메라 목록은 아니죠."

> 💡 `OnNetworkDespawn` 에서 빼는 것도 중요하다. 안 빼면 나간 사람 쪽으로 카메라가 끌린다.
> 115회차에서 `OnValueChanged` 를 해제한 것과 **같은 습관**이다.
