## 00:10–00:50 · 같이 하기 ★

### ① 얼마나 멀어졌나 재기 (10분)

`Center()` 안에서 **가장 먼 두 점 사이 거리**를 같이 계산한다.

```csharp
// 121회차 · 가장 먼 두 점 사이의 거리를 재둔다.
float span = 0f;
foreach (Transform a in targets)
{
    if (a == null) continue;
    foreach (Transform b in targets)
    {
        if (b == null) continue;
        span = Mathf.Max(span, Vector2.Distance(a.position, b.position));
    }
}

Span = span;
CenterPoint = center;
```

> 💬 "이중 반복문이죠. **모든 짝을 다 재봅니다.**"
> 💬 "2명이면 4번, 4명이면 16번. 사람 수가 적어서 괜찮습니다."

> 🔑 💬 "**목록이 하나면 `Span` 이 0 입니다.** 자기와 자기 거리는 0이니까요."
> 💬 "이게 오늘의 핵심입니다. **싱글은 자동으로 안 바뀝니다.**"

### ② 줌아웃 (12분)

```csharp
// 121회차 · 멀어진 만큼 화면을 넓힌다.
private void Zoom()
{
    Camera cam = GetComponent<Camera>();
    if (cam == null || !cam.orthographic) return;

    // 🔑 목록이 하나면 Span 이 0 이다 → goal 이 baseSize → 싱글은 그대로다.
    float goal = Mathf.Clamp(baseSize + Span * zoomPadding, baseSize, maxSize);

    cam.orthographicSize = Mathf.Lerp(cam.orthographicSize, goal, Time.deltaTime / zoomSmooth);
}
```

| 항목 | 우리 값 | 뜻 |
|---|---|---|
| `baseSize` | **5** | 기본 화면 크기 (091 그대로) |
| `maxSize` | **8.5** | 이 이상은 안 넓힌다 |
| `zoomPadding` | **0.6** | 거리 1당 얼마나 넓힐지 |
| `zoomSmooth` | **0.4** | 부드럽게 (0이면 뚝뚝) |

> 💬 "`Clamp` 로 **위아래를 막습니다.** 안 막으면 무한히 넓어져요."
> 💬 "`Lerp` 로 **서서히** 바꿉니다. 095의 `SmoothDamp` 와 같은 생각이에요."

**실측**

```
Span = 1.34   →   orthographicSize = 5.80
                  (5 + 1.34 × 0.6 = 5.80)
```

> 💬 "계산이 맞죠. **거리 1.34만큼 멀어졌더니 화면이 0.8만큼 넓어졌습니다.**"

### ③ 소프트 리쉬 (12분)

> 💬 "줌만으로 충분할까요?"
> 💬 "둘이 화면 두 개 거리만큼 멀어지면 **캐릭터가 점이 됩니다.** `maxSize` 로 막아뒀으니까요."

```csharp
private void LateUpdate()
{
    // 내 캐릭터만 당긴다. 상대 캐릭터는 그쪽에서 당겨진 결과가 넘어온다.
    if (!IsOwner) return;
    if (cam == null) return;

    // 혼자면 당길 이유가 없다. 싱글에서도 이 검사로 걸러진다.
    if (cam.Span <= 0.01f) return;

    Vector2 toCenter = (Vector2)cam.CenterPoint - (Vector2)transform.position;
    float dist = toCenter.magnitude;

    if (dist <= maxDistance) return;

    // 넘은 만큼만 당긴다. 많이 넘을수록 세게.
    float over = dist - maxDistance;

    transform.position += (Vector3)(toCenter.normalized * over * pullStrength * Time.deltaTime);
}
```

> 🚨 💬 "**'딱딱하게' 막으면 안 됩니다.**"
> 💬 "벽에 부딪힌 것처럼 멈추면 **조작이 씹히는 느낌**이 나요."
> 💬 "그래서 이름이 '**소프트**' 리쉬입니다. 넘은 만큼만, 조금씩 당깁니다."

| 항목 | 우리 값 |
|---|---|
| `maxDistance` | **7** (중심에서 이만큼까지 허용) |
| `pullStrength` | **2.5** |

> 💬 "`IsOwner` 검사가 왜 여기 있을까요?"
> 💬 "**내 캐릭터만 내가 당깁니다.** 상대는 그쪽에서 당겨진 결과가 넘어와요. (114 회수)"

> 💡 120회차에서는 `IsOwner` 를 **넣으면 안 됐다.** 여기서는 **넣어야 한다.**
> 매번 "이 동작이 나만의 것인가" 를 물어야 하는 이유다.
