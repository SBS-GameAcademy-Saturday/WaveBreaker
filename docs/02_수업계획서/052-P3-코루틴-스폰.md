>
> 🔑 **설계 의도**: 오늘 만드는 `SpawnRoutine`이 **Phase 5 웨이브 매니저의 원형**이다.
> 그리고 `while` + `yield`는 **무한 루프로 유니티를 얼려버릴 수 있는** 첫 코드다.
> 그 사고를 **강사가 먼저 재현해서** 보여주고 대처법을 준다. 안 보여주면 학생 컴퓨터에서 처음 만난다.

## 00:10–00:45 · 같이 치기 ★

### ① `while` 을 넣는다 (10분) — 오늘의 핵심

`052_Spawn_Start` 를 연다. 048의 `EnemySpawner`가 `E` 키 방식으로 붙어 있다.

```csharp
using UnityEngine;
using System.Collections;

public class EnemySpawner : MonoBehaviour
{
    [SerializeField] private GameObject enemyPrefab;
    [SerializeField] private float spawnInterval = 2f;
    [SerializeField] private float spawnRangeX = 7f;
    [SerializeField] private float spawnY = 4f;

    void Start()
    {
        StartCoroutine(SpawnRoutine());
    }

    IEnumerator SpawnRoutine()
    {
        while (true)
        {
            SpawnOne();

            yield return new WaitForSeconds(spawnInterval);
        }
    }

    private void SpawnOne()
    {
        float x = Random.Range(-spawnRangeX, spawnRangeX);

        Instantiate(enemyPrefab, new Vector3(x, spawnY, 0f), Quaternion.identity);
    }
}
```

▶ Play → **아무것도 안 눌렀는데 2초마다 몬스터가 나온다.**

> 🎉 **이게 Phase 3의 마지막 종료 조건이다.** 서두르지 않는다.

**한 줄씩 짚는다.**

| 줄 | 뜻 |
|---|---|
| `while (true)` | **계속 반복해라** |
| `SpawnOne()` | 한 마리 만든다 |
| `yield return new WaitForSeconds(...)` | **여기서 2초 쉬었다 다시 위로** |

> 💬 "3주차에 배운 `while` 그대로예요. 조건이 `true`니까 **끝나지 않습니다.**"
> 💬 "**끝나지 않는데 게임이 안 멈추는 이유**가 뭘까요? **중간에 쉬기 때문**입니다."

### ② 유니티를 얼려 본다 (8분) — 오늘 반드시 하는 시연

> 🚨 **강사만 한다. 학생에게는 시키지 않는다.** 미리 한 번 연습해 둔다.

`yield` 줄을 **주석 처리**하고 ▶ Play.

**유니티가 멈춘다.** 응답이 없다.

> 💬 "지금 유니티가 죽었죠. **`while (true)`인데 쉬지를 않으니까** 한 프레임 안에서 무한히 돕니다."
> 💬 "몬스터를 **1초에 수십만 마리** 만들려고 하는 중이에요."

**탈출 방법을 알려준다.**

| 상황 | 대처 |
|---|---|
| 아직 반응함 | **`Ctrl+Shift+P`** (Play 토글) 를 눌러 본다 |
| 완전히 멈춤 | 작업 관리자에서 **Unity 강제 종료** |
| 다시 열었을 때 | **저장 안 한 씬은 날아간다.** 코드는 남아 있다 |

> 💬 "그래서 **`while` 을 쓸 때는 `yield`가 있는지 먼저 확인**하세요. 이건 습관입니다."
> 💬 "그리고 **Play 하기 전에 `Ctrl+S`.** 오늘부터 이거 꼭 하세요."

주석을 풀고 다시 Play. 정상으로 돌아온다.

### ③ 시작과 정지 (9분)

```csharp
private Coroutine spawnRoutine;

void Start()
{
    spawnRoutine = StartCoroutine(SpawnRoutine());
}

void Update()
{
    if (Input.GetKeyDown(KeyCode.P))
    {
        if (spawnRoutine != null)
        {
            StopCoroutine(spawnRoutine);
            spawnRoutine = null;
            Debug.Log("스폰 정지");
        }
        else
        {
            spawnRoutine = StartCoroutine(SpawnRoutine());
            Debug.Log("스폰 시작");
        }
    }
}
```

▶ Play → `P`로 껐다 켰다 한다.

| 조각 | 뜻 |
|---|---|
| `private Coroutine spawnRoutine` | **시작한 코루틴을 담아두는 손잡이** |
| `StopCoroutine(spawnRoutine)` | **그 손잡이로 멈춘다** |
| `spawnRoutine = null` | **지금 안 돌고 있다**는 표시 |

> 💬 "`StartCoroutine`은 **손잡이를 돌려줍니다.** 그걸 안 받아두면 나중에 못 멈춰요."
> 💬 "049에서 배운 **`null` 확인**이 여기서도 나옵니다. **'지금 돌고 있나'** 를 그걸로 봅니다."

> 💡 **`StopAllCoroutines()`** 도 있다는 걸 한 줄. "이 오브젝트의 코루틴을 전부 멈춥니다. 편한데 거칠어요."

> ⚠️ **`StopCoroutine("SpawnRoutine")` 처럼 문자열로도 된다**는 걸 검색해 온 학생이 있다.
> **"문자열은 오타를 못 잡아줍니다. 손잡이로 쓰세요."** 까지만.

### ④ `E` 키를 지운다 (3분)

048의 `E` 키 스폰과 `[ContextMenu]`를 **어떻게 할지 결정하게 한다.**

### ⭐ 도전 미션

- [ ] 스폰할 때마다 `spawnInterval`을 조금씩 줄여 **점점 빨라지게** 한다 (`Mathf.Max`로 하한을 둔다)
- [ ] 몬스터를 **한 번에 3마리씩** 스폰한다 (`for` 를 코루틴 안에)
- [ ] 스폰 위치를 **화면 위·아래·좌·우 랜덤**으로 한다
- [ ] `spawnY`를 넘어간 몬스터를 지운다 (048의 `Destroy` + `lifeTime`)
- [ ] 몬스터가 아래로 천천히 내려오게 한다 (`Rigidbody 2D` + `linearVelocity`)
- [ ] `StopAllCoroutines()`와 `StopCoroutine(손잡이)`의 차이를 한 줄로 쓴다

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **유니티가 완전히 멈춤** | **`while` 안에 `yield`가 없음** | **오늘 1등.** 강제 종료. 그래서 `Ctrl+S`를 시킨다 |
| 몬스터가 안 나옴 | `StartCoroutine`을 안 씀 | 051 그대로 |
| 몬스터가 한 마리만 나옴 | `while`이 없음 | 코루틴이 한 번 돌고 끝났다 |
| 몬스터가 너무 많이 나옴 | `Update`에서 `StartCoroutine`을 부름 | **매 프레임 새 코루틴이 시작된다.** `Start`로 |
| `P`를 눌러도 안 멈춤 | 손잡이를 안 받아둠 | `spawnRoutine = StartCoroutine(...)` |
| 멈춘 뒤 다시 안 켜짐 | `spawnRoutine = null` 을 안 함 | 정지할 때 `null`로 |
| `Coroutine` 타입을 못 찾음 | 오타 (`coroutine`) | 대문자 `Coroutine` |
| 몬스터가 화면 밖에 쌓임 | 아무도 안 지움 | ⭐도전. `lifeTime` 또는 화면 밖 삭제 |
| 프레임이 떨어짐 | 몬스터가 수백 마리 | `spawnInterval`을 늘린다. **Phase 8 풀링 예고** |
| Play 중 스폰된 게 저장 안 됨 | 037 그대로 | 정상 |
| `E` 키가 아직 동작함 | 지우지 않음 | 판단은 학생이. 지우기로 했으면 지운다 |
| 씬을 저장 안 하고 강제 종료 | 위 1등 사고의 여파 | **씬은 다시 만든다.** 코드는 남아 있다 |
