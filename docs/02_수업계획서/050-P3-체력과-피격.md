## 00:10–00:45 · 같이 치기 ★

### ① 콘솔 코드를 옆에 놓는다 (7분) — 오늘의 도입

**5~6주차 콘솔 `Enemy` 클래스를 띄운다.**

```csharp
// 5~6주차 · 콘솔
class Enemy
{
    private int hp = 30;

    public void TakeDamage(int damage)
    {
        hp = hp - damage;
        Console.WriteLine("남은 체력: " + hp);
    }
}
```

> 💬 "이거 여러분이 만들었죠. **오늘 만들 게 이겁니다.** 딱 두 군데만 바뀝니다."

| 콘솔 | 유니티 | 왜 |
|---|---|---|
| `class Enemy` | `class Health : MonoBehaviour` | **컴포넌트가 되려고** (036) |
| `Console.WriteLine` | `Debug.Log` | **찍히는 곳만** 다르다 (036) |

> 💬 "**나머지는 전부 똑같습니다.** 필드도, 메서드도, 매개변수도요."

### ② `Health` 를 만든다 (11분) — 오늘의 핵심

`Assets/_Project/Scripts/Enemy/` 에 **`Health`** 스크립트를 만든다.

```csharp
using UnityEngine;

public class Health : MonoBehaviour
{
    [SerializeField] private int maxHealth = 30;

    private int currentHealth;

    void Awake()
    {
        currentHealth = maxHealth;
    }

    public void TakeDamage(int damage)
    {
        currentHealth = currentHealth - damage;

        Debug.Log(gameObject.name + " 남은 체력: " + currentHealth);

        if (currentHealth <= 0)
        {
            Die();
        }
    }

    private void Die()
    {
        Debug.Log(gameObject.name + " 사망");

        Destroy(gameObject);
    }
}
```

**몬스터 프리팹에 붙인다.** (씬이 아니라 **프리팹 모드에서** — 046 그대로)

**짚을 것 네 가지.**

| 짚을 것 | 설명 |
|---|---|
| `public void TakeDamage` | **`public`이어야 남이 부를 수 있다** (6주차 접근 제한자) |
| `private void Die` | 죽는 건 **자기가 결정**한다. 남이 부를 일이 없다 |
| `[SerializeField] maxHealth` | **Inspector에서 몬스터마다 다르게** (037) |
| `currentHealth`는 안 보인다 | **게임 중에 변하는 값**이라 Inspector에 열 이유가 없다 |

> 💬 "`public`과 `private`을 6주차에 배웠죠. **오늘 그게 실제로 필요한 자리**입니다."
> 💬 "총알이 `TakeDamage`를 부릅니다. 그래서 `public`. `Die`는 아무도 안 불러요. 그래서 `private`."

> ⚠️ **`Awake`에 초기화하는 이유를 짚는다.** 049에서 규칙만 줬던 그것이다.
> 💬 "`Start`에 넣으면요? **총알이 첫 프레임에 때리면 체력이 아직 0**일 수 있습니다."
> 💬 "**내 값 챙기는 건 `Awake`, 남을 쓰는 건 `Start`.** 049에서 말한 그 순서예요."

### ③ 총알이 깎는다 (10분)

049의 "색 바꾸기"를 **체력 깎기**로 바꾼다.

```csharp
[SerializeField] private int damage = 10;

private void OnTriggerEnter2D(Collider2D other)
{
    if (other.CompareTag("Enemy"))
    {
        Health health = other.GetComponent<Health>();

        if (health != null)
        {
            health.TakeDamage(damage);
        }

        Destroy(gameObject);
    }
}
```

▶ Play → 몬스터를 쏜다 → Console에 **`남은 체력: 20` → `10` → `0` → `사망`**

> 🎉 **여기가 Phase 3의 종료 조건이다.** 서두르지 않는다.

> 💬 "049에서 `SpriteRenderer`를 찾았죠. 오늘은 **내가 만든 `Health`** 를 찾습니다."
> 💬 "`GetComponent`는 **유니티 부품만 찾는 게 아닙니다.** 내가 만든 스크립트도 부품이에요. **034회차 그대로.**"

> 🔑 이 문장을 반드시 한다: **"내가 만든 클래스도 컴포넌트다."**
> 이걸 이해하면 앞으로 나올 모든 스크립트 간 통신이 같은 그림이 된다.

### ④ 체력이 음수가 되는 문제 (7분)

`maxHealth = 30`, `damage = 10` 인데 **한 번에 50 데미지**를 주면 `-20`이 찍힌다.

```csharp
currentHealth = Mathf.Clamp(currentHealth - damage, 0, maxHealth);
```

> 💬 "`Mathf.Clamp(값, 최소, 최대)` — **범위 밖으로 못 나가게 자릅니다.**"
> 💬 "040 ⭐도전에서 화면 밖으로 못 나가게 할 때 쓴 그거예요."
> 💬 "체력바를 만들 때(Phase 7) 음수가 있으면 바가 뒤집힙니다. **지금 막아두는 게 낫습니다.**"

> 💡 **회복도 같은 메서드로 되는지** 물어보는 학생이 있다. `TakeDamage(-10)` 은 동작하지만
> 이름이 거짓말이 된다. **"`Heal`을 따로 만드는 게 맞다"** 까지만 말하고 ⭐도전으로 넘긴다.

### ✅ 10주차 종료 조건 (한 명씩 확인)

- [ ] GameObject를 프리팹으로 만든다
- [ ] **Project = 원본, Hierarchy = 복사본**을 구분한다
- [ ] 프리팹 원본을 고쳐 전부 반영시킨다
- [ ] `Instantiate`로 총알을 발사한다
- [ ] 프리팹 칸에는 **Project 창에서** 드래그한다
- [ ] `Destroy(gameObject, 시간)`으로 수명을 준다
- [ ] `gameObject`와 `this`의 차이를 말한다
- [ ] `GetComponent`로 내 부품과 **남의 부품**을 찾는다
- [ ] 못 찾으면 `null`이 오는 걸 알고 대비한다
- [ ] **`GetComponent`로 다른 오브젝트 체력을 깎는다**
- [ ] **체력이 0이면 몬스터가 사라진다**

> 하나라도 안 되는 학생이 있으면 **주말 안에 개별 시간**을 잡는다.
> 특히 **`GetComponent`와 `null`** 이 안 되면 11주차 이후가 통째로 막힌다.
> Phase 5부터는 스크립트끼리 부르는 게 **전부 이 방식**이다.

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **`TakeDamage` 를 못 부름** | **`public`이 아님** | **오늘 1등.** 6주차 접근 제한자로 연결 |
| `NullReferenceException` | 몬스터에 `Health`가 없음 | **프리팹에** 붙였는지 확인 (046) |
| 체력이 안 깎임 | Tag `Enemy` 없음 | 프리팹 모드에서 |
| 체력이 안 깎임 (2) | 044 충돌 체크리스트 | "1번부터 보세요" |
| 체력이 `0`인 채로 시작 | **`Awake`가 아니라 딴 데서 초기화** | `Awake`에 넣는다 |
| 체력이 안 줄고 매번 30 | `currentHealth` 대신 `maxHealth`를 깎음 | 변수를 구분한다 |
| 체력이 음수 | `Mathf.Clamp` 없음 | 넣는다 |
| **한 방에 죽음** | `damage`가 `maxHealth` 이상 | Inspector에서 조절. **수업의 핵심 실습** |
| 여러 번 깎임 (한 발인데) | 총알에 Collider가 2개 | 프리팹에서 하나 제거 |
| `Die`를 못 부름 | `private`인데 밖에서 부름 | 안에서만 부른다 |

| `Health` 파일명 ≠ 클래스명 | 036 그대로 | 파일을 지우고 다시 만든다 |
