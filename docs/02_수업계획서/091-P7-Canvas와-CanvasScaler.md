## 00:10–00:45 · 같이 하기 ★

### ① 문제를 먼저 본다 (8분)

Game 뷰 위쪽의 **해상도 드롭다운**을 연다. `Free Aspect` 대신 숫자를 고른다.

1. `1280x720` — 지금 상태다. 멀쩡하다.
2. `640x480` 을 만들어 고른다 (`+` → Fixed Resolution)

> 💬 "글자가 **화면에 비해 커졌죠.** 게임 화면을 다 가립니다."

3. `1920x1080` 을 고른다

> 💬 "이번엔 **작아졌습니다.** 안 보여요."

> 🔑 💬 "지금 UI 는 **'글자 크기 32픽셀'** 로 고정돼 있습니다.
> 화면이 작아지면 상대적으로 커지고, 커지면 상대적으로 작아집니다."
> 💬 "우리가 원하는 건 **'화면 폭의 몇 %'** 예요."

### ② Canvas 를 뜯어본다 (10분)

Hierarchy 에서 `HUD` 를 클릭한다. 컴포넌트가 네 개 붙어 있다.

| 컴포넌트 | 하는 일 |
|---|---|
| `Rect Transform` | UI 전용 Transform. 다음 시간 주인공 |
| **`Canvas`** | **"UI 를 어디에 어떻게 그릴지"** |
| **`Canvas Scaler`** | **"얼마나 크게 그릴지"** ← 오늘 |
| `Graphic Raycaster` | 클릭을 UI 가 받게 해준다 (085에서 이미 씀) |

**`Canvas` 의 Render Mode 3가지**

| 모드 | 뜻 | 언제 |
|---|---|---|
| **Screen Space - Overlay** | **화면 맨 위에 무조건 그린다** | **우리 것.** HUD 는 항상 보여야 한다 |
| Screen Space - Camera | 카메라가 그린다. 앞에 뭐가 끼어들 수 있다 | 연출이 필요할 때 |
| World Space | **월드에 판때기로 놓는다** | 몬스터 머리 위 체력바 |

> 💬 "우리는 **Overlay** 입니다. 지금도 그렇게 돼 있어요. 안 바꿉니다."
> 💡 World Space 는 도전 미션에 있다. 보스 머리 위 체력바를 만들 때 쓴다.

**`Canvas` 를 클릭한 채 Scene 뷰에서 `F` 를 눌러본다.**

> 💬 "Scene 뷰에서 보면 Canvas 가 **게임보다 훨씬 큽니다.** 놀라지 마세요. 정상입니다."
> 🚨 학생 사고 1위 — "UI 가 Scene 에서 안 보여요". Hierarchy 에서 클릭하고 `F`.

### ③ Canvas Scaler 3모드 (12분)

`Canvas Scaler` 의 **UI Scale Mode** 를 하나씩 바꾸며 `640x480` 에서 본다.

| 모드 | 뜻 | 결과 |
|---|---|---|
| **Constant Pixel Size** | 픽셀 수 고정 | 화면이 작아지면 **UI 가 상대적으로 커진다** |
| Constant Physical Size | 실제 물리 크기(cm) 고정 | DPI 를 아는 기기에서만 의미 있다 |
| **Scale With Screen Size** | **기준 해상도 대비 비율로 키운다** | ✅ **우리 것** |

**설정값**

| 항목 | 값 | 뜻 |
|---|---|---|
| UI Scale Mode | **Scale With Screen Size** | |
| Reference Resolution | **1280 × 720** | "이 해상도를 기준으로 만들었다" |
| Screen Match Mode | Match Width Or Height | |
| **Match** | **0.5** | 가로·세로를 **반반** 참고한다 |

### ④ Match 가 뭔지 눈으로 (10분) — 실측

`640x480` (4:3) 에서 네 설정을 재봤다. **`scaleFactor`** 는 "UI 를 몇 배로 그리는가" 다.

| 설정 | `scaleFactor` | 계산 |
|---|---|---|
| Constant Pixel Size | **1.000** | 안 키운다 |
| Scale With Screen Size · **Match 0** (가로) | **0.500** | `640 / 1280` |
| Scale With Screen Size · **Match 1** (세로) | **0.667** | `480 / 720` |
| Scale With Screen Size · **Match 0.5** | **0.577** | 둘의 중간 |

> 💬 "Match 0 은 **가로만 봅니다.** 화면이 세로로 길어지면 UI 가 위아래로 남아돌아요."
> 💬 "Match 1 은 **세로만 봅니다.** 가로로 길어지면 좌우가 넘칩니다."
> 💬 "**0.5 는 둘 다 반씩 봅니다.** 대부분의 게임이 이렇게 씁니다."

**같은 화면에서 실제 크기 비교** — 체력바(기준 폭 440) 가 화면에서 차지하는 폭

| 설정 | 640×480 | **1280×720 (기준)** | 1920×1080 |
|---|---|---|---|
| Constant Pixel Size | 440px = **68.8%** | 440px = 34.4% | 440px = **22.9%** |
| Scale With Screen Size (0.5) | 254px = **39.7%** | 440px = 34.4% | 660px = **34.4%** |

> 🔑 💬 "Constant 는 68.8% → 22.9%. **세 배가 차이납니다.**"
> 💬 "Scale With 는 39.7% → 34.4%. **거의 같죠.** 이게 우리가 원하는 겁니다."
>
> 🚨 **기준 해상도(1280×720)에서는 둘이 완전히 똑같다** — 34.4% 로 같은 값이 나온다.
> 💬 "그래서 **해상도를 안 바꿔보면 이 문제는 절대 안 드러납니다.**
> 여러분이 개발하는 해상도에서만 멀쩡한 거예요. 그러다 빌드해서 남한테 보내면 터집니다."

### ⑤ 🔎 오늘 재보고 알게 된 것 (5분) — 중요

**네 설정 전부, UI 가 화면 밖으로 나가지는 않았다.**

`640x480` 에서 다섯 요소의 화면 좌표를 재본 결과다.

```
[A] Constant Pixel Size          모두 화면안=True
[B] Scale With Screen Size · 0   모두 화면안=True
[C] Scale With Screen Size · 1   모두 화면안=True
[D] Scale With Screen Size · 0.5 모두 화면안=True
```

> 💬 "그럼 Scaler 는 뭘 고친 걸까요?"
>
> 🔑 💬 "**Scaler 는 '크기' 문제만 고칩니다.** '위치' 는 안 고쳐요."
> 💬 "위치를 정하는 건 **Anchor** 입니다. 그게 다음 시간이에요."
> 💬 "오늘 화면 밖으로 안 나간 이유는, **Anchor 가 이미 제대로 잡혀 있어서** 입니다."

### 필수 미션 — Canvas Scaler 잡기

| ③ | Reference Resolution → **1280 × 720** |
| ④ | Match → **0.5** |

<details>
<summary>막히면 열기 (정답)</summary>

**Game 뷰 해상도 추가**
Game 뷰 상단 드롭다운 → 맨 아래 `+` → Type: `Fixed Resolution`, Width `640`, Height `480`, Label `640x480` → OK.

**Canvas Scaler**

| 항목 | 값 |
|---|---|
| UI Scale Mode | `Scale With Screen Size` |
| Reference Resolution X | `1280` |
| Reference Resolution Y | `720` |
| Screen Match Mode | `Match Width Or Height` |
| Match | `0.5` |

> 🚨 **Reference Resolution 을 바꾸면 UI 크기가 통째로 변한다.**
> `1280x720` 으로 맞춘 다음 다른 값으로 바꾸지 않는다. **이 프로젝트의 기준은 1280×720 이다.**

**확인하는 법**
Play 중에 `HUD` 의 `Canvas` 컴포넌트를 보면 `Scale Factor` 가 회색으로 표시된다.
`640x480` 에서 `0.577`, `1920x1080` 에서 `1.5` 가 나오면 맞다.

</details>
