## 00:10–00:50 · 같이 하기 ★

### ① 주변을 한꺼번에 훑는다 (12분)

`Scripts/Player/PlayerAttack.cs`

```csharp
using UnityEngine;

public class PlayerAttack : MonoBehaviour
{
    [SerializeField] private float attackRadius = 3f;
    [SerializeField] private int damage = 4;

    public void Swing()
    {
        Collider2D[] hits = Physics2D.OverlapCircleAll(transform.position, attackRadius);

        int count = 0;

        foreach (Collider2D hit in hits)
        {
            // 내 몸도 목록에 들어온다. 안 걸러내면 내가 나를 때린다.
            if (hit.gameObject == gameObject) continue;

            if (hit.TryGetComponent(out IDamageable target))
            {
                target.TakeDamage(damage);
                count++;
            }
        }

        Debug.Log($"휘두르기 — {count}마리 명중");
    }
}
```

| 조각 | 뜻 |
|---|---|
| `Physics2D.OverlapCircleAll(위치, 반지름)` | **그 원 안에 있는 Collider 전부**를 배열로 준다 |
| `hit.gameObject == gameObject` | **나 자신**을 걸러낸다 |
| `TryGetComponent(out IDamageable target)` | 맞을 수 있는 놈만 골라낸다 (070) |

> 🚨 **`if (hit.gameObject == gameObject) continue;` 를 빼면 내가 나를 때린다.**
> 플레이어도 `IDamageable` 이기 때문이다. 반드시 겪게 한 뒤 고친다.

> 💬 "이 코드에 **`Enemy` 라는 글자가 있나요?** 없죠."
> 💬 "플레이어는 **뭘 때리는지 모릅니다.** 그냥 '맞을 수 있는 것' 을 때려요."

### ③ Space 로 때린다 + 쿨다운 (10분)

```csharp
[SerializeField] private float cooldown = 0.4f;

private float nextAttackTime;

private void Update()
{
    if (!Input.GetKey(KeyCode.Space)) return;
    if (Time.time < nextAttackTime) return;

    nextAttackTime = Time.time + cooldown;
    Swing();
}
```

**쿨다운 없이 먼저 해본다.**

▶ Space 를 꾹 누른다 → **매 프레임 공격**한다. Console 이 폭발하고 몬스터가 순식간에 사라진다.

> 💬 "재미없죠? **누르고 있으면 다 죽어요.**"
> 💬 "그리고 이건 061에서 본 것과 **같은 문제**입니다. `Update` 는 매 프레임 돕니다."

| 조각 | 뜻 |
|---|---|
| `Time.time` | 게임이 시작하고 지난 시간(초) |
| `nextAttackTime` | **다음에 때릴 수 있는 시각** |
| `Time.time < nextAttackTime` | 아직 그 시각이 아니면 그냥 나간다 |

> 💡 **`Invoke` 나 코루틴을 안 써도 된다.** "다음 시각을 적어두고 비교" 가 제일 간단하다.
> 078회차의 무기 쿨다운도 이 방식이다.


> 🔑 💬 "**부모의 `Die()` 한 곳**에만 넣었습니다. 그런데 **세 종류가 다 세어져요.**"
> 💬 "몬스터를 열 종류로 늘려도 **여기 한 줄이면 끝**입니다. 이게 070에서 상속을 쓴 이유예요."

> 🚨 **`if (GameManager.Instance != null)`** 가 필요하다.
> 매니저가 없는 씬에서 몬스터를 테스트하면 `NullReferenceException` 이 난다.

### ⭐ 도전 미션

- [ ] `attackRadius` 를 `1.5` 로 줄여 **아슬아슬하게** 만들어본다
- [ ] `damage` 를 `2` 로 낮추고 탱커를 잡는 데 **몇 번** 걸리는지 세어본다
- [ ] 공격할 때 화면에 **원을 잠깐 그려준다** (`LineRenderer` 또는 스프라이트 켰다 끄기)
- [ ] 처치 수가 **10의 배수**가 될 때마다 Console 에 축하 로그를 찍는다
- [ ] `Physics2D.OverlapCircleAll` 대신 **`OverlapBoxAll`** 로 바꿔 네모 범위를 만든다
- [ ] 가장 가까운 한 마리만 때리게 바꾼다 (064의 최솟값 찾기 — **078회차 예습**)
- [ ] HUD 에 **살아있는 몬스터 수**도 표시한다

> 💡 여섯 번째 도전이 **078회차 자동 조준의 예습**이다. 해본 학생은 데모시킨다.
