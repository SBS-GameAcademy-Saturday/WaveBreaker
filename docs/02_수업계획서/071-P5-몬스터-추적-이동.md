## 00:10–00:45 · 같이 하기 ★

### ① 쫓아오게 만든다 (10분)

`Enemy.cs` 에 세 가지를 더한다.

```csharp
[SerializeField] protected float moveSpeed = 2f;

protected Rigidbody2D rb;
protected SpriteRenderer sprite;
protected Transform player;

protected virtual void Awake()
{
    rb = GetComponent<Rigidbody2D>();
    sprite = GetComponent<SpriteRenderer>();
}

protected virtual void Start()
{
    currentHealth = maxHealth;

    GameObject found = GameObject.FindWithTag("Player");

    if (found != null)
    {
        player = found.transform;
    }
}

protected virtual void FixedUpdate()
{
    if (player == null) return;

    Vector2 dir = ((Vector2)player.position - rb.position).normalized;

    rb.linearVelocity = dir * moveSpeed;
}
```

▶ Play → 몬스터가 걸어온다.

**한 조각씩 짚는다.**

| 조각 | 뜻 | 어디서 배웠나 |
|---|---|---|
| `protected` | 자식도 쓸 수 있게 | 070 |
| `Awake` 에서 `GetComponent` | 한 번만 찾는다 | 049 |
| `FindWithTag` 를 `Start` 에 | 무거운 함수라 한 번만 | 063 |
| `목표 - 나` `.normalized` | 방향만 남긴다 | 063 |
| `FixedUpdate` | 물리는 여기서 | 042 |

> 🚨 **`Awake` 도 `virtual` 로 만든다.** 자식이 나중에 자기 부품을 더 찾아야 할 수 있다.
> 070에서 `Start` 를 `virtual` 로 만든 것과 같은 이유다.

> 🚨 **`if (player == null) return;`** 이 없으면 플레이어가 죽는 순간 에러가 쏟아진다.
> 063에서 이미 겪은 것과 같다.

### ② 가는 방향으로 그림을 뒤집는다 (5분)

```csharp
rb.linearVelocity = dir * moveSpeed;
sprite.flipX = dir.x < 0f;
```

> 💬 "067에서 플레이어에 한 거랑 **똑같습니다.**"
> 💬 "몬스터는 `if` 가 필요 없어요. **항상 움직이니까** `dir.x` 가 0인 순간이 거의 없습니다."

### ③ 오늘의 핵심 — `Move()` 로 빼낸다 (15분)

**여기서 반드시 학생이 먼저 질문하게 만든다.**

> 💬 "이동 부분만 **따로 메서드로 빼겠습니다.**"

```csharp
protected virtual void FixedUpdate()
{
    if (player == null) return;

    Move();
}

protected virtual void Move()
{
    Vector2 dir = ((Vector2)player.position - rb.position).normalized;

    rb.linearVelocity = dir * moveSpeed;
    sprite.flipX = dir.x < 0f;
}
```

▶ Play → **똑같이 동작한다.**

> 💬 "동작이 하나도 안 바뀌었죠. 그럼 **왜 나눴을까요?**"
> 학생 답을 기다린다. 안 나오면 힌트: "`virtual` 이 붙어 있죠?"

> 💬 "다음 시간에 몬스터가 **세 종류**가 됩니다."
> 💬 "그중 하나는 **다르게 움직여요.** 그때 이 `Move()` 만 갈아끼우면 됩니다."
> 💬 "지금 안 나눠두면, 그때 `FixedUpdate` 를 통째로 복사해야 해요."

**칠판**

```
지금                                     다음 시간
─────────────────                        ─────────────────
Enemy.Move()   ← 플레이어를 향해           Enemy.Move()        ← 그대로
                                         RunnerEnemy.Move()  ← 직진만 (override)
```

> 🔑 **이게 이번 Phase 가 가르치는 방식이다.**
> **필요해지기 한 회차 전에 자리를 만들어 둔다.** 그러면 다음 시간이 3줄로 끝난다.

<summary>막히면 열기 (정답)</summary>

```csharp
using UnityEngine;

public abstract class Enemy : MonoBehaviour, IDamageable
{
    [SerializeField] protected int maxHealth = 10;
    [SerializeField] protected int damage = 1;
    [SerializeField] protected float moveSpeed = 2f;

    protected int currentHealth;
    protected Rigidbody2D rb;
    protected SpriteRenderer sprite;
    protected Transform player;

    protected virtual void Awake()
    {
        rb = GetComponent<Rigidbody2D>();
        sprite = GetComponent<SpriteRenderer>();
    }

    protected virtual void Start()
    {
        currentHealth = maxHealth;

        GameObject found = GameObject.FindWithTag("Player");

        if (found != null)
        {
            player = found.transform;
        }
    }

    protected virtual void FixedUpdate()
    {
        if (player == null) return;

        Move();
    }

    protected virtual void Move()
    {
        Vector2 dir = ((Vector2)player.position - rb.position).normalized;

        rb.linearVelocity = dir * moveSpeed;
        sprite.flipX = dir.x < 0f;
    }
}
```

씬 설정도 확인한다.

| 오브젝트 | 확인할 것 |
|---|---|
| `Enemy` | `Rigidbody 2D` Gravity Scale `0` · Freeze Rotation Z |
| `Player` | Tag 가 `Player` 다 |

</details>

**확인 조건**: 어디로 도망가도 몬스터가 따라온다. 왼쪽으로 갈 때 몬스터 그림이 뒤집힌다.
부딪히면 Console 에 피해 로그가 나온다.

### ⭐ 도전 미션

- [ ] `moveSpeed` 를 `6` 으로 올려 **도망칠 수 없게** 만들어본다 (그리고 되돌린다)
- [ ] 몬스터를 5마리 복사해서 놓는다 — **서로 밀리는 걸** 관찰한다
- [ ] `.normalized` 를 지우고 실행 → **왜 멀수록 빨라지는지** 한 줄로 쓴다
- [ ] `목표 - 나` 를 `나 - 목표` 로 뒤집어 **도망가게** 만들어본다
- [ ] `Move()` 안을 통째로 지우고 `rb.linearVelocity = Vector2.up * moveSpeed;` 로 바꿔본다
- [ ] `Rigidbody 2D` 의 `Linear Damping` 을 `5` 로 올려보고 뭐가 달라지는지 쓴다
- [ ] 플레이어와의 거리를 `Debug.Log` 로 찍어본다 (`Vector2.Distance`, 064)

> 💡 다섯 번째 도전이 **다음 시간의 예습**이다. `Move()` 만 바꾸면 완전히 다른 몬스터가 된다.
