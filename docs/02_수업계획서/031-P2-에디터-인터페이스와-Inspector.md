## 00:10–00:45 · 같이 치기 ★

> 🚨 **여기서 못을 박는다.** 화면 공유로 경로를 한 명씩 확인한다.
> 💬 "이거 안 지키면 **21주차 빌드에서 터집니다.** 그때 고치면 프로젝트를 다시 만들어야 해요."
>

> ⚠️ 첫 실행은 **1~3분 걸린다.** 미리 말하지 않으면 "멈췄어요"가 쏟아진다.

### ② 6개 창 — 이름과 역할 (10분)

> 💬 "이름만 외우세요. 뭘 하는 창인지는 쓰면서 알게 됩니다."

| 창 | 한 줄 | 학생이 실제로 하는 일 |
|---|---|---|
| **Hierarchy** | 지금 씬에 **있는 것들의 목록** | 클릭해서 고른다 |
| **Scene** | 내가 **배치하는** 작업대 | 끌어서 옮긴다 |
| **Game** | 플레이어가 **보게 될** 화면 | 결과를 본다 |
| **Inspector** | 고른 것의 **설정판** | ⭐ **숫자를 바꾼다** |
| **Project** | 이 프로젝트의 **파일 전부** | 파일을 만든다 |
| **Console** | **에러와 메시지**가 뜨는 곳 | 빨간 줄을 읽는다 |

**Scene과 Game의 차이를 실습으로 보여준다.** Scene에서 시점을 돌려도 Game 화면은 그대로다.

> 💬 "Scene은 **작업대**, Game은 **손님이 보는 접시**입니다."

> 🔧 **창을 잃어버렸을 때**: `Window → Layouts → Default`. 오늘 반드시 알려준다.
> 학생이 창을 실수로 닫거나 떼어내는 일이 첫 주에 가장 많다.

### ③ Scene 창 조작법 3가지 (7분)

**손에 붙을 때까지 같이 반복한다.** 이게 안 되면 이후 모든 회차가 느려진다.

| 조작 | 결과 |
|---|---|
| **마우스 휠** | 확대 / 축소 |
| **가운데 버튼 드래그** | 화면 밀기 (Pan) |
| **오브젝트 클릭 후 `F`** | 그 물체로 **날아가기** |

> 💬 "물체가 안 보이면 이거 하나만 기억하세요. **클릭하고 F.**"
>
> ⚠️ 마우스가 **Scene 창 위에** 있어야 `F`가 먹는다. 안 짚으면 "F 눌러도 안 돼요"가 나온다.
> ⚠️ 한/영 키가 한글이면 안 먹는다. **"F가 안 되면 한영키."**

**툴바 좌측 5개 아이콘**도 짚는다: 손(Pan) / 이동 / 회전 / 크기 / 사각형. 단축키 `Q W E R T`.

> 💬 "`W`가 이동, `E`가 회전, `R`이 크기예요. 지금은 `W`만 써도 됩니다."

### ④ Inspector — 오늘의 중심 (12분)

Hierarchy 우클릭 → **2D Object → Sprites → Square** (이름 `Box`)

`Box`를 클릭한다. **Inspector에 뭐가 떴는지 같이 읽는다.**

```
Box                          ← 이름. 체크박스 = 켜기/끄기
├── Transform                ← 어디에 / 얼마나 돌아서 / 얼마나 크게
│   ├── Position   X  Y  Z
│   ├── Rotation   X  Y  Z
│   └── Scale      X  Y  Z
└── Sprite Renderer          ← 무슨 그림으로 보일지
    ├── Sprite
    └── Color
```

**세 가지를 직접 시킨다.**

| 시키는 것 | 학생이 보는 것 |
|---|---|
| Position X에 `3` 입력 | 물체가 **오른쪽으로** 간다 |
| Position Y에 `2` 입력 | 물체가 **위로** 간다 |
| Sprite Renderer → Color 클릭 → 빨강 | 색이 바뀐다 |

> 💬 "코드 한 줄 없이 물체를 움직였죠. **Inspector는 설정판이자 리모컨입니다.**"

**숫자 칸 드래그를 반드시 알려준다.**

> 💬 "숫자 위에 마우스를 올리면 커서가 ↔ 로 바뀝니다. 그 상태로 **좌우로 끌어보세요.**"
> → 반응이 가장 좋은 지점이다. 여기서 학생이 유니티를 재밌다고 느낀다.

**체크박스로 껐다 켜기**

이름 왼쪽 체크박스를 끄면 물체가 사라진다. 켜면 돌아온다.

> 💬 "지운 게 아니라 **꺼둔** 겁니다. 이건 040회차에 코드로 하게 됩니다." ← `SetActive` 복선

> ⚠️ **아직 Play를 누르지 않는다.** 오늘은 Play 없이 Scene에서만 논다.
> Play를 누르면 "Play 중 변경 날림" 사고가 오늘부터 시작된다. 그건 037회차 주제다.

## 00:55–01:35 · 개인 미션

### 필수 미션 — 얼굴 만들기

Square와 Circle만으로 **얼굴 하나**를 만든다. **코드 없음, Play 없음.**

- [ ] `Circle` 하나로 얼굴 윤곽을 만든다 (Scale로 크게)
- [ ] `Circle` 두 개로 눈을 만든다 (Position으로 배치)
- [ ] `Square` 하나로 입을 만든다 (Scale로 납작하게)
- [ ] 각 부위의 **색을 다르게** 준다
- [ ] Hierarchy에서 이름을 알아보게 바꾼다 (`Face`, `EyeL`, `EyeR`, `Mouth`)
- [ ] 씬을 저장한다

**확인 조건**: Scene 창에 얼굴이 보이고, Hierarchy 이름만 봐도 뭐가 뭔지 안다.

<details>
<summary>막히면 열기 (값 예시)</summary>

| 오브젝트 | Position (X, Y) | Scale (X, Y) | Color |
|---|---|---|---|
| `Face` (Circle) | 0, 0 | 4, 4 | 노랑 |
| `EyeL` (Circle) | -0.8, 0.7 | 0.5, 0.5 | 검정 |
| `EyeR` (Circle) | 0.8, 0.7 | 0.5, 0.5 | 검정 |
| `Mouth` (Square) | 0, -0.8 | 2, 0.3 | 검정 |

눈이 얼굴 **뒤에 가려지면** `Sprite Renderer → Order in Layer`를 `1`로 올린다.
(왜 그런지는 Phase 3에서 제대로 다룬다. 지금은 "앞으로 꺼내는 숫자"로만)
</details>

### ⭐ 도전 미션

- [ ] Rotation Z를 바꿔서 얼굴을 기울인다
- [ ] Scale X에 **음수**를 넣고 뭐가 달라지는지 한 줄로 쓴다
- [ ] `Order in Layer`를 바꿔가며 **누가 앞에 오는지** 실험한다
- [ ] Hierarchy에서 `EyeL`을 `Face` **안으로 끌어넣고**, `Face`의 Position을 바꿔본다
- [ ] `Window → Layouts`에서 다른 배치(`2 by 3` 등)를 써보고 마음에 드는 걸 고른다
- [ ] 툴바의 `Q W E R T`를 전부 눌러보고 각각 뭘 하는지 정리한다

## 🚨 흔한 사고 & 대응 (강사용)

| 에러/상황 | 진짜 원인 | 대응 |
|---|---|---|
| **"물체가 안 보여요"** | 화면 밖 / 카메라 밖 | **오늘 1등 질문.** Hierarchy 클릭 → `F`. 매번 같은 말로 |
| `F`가 안 먹음 | 마우스가 Scene 창 밖 / 한영키 | "마우스를 Scene 위에" + "한영키" |
| 창을 닫아버림 | 실수로 X 클릭 | `Window → Layouts → Default` |
| 창이 떨어져 나감 | 탭을 밖으로 드래그 | 위와 동일. **첫 주 최다 사고** |
| Inspector가 비어 있음 | 아무것도 선택 안 함 | Hierarchy에서 클릭해야 뜬다 |
| 물체가 서로 가려짐 | Order in Layer가 같음 | `1`로 올린다. 깊은 설명은 Phase 3 |
| Position Z를 건드림 | 2D에서 의미 거의 없음 | "2D는 X, Y만. Z는 0으로 두세요" |
| 프로젝트 경로가 한글 | 사용자 이름이 한글 | **지금 다시 만든다.** 나중에 고치면 훨씬 비싸다 |
| 첫 실행이 오래 걸림 | 정상 (1~3분) | 미리 공지 |
| Play를 눌러버림 | 호기심 | 오늘은 Stop시킨다. "Play는 다음 주부터" |
| "6주 배운 게 안 나오네요" | 정당한 의문 | "다음 주부터 나옵니다. 오늘은 도구 익히는 날" |
