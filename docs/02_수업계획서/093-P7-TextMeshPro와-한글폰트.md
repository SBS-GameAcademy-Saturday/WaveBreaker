## 00:10–00:45 · 같이 하기 ★

### ① TMP 는 왜 쓰나 — SDF (8분)

Unity 에는 글자 컴포넌트가 두 개 있다.

| | 레거시 `Text` | **`TextMeshPro`** |
|---|---|---|
| 원리 | 픽셀 그림 | **SDF (거리 정보)** |
| 확대하면 | **뭉개진다** | **선명하다** |
| 외곽선·그림자 | 어렵다 | 인스펙터 체크 한 번 |
| 리치 텍스트 | 제한적 | `<size>` `<color>` `<b>` |
| Unity 권장 | ❌ 사실상 폐기 | ✅ |

> 💬 "**SDF = Signed Distance Field.** 글자 그림 대신 **'글자 경계선까지의 거리'** 를 저장합니다."
> 💬 "거리를 알고 있으니 아무리 키워도 경계선을 다시 계산할 수 있어요. **그래서 안 뭉개집니다.**"

▶ `CenterText` 의 Font Size 를 `56` → `200` 으로 올려 보여준다. 선명하다.

> 💡 우리는 085회차에서 이미 `<size=60%>` 를 썼다. 그게 TMP 의 리치 텍스트다.

### ② Font Asset 이란 (10분)

**폰트 파일(`.ttf`) 을 그대로 못 쓴다.** TMP 는 `.asset` 을 하나 더 만들어 쓴다.

```
Pretendard-Regular.ttf   ← 원본 폰트 (글자 모양 정보)
        ↓ TMP 가 구워낸다
Pretendard SDF.asset     ← 폰트 애셋 (아틀라스 그림 + 글자 위치표)
```

**우리 배포본을 뜯어본 값**

| 항목 | 값 | 뜻 |
|---|---|---|
| 소스 폰트 | `Pretendard-Regular` | 원본 `.ttf` |
| 렌더 모드 | `SDFAA` | SDF + 안티에일리어싱 |
| 아틀라스 크기 | **1024 × 1024** | 글자를 구워 넣는 그림 한 장 |
| 멀티 아틀라스 | **켜짐** | 한 장이 차면 **자동으로 한 장 더** |
| 패딩 | 9 | 글자 사이 여백 (외곽선 여유) |
| 생성 방식 | **`Dynamic`** | ← 오늘의 핵심 |
| 지금 담긴 글자 수 | **96** | 11,172자가 아니다 |
| 파일 크기 | 약 3.0 MB | |

### ③ Static 과 Dynamic (10분) — 오늘의 핵심

| | **Static** | **Dynamic** |
|---|---|---|
| 언제 굽나 | **미리 전부** | **화면에 나올 때 그때그때** |
| 한글이면 | 11,172자를 다 구워야 | **쓴 글자만** 들어간다 |
| 애셋 크기 | 크다 | 작게 시작해 **자란다** |
| 없는 글자 | **□** | **그 자리에서 만들어 넣는다** |
| 원본 `.ttf` | 빌드에 없어도 된다 | **빌드에 있어야 한다** |

**실측 비교**

```
LiberationSans SDF   생성 방식=Static    담긴 글자 수=250
Pretendard SDF       생성 방식=Dynamic   담긴 글자 수=96
```

> 🔑 💬 "`LiberationSans` 는 **250자를 미리 다 구워둔** 겁니다. 영어라 그걸로 충분해요."
> 💬 "한글로 그걸 하면 **11,172자**입니다. 애셋이 수십 MB 가 됩니다."
> 💬 "그래서 한글은 **Dynamic** 을 씁니다. 우리 게임에 실제로 나온 글자가 **96자** 뿐이거든요."

> 🚨 **Dynamic 의 함정**: 게임 중에 처음 나온 글자는 **그 프레임에 구워진다.**
> 아주 잠깐 끊길 수 있다. 우리 게임 규모에선 티가 안 난다.
> 💡 Phase 8(빌드) 에서 **자주 쓰는 글자를 미리 채워두는 법**을 다시 본다.

### ④ 프로젝트에 넣고 전부 적용 (12분)

**① 배포본 임포트**

강사가 준 `Pretendard_SDF.unitypackage` 를 더블클릭 → Import.
`Assets/_GameAssets/Fonts/` 에 두 파일이 들어온다.

| 파일 | 정체 |
|---|---|
| `Pretendard-Regular.ttf` | 원본 폰트 |
| `Pretendard SDF.asset` | **폰트 애셋** ← 이걸 쓴다 |

> ⚠️ **`.ttf` 를 지우면 안 된다.** Dynamic 이라 원본이 필요하다.

**② 전 UI 에 적용**

`HUD` 아래 글자를 **전부** 바꾼다. 하나라도 빠지면 그 자리만 □ 가 된다.

| 오브젝트 | 크기 |
|---|---|
| `LevelLabel` | 32 |
| `TimeLabel` | 40 |
| `KillLabel` | 32 |
| `HealthBar/Label` | 18 |
| `CenterText` | 56 |
| `LevelUpPanel/Title` | 52 |
| `Card_0/1/2 의 Label` | 30 |

> 💡 **한 번에 바꾸는 법**: Hierarchy 에서 여러 개를 `Ctrl` 클릭으로 고르면
> Inspector 에서 **Font Asset 을 한 번에** 지정할 수 있다.

**③ 기본 폰트로 지정해두기**

`Edit → Project Settings → TextMesh Pro → Settings` 의
**Default Font Asset** 을 `Pretendard SDF` 로 바꾼다.

> 💬 "이러면 **앞으로 만드는 글자는 처음부터 한글이 나옵니다.**"
> 💬 "096회차에 UI 를 많이 만들 텐데, 그때 안 하면 매번 손으로 바꿔야 해요."

▶ Play → HUD·레벨업 창·게임오버 전부 확인.

### ⑤ Fallback — 없는 글자를 다른 폰트에서 (5분)

> 💬 "일본어나 이모지가 섞이면요? 폰트 하나로는 못 덮습니다."

`Project Settings → TextMesh Pro → Settings → Fallback Font Assets` 에
**순서대로** 폰트 애셋을 넣으면, 없는 글자를 **다음 폰트에서 찾는다.**

**실측** — 우리 프로젝트

```
Pretendard SDF  fallback 개수 = 0
```

> 💬 "지금은 **0개입니다.** 한글·영어·숫자가 다 Pretendard 에 있으니까요."
> 💬 "필요해지면 그때 넣습니다. **지금 미리 넣을 이유가 없어요.**"
