## 1. 구성 방침 — C# 선행

| 구간 | 주차 | 내용 |
|---|---|---|
| C# 전용 | 1~4주 | 콘솔 기반 문법 (변수~메서드·디버깅) |
| C# 객체지향 | 5~6주 | 클래스·상속·인터페이스 (콘솔) |
| **C# + 유니티 병행** | **7주~** | 유니티 입문 → 2D 핵심 → 게임 제작 |

**대가를 정확히 안 상태로 선택한 구성이다.** 게임 제작 시간이 이전 구성 대비 10회차(20시간) 줄었다. 그 대신 문법 기반이 탄탄해져 Phase 5 이후 설명 비용이 낮아진다.

> ⚠️ **최대 리스크: 1~4주차 콘솔 구간의 이탈.** 대응 장치는 [주차별-커리큘럼표.md](./주차별-커리큘럼표.md) 하단 참고.

## 2. 만들 게임: 웨이브 브레이커 (`WaveBreaker`)

**📄 사양서: [확정-게임기획서.md](./확정-게임기획서.md)** — Phase 5~10 강의안은 전부 이 문서 기준.

아레나 하나에서 몰려오는 몬스터를 막는다. 10웨이브 클리어, 한 판 5~7분. 무기 3종 / 몬스터 3종 + 보스 / 업그레이드 8종 / **동시 화면 몬스터 최대 15**.

**타이틀에서 두 가지를 고른다**

- **[혼자 하기]** — 싱글. Phase 8(21주차)에 먼저 완성된다
- **[같이 하기]** — 방을 만들어 코드를 주면 친구가 입장. Phase 9(22~25주차)에서 붙인다

> 🔑 **내부적으로는 하나의 코드다.** 싱글 = "아무도 안 들어온 방(호스트 1인)". 싱글용·멀티용 코드를 따로 두면 같은 기능을 두 번 만들고 두 번 고쳐야 한다.

**후보 4개를 비교해 A를 선택했다** → [후보검토/](./후보검토/)
- B(던전 탐험): 방 전환 동기화·레벨 디자인 공수로 탈락
- C(1v1 대전): 싱글 완결이 안 돼 안전장치가 무너지고, 몬스터 AI가 없어 교육 소재 절반이 사라져 탈락
- D(타워디펜스): 2순위. A→D 전환은 가능하나 역은 불가

## 3. 기술 스택 선택 근거

| 항목 | 선택 | 근거 |
|---|---|---|
| 엔진 | **Unity 6 LTS 고정** | Multiplayer Play Mode가 Unity 6 이상 요구. 이걸로 버전 논쟁이 끝난다 |
| 네트워크 | **Netcode for GameObjects** | Unity 공식, 패키지 매니저 설치, 노베이스에게 설명 가능한 최소 개념 수 |
| 접속 | **Relay** | 포트포워딩·공유기 설정 불필요. 학생 집 네트워크가 제각각인 비대면에서 필수 |
| 로컬 테스트 | **Multiplayer Play Mode** | 에디터 하나에서 가상 플레이어 최대 3개. 외부 도구·프로젝트 복제 불필요 |
| 에셋 | **Kenney CC0** | 출처 표기 불필요, 상업 이용 가능 → 포트폴리오에 그대로 사용 |

📄 에셋 상세: [에셋-리소스.md](./에셋-리소스.md)

## 4. 이 과정을 지탱하는 원칙 4가지

**① 21주차에 싱글 완성본을 확정하고 백업한다**
네트워크는 그 위에 얹는 별도 레이어. 네트워크가 끝내 안 되는 학생도 **이미 빌드된 완성작을 갖고 종강한다.** 최대 안전장치.

**② Phase마다 스냅샷 프로젝트를 배포한다**
뒤처진 학생이 완성된 중간 프로젝트를 받아 다음 회차에 정상 합류한다. 7개월 과정에서 완주율을 가장 크게 바꾸는 장치.

**③ 불편함을 먼저 겪게 한 뒤 해결책을 준다**
풀링은 렉을 겪은 뒤에(101회차), 씬 전환 데이터 소실은 겪은 뒤에. 순서가 바뀌면 코드만 베낀다.

**④ 14주차에 Phase 1 콘솔 코드를 다시 꺼낸다**
6주차에 콘솔로 짠 `Enemy` 상속·`IDamageable`을 유니티로 옮기는 형태로 본 프로젝트를 시작한다. C# 선행 구성의 투자를 회수하는 지점이다.

## 5. 진도가 밀릴 때

**축소 순서** (위에서부터)
1. 폭발탄 (무기 3종 → 2종)
2. 보스 → 강화된 탱커 웨이브로 대체
3. 업그레이드 8종 → 5종
4. 탱커형 몬스터 삭제
5. 웨이브 10 → 7
6. 미니게임 3개 → 2개(①③) — 5회차 회수

**절대 자르지 않는 것**
- ❌ 업그레이드 3택 시스템 — 없으면 그냥 총 쏘는 화면이다
- ❌ 21주차 싱글 빌드·백업 — 안전장치
- ❌ 동료 부활 메커닉 — 협동의 유일한 근거

**하드 게이트**: 105회차(21주차 종료) 전원 빌드+백업 미달 시 Phase 9로 진입하지 않는다. 버퍼를 여기 쓴다.
