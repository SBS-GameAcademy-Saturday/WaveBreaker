# 리소스 교체 가이드 — 나중에 진짜 그림으로 바꾸기

> **질문**: "지금은 임시 그림인데, 나중에 리소스를 추가하면 그걸로 교체할 수 있나?"
> **답**: **된다.** 이 문서가 그 절차다.
>
> 관련 문서: [미니게임-3종-기획.md](./미니게임-3종-기획.md) · [에셋-리소스.md](./에셋-리소스.md)

---

## 1. 왜 교체가 되는가 — GUID

유니티는 에셋을 **파일 경로가 아니라 GUID(고유 번호)** 로 참조한다.
GUID는 `.meta` 파일에 들어 있다.

```
Assets/_GameAssets/Sprites/Characters/Player_Walk.png
Assets/_GameAssets/Sprites/Characters/Player_Walk.png.meta   ← 여기에 guid 가 있다
```

프리팹·애니메이션 클립·씬은 전부 이 GUID를 가리킨다.

```yaml
# Player.prefab 안 (일부)
m_Sprite: {fileID: 21300000, guid: a1b2c3..., type: 3}
```

> 🔑 **그러니까 `.meta` 를 유지한 채 이미지 내용만 바꾸면, 아무것도 안 고쳐도 새 그림이 나온다.**
> 이게 아래 **방법 A** 다.

---

## 2. 방법 A — 같은 이름으로 덮어쓰기 ⭐ 권장

**가장 안전하고 손이 제일 적게 간다.**

### 절차

1. **유니티를 켜 둔 채로** 탐색기에서 새 그림을 같은 경로·같은 파일명으로 복사한다
   ```
   Assets/_GameAssets/Sprites/Characters/Player_Walk.png  ← 덮어쓴다
   ```
2. **`.meta` 파일은 건드리지 않는다** (덮어쓰지도, 지우지도 않는다)
3. 유니티로 전환 → 자동 재임포트
4. 임포트 설정을 확인한다 (PPU · Filter · Compression — 아래 3장)

### 이때 자동으로 따라오는 것

| 무엇 | 따라오나 |
|---|---|
| 프리팹의 `Sprite` 칸 | ✅ |
| 애니메이션 클립의 프레임 | ✅ **단, 슬라이스 이름이 같아야 한다** |
| 씬에 놓인 오브젝트 | ✅ |
| Collider 크기 | ❌ **안 따라온다** (043에서 배운 그대로) |

> ⚠️ **`.meta` 를 지우면 GUID가 새로 생긴다.** 그러면 프리팹이 전부 끊어져
> Missing(분홍색)이 된다. **절대 지우지 않는다.**

---

## 3. 방법 B — 새 파일을 추가하고 갈아 끼우기

파일명을 바꾸고 싶거나, 여러 후보를 놓고 고르고 싶을 때.

### 절차

1. 새 그림을 `Assets/_GameAssets/Sprites/` 아래에 넣는다 (이름은 자유)
2. 임포트 설정 3줄 적용 (아래 4장)
3. **프리팹을 열어** `Sprite Renderer` 의 `Sprite` 칸에 새 그림을 드래그
4. 프리팹 저장 → **씬의 인스턴스가 전부 반영된다** (046회차)

> 💡 **프리팹 하나만 고치면 끝**이라는 게 046회차의 요점이다. 씬을 하나씩 고칠 필요 없다.
>
> ⚠️ 씬에 **직접 놓인** 오브젝트(프리팹이 아닌 것)는 따로 고쳐야 한다.
> 이 프로젝트에서는 `Paddle`, `Wall_*`, `Background` 가 그렇다.

---

## 4. 임포트 설정 — 무조건 이 세 줄

**어느 방법을 쓰든 이건 매번 확인한다.** 053회차에서 가르치는 그대로다.

| 항목 | 값 | 안 하면 |
|---|---|---|
| **`Pixels Per Unit`** | **32** | 캐릭터 크기가 제각각이 된다 |
| **`Filter Mode`** | **Point (no filter)** | 그림이 흐릿해진다 |
| **`Compression`** | **None** | 화질이 깎인다 |

그리고 **`Apply`** 를 누른다. 안 누르면 아무것도 안 바뀐다.

> 🚨 **PPU 32 는 이 프로젝트의 약속이다.** 32픽셀 = 1유닛.
> Kenney 팩은 원본이 64×64 인 경우가 많은데, 그럴 땐 **PPU를 64로 통일**하거나
> **그림을 32로 줄여서** 넣는다. **섞으면 안 된다.**
>
> 📐 판단 기준: 캐릭터 한 명이 **화면 세로의 1/12 정도**로 보이면 적당하다
> (카메라 `orthographicSize = 6` → 세로 12유닛).

## 5. 애니메이션이 있는 그림 (걷기 시트)

**이게 제일 조심할 부분이다.**

애니메이션 클립은 스프라이트를 **슬라이스 이름**으로 기억한다.

```
Player_Walk.png
 ├ Player_Walk_0   ← 클립이 이 이름들을 순서대로 참조한다
 ├ Player_Walk_1
 ├ Player_Walk_2
 └ Player_Walk_3
```

### 클립을 살리면서 교체하려면

1. 새 시트를 **같은 파일명**으로 덮어쓴다 (방법 A)
2. `Sprite Mode = Multiple` → `Sprite Editor` → `Slice`
3. **`Grid By Cell Size`** 로 자르고, **이름이 `Player_Walk_0 ~ _3` 이 되는지 확인**
4. 프레임 수가 다르면? → **클립을 다시 만든다** (054회차 절차, 5분)

| 상황 | 클립 |
|---|---|
| 프레임 수 같음 + 이름 같음 | ✅ 그대로 산다 |
| 프레임 수 다름 | ❌ 다시 만든다 |
| 이름 다름 | ❌ 다시 만든다 |

> 💡 **클립 다시 만드는 게 5분이면 된다.** 이름 맞추느라 30분 쓰지 말고 그냥 다시 만든다.
> 054회차 절차: 오브젝트 선택 → `Ctrl+6` → 그림 전체 선택 → 타임라인에 드래그 → `Samples` 10.

### 현재 프로젝트의 클립

| 클립 | 참조하는 것 | 프레임 |
|---|---|---|
| `Player_Walk.anim` | `Player_Walk_0` ~ `_3` | 4 (10fps) |
| `Enemy_Walk.anim` | `Enemy_Walk_0` ~ `_1` | 2 (6fps) |

## 6. 교체 후 확인 체크리스트

교체한 다음 **반드시** 이 순서로 확인한다.

- [ ] 1. 프리팹이 **분홍색(Missing)** 이 아닌가 → 분홍이면 `.meta` 를 지웠다
- [ ] 2. 크기가 다른 것들과 **맞는가** → 안 맞으면 PPU
- [ ] 3. 확대해서 **또렷한가** → 흐리면 Filter Mode
- [ ] 4. **Collider(초록 선)** 가 그림과 맞는가 → `⋮ → Reset` 또는 `Edit Collider`
- [ ] 5. 애니메이션이 **도는가** → 안 돌면 클립 다시 만들기
- [ ] 6. **Sorting Layer** 가 맞는가 → 배경이 캐릭터를 가리지 않는지 (045)
- [ ] 7. 미니게임 3종을 **Play 로 전부** 확인

> 🚨 **4번(Collider)이 가장 자주 빠진다.** 그림만 바뀌고 판정은 그대로라
> "왜 안 맞아요" 가 나온다. 043회차의 초록 선 이야기 그대로다.

---

## 7. 배경을 새로 넣을 때

미니게임 3종은 지금 **배경이 없다** (단색). 배경을 넣을 때는 이렇게 한다.

1. 배경 그림을 `Assets/_GameAssets/Sprites/Environment/` 에 넣는다
2. 씬에 빈 Square 를 놓고 `Sprite` 를 배경으로 지정
3. **`Sorting Layer = Background`** 로 (045회차)
4. Scale 로 화면을 덮게 맞춘다 (카메라 `orthographicSize 6` → 세로 12유닛, 16:9면 가로 21.3유닛)
5. **Collider 를 붙이지 않는다** — 배경은 부딪히면 안 된다

> 💡 **타일로 반복**하고 싶으면 `Sprite Renderer` 의 `Draw Mode = Tiled` 를 쓴다.
> 이때 스프라이트 임포트 설정에서 `Mesh Type = Full Rect` 여야 한다. 안 그러면 경고가 뜬다.

## 8. 현재 무엇이 임시인가

| 종류 | 파일 | 상태 |
|---|---|---|
| 스프라이트 | `Player_Walk.png` · `Enemy_Walk.png` · `Obstacle.png` · `GroundTile.png` · `Enemy_Base.png` | ⚠️ **코드로 생성한 임시** |
| 스프라이트 | 총알 · 공 · 블록 · 패들 · 벽 | ⚠️ **유니티 기본 흰 Square + 색** |
| 배경 | 전부 | ❌ **없음** (단색 카메라) |
| 사운드 | 전부 | ❌ **없음** |
| 이펙트 | 전부 | ❌ **없음** |
| 폰트 | `Pretendard` | ✅ **정식** (SIL OFL 1.1) |

> 임시 스프라이트의 생성 경위는 [Fonts/README.md](../../Assets/_GameAssets/Fonts/README.md) 와
> [에셋-리소스.md](./에셋-리소스.md) 의 "현재 저장소 상태" 절 참고.
