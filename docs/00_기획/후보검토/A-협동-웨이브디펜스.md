# 후보 A · 2인 협동 웨이브 디펜스 (탑다운 슈터)

> **한 줄**: 아레나 하나에서, 둘이 같이 몰려오는 적을 10웨이브 동안 막아낸다.
> **종합 평가**: ★★★★★ — **1순위 권장안**

## 1. 코어 루프

```
방 만들기 / 코드로 입장
        ↓
  웨이브 시작 (적 10~15마리)
        ↓
   이동 · 사격 · 회피
        ↓
   웨이브 클리어
        ↓
  업그레이드 3택 1  ←── 게임의 심장
        ↓
   (10웨이브 반복)
        ↓
      보스전
        ↓
   클리어 / 전멸
```

**한 판 5~7분.** 짧아야 수업 중에 전체 루프를 몇 번이고 검증할 수 있다.

## 2. 화면 & 조작

| | |
|---|---|
| 시점 | 2D 탑다운 (고정 카메라, 아레나 전체가 한 화면) |
| 이동 | WASD |
| 조준 | 마우스 방향 |
| 사격 | **자동** ← 노베이스 손이 편하고, 코드도 단순 |
| 부활 | 쓰러진 동료 옆에 3초 서 있으면 부활 ← 협동의 핵심 장치 |

> 💡 **고정 카메라를 선택한 이유**: 카메라 추적을 넣으면 2인 플레이에서 "화면 분할이냐, 한쪽만 따라가냐"라는 어려운 문제가 생긴다. 아레나 하나를 통째로 보여주면 이 문제가 사라진다.

## 3. 콘텐츠 규모 (확정값)

| 항목 | 수량 | 비고 |
|---|---|---|
| 플레이어 | 2인 협동 | 같은 캐릭터, 색만 다름 (아트 부담 0) |
| 무기 | 3종 | 직선 / 관통 / 범위 |
| 적 | 3종 + 보스 1 | 돌진형 / 원거리형 / 탱커 |
| 업그레이드 | 6~8개 | 공격력·연사·이동속도·체력·관통·범위 |
| 맵 | **1개** | 단일 아레나. 장애물 몇 개만 배치 |
| 웨이브 | 10 | 마지막이 보스 |
| 동시 적 수 | **최대 15** | 네트워크 부하 상한선 |

## 4. 학생이 배우게 되는 것 (Phase 매핑)

| Phase | 이 게임에서 나오는 형태 |
|---|---|
| 1 · 문법 | 체력(`int`), 속도(`float`), 생존여부(`bool`), 적 목록(`List`) |
| 2 · Unity | 총알 충돌(`OnTriggerEnter2D`), 적 프리팹, 코루틴 스폰 |
| 4 · OOP | `Enemy` → 돌진적/원거리적/탱커 **상속**, `IDamageable` **인터페이스** |
| 5 · 데이터 | 무기·적 스탯을 **ScriptableObject**로 분리 → 코드 안 고치고 밸런싱 |
| 6 · UI | 체력바, 웨이브 표시, 업그레이드 선택창 |
| 7 · 최적화 | 적·총알이 많아지면 끊긴다 → **오브젝트 풀링** (문제를 겪은 뒤 해결) |
| 8 · 네트워크 | 플레이어 2 동기화 + **호스트만 적 스폰** |

> 이 표가 A안의 진짜 강점이다. **교육 항목을 억지로 끼워넣은 데가 한 군데도 없다.**

## 5. 네트워크 설계

| 동기화 대상 | 방식 | 난이도 |
|---|---|---|
| 플레이어 위치·회전 | `NetworkTransform` | 하 |
| 내 캐릭터만 내가 조종 | `IsOwner` 체크 | 하 |
| 체력 · 점수 · 웨이브 번호 | `NetworkVariable` | 중 |
| 적 생성 | **호스트만 스폰** → 자동 복제 | 중 |
| 총알 | 호스트 권한 스폰 (또는 시각효과만 로컬) | 중 |
| 업그레이드 선택 | `Rpc` | 중 |

**총 동기화 대상: 플레이어 2 + 적 최대 15.** 노베이스가 감당 가능한 상한선에서 설계했다.

> 🔑 Phase 4에서 "적 스폰과 체력 계산은 **매니저 한 곳에서만** 한다"를 규칙으로 심어두면, Phase 8에서 그 매니저에 `if (!IsServer) return;` 한 줄을 넣는 것으로 호스트 권한 전환이 끝난다. **코드를 갈아엎지 않는다.**

## 7. 수업 관점 장점

- **기능 하나 = 재미 하나.** 자동사격이 붙는 날, 적이 처음 몰려오는 날, 업그레이드가 처음 뜨는 날 — 매번 체감이 달라진다. 비대면 출석의 연료다.
- **레벨 디자인 공수가 0에 수렴한다.** 맵 하나로 끝. 콘텐츠는 웨이브 구성표(숫자)만 바꾸면 나온다.
- **잘하는 학생을 흡수한다.** "무기 하나 더", "적 하나 더"가 그대로 ⭐도전 과제. 연령·속도 편차가 큰 반에 필수.
- **한 판이 짧다.** 수업 중 "고쳤다 → 5분 돌려본다 → 또 고친다" 사이클이 성립한다.

## 8. 리스크

| 리스크 | 대응 |
|---|---|
| 맵 1개라 후반에 단조로워 보임 | 웨이브별 적 조합·배치 변화 + 보스전으로 마무리. 그래도 부족하면 버퍼 회차에 아레나 1개 추가 |
| 적 수를 학생이 임의로 늘려 렉 발생 | Phase 7 풀링 수업의 **소재로 활용**. 오히려 좋다 |
| 자동사격이라 조작 재미가 얕음 | 회피(대시)를 ⭐도전 과제로. 필수는 아님 |
| "이거 어디서 본 것 같은데" | 맞다. **의도된 것이다.** 검증된 구조라 막힐 때 참고할 레퍼런스가 많다 |
