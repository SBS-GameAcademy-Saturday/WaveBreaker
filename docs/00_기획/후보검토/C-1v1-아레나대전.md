# 후보 C · 1v1 아레나 대전 (탱크 배틀)

> **한 줄**: 아레나에서 탱크 둘이 맞붙는다. 3라운드 선승.
> **종합 평가**: ★★☆☆☆ — **탈락 권장. 매력적으로 보이지만 함정이 있다.**

## 1. 코어 루프

```
방 만들기 / 코드로 입장
        ↓
   라운드 시작
        ↓
  이동 · 조준 · 사격 · 엄폐
        ↓
   상대 격파
        ↓
  (3선승제 반복)
        ↓
      승패
```

**한 판 3~5분.** 가장 짧다.

## 2. 화면 & 조작

| | |
|---|---|
| 시점 | 2D 탑다운 고정 카메라 |
| 이동 | WASD |
| 포탑 조준 | 마우스 |
| 사격 | 클릭 (쿨다운 있음) |
| 아레나 | 엄폐물이 있는 대칭 맵 1개 |

## 3. 콘텐츠 규모 — 가장 작다

| 항목 | 수량 |
|---|---|
| 플레이어 | 2인 대전 |
| 무기 | 2~3종 (필드에서 획득) |
| **적 AI** | **없음** ← 이게 문제다 |
| 맵 | 1개 (대칭) |
| 아이템 | 회복·속도업 등 2~3종 |

## 4. 왜 매력적으로 보이는가

솔직히 말하면 **이게 제일 만들기 쉬워 보인다.**

- 적 AI를 안 만들어도 된다
- 웨이브 관리, 스폰 매니저, 난이도 곡선이 필요 없다
- 승패 조건이 명확하다 (상대 체력 0)
- 발표회 데모 임팩트가 크다 ("친구랑 붙어보세요")

**그래서 후보에 넣었다. 그리고 그래서 위험하다.**

## 5. 🔴 치명적 문제 두 가지

### ① 싱글 완성본이 나오지 않는다

이 커리큘럼의 최대 안전장치는 **Phase 7에서 싱글 완성본을 확정·백업하고, 네트워크는 그 위에 별도로 얹는 것**이다. 네트워크가 끝내 안 되는 학생도 완성작을 갖고 종강하게 만드는 구조다.

**대전 전용 게임은 상대가 없으면 게임이 아니다.**

- Phase 7 시점에 학생 손에 남는 것: "혼자 움직이는 탱크"
- 네트워크가 실패하면 → **7개월간 만든 게 아무것도 아니게 된다**

> 노베이스 반에서 마지막 두 달을 통째로 도박에 거는 셈이다. 이건 받아들일 수 없는 리스크다.

### ② 교육 소재의 절반이 사라진다

적 AI가 없으면 다음이 통째로 날아간다.

| 사라지는 것 | 원래 어디서 배웠나 |
|---|---|
| 상속 (`Enemy` → 하위 적 3종) | Phase 4 OOP의 핵심 |
| 인터페이스 (`IDamageable`) | Phase 4 |
| 스폰 매니저 · 코루틴 | Phase 2, 5 |
| 난이도 곡선 · 웨이브 데이터 | Phase 5 |
| ScriptableObject (적 스탯) | Phase 5 |
| **오브젝트 풀링** (적이 많아야 성립) | Phase 7 |

**Phase 4·5·7의 뼈대가 무너진다.** 남는 건 입력 처리와 네트워크 동기화뿐이고, 그걸로 130회를 채울 수 없다.

## 6. 추가 문제 — 대전은 네트워크 난이도가 오히려 높다

협동은 조금 어긋나도 넘어간다. **대전은 안 넘어간다.**

| 상황 | 협동(A안) | 대전(C안) |
|---|---|---|
| 위치가 0.2초 어긋남 | 티 안 남 | **"내가 먼저 쐈는데 왜 내가 죽어?"** |
| 판정 주체 | 대충 호스트 | 호스트가 유리해짐 (**호스트 어드밴티지**) |
| 필요한 개념 | 서버 권한 | 서버 권한 + 지연 보상 + 클라이언트 예측 |

지연 보상과 클라이언트 예측은 **노베이스에게 가르칠 수 있는 주제가 아니다.** 안 가르치면 학생들이 "이 게임 이상해요"를 계속 겪는다.

## 7. 그 외 리스크

| 리스크 | 설명 |
|---|---|
| 혼자 테스트가 재미없다 | 개인 미션 시간에 확인할 게 별로 없다. 노베이스에게 치명적 |
| 반 인원이 홀수면 짝이 안 맞는다 | 매 수업 짝 매칭을 관리해야 함 |
| 밸런싱이 어렵다 | 대전 밸런스는 협동보다 훨씬 민감하다 |

## 9. 대전을 포기하지 않는 방법

대전 요소 자체가 나쁜 게 아니다. **순서가 문제다.**

> **A안(협동 웨이브 디펜스)을 완성한 뒤, 버퍼 10회에 "2인 대전 모드"를 추가 모드로 얹는다.**

이러면:

- Phase 7 싱글 완성본 안전장치가 그대로 유지된다
- 이미 만든 캐릭터·무기·맵·네트워크를 재사용하므로 **추가 공수가 작다**
- 발표회 데모 임팩트도 챙긴다
- 진도 빠른 학생의 ⭐도전 과제로도 딱 맞는다

**대전은 메인 요리가 아니라 디저트로.**
