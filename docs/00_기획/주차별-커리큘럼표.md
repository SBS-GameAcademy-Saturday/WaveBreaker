# 유니티 커리큘럼 (7개월) — 주차별 제출용

> **구성 방침: C# 선행.** 1~4주차 C# 문법 전용(콘솔), 5~6주차 객체지향, **7주차부터 C# + 유니티 병행.**
> **회차 환산**: 주 5일 × 2시간 = 주당 5회 10시간. N주차 = (5N-4) ~ 5N회차. 총 28주 140회.
> **최종 산출물**: **웨이브 브레이커** — 타이틀에서 [혼자 하기] / [같이 하기] 를 모두 지원하는 **2D 로그라이크 서바이버(뱀서라이크)**
> 게임 사양은 [확정-게임기획서.md](./확정-게임기획서.md), 회차 설계는 [01_Phase개요/](../01_Phase개요/)

## 📌 실제 프로젝트와 맞춘 사항 (2026-09-02)

`WaveBreaker` 저장소의 실제 Unity 프로젝트를 확인해 아래를 반영했다.

| 항목 | 값 | 커리큘럼 반영 |
|---|---|---|
| Unity 버전 | **6000.5.4f1** | 확정. 문서 전체 이 버전 기준 |
| 렌더 파이프라인 | **URP 17.5.0** (Unity 6 2D 템플릿 기본값) | URP 기능은 가르치지 않는다. 9주차에 **Sorting Layer / Order in Layer** 한 가지만 짚는다 |
| Input System | 설치됨 (1.19.0) / **Active Input Handling = Both** | 수업은 구 `Input.GetAxisRaw`로 진행. Input System은 27주차 도전 과제 |
| 폴더 구조 | `_GameAssets` / `_Project` 생성 완료 | 그대로 사용 |
| 연습 폴더 | `_Project/Scripts/Practice` | 7~13주차 연습 스크립트 보관용 |

### 장르 변경 반영 (웨이브 디펜스 → 로그라이크)

| 항목 | 이전 | **현재** | 영향 주차 |
|---|---|---|---|
| 적 스폰 | 웨이브 단위 + 휴식 | **지속 스폰**, 시간 경과로 강화 | 15주차 |
| 맵 | 고정 아레나 1개 | **무한 맵** (타일 순환) | 14주차 |
| 성장 | 웨이브 클리어 시 3택 | **경험치 젬 → 레벨업 3택** | 17주차 |
| 무기 | 3종 중 선택 | **근접·원거리 동시 보유**, 레벨업으로 강화 | 16주차 |
| 승리 | 10웨이브 + 보스 | **10분 생존 + 최종 보스** (보스 3회) | 18주차 |
| 카메라 | 고정 | **추적 + 협동 시 2인 대응** | 14 · 24 · 25주차 |

> ⚠️ **무한 맵을 택한 대가로 협동 카메라 설계가 필요해졌다.** 이전 고정 카메라 안에서는 없던 작업이라
> 24~25주차에 별도 편성했다. Phase 9는 참고 강좌 범위 밖이므로 **강사 레퍼런스 준비 부담이 가장 큰 구간**이다.

### 축소 순서 (진도가 밀릴 때)

1. 보스 II·III (3분 보스만 남김)

### 레퍼런스 커리큘럼과의 차이

제외: 구조체(struct), 템플릿(제네릭) 클래스, 연산자 오버로딩 — 제작할 게임에서 사용처가 없고 노베이스 대상 추상도가 높다. 필요 시 4주차 또는 27주차에 편성 가능.
포함: property, static, switch, enum, 인터페이스, 다형성, Visual Studio 디버깅.
