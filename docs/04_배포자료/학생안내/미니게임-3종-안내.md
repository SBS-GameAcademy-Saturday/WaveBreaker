## 세 개가 뭔가요

### ① 낙하 지대 (피하기) — 055 · 056 · 057회차

**붕괴 중인 전초기지.** 천장이 무너집니다. 무기는 없고, 피하는 것만 할 수 있어요.

| | |
|---|---|
| **조작** | `A` `D` (좌우) |
| **목표** | 오래 버티기 — 버틴 시간이 점수 |
| **끝** | 낙하물 세 번 맞으면 게임오버 → `R` 로 다시 |

### ② 방벽 붕괴 (벽돌깨기) — 058 ~ 062회차

**적이 방벽을 쌓았습니다.** 반사 드론을 튕겨 뚫습니다. 드론은 세 대뿐이에요.

| | |
|---|---|
| **조작** | `A` `D` (패들 좌우) |
| **목표** | 블록 50개 전부 깨면 클리어 |
| **끝** | 드론 세 번 놓치면 게임오버 → `R` 로 다시 |

### ③ 웨이브 브레이커: 프롤로그 (생존 슈팅) — 063 · 064 · 065회차 ⭐

**여기가 본편입니다.** 1회차에 보여드린 그 게임의 축소판이에요.
사방에서 적이 몰려오고, 총은 **알아서** 나갑니다. 여러분은 움직이기만 합니다.

| | |
|---|---|
| **조작** | `W` `A` `S` `D` (전방향) — 발사는 자동 |
| **목표** | 오래 버티기 — 시간이 지날수록 적이 더 자주 나옴 (**웨이브**) |
| **끝** | 적에게 다섯 번 닿으면 게임오버 → `R` 로 다시 |

> ⭐ **셋 중 ③번이 제일 중요합니다.** 14주차부터 만들 본 프로젝트가 여기서 이어져요.
> 시간이 부족하면 ①②는 넘어가도 되지만 **③은 꼭 완주하세요.**

## 개조 시간 — 이게 진짜 과제입니다

057회차와 062회차에는 **각자 게임을 하나 이상 바꾸는** 시간이 있습니다.

> **뭘 바꿔도 됩니다.** 크게 안 해도 돼요. 숫자 하나만 바꿔도 개조입니다.

### 막히면 이 중에서 고르세요

**① 피하기 개조 예시**

1. 장애물이 점점 빨라진다 *(쉬움)*
2. 장애물 색·크기가 랜덤 *(쉬움)*
3. 회복 아이템이 떨어진다 *(보통)*
4. 10초마다 장애물이 두 배로 *(보통)*
5. 맞고 1초는 무적 *(어려움)*

**② 벽돌깨기 개조 예시**

1. 블록 모양을 바꾼다 (삼각형·구멍) *(쉬움)*
2. 패들 크기를 바꾼다 *(쉬움)*
3. 공이 점점 빨라진다 *(쉬움)*
4. 패들 어디에 맞았는지로 반사 각도가 바뀐다 *(보통)*
5. 튼튼한 블록 — 두 번 맞아야 깨짐 *(보통)*
6. 아이템이 떨어진다 — 먹으면 패들이 커진다 *(어려움)*
7. 스테이지 2 *(어려움)*

> 🎯 **시연할 때 "제가 ○○를 ○○해서 바꿨습니다" 한 문장**을 말해야 합니다.
> 그게 오늘의 진짜 과제예요. 미리 한 줄 적어두세요.

## 자주 막히는 곳 — 먼저 여기를 보세요

### 글자가 안 보이거나 깨져요

**TMP Essentials** 를 임포트하지 않았습니다. TMP 오브젝트를 처음 만들면 창이 뜨는데,
거기서 **`Import TMP Essentials`** 를 누르세요. 한 번만 하면 됩니다.

한글이 빈칸으로 나오면 **한글 폰트**를 지정해야 합니다 (강사가 안내).

### 씬을 못 연다는 에러가 나요

```
Scene 'xxx' couldn't be loaded because it has not been added to the Build Settings
```

`File → Build Profiles`(또는 `Build Settings`) → **`Add Open Scenes`** 를 누르세요.
`R` 키 재시작을 쓰려면 그 씬이 빌드 목록에 있어야 합니다.

### 재시작했는데 화면이 멈춰 있어요

`Time.timeScale` 을 `0` 으로 만든 채 씬을 다시 열었습니다.
**`LoadScene` 앞에서 `Time.timeScale = 1f;`** 를 먼저 하세요.

### 목숨이 순식간에 0이 돼요

공이 없어진 동안 `Update` 가 **매 프레임** 목숨을 깎고 있습니다.
`isRespawning` 같은 **표시(bool)** 로 한 번만 실행되게 막으세요.

### 유니티가 통째로 멈췄어요

`while` 안에 **`yield` 가 없습니다.** 무한 루프예요.

- 작업 관리자에서 Unity 강제 종료
- **저장 안 한 씬은 날아갑니다** → 그래서 **Play 전에 `Ctrl+S`**

### 공이 벽에 붙어서 안 튀어요

**Physics Material 2D** 가 없거나 `Bounciness` 가 `0` 입니다.
`Bounciness = 1`, `Friction = 0` 으로 만들어 **Collider 의 `Material` 칸**에 넣으세요.
(Rigidbody 가 아니라 **Collider** 에 있습니다)

### 총알이 엉뚱한 데로 가요

`Instantiate` 한 다음 **`bullet.transform.up = dir;`** 을 안 했습니다.

### 적이 반대로 도망가요

방향 계산 순서가 반대입니다. **`목표 위치 - 내 위치`** 입니다.

### 에러가 났는데 뭔지 모르겠어요

**Console 에 적힌 내용을 소리 내어 읽어보세요.** 대부분 답이 그 안에 있습니다.
빨간 줄을 **더블클릭하면 문제가 난 코드 줄로 이동**합니다.

그래도 모르겠으면 **에러 메시지를 그대로 복사해서** 질문하세요.
"안 돼요" 보다 훨씬 빨리 해결됩니다.
